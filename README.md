# Suen System

Suen 的长期规则、内容系统、择时规范与自动化配置总仓库。

## 这个仓库负责什么

- 保存长期稳定规则的**当前正式版本**
- 保存每次重要规则调整的版本记录
- 为 ChatGPT / Slack / 自动化提供统一规则真源
- 避免同一规则散落在不同对话、Slack 消息和旧提示词中

## 不放什么

- 客户姓名、联系方式、付款信息等隐私数据
- 密码、API Key、Token、恢复码等密钥
- 每日临时聊天记录
- 大体积 PDF、图片、视频成品（这些继续放 Drive / Library 等文件系统）

## 系统分工

- **GitHub**：长期规则、模板、自动化配置、版本记录
- **Slack**：当日执行、商业状态、客户阶段、天象预约池、内容数据
- **Drive / Library**：课程、PDF、图片、视频、HTML 等成品文件
- **ChatGPT**：读取规则、执行分析、跨系统整理与更新

## 目录

- `00-系统总控/`：系统架构与商业总控
- `01-抖音大号/`：Hesuen Sol 各固定栏目规则
- `02-小红书/`：长卷规则
- `03-公众号/`：阿赫特之门规则
- `04-朋友圈/`：朋友圈文笔与发布规则
- `05-择时与仪式/`：古典魔法择时、PGM/PDM、星符规则
- `06-自动化/`：每日自动化与任务提示词
- `99-模板/`：Slack 记录、预约池等固定模板

## 版本原则

1. 同一主题只保留一个“当前正式规则”文件。
2. 旧规则不继续散落复制；重大变化写入 `CHANGELOG.md`。
3. 从 Slack / ChatGPT 迁移旧规则时，必须先核对是否仍为最新版。
4. GitHub 中的正式文件一旦标记为“已迁移”，后续优先以该文件为长期规则真源。
