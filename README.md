# Suen System

Suen 的长期规则、内容系统、择时规范、研究方法、课程制作与自动化配置总仓库。

**当前状态：2026-09-17 第一轮全量规则迁移已完成，进入持续维护。**

## 这个仓库负责什么

- 保存长期稳定规则的**当前正式版本**
- 保存重要规则调整的版本记录
- 为 ChatGPT / Slack / Automations 提供统一规则真源
- 避免同一规则散落在不同对话、Slack 消息、旧提示词和历史文件中

## 不放什么

- 客户姓名、联系方式、付款信息、完整聊天原文等隐私数据
- 密码、API Key、Token、恢复码等密钥
- 每日临时聊天记录
- 每日播放/点赞/预约人数等动态经营数据
- 大体积 PDF、图片、视频、HTML 成品

## 系统分工

- **GitHub**：长期规则、模板、自动化业务要求、版本记录
- **Slack**：当日执行、内容复盘、商业状态、询盘/成交、天象经营状态
- **Drive / Library**：课程母本、研究资料、PDF、图片、视频、HTML、品牌母版
- **Automations**：实际定时执行层；是否启用以实时状态为准
- **ChatGPT**：读取规则、分析、研究、跨系统整理与更新

详细结构见 `00-系统总控/系统架构.md`。

## 版本原则

1. 同一主题只保留一个当前正式规则文件；模板与索引可以引用它，但不另造第二套规则。
2. 新规则明确覆盖旧规则时，更新正式文件并记录到 `CHANGELOG.md`。
3. 从 Slack、专用对话或 Library 迁移内容时，先判断新旧版本和适用范围。
4. 动态数据留在业务系统；GitHub 只保留长期规则。
5. GitHub 文件成为长期规则真源后，后续用户新的明确指令仍然可以覆盖并更新它。
