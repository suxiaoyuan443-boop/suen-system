# 神秘学资料鉴别与研究规则

状态：当前正式规则
最后核对：2026-09-17
依据：《神秘学研究与资料鉴别指南》内容母稿 V8

## 核心原则

不要先问“这个说法听起来像不像真的”，先把它拆成可以核查的问题。

## 四个起始问题

1. 它声称自己属于哪个时期、地区或传统？
2. 这种说法如果真实，应该留下什么类型的一手证据：纸草、泥板、手稿、文物、报刊、访谈还是现代出版物？
3. 能否找到稳定标识：馆藏号、纸草号、手稿 shelfmark、folio、泥板号、DOI、ISBN、TM ID 等？
4. 现代说法是否忠实保留了原资料的范围，还是把“可能/局部/后世改写”扩大成“确定/完整/古代原样”？

## 最短研究链

传统与年代 → 稳定编号 → 原始对象/原始文本 → 校勘版/学术解释 → 比较现代说法增加了什么 → 只下证据允许的结论。

## 查到什么才算成功

只打开数据库首页或只看到搜索结果标题不算完成。

一个“跟我查一次”的完整路线至少要让读者知道：

1. 从哪个页面进入
2. 点哪里
3. 输入什么
4. 搜对后应该看到什么
5. 下一步点哪里
6. 页面打不开时如何替代
7. 最后可以说到什么程度

应尽量落到可复核字段，例如 object number、shelfmark、papyrus number、tablet number、行号、年代、语言、作者与出版信息。

## 不同传统不要混

检索前先分清历史对象。例如：

- Heka ≠ PGM
- PGM ≠ “纯古埃及魔法”
- Jewish magic ≠ Kabbalah
- Folk magic ≠ Wicca
- Goetia ≠ 所有所罗门魔法
- Grimoire ≠ 古代魔法书
- Astrology ≠ Planetary Magic

跨传统影响可以讨论，但需要给出文本、人员、翻译、出版或明确接受史链条。

## 现代拼合

一个现代仪式可能把多个真实历史元素拼在一起。每个元素有历史来源，不代表完整组合本身就是古代原仪式。

核查时逐项标年代、来源和最早可追溯证据，再判断完整组合是连续传统、后世吸收、现代重构还是目前无法确认。

## “没找到”怎么写

找不到资料不能直接证明“绝对不存在”。更准确的写法是：

“在当前可查的主要资料与研究范围内未找到支持。”

并写明检索范围、数据库/出版物与核查日期。

## PGM / 手稿 / 图片的最低引用

- PGM / PDM：尽量给具体编号 + 行号 + 实际纸草/版本
- 中世纪手稿：馆藏机构 + shelfmark + folio + 版本
- 文物：馆藏机构 + accession/object number + 年代
- 图片：优先追原图，不把 Pinterest、博客或现代重绘当最终出处
- 论文：题名、作者、年份、期刊/出版社、DOI 等应互相对得上

## 结论强度

结论范围必须与证据范围一样大。只能证明其中两步，就只确认两步，不写“完整仪式已被证实”。
