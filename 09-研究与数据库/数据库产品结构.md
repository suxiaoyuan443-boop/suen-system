# Suen Akhet｜数据库产品结构

状态：当前暂定产品方案
最后核对：2026-09-17

## 核心载体

- 内容维护：Obsidian
- 对外访问：Obsidian Publish
- 需要正式首页 / 导航首页

## 销售方式

数据库支持两种购买方式：

1. **单独购买数据库**
2. **《古埃及魔法实践》课程 + 数据库打包**

课程与数据库互补，但不强制数据库只能依附课程销售。

## 访问模式

当前暂定为 **订阅制**。

尚未定案：

- 月付 / 季付 / 年付
- 首购价格
- 续费价格
- 课程学员是否包含一定期限数据库访问
- 打包用户订阅权益
- 取消订阅后的访问规则
- 数据库更新频率承诺

这些没有定案前，不在销售页面自行承诺永久更新或永久访问。

## 首页必须解决的问题

数据库首页不是装饰页，至少需要让购买者快速完成：

- 知道数据库包含什么
- 知道从哪里开始
- 按神明查
- 按仪式目的查
- 按文本 / 文物查
- 按历史时期查
- 找到现代实践入口
- 找到“怎么判断资料真假”的方法页
- 回到课程对应章节（适用时）

## 推荐首页一级入口

最终命名可调整，但信息架构至少覆盖：

- 神明
- 历史时间线
- 神话与宗教背景
- 文物 / 原典 / 纸草
- 仪式与魔法实践
- 供奉与神庙实践
- 现代实践
- 资料鉴别 / 研究工具
- 课程配套索引
- 更新记录

## 课程与数据库的边界

### 课程卖什么

- 学习路径
- 历史框架
- 机制
- 讲解
- 案例推理
- 仪式复原能力
- 资料鉴别能力

### 数据库卖什么

- 长期可查询资料库
- 神明资料
- 原文与译读
- 仪式条目
- 文物与来源索引
- 现代实践说明
- 后续持续扩充内容

数据库不能只是“课程讲义复制过去”。

## 当前产品原则

- 单独买数据库的人，也应该能独立使用数据库。
- 课程学员进入数据库后，应能明显感觉到课程和数据库互相补充，而不是重复购买同一份内容。
- 数据库持续更新是订阅价值的重要来源，但具体更新承诺频率尚未写死。
