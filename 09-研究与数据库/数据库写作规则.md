# 当前已经确认、可以继续使用的基础规则

## 数据库的核心任务

数据库不是“神秘学营销百科”，也不是神明关键词卡片。

每个页面都要真正解决一个查询问题：

- 这个对象是什么；
- 来自什么历史环境；
- 现存证据是什么；
- 古人实际怎么使用 / 怎么理解；
- 现代实践可以做到什么程度；
- 哪些部分是复原，哪些是现代新增；
- 读者接下来去哪里核查原始资料。

读完一页以后，不能只留下“某神掌管爱情 / 某仪式用来保护”这种空结论。

## 总体文笔

### 1. 正文默认不出现作者第一人称

不用：

- 我认为
- 我查到
- 我觉得
- 我们可以看到
- 今天来讲

优先采用对象本身作为句子主体，例如：

- “现存材料中可以看到……”
- “这件文物的铭文写明……”
- “在该版本中，这一段位于……”

### 2. 禁止明显 AI 开头

避免：

- 你有没有想过
- 很多人不知道
- 你绝对想不到
- 在神秘学的世界里
- 自古以来
- 今天让我们一起探索

直接进入具体对象、文本、问题或历史事实。

### 3. 禁止连续反驳模板

尤其避免整段连续使用：

- 不能
- 并不
- 不等于
- 不是……而是……

需要纠正误解时，先把正确内容自然讲清楚；只有真的需要对比时再使用反驳句。

### 4. 不一句一段

数据库不是短视频字幕。以完整自然段承载一个完整信息单元。每一段至少推进一个新的事实、材料、动作、版本问题或解释。

### 5. 不写看完等于没看的长文

长页面必须持续增加新原文、新文物、新案例、新动作、新材料、新版本信息、新比较或新解释。

### 6. 专业感来自具体性

优先写对象名称、年代、地点、馆藏号/手稿号/纸草号、行号/folio、材料、动作、原文、译文、版本与学术解释。

### 7. 术语第一次出现必须解释

第一次出现时说明原文/原词、转写、基本含义，以及在当前语境里为什么重要。

# 当前已经确认的证据分层

页面至少区分：

1. 可直接确认的历史事实
2. 原始文本 / 文物所表达的古代观念
3. 学术解释 / Scholarly Reconstruction
4. 学界存在争议的解释
5. 后世接受与改写
6. Modern Adaptation / 现代改编
7. Modern Synthesis / 现代综合
8. Unclear / 暂无法判断

如果证据只支持“可能 / 局部 / 某一时期”，不能扩大成“古埃及人一直都这样做”。

## 结论状态

研究与写入过程中，必要时使用：

- Confirmed / 可确认
- Probable / 很可能、证据倾向支持
- Disputed / 存在争议
- Unverified / 尚未核实
- Unsupported / 目前缺乏可靠依据
- False / 与可确认材料冲突

`Unsupported` 不等于 `False`，不能随意都翻成“假的”。

# 当前已恢复的稳定标识要求

涉及资料时，按对象类型尽量记录并使用稳定标识：

- accession / object number
- papyrus number
- tablet number
- TM ID
- shelfmark
- folio
- siglum
- DOI
- ISBN

涉及手稿/文本研究时，按需要继续记录：

- witness
- recension
- critical edition
- facsimile
- transcription
- transliteration
- translation
- lacuna
- restoration
- interpolation
- incipit
- explicit
- colophon
- editio princeps

数据库不能只存“一个网页链接”；要尽量让对象离开网页后仍可以通过稳定编号重新定位。

# 仪式页｜当前仅为基础框架，最新版细化规则尚未恢复

> **警告：本节明确不是 Suen 前两天细化后的完整仪式模板。** 在最新专用规则恢复前，禁止把以下 8 项当作完整验收标准。

当前已确认至少涉及：

1. 基本信息：名称、来源、编号/行号/folio、年代、语言、文本传统、目的
2. 使用情境：谁使用、为谁使用、什么环境、什么问题触发
3. 原文与译文：原文/转写、working translation、中文译文、逐段讲读
4. 材料：原文材料、现代对应、版本问题、材料在仪式里的作用
5. 动作：按原文顺序还原准备、制作、触碰/涂抹/书写/佩戴/放置、诵读、埋藏/焚烧/沉水/保存等
6. 时间与空间：日期、月相、时段、行星要求、方位、房间/神庙/户外环境——只在原文确有要求时写
7. 因果机制：材料、动作、名字、图像、话语之间的关系
8. 现代执行：哪些可以复原、哪些需要替代、哪些因安全/法律/环境调整、哪些是现代新增

## 当前可以确定还必须增加的研究层

### A. 仪式逐元素来源表

不得只给整个仪式一个“来源”。要拆到元素级：

- 材料
- 动作
- 言词
- 时间
- 图像
- 名字
- 方位
- 收束方式

每个元素记录：

- 来源
- 年代
- 是否与其他元素在同一历史对象/文本中共同出现

最后必须能判断完整流程属于：

- 历史原式
- 学术复原
- 现代改编
- 现代综合
- 无法判断

### B. 现代拼合检查

如果步骤 A 来自 PGM IV、步骤 B 来自 PGM VII、步骤 C 来自现代 correspondence、步骤 D 来自 Golden Dawn，就只能诚实标注为现代综合，不能称为“PGM 原始完整仪式”。

### C. 证据边界

每个仪式页应能够回答：

- 我能直接证明什么？
- 我不能证明什么？
- 证据强度是什么？
- 结论状态是什么？
- 最容易被误读的地方是什么？
- 发布/对外表达时最多可以说到什么程度？

# 检索与写入过程｜目前已恢复的硬规则

## 搜索日志

重要条目应保留：

- 日期
- 问题
- 第一轮关键词
- 结果
- 第二轮关键词
- 加入的编号 / 地点 / 作者
- 找到的核心来源
- 尚未解决的问题
- 下一步

## 数据库实操验收

“打开数据库首页”不算完成检索。

至少要拿到：

- 稳定编号
- 具体对象 / 文本
- 年代 / 语言 / 馆藏字段
- 下一层原文、扫描、校勘版或文献入口

## 图片 / 页面证据

如果数据库页面使用截图或图片做检索教程/证据展示，应记录：

- 来源机构
- 页面链接
- 截图/核查日期
- object number / 稳定编号
- copyright / licence statement
- 是否允许商业使用
- attribution 要求

实际教程不能只说“去某数据库搜”。需要在可行时给真实操作路径：输入什么、搜对后看到什么、下一步点哪里、它能证明什么、不能证明什么、页面失效时的备用路线。

# 来源要求

优先级：

1. 原始对象 / 原始文本
2. 权威馆藏或数据库
3. 学术项目
4. critical edition / 校勘版
5. 同行评议论文
6. 可靠学术出版物
7. 二手资料仅用于发现线索

关键历史断言不能只依赖博客、Pinterest、营销网站或无来源社交媒体内容。

## “没有找到”的表达

没有找到支持材料时，不直接写“绝对不存在”。

优先写：

> 在当前可查的主要资料与研究范围内，尚未找到支持这一说法的材料。

并记录核查过的数据库、关键词、编号、出版物和核查日期。
