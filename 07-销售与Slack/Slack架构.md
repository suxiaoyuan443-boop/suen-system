# Slack｜当前工作区架构

状态：当前正式规则
最后核对：2026-09-17

## 1. #内容历史台账

用途：记录各平台实际已经发布的内容与复盘数据。

2026-09-16 以前包含旧商业总控历史混合记录；此后只新增内容表现事实，不再记录商业决策、客户沟通与天象安排。

完整规则见 `00-系统总控/内容历史台账规则.md`。

## 2. #商业决策总控

用途：读取内容台账与天象经营状态，判断当前瓶颈，统筹：

- 每日内容任务
- 商业信号
- 询盘
- 报价
- 成交
- 产品推进

不作为日常播放/点赞数据库。

每天“更新”完成后，简短的“今日更新总表”写入这里，作为下一次总控判断的经营上下文。

完整规则见 `00-系统总控/商业总控.md`。

## 3. #天象检索与预约

用途：只保存已经筛选过的天象经营状态。

不做完整星盘分析，不粘贴 Bonatti 全检查、原典长文和完整择时推导。

完整规则见 `05-天象经营/Slack天象预约池规则.md`。

## 每日数据流

中午：

`Suen 说“总结” → 补齐各平台事实数据 → 写入 #内容历史台账`

随后：

`Suen 说“更新” → 读取 #内容历史台账 + #商业决策总控 + #天象检索与预约 → 诊断瓶颈 → 生成今日总控 → 写入 #商业决策总控 → 给实际需要执行的专用对话提示词`

完整工作流见 `00-系统总控/每日总结与更新工作流.md`。
