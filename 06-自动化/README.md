# 自动化

状态：当前正式索引
最后核对：2026-09-17

本目录分开保存两类信息：

1. **业务规则**：自动化如果运行，必须遵守什么；
2. **实际状态**：连接器里当前任务究竟启用还是停用、保存的提示词是否过期。

不要把“GitHub 里有规则”理解成“自动化已经启用”。

## 文件

- `自动化状态.md`：2026-09-17 实际连接器核查结果
- `上海省钱情报局.md`：省钱号最新事实核查与成品要求
- `Hesuen大号.md`：大号自动化最新调度与内容要求

## 版本原则

旧自动化提示词如果早于最新专用规则，只作为历史配置。重新启用前必须先按 GitHub 当前正式规则复核/重建，不能直接打开旧任务继续跑。

自动化规则修改时，不覆盖与本次修改无关的有效要求；重大变更写入根目录 `CHANGELOG.md`。
