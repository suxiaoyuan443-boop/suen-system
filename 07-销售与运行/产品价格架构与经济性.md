# Suen｜产品价格架构与经济性

状态：当前正式规则  
建立：2026-09-27
最后核对：2026-10-14

本文件负责从商业经营角度判断：
- 一个产品在整个价格体系里承担什么角色；
- 当前价格与工时 / 直接成本是否基本匹配；
- 哪些产品适合承担首次付款、标准执行、高客单定制或预约型高价值角色。

本文件不擅自改价。正式价格仍以 Suen 最新明确确认和 `08-动态运行/商业/当前商业状态.md` 为准。

2026-10-08 Suen 明确：每个仪式、每个具体物品价格不同；先确定具体项目再核价，不设一个抽象“完整定制”统一售价。常规单材料包装快递合计口述估计≤¥30，适用项目待定位；已有特殊材料成本不因此覆盖。

---

## 一、判断维度

每个产品优先看：

1. 当前真实售价；
2. 直接材料 / 外采成本；
3. 实际工时；
4. 标准化程度；
5. 是否需要重新判断 / 重新设计；
6. 是否占用稀缺时间窗口；
7. 是否具有明显案例 / 品牌 / 专业展示价值；
8. 是否适合规模化或天然低容量。

产品比较统一包含沟通、判断/研究、择时、制作/执行、视频、包装寄送和售后；制作1小时、咨询30min与完整交付4—5小时不是可直接排序的同口径数据。沿用现有已知参数，缺项补核，不能由最高售价预定核心利润。

有限知识产品另按 `有限知识产品验证规则v1.md` 核对初次制作与每位新增支持/维护投入，不把可复制写成零工时。

## 二、当前价格层级

### A｜低风险首次付款 / 轻咨询层

当前主要覆盖：
- 通灵 / 传讯；
- 查事；
- 月运；
- 基础塔罗 / 二择一 / 三择一；
- 部分低价护符 / 祈愿。

商业作用：
- 低风险首次付款；
- 老客加购；
- 快速问题判断；
- 现金流补充。

不要求全部升级高客单。

### B｜标准咨询 / 标准产品层

当前主要覆盖：
- 30min 塔罗咨询；
- 季度运势；
- 蜂蜜罐；
- 道家符；
- 羊皮纸星符；
- 铜制星符；
- 固定流程的感情 / 复合仪式。

商业作用：
- 客户已经比较清楚自己购买什么；
- 适合明码标价；
- 不需要完整高客单销售流程才能成交。

### C｜高时耗专业服务层

当前明确包括：
- Ars Paulina 24小时天使召唤：¥528 / 次，约2—3小时；
- 水晶召灵之术：¥528 / 次，约2—3小时。

当前粗略毛收入 / 工时：
完整经济性待结合实际工时、成本和经营支出在获授权私有位置核对。

经营判断：
- 专业时耗明显高于普通咨询；
- 当前价格经济性偏紧；
- 在价格重新验证前，不作为最优先放量产品；
- 后续需要判断其品牌 / 案例价值是否足以弥补较低的直接时间收益。

本条不自动改价。

### D｜高价值个别方案层（逐项目报价）

当前目标：
- 适合的具体高价值项目可验证四位数客单，不能推出所有仪式 / 物品同价；
- 完整交付口述约3—4或4—5小时，当前按3—5小时比较；
- 有实物时包邮，快递费含报价，内部仍扣真实寄送成本；
- 舒适承载约4个 / 月。

定义：
- 从现实问题出发；
- 需要重新判断适配；
- 可能重新选择体系、材料、择时和执行结构；
- 不是从固定菜单中直接选一个已有流程。

商业作用：
- 高贡献潜力，须由具体报价、完整成本与真实订单验证；
- 低容量；
- 需要机会漏斗与正式报价；
- 更依赖真实执行证据和案例资产。

### E｜高成本手工星符层

当前新方向：
- 银制行星星符；
- 预计直接材料成本约 〔内部金额略〕 / 件；
- 计划 Suen 手工编织吊坠绳；
- 完整工时尚未取得。

经营判断：
- 与当前铜制 ¥500 / 羊皮纸 ¥300 星符属于不同产品等级；
- 正式售价必须在真实制作后结合总工时、损耗与直接成本确定；
- 未确认价格前不进入公开价目表；
- 当前为待验证产品，资金、需求、经济性与恢复授权统一回产品矩阵第三节，不预定下一项核心利润。

## 四、价格架构原则

### 1. 低价产品不因高客单目标被全部取消

只要：
- 实际交付轻；
- 能形成首次付款；
- 有复购 / 加购价值；
- 不明显拖累时间；

可以继续存在。

### 2. 工时高但价格低的项目优先审计

尤其关注：
- 2—3小时以上；
- 大量前期研究；
- 稀缺时间窗口；
- 需要复杂准备；
- 售价却与普通咨询接近。

这类产品比“¥20一问是否太低”更值得优先处理。

### 3. 高客单必须有清晰产品差异

四位数定制不能只是把固定 ¥688 仪式改名涨价。

必须在真实服务上存在差异：
- 重新判断；
- 重新选方案；
- 定制准备；
- 择时；
- 材料 / 执行调整；
- 更完整的服务流程。

### 4. 高成本实物不能只按材料加价

银制星符以后定价至少覆盖：
- 材料；
- 损耗；
- 排版 / 制作；
- 手工编绳；
- 择时 / 执行；
- 包装；
- 有限产能；
- 合理利润。

## 五、经济性核对与当前经营优先级

当日资源顺序读取 `00-系统总控/商业目标与产品优先级.md`、`产品矩阵与主推优先级.md` 与最新商业状态；本节只给经济性核对动作，不另设一套主推顺序。现金安全、已付款履约及实际可售条件先核。

1. 有真实适配需求时，核对该具体高价值项目的现价、范围、成本和可售条件，再观察报价 / 成交；不在无客户需求时优先开发抽象定制；
2. 纯银星符暂停状态按动态真源执行，恢复须同时通过产品矩阵中的需求、经济性、资金和授权条件；真实制作后再补完整工时与总成本，本条不构成打样 / 采购任务；
3. Ars Paulina / 水晶召灵继续记录真实订单工时，判断是否需要调价或降低主推频率；
4. 固定感情/复合项目保留现价，实际工时、成本与售后在真实订单中核对；价格调整仍由Suen确认；
5. 铜制星符核对完整经济性，观察真实成交与复购。

不为了“价格体系看起来整齐”一次性全线涨价。

## 六、完整经济性与重复交付

成本同时检查固定支出和随订单变化的支出；盈亏与现金按 `00-系统总控/商业指标口径.md` 区分。每单除执行外，核对沟通、研究、采购、包装、寄送、返工与回访时间，未知写缺项。方法、询问信息、采购和完成通知允许标准化，个别适配判断继续对应真实客户。

高客单不要求每单从零研究，不用增加无必要工时证明价值；价格要覆盖完整交付、有限产能与实际经营支出，最终仍由 Suen 确认。
