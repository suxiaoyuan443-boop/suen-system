# Suen｜产品价格架构与经济性

状态：当前正式规则  
建立：2026-09-27

本文件负责从商业经营角度判断：
- 一个产品在整个价格体系里承担什么角色；
- 当前价格与工时 / 直接成本是否基本匹配；
- 哪些产品适合承担首次付款、标准执行、高客单定制或预约型高价值角色。

本文件不擅自改价。正式价格仍以 Suen 最新明确确认和 `08-动态运行/商业/当前商业状态.md` 为准。

2026-10-08 Suen 明确：每个仪式、每个具体物品价格不同；先确定具体项目再核价，不设一个抽象“完整定制”统一售价。常规单材料包装快递合计口述估计≤¥30，适用项目待定位；已有特殊材料成本不因此覆盖。

---

## 一、判断维度

每个产品优先看：

1. 当前真实售价；
2. 直接材料 / 外采成本；
3. 实际工时；
4. 标准化程度；
5. 是否需要重新判断 / 重新设计；
6. 是否占用稀缺时间窗口；
7. 是否具有明显案例 / 品牌 / 专业展示价值；
8. 是否适合规模化或天然低容量。

不只看“卖多少钱”。

商业作用：
- 客户已经比较清楚自己购买什么；
- 适合明码标价；
- 不需要完整高客单销售流程才能成交。

### C｜高时耗专业服务层

当前明确包括：
- Ars Paulina 24小时天使召唤：¥528 / 次，约2—3小时；
- 水晶召灵之术：¥528 / 次，约2—3小时。

当前粗略毛收入 / 工时：
- 约 ¥176—264 / 小时，尚未扣其它成本。

经营判断：
- 专业时耗明显高于普通咨询；
- 当前价格经济性偏紧；
- 在价格重新验证前，不作为最优先放量产品；
- 后续需要判断其品牌 / 案例价值是否足以弥补较低的直接时间收益。

本条不自动改价。

### D｜高价值个别方案层（逐项目报价）

当前目标：
- 适合的具体高价值项目可验证四位数客单，不能推出所有仪式 / 物品同价；
- 完整交付口述约3—4或4—5小时，当前按3—5小时比较；
- 有实物时包邮，快递费含报价，内部仍扣真实寄送成本；
- 舒适承载约4个 / 月。

定义：
- 从现实问题出发；
- 需要重新判断适配；
- 可能重新选择体系、材料、择时和执行结构；
- 不是从固定菜单中直接选一个已有流程。

商业作用：
- 核心高利润；
- 低容量；
- 需要机会漏斗与正式报价；
- 更依赖真实执行证据和案例资产。

### E｜高成本手工星符层

当前新方向：
- 银制行星星符；
- 预计直接材料成本约 ¥600 / 件；
- 计划 Suen 手工编织吊坠绳；
- 完整工时尚未取得。

经营判断：
- 与当前铜制 ¥500 / 羊皮纸 ¥300 星符属于不同产品等级；
- 正式售价必须在真实制作后结合总工时、损耗与直接成本确定；
- 未确认价格前不进入公开价目表。

## 四、价格架构原则

### 1. 低价产品不因高客单目标被全部取消

只要：
- 实际交付轻；
- 能形成首次付款；
- 有复购 / 加购价值；
- 不明显拖累时间；

可以继续存在。

### 2. 工时高但价格低的项目优先审计

尤其关注：
- 2—3小时以上；
- 大量前期研究；
- 稀缺时间窗口；
- 需要复杂准备；
- 售价却与普通咨询接近。

这类产品比“¥20一问是否太低”更值得优先处理。

### 3. 高客单必须有清晰产品差异

四位数定制不能只是把固定 ¥688 仪式改名涨价。

必须在真实服务上存在差异：
- 重新判断；
- 重新选方案；
- 定制准备；
- 择时；
- 材料 / 执行调整；
- 更完整的服务流程。

### 4. 高成本实物不能只按材料加价

银制星符以后定价至少覆盖：
- 材料；
- 损耗；
- 排版 / 制作；
- 手工编绳；
- 择时 / 执行；
- 包装；
- 有限产能；
- 合理利润。

## 五、当前经营优先级

在没有 Revenue P0 时，当前价格体系优先做：

1. 先选定具体高价值项目，核对现价、范围和可售条件，再观察对应报价 / 成交；
2. 银制星符真实制作后补完整工时与总成本；
3. Ars Paulina / 水晶召灵继续记录真实订单工时，判断是否需要调价或降低主推频率；
4. 感情 / 复合 ¥688 补一次真实完整工时；
5. 铜制星符核对完整经济性，观察真实成交与复购。

不为了“价格体系看起来整齐”一次性全线涨价。

## 六、完整经济性与重复交付

成本同时检查固定支出和随订单变化的支出；盈亏与现金按 `00-系统总控/商业指标口径.md` 区分。每单除执行外，核对沟通、研究、采购、包装、寄送、返工与回访时间，未知写缺项。方法、询问信息、采购和完成通知允许标准化，个别适配判断继续对应真实客户。

高客单不要求每单从零研究，不用增加无必要工时证明价值；价格要覆盖完整交付、有限产能与实际经营支出，最终仍由 Suen 确认。
