## 三、改期与取消处理提案｜待 Suen 确认

建议采用按实际进度协商的方案，不预设“付款后概不退款”：

1. 付款前书面说明服务内容、价格、执行条件、改期、取消 / 退还方式和责任；未确定事项先明确，不能以“后面再说”收款。
2. 尚未发生约定准备 / 执行时，提案为客户可以提出取消并退还未使用款项。
3. 已发生事先确认的工作或外采成本时，根据可核对的完成事项、不可回收成本及双方约定协商结算；保留事先说明和实际依据，不单方面临时定扣款比例。
4. Suen 的执行条件发生变化时，及时说明并协商可接受的改期；无法按约履行的部分安排退还处理。客户变更目标 / 日期则先说明对费用与排期的实际影响，再获确认。
5. 已完成服务仍须按实际履约及适用法律处理售后争议，结果不保证不能替代履约义务或排除消费者权利。

这是审议方案，尚未形成正式售后条件；未批准前不对客户作上述承诺，也不代替具体法律核查。预付服务的书面内容与价款 / 退还约定参照《消费者权益保护法实施条例》第二十二条：[国务院公布文本](https://app.www.gov.cn/govdata/gov/202403/19/513111/article.html)。

确认时一次审议价格、目标、回访、记录 / 实体、改期与取消方案；需要修改的字段直接改为 Suen 的具体决定。确认之后再同步当前商业状态、报价模板和前台说明，避免版本不一致。

## 四、不阻塞第一位客户来咨询的事项

以下可以继续边验证边完善，不需要为了“系统完美”延迟接触真实客户：

- 最终长期售价；
- 成熟案例库；
- 稳定转化率；
- 完整复购模型；
- 银制星符正式价格；
- 是否未来增加套餐；
- 是否未来公开起价。

真实客户可以先进入：
**有效询盘 → 合格机会 → 方案判断。**

可售条件可以在客户出现前完成；进入正式报价 / 付款前必须补齐，不把经营准备一直推迟到有人来问以后。平台 / 交易入口仍按 `00-系统总控/商业信号与动态状态规则.md` 核查。
