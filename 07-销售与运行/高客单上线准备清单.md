## 二、第一笔正式报价前仍需确认

### 1. 正式测试价格

当前只有内部情景：
- ¥1380
- ¥1580
- ¥1680
- ¥1980

**均不是正式售价。**

第一位真实合格机会进入方案阶段后，必须由 Suen 明确：
- 本次正式报价是多少；
- 是否把它作为首3单阶段的默认测试价；
- 还是只针对本单复杂度报价。

没有 Suen 确认不得自动发价。

## 三、第一笔付款前必须确认

这些内容可以等真实客户出现后确定，但必须在收款前说清。

### 1. 后续回访

待确认：
- 是否默认包含回访；
- 如果包含，包含几次；
- 大概在什么阶段回访；
- 超出约定范围的持续咨询怎么处理。

### 2. 改期

待确认：
- 已确定执行时间后，如果客户原因需要调整怎么办；
- 如果是材料 / 天象 / Suen执行条件导致需要调整怎么办。

不得临时根据客户情绪随意改变规则。

### 3. 取消 / 退款

待确认：
- 付款后、尚未采购 / 准备时是否允许取消；
- 已产生材料 / 外采成本后如何处理；
- 已开始择时 / 方案 / 执行后如何处理。

当前没有正式规则，不能在成交时临场编造。

### 4. 目标范围

待确认：
- 一个完整定制默认处理一个主要现实目标，还是允许多个；
- 如果客户聊天过程中不断追加独立目标，如何重新判断范围 / 报价。

### 5. 过程记录

待确认：
- 是否默认提供照片 / 视频；
- 是否只提供完成通知；
- 哪些项目因为隐私、仪式结构或现实条件不适合提供过程素材。

### 6. 实体交付

待确认：
- 完整定制是否默认没有实体物；
- 如果方案确实产生护符 / 星符 / 其它实物，是包含还是另算。

## 四、不阻塞第一位客户来咨询的事项

以下可以继续边验证边完善，不需要为了“系统完美”延迟接触真实客户：

- 最终长期售价；
- 成熟案例库；
- 稳定转化率；
- 完整复购模型；
- 银制星符正式价格；
- 是否未来增加套餐；
- 是否未来公开起价。

真实客户可以先进入：
**有效询盘 → 合格机会 → 方案判断。**

只有进入正式报价 / 付款前，才必须补对应真实条款。

- 回访 / 改期 / 取消退款 / 目标范围 / 过程记录 / 实体交付范围仍待确认。

## 六、什么时候算“完整可售 v1”

满足：

- [ ] Suen 明确首轮正式测试价格或报价原则
- [ ] 回访范围明确
- [ ] 改期规则明确
- [ ] 取消 / 退款规则明确
- [ ] 目标范围明确
- [ ] 过程记录 / 实体交付边界明确

完成后可把产品状态从：

**首3单验证前 / 可接咨询**

升级为：

**首3单验证中 / 可正式报价与收款**

---

## 七、系统纪律

不为了“上线完整”一次性发明复杂售后制度。

规则只解决真实需要：
- 客户付钱前知道自己买什么；
- Suen知道自己承诺什么；
- 发生变化时有基本处理原则；
- 不靠临场情绪决定退款、追加服务或无限售后。
