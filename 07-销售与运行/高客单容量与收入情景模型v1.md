# Suen｜高客单容量与收入情景模型 v1

状态：内部经营模型  
建立：2026-09-27

用途：
用 Suen 当前真实产能判断不同价格下的收入结构和时间效率。

**本文件不是 KPI，也不是正式价格表。**

当前真实参数：
- 完整定制仪式约 3—4 小时 / 单；
- 舒适承载约 4 单 / 月；
- 未来希望四位数客单；
- 当前尚无正式定价；
- 当前首3单为 0 / 3。

## 三、每月时间占用

按舒适上限 4 单：

- 如果每单 3 小时：约 12 小时 / 月；
- 如果每单 4 小时：约 16 小时 / 月。

这说明完整定制的经营逻辑不是“大量接单”，而是：

**少量高质量机会 → 四位数成交 → 可控交付 → 案例 / 复购。**

即使达到舒适满载，也仍应给课程、Database、内容和其它产品留出主要工作时间。

## 四、当前价格测试解读

### ¥1,380

优点：
- 首次进入四位数的心理跨度较低；
- 相对现有 ¥688 固定仪式更容易解释成不同产品层。

风险：
- 如果真实工时经常接近4小时甚至超出，价格余量有限；
- 不适合作为“为了好成交”的默认低价。

### ¥1,580

当前内部较有价值的测试情景。

原因：
- 与现有 ¥688 固定仪式形成清晰层级；
- 4单满载约¥6,320；
- 3—4小时下粗略毛收入 / 工时约¥395—527；
- 仍处于首轮真实市场可以验证的四位数区间。

**注意：当前仍不是正式售价。**

### ¥1,680

适合在：
- 实际工时偏向4小时；
- 方案复杂度较高；
- 客户对完整定制的差异理解良好

时作为后续测试情景。

### ¥1,980

更接近成熟高客单层。

当前在案例不足、首3单尚未发生时，不自动设为第一正式测试价。

后续如果：
- 客户真实支付意愿成立；
- 结果证据增加；
- 工时稳定；
- 复购 / 转介绍出现；

可进入正式测试候选。

## 五、容量利用率

用 4 单 / 月作为当前舒适容量基线：

- 1 单 = 25% 容量利用；
- 2 单 = 50%；
- 3 单 = 75%；
- 4 单 = 100%。

容量利用率不是越高越好。

需要同时看：
- 是否挤压课程 / Database；
- 是否造成疲劳；
- 是否影响其它健康产品；
- 是否因为售后 / 沟通导致真实工时超标。

## 六、当前最值得观察的商业信号

在首3单阶段，比月收入更重要的是：

1. 是否有人愿意正常支付四位数；
2. 报价后主要阻力是什么；
3. 真实工时是不是3—4小时；
4. 是否经常发生额外工作；
5. 客户是否理解与 ¥688 固定仪式的区别；
6. 是否出现真实结果证据；
7. 是否有后续购买 / 转介绍。

## 七、未来何时重新评价格

首3单完成后第一次复盘。

可能结论：

### 保持价格
如果：
- 客户理解价值；
- 报价没有出现重复价格阻力；
- 工时符合预期；
- 贡献合理。

### 提高价格测试
如果：
- 真实工时持续偏高；
- 客户支付阻力不明显；
- 需求质量高；
- 产能快速接近上限；
- 案例与转介绍增加。

### 优化 Offer 而不是降价
如果：
- 客户总在问“为什么这个比¥688贵”；
- 方案差异没有被理解；
- 流程不清楚；
- 风险感来自案例不足，而不是价格本身。

### 降低 / 调整价格
只有当多个真实合格机会反复显示价格本身是主要阻力，同时其它价值、流程和案例问题已经相对清楚时，才进入价格下调讨论。

不因单个客户做全局调整。
