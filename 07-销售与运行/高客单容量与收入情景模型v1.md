## 三、每月时间占用

按此前舒适承载约4单 / 月比较：

- 每单3小时：约12小时 / 月；
- 每单4小时：约16小时 / 月；
- 每单5小时：约20小时 / 月。

这是已成交项目的交付时间情景；内容、获客和经营管理的其它时间仍需安排。4单不是已验证月需求，不自动增减容量或设成销量目标。

## 四、按具体项目比较

先定位具体仪式 / 物品 / 个别方案，再核对它的现价、范围、工时与现金成本。不能先选 ¥1580 / ¥1680，再替没有名称的项目补服务。

Suen 对“常规一单”的材料、包装、快递合计口述估计≤¥30；具体适用项目仍待定位。已有铜制材料约¥45、银制预计材料约¥600等记录继续独立保存，不能用这个粗估全局覆盖。

3—5小时是本轮服务讨论的工时区间，须与实际项目对应。每个项目记录自己的完整交付时间与成本，价格不同的项目分别观察；客户支付意愿由该项目的真实报价 / 付款验证。

现金成本粗估不包含已确认之外的手续费、固定支出、获客、退款、税费及经营留存，不能把“售价减30”叫净利润或生活可用资金。

## 五、容量利用率

用 4 单 / 月作为当前舒适容量基线：

- 1 单 = 25% 容量利用；
- 2 单 = 50%；
- 3 单 = 75%；
- 4 单 = 100%。

容量利用率不是越高越好。

需要同时看：

- 是否造成疲劳；
- 是否影响其它健康产品；
- 是否因为售后 / 沟通导致真实工时超标。

## 七、未来何时重新评价格

首3单完成后第一次复盘。

可能结论：

### 保持价格
如果：
- 客户理解价值；
- 报价没有出现重复价格阻力；
- 工时符合预期；
- 贡献合理。

### 提高价格测试
如果：
- 真实工时持续偏高；
- 客户支付阻力不明显；
- 需求质量高；
- 产能快速接近上限；
- 案例与转介绍增加。

### 优化 Offer 而不是降价
如果：
- 客户总在问“为什么这个比¥688贵”；
- 方案差异没有被理解；
- 流程不清楚；
- 风险感来自案例不足，而不是价格本身。

### 降低 / 调整价格
只有当多个真实合格机会反复显示价格本身是主要阻力，同时其它价值、流程和案例问题已经相对清楚时，才进入价格下调讨论。

不因单个客户做全局调整。
