# Suen｜当前收入与高客单情景模型 v1

状态：内部经营模型
更新：2026-10-08

本文件用于比较实际可售项目的收入贡献与工作量，不设新销量KPI、不自动改价，不以算式证明需求或渠道许可。正式价格与范围读取各项目真源及 `08-动态运行/商业/当前商业状态.md`。

## 一、当前可售基准｜固定感情 / 复合仪式

2026-10-08独立产品定义的口述参数：
- 当前价格¥688 / 次；
- 完整交付约4—5小时；
- 直接成本约¥100以内；
- 无实物寄送；
- 含实际执行 / 现场视频、完成通知、一次效果占卜和一次回访。

后续价格、范围或成本变化先更新真源，再刷新本模型输入。3—5小时、≤¥30与包邮属于此前通用讨论，不能覆盖这个已定义项目。

## 二、单笔贡献情景

若按直接成本¥100计算：

`688 - 100 = 588`

¥588只代表扣这一项直接成本的贡献情景，不是净利润或生活现金。成本是口述上限附近的粗估，不写成每单已审计恰好支出¥100。

按4—5小时，约¥118—147 / 交付小时，同样未扣其它经营支出；获客、内容、经营管理的时间和费用另行观察。

## 四、如何对照生活资金

目标和实际计算口径读 `00-系统总控/商业目标与产品优先级.md` 与 `商业指标口径.md`。

以当前¥4000生活基准作情景：
- 7单扣上述直接成本后¥4116，只剩¥116容纳其它经营支出 / 必要留存增加；
- 8单为¥4704，余量¥704。

手续费、工具、实际税费、获客、退款、固定开支和未履约留存等未齐全时，不宣布独立生活达标。真实生活可用资金应按现金与留存核对，不能拿贡献情景直接充当。

## 五、已有收入组合

按实际月份汇总：
- 固定¥688项目；
- 已有塔罗 / 判断类咨询与运势等实际订单；
- 有真实需求的标准星符、实物与复购；
- 实际承接的原典核查 / 研究服务；
- 其它确实发生的收入。

每类只计真实收款与对应成本，价格从当前真源读。没有订单不预填收入，不以亲友付款或旧储蓄证明陌生市场跑通；同一客户补款不重复增加订单。

当前先观察询盘、适配、报价、付款、真实交付与后续反馈，银制暂停期间不预设其填补现金缺口。固定¥688的正常付款样本不计入≥¥1000高客单首3单分类。

## 六、未来高价值项目

纯银金属行星星符当前因可支配资金不足暂缓。恢复前核对完整样品预算、生活 / 履约留存和Suen确认；样品、工时与完整成本取得后再定具体售价，不把预计¥600材料成本当总成本。

高价值个别方案保留后台承接能力。遇到真实需求按具体项目记录工时、成本、价格与交付；不同项目分别观察，不让所有订单共用同一价或同一产能参数。

## 七、旧金额只作历史算术

¥1380 / ¥1580 / ¥1680 / ¥1980从未成为统一商品价。旧表可在Git历史追溯，不进入当前主收入看板，不能用于自动报价或推算每月已有3—4笔高客单。

若将来某个具体项目确实确认相应价格，再以它的实际成本、范围、容量与需求重算。
