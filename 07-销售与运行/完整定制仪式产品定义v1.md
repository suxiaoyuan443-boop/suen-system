## 一、具体项目与报价口径

客户可以从现实问题开始咨询；Suen 再判断适合哪个具体仪式、物品或个别方案。内部报价记录至少写清：具体项目 / 方案、主要目标、交付范围、实际工时、该项目现金成本与最终报价。

常规单材料、包装、快递合计，Suen 口述估计“不超过¥30”，主要是快递较贵。对应哪些项目尚未逐项确认，不能把这个粗估覆盖铜制材料约¥45或银制预计材料约¥600等已有特殊记录，也不能当成所有项目完整净成本。

## 一-A、服务接口定位

2026-10-08 Suen 明确确认：一笔完整定制默认处理一个主要目标；追加独立目标时重新确认服务范围和报价。完整定制围绕该目标进行适配判断、方案选择、准备、执行与完成说明。差异由真实服务范围证明：信息判断、个别材料 / 择时条件、执行安排和约定沟通。

允许复用已核实的方法、成熟技术和操作清单，同时针对本案作个别判断；每单从零研究、复杂度或稀缺话术不作为高价格的必要条件。共通流程越清楚，越能控制工时与履约质量。

## 二、与固定 ¥688 仪式的区别

固定仪式提供既定流程及正常信息适配。完整定制需要单独判断服务是否适合、如何组合或调整实际方案，并确认本单范围、条件和交付。

固定项目已足够时按固定项目承接。完整定制不靠改名涨价，不通过增加无必要的材料 / 步骤制造差异。

## 三、本轮已确认的服务组成

以下是 Suen 在本轮回答中明确提供的交付方式，落实到被选定的具体项目。不能自动把整套制作视频、效果占卜和实体寄送套到所有咨询、固定仪式或物品，也不能据此统一售价。实际包含事项在本单报价前确认。

### 1. 前期信息与适配判断

目标：
确认客户的问题是否适合进入完整定制。

只收会改变方案判断的信息，不做冗长问卷。

### 2. 方案设计

Suen 根据客户情况决定：
- 是否适合执行；
- 使用哪一类方法；
- 是否需要组合不同技术；
- 哪些材料 / 条件会改变执行；
- 是否有更适合的标准项目而不需要进入完整定制。

### 3. 择时

需要择时的项目：
- 由 Suen 进行择时；
- 当前平均约占 1 小时；
- 不为了成交虚构“最佳时间”或唯一窗口。

不需要择时的项目，不为了显得高级强行加入择时。

### 4. 准备

当前平均约 2 小时，包括真实项目需要的：
- 材料准备；
- 仪式准备；
- 方案核对；
- 其它必要执行前工作。

不同项目可变化。

### 5. 实际执行

按最终确定方案执行。

执行内容不要求客户理解全部技术细节，但必须保证实际做法与对客户说明的方案一致。

### 6. 执行时间与现场视频

Suen 已确认向客户提供执行时间信息，以及现场制作 / 仪式视频。时间必须来自实际确认的安排，计划与实际执行分别记录；视频使用真实现场记录。

本次没有约定固定视频时长、剪辑形式、交付份数、未经剪辑全程或公开客户资料，不自行扩成这些承诺。客户交付视频与公开营销素材分开，公开使用另按授权与平台规则。

### 7. 完成通知与效果占卜

执行完成后通知客户，并提供完成后的效果占卜。这是 Suen 已确认的交付组成；具体进行时间、解读范围与是否和回访同节点，仍须落实到项目。

效果占卜记录为占卜解读；实际执行记录、客户后续报告和可核实的现实变化分别记录。解读不能作为现实效果已发生、因果关系成立或固定成功率的证明，也不预设只能给出正面结论。

### 8. 一次回访

每单包含一次回访，了解与本单有关的后续情况、回答相关问题。具体时间待项目约定；此前提出的 7—14 天仍是未批准建议，不自动写成默认日期。

### 9. 有实物时寄送与手写信

方案产生实物时寄送，并随快递附赠手写信，说明如何使用以及注意事项。无实物的方案不因此承诺额外制造实物。

Suen 已确认包邮，快递费直接包含在本单报价内；地域及具体寄出时间未确认，按本单说明，不自行承诺全球包邮或固定快递时效。使用说明对应实际交付物，内部成本核算必须计入真实快递费用。

## 四、v1 已收口的通用交易与交付规则｜2026-10-08

以下为高价值个别方案的**通用 v1 规则**。具体项目、价格、执行日期、回访节点和寄送地域仍按每一单填写，但不再视为“系统尚未完成”。

### 1. 付款方式

首 3 单验证期默认：
- 在具体项目、服务范围、价格、执行条件、改期 / 取消处理已经以可保存的书面形式确认后，再收款；
- 默认一次性全款后进入准备 / 采购 / 择时 / 执行；
- 不自动提供分期、定金或尾款方案；具体项目若以后需要分阶段付款，再单独确认。

这不是统一商品统一价。每单必须先写明具体项目与实际价格。

### 2. 一单一个主要目标

- 一单默认处理一个主要目标；
- 客户在进行中提出新的独立目标，重新判断是否适配，并重新确认范围与报价；
- 同一目标下的小幅信息变化可在原方案内处理；若变化已经改变技术、材料、时间或工作量，则先说明影响，再决定是否调整方案 / 价格。

### 3. 视频与完成通知

- 提供真实现场制作 / 仪式视频，目的是让客户看到实际执行；
- 默认不承诺直播、未经剪辑全程录像、固定分钟数或完整技术演示；
- 本单视频发送时间在付款前确认，可与完成通知同节点或另约；
- 客户交付视频默认仅用于本单私人交付；未经另行明确授权，不把客户相关信息或专属执行记录公开作为营销素材。

### 4. 效果占卜

- 执行完成后包含一次效果占卜；
- 具体占卜时间与解读范围在本单付款前写明；不同项目可以不同，不设一个虚假的全项目统一天数；
- 效果占卜属于占卜解读，不等于现实结果已经发生，也不替代后续现实反馈。

### 5. 回访

- 每单包含一次与本单有关的回访；
- 回访的具体节点由项目性质决定，并在付款前写明；
- 不再把“7—14 天”当成所有项目的自动规则；
- 回访负责了解现实变化与回答本单范围内问题，不自动升级成无限期售后或新增目标咨询。

### 6. 实物、包邮与寄送

- 本单确有实物时寄送，并附使用方法与注意事项手写信；
- 快递费用计入本单报价，不另向客户收取已约定范围内的普通寄送费用；
- 具体寄送地域、寄出节点和特殊物流条件必须在本单付款前写清；
- 未确认地域时不对外写“全球包邮 / 全国任何地区无条件包邮”等扩大承诺；
- 需要静置、干燥、等待材料状态或其它客观条件的实物，按本单真实情况说明寄出时间。

### 7. 改期

- 因 Suen 的实际执行条件、材料、真实择时或其它必要条件需要调整时，及时告知并协商新安排；
- 客户要求改期时，先判断是否影响已经发生的准备、采购、择时或其它成本；
- 没有新增成本 / 工作量时，正常协商调整；
- 已产生不可回收成本、需要重新采购 / 择时或明显增加工作时，先说明实际影响，再由双方确认新安排与必要费用；
- 不使用虚假“唯一窗口”制造压力。

### 8. 取消 / 退款

不采用“付款后概不退款”的一刀切条款。

- 尚未开始约定的个别准备、采购或执行，且没有发生不可回收成本时：原则上退还未使用款项；
- 已经发生经约定的个别方案工作、采购、材料或其它不可回收成本，但尚未完成全部服务时：按实际已完成事项、可核对成本、双方付款前约定及适用法律处理，并说明结算依据，剩余未履行部分按实际情况退还；
- 已进入或完成实际执行后：结果未达到客户期望本身，不自动等于服务未履行；但服务质量、未履行部分、违约或依法应退事项仍按真实履约和适用法律处理；
- 因 Suen 无法按约继续提供服务时，对未履行部分及时协商履行或退款。

收取预付款提供服务时，付款前书面说明服务内容、价款、预付款退还方式和责任。不得用格式条款排除消费者依法享有的权利。

### 9. 完整技术文本与加急

- 完整仪式文本、完整技术步骤、内部研究笔记、采购渠道 / 成本清单，不属于默认客户交付；
- 本单确有需要交付的使用说明、注意事项和必要信息照常提供；
- 首 3 单验证期默认不提供“加急服务”，不为了多收费压缩真实准备、材料或择时要求。

### 10. 每单付款前必须填完的变量

以下属于**每单变量**，不是系统待办：

- 具体项目 / 个别方案；
- 本单主要目标；
- 本单正式价格；
- 是否需要择时及已确认的排期条件；
- 视频发送节点；
- 效果占卜节点与范围；
- 一次回访节点；
- 有实物时的寄送地域与寄出节点；
- 本单已知特殊材料 / 外采条件；
- 本单如发生取消 / 改期，哪些工作或成本已经实际发生。

产品接口与通用条款已收口。每单字段在付款前填清后，还须按 `00-系统总控/商业信号与动态状态规则.md` 核对对应发布 / 交易渠道与适用条件；完成这些核对后按本单承接。系统收口不代表所有平台已允许此服务，未核查时不得自称渠道许可已通过。

## 五、结果边界

可以确定：
- 是否接单；
- 最终方案；
- 需要的准备；
- 择时与执行条件（适用时）；
- 是否已经执行；
- 已约定的后续沟通。

不能承诺：
- 百分百结果；
- 固定天数见效；
- 客户希望发生的现实结果一定发生；
- 虚构成功率。

高客单价值来自更完整的判断与执行，不来自更夸张的效果承诺。

## 六、适配判断

更适合完整定制的情况通常包括：

- 现实情况较复杂；
- 固定项目无法直接对应；
- 需要重新选择方案；
- 材料 / 时间 / 技术条件需要个别设计；
- 客户愿意提供必要信息并接受结果不作百分百保证。

以下不因为预算高就强行进入完整定制：
- 固定标准项目已经足够；
- 客户只需要轻量判断；
- 需求本身不适合 Suen 当前服务；
- 客户只接受百分百保证。
