## 一、五种商业角色

### A｜首次付款入口

目标：
让一个已经产生真实兴趣的人，能够用较低决策成本完成第一次真实付款。

要求：
- 客户容易理解；
- 交付清楚；
- 不需要复杂销售；
- Suen 工时不能明显失控。

### B｜稳定现金流

目标：
用相对标准化、可重复的产品形成较稳定收入。

要求：
- 交付相对成熟；
- 单笔利润 / 时间合理；
- 不需要每单从零研究。

### C｜核心利润

目标：
在有限产能下提高单客贡献。

要求：
- 客户需求明确；
- 专业差异明显；
- 定制 / 稀缺执行合理；
- 价格能够覆盖真实工时和有限产能。

### D｜专业权威 / 品牌资产

目标：
证明 Suen 具备普通低价服务无法替代的研究与执行能力。

这类产品不一定当前最赚钱，但可以：
- 形成内容；
- 形成案例；
- 强化专业识别；
- 提高其它产品的信任。

如果长期高工时低回报，只保留有限承接或调价，不因“显得专业”无限接单。

### E｜复购 / 加购

目标：
让已经建立信任的人继续购买，而不是每次重新从陌生流量开始。

要求：
- 和客户既有关系 / 需求自然衔接；
- 不强制升级；
- 不制造无需求消费。

## 五、产品主推逻辑

每天不按“价格最高”决定主推。

总控按以下顺序判断：

1. 当前是否有 Revenue P0；
2. 当前商业漏斗最缺什么；
3. 哪个产品与当前真实业务 / 内容素材自然匹配；
4. 产品经济性是否健康；
5. 是否会挤压更高价值的时间；
6. 当前是否已经连续出现太多销售信号。

因此：
- 没有高客单询盘时，不天天发高客单广告；
- 正在制作铜制 / 银制星符时，可以优先复用真实工作；
- Ars / 水晶召灵即使专业度高，也不因“看起来厉害”默认主推；
- 有老客真实需求时，低价 / 标准产品继续正常成交。

## 六、产品矩阵的目标

最终不是让所有产品都卖得一样多。

而是形成：

**首次付款入口**
→ **标准产品 / 现金流**
→ **适配时进入高价值定制**
→ **复购 / 加购 / 转介绍**

同时让：
- 专业权威产品提高信任；
- 高客单产品提高单客贡献；
- 标准产品维持现金流；
- 低风险产品降低第一次购买门槛。

不同产品各做自己的工作。
