# 择时｜历史规则说明

状态：版本说明
最后核对：2026-09-17

## 2026-06-11 七政星符择日报告

Library 中的《2026-06-11_2026下半年七政星符择日_所罗门.pdf》仍然有以下价值：

- 保留当时的候选日扫描结果
- 记录行星日、行星时与宫位评分方法
- 保留当时使用的 via-negativa 与取吉评分结构
- 可用于回看旧候选为何入选

但该报告不是 2026-09-17 之后的唯一规则真源。

## 为什么不直接照旧报告使用

旧报告允许部分项目在“警告 / 减伤”逻辑下保留候选，并包含较宽松的接纳、sect 与凶相减伤机制。Suen 后续对月亮条件和目标行星条件进行了加严。

因此：

- 旧报告中的高分或“警告”不能自动视为当前可用；
- 当前 Moon Hard Filter 触发时，不能用旧评分补偿；
- 每个将来要实际执行的窗口都按当前项目规则复核。

## 历史修正原则

过去被报告列为候选的日期，如果后来发现月亮存在当前严格规则下不可接受的凶相、目标行星问题或其他硬筛条件，应以后续复核结果为准。

GitHub 只保存规则，不把旧候选日批量改写成“永久有效”。动态窗口状态继续由专用择时系统与 Slack `#天象检索与预约` 管理。
