# 择时与仪式

状态：迁移索引
最后更新：2026-09-17

本目录用于保存长期稳定的古典魔法择时与仪式筛选规则。

## 计划拆分

- `古典魔法择时.md`：所罗门星符、Ars Paulina、水晶显灵等通用与项目专用规则
- `PGM-PDM择时.md`：PGM / PDM / 同一希腊—埃及语境 recipe 的原典时间要求与附加天象质量系统
- `星符规则.md`：行星日、行星时、目标行星、月亮 Hard Filter 与项目级筛选

## 迁移原则

择时规则技术细节多、历史修正频繁。正式文件写入前必须逐条核对当前版本，尤其：
- 行星顺逆与灼烧
- 月亮 VOC
- 月亮与太阳距离
- 月亮与火星/土星凶相
- 月亮与目标行星刑冲
- 下一应用相位
- 行星日与行星时硬条件
- 原典本身的日期、月相、时段或行星要求

当前目录先建立索引，不把未经逐条复核的旧版本直接标记为正式真源。
