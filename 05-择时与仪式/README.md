# 择时与仪式

状态：当前正式索引
最后核对：2026-09-17

本目录只保存长期稳定的择时规则，不保存每日星盘截图、动态预约人数或完整历史推导。

## 文件分工

- `古典魔法择时.md`：所罗门星符、Ars Paulina、水晶显灵等当前严格规则
- `PGM-PDM择时.md`：PGM / PDM / 同一希腊—埃及语境 recipe 的“原典先行”模式
- `Slack天象预约池规则.md`：技术择时如何压缩成 Slack 经营记录
- `历史规则说明.md`：旧择日报告与当前严格规则的关系

## 总原则

不同传统的择时要求必须分开，不能因为都属于“魔法”就自动套同一套行星日/行星时。

- 所罗门星符 / Ars Paulina / 当前水晶显灵项目：执行项目自己的古典行星规则。
- PGM / PDM：先服从具体 recipe 原文的时间要求，再决定是否额外叠加 Suen 的天象质量筛选。

地点默认上海、Asia/Shanghai；如果项目原文或用户另行指定地点，则按具体项目处理。
