# Suen｜古典魔法择时与星符

状态：当前严格规则
最后核对：2026-09-17
默认地点：上海（Asia/Shanghai）

## 适用范围

本文件用于：

- 所罗门系星符
- Ars Paulina
- 当前按行星体系执行的水晶显灵
- 其他明确要求行星日与行星时的古典行星魔法项目

PGM / PDM 不默认套用本文件，见 `PGM-PDM择时.md`。

## 硬条件：行星日 + 行星时

对应目标行星的 **行星日** 和 **行星时** 均为硬条件。

行星日以日出为界，而不是公历午夜。夜间行星时跨入次日凌晨时，仍归属于前一个日出开始的行星日。

## 目标行星

目标行星至少满足：

- 不逆行
- 不灼烧
- 不接受明显不可接受的火星/土星硬相位
- 优先有尊贵、角宫、临轴、良好接纳、吉相等加分

目标行星的宫位、速度、尊贵、应用/分离、接纳等用于候选窗口之间继续取吉，但不能用高分抵消已经触发的硬淘汰条件。

## Moon Hard Filter

当本项目执行 Suen 当前严格月亮规则时，以下任一项触发即淘汰候选：

1. 月亮与太阳距离过近：应用阶段 <15°，或分离阶段 <12°。
2. 月亮空亡（VOC）。
3. 月亮位于天蝎或摩羯。
4. 月亮位于 Via Combusta。
5. 月亮与火星或土星形成合、刑、冲。
6. 月亮与目标行星形成刑或冲。
7. 月亮下一应用相位为凶相。

严格模式下，不因为某个窗口其他分数很高，就忽略上述 Hard Filter。

## 进一步检查

候选通过硬筛后，再看：

- 月亮下一应用相位
- 月亮是否向目标行星形成合/六合/拱等支持结构
- 目标行星是否角宫、临 ASC/MC/DSC/IC
- 行星尊贵与失势
- 应用/分离
- orb
- reception / mutual reception
- sect
- 其他与具体项目有关的古典条件

Bonatti 月亮条件等深入检查用于候选间进一步复核，不取代当前 Moon Hard Filter。

## 分体系执行

如果同一时间窗口同时安排“星符制作”和“水晶显灵”，必须先确认两套体系各自要求。两者可以共享时间窗口，但不能因为时间相同就写成同一个仪式体系。

## 状态规则

技术分析中的“候选”不能自动变成“已确认”。只有 Suen 明确确认后，才能在 Slack 经营层标记为“已确认”。

## 输出

完整技术分析至少保留：

- 地点
- 日期与钟表日期
- 行星日
- 行星时
- 目标行星状态
- 月亮 Hard Filter
- 应用/分离与 orb
- 宫位/角点
- 接纳与关键相位
- 淘汰原因或候选优点
- 最终技术评级与状态
