# Suenakhet Database Rules

**区域类型：隔离 Rule Vault｜不属于商业总控运营区**

本目录专门保存 Suenakhet 历史宗教与仪式数据库的**长期写作、资料、原文、图像、现代重构和验收规则**。

## 真源关系

从 2026-09-19 起：

- **GitHub 本目录 = 数据库写作 / 验收规则唯一长期真源**
- **Obsidian = 数据库内容本体**
- 数据库专用对话 / Work = 执行层

Obsidian 不再维护第二份完整写作规则，避免以后对话变长或换新会话时出现两套要求。

## 隔离要求

虽然本目录与商业运营配置存在同一个 GitHub 仓库，但两者逻辑上完全隔离：

- 商业总控的“更新 / 总结 / 周复盘”默认不得读取本目录；
- 抖音、小红书、公众号、朋友圈、Patreon 等内容运营规则不得覆盖这里；
- 本目录规则也不得自动改变商业内容调度、价格、销售 CTA、天象预约或平台发布节奏；
- 只有 Suen 明确进行数据库写作 / 重构 / 校验，或数据库专用对话接管工作时才读取；
- 数据库正文、神明档案、仪式页面、文物资料、图片、附件继续留在 Obsidian / 对应资产位置，不迁入这里。

## 新数据库对话接管方式

新开的数据库专用对话或 Work 在继续数据库工作前，应先实际读取：

1. `Suenakhet Database Rules/README.md`
2. `Suenakhet Database Rules/Suenakhet数据库写作完整要求.md`

然后再读取 / 打开 Obsidian 中当前需要继续的数据库页面。

不要依赖旧对话记忆冒充当前规则。

正式规则文件：

- [Suenakhet数据库写作完整要求](./Suenakhet数据库写作完整要求.md)
