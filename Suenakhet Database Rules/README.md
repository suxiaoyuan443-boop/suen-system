# Suenakhet Database Rules

版本：2026-10-21。隔离的数据库规则区，不属于商业总控运营区。

## 唯一真源与内容位置

GitHub本目录保存Suenakhet数据库的长期写作、资料、原文、图像、现代重构和验收要求。Obsidian保存数据库内容本体；数据库专用对话或Work负责执行。Obsidian不再维护可独立改动的第二套完整规则。

数据库正文、神明档案、仪式、文物图片、手稿附件、草稿、审计、改前留存及任务进度不迁入商业仓库。临时上传副本、导出件和旧版本也不充当另一真源。

## 隔离

- 商业总控的更新、总结和周复盘默认不读取本目录。
- 平台运营、口播、价格、销售CTA和发布节奏不得覆盖数据库要求。
- 本目录不得自动修改商业调度、价格、天象预约或经营状态。
- 只有数据库写作、重构、清理、核查或明确的数据库接管任务使用本目录。
- 仓库其他区域的规则不因数据库更新而改动。

## 新数据库任务必读

按顺序完整读取：

1. 本README。
2. [Suenakhet数据库写作完整要求](./Suenakhet数据库写作完整要求.md)：全库结构、神明母本顺序、原字、三层仪式、现代实践、图片、日期、排版和执行顺序。
3. [Suen通用写作文风总规范](./Suen通用写作文风总规范.md)：Suen于2026-10-21更新的长期语言风格与工作方式。
4. [制作与验收逐项清单](./制作与验收逐项清单.md)：从资料到实际阅读检查的执行检查表。

再实际读取Obsidian中的当前页面、内部进度及本次改前文件。不要只依赖旧对话摘要或过去的“完成”说法。

## 优先关系与本次更新

Suen当前明确指示优先，其次是数据库专门要求，再次是通用规范和清单。通用规范中的内部检查词不会成为公开页的栏目；古代原文、译文和祷词的第一人称、否定、重复及强制语气不受现代作者文风删改。

2026-10-21版将Suen本日提供的中文语言规范整合到通用文风文件，并同步本入口、完整要求和验收清单的对应说明。原文完整性、事实区分、图片、现代实践及验收标准继续按数据库专门要求执行。

2026-10-12版将当时最新要求直接整合并替代冲突旧条款，包括：全库按拉神母本顺序、本人首图、完整名称异体及2em圣书体、仅称号原字的三列表、现代仪式独立可用及同位补缺、一次括注的材料替代、合法原图查看例外、逐章首见整词链接、无公开制作语或属性、字符与真实阅读软件检查、整套母本验收及中断恢复。

规则更新完成不等于数据库清理或母本完成。Suen已明确授权：后续数据库要求、执行方法、制作顺序或验收标准有确认的变动时，在当前执行轮直接更新GitHub相应章节，清掉旧冲突，并同步本接管说明和清单；无须为同一授权范围再次请求批准，不积累到以后统一上传。更新后读回远端全文核对，并记录实际提交、文件及适用范围；同步失败或尚未执行时照实报告，不称已经同步。数据库正文、附件、逐项审计、改前留存和详细进度仍保存在本地。
