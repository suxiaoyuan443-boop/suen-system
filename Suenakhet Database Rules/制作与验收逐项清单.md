# Suenakhet｜制作与验收逐项清单

版本：2026-10-21。本清单是内部执行工具，不放进公开正文。完整要求和Suen当前指示优先，清单不得作为缩减正文的模板。

每项在内部记“通过／未通过／有准确依据的不适用”，附实际文件、原件位置或核查记录。缺项不能只改状态。以下方括号是内部检查用，不作为公众任务卡。

## 一、接管和范围

- [ ] 已完整读README、完整制作要求、当前通用文风与工作方式及本清单。
- [ ] 已读取当前本地正文、配套页、实际内部进度和改前文件，而非只看摘要。
- [ ] 本次范围、制作顺序与用户最新指示一致；没有自行缩小、跳级或新开一批短档案。
- [ ] GitHub规则与Obsidian内容、商业运营文件分开；没有第二套可独立修改的规则。
- [ ] 断点恢复已核成功命令、实际文件差异和未执行步骤，未重跑或覆盖已完成内容。

## 二、资料取得

- [ ] 每个重要事实指向实际原件、馆方对象、可靠刊本、原典或正式研究，而非搜索结果、商品页或泛主页。
- [ ] 作者、题名、年代、卷页、栏行、图号和馆藏号核对。
- [ ] 原件、摹本、校订、转写、译文、补绘和现代设计清楚区分。
- [ ] 用户指定的Thorn等参考文件确已实际取得并阅读相关篇章，未冒称读过，也未把现代作者的话或设计冒充古代原文原图。
- [ ] 多个传本各自的名称、数量、顺序、代词、神名、重复和缺损没有混成一份不存在的原文。
- [ ] 真正未取得的资料留内部，不在公开页用概述或施工话冒充完整仪式。
- [ ] 检索范围可说明；没有声称全网绝无遗漏，没有以重复转载凑材料量。

## 三、神明主档顺序

- [ ] 开头是该神本人的准确照片，优先单独全身考古实物；复合神和多人图不冒充本人首图。
- [ ] 新手能由开头的具体图像、器物或故事进入主题。
- [ ] 名称与基本字段没有在改结构时删掉；异写、原语言、圣书体、转写、MdC、Gardiner和词义对应。
- [ ] 可靠拼写变化分别列出，秘密名不自造。
- [ ] 称号表三列为中文、原文、解释；原文只有该称号，不多截句子，不只放转写。
- [ ] 自身形象及故事在前，公羊首、隼首等变化有对应场景和准确图片。
- [ ] 普通亲属、神群、审判同伴和夜航故事没有错放到复合形态末尾。
- [ ] 地区、城市、神庙、祭司、祭坛、地方故事与遗存实际展开，按赫利奥波利斯深度组织。
- [ ] 节庆与现代日期并列。
- [ ] 供桌表讲清供物、花、器皿、数量、摆放、献奉与收礼。
- [ ] 赞美诗和仪式分开分类，每项解释与该神的实际联系。
- [ ] 原典详细原图、原文和中文在对应文本页齐全；主档现代供奉依然能独立使用。
- [ ] 复合形态、希腊罗马对应、服装和神形变化放在最后相关部分，来源收尾。
- [ ] 连续自然段有信息增量，没有每个小字段都拆一标题；地点字段与长段没有重复整块内容。
- [ ] 首图至现代供奉始终围绕本神，复合神的独立崇拜中心与形态没有提前混入；相关人物按实际故事或受供关系出现。
- [ ] 深度以具体材料、解释和完整实践判断，不按字数、标题数量或与拉等长判断。

## 四、字形与符号

- [ ] 圣书体按认可的2em基准及支持字体显示，字图足够大，实际软件可读。
- [ ] Unicode、MdC和Gardiner逐组一致，又有实际古代见证，不以编码一致代替源文真实性。
- [ ] 方形原字与字体缺字方框已区分；Q3等实际符号没有误删。
- [ ] 字图没有生成、补坏字、拼接神名、错截相邻句或改原方向。
- [ ] 实践实际书写处有可照写神名；希腊或德摩提克原式没有伪造圣书体替换。
- [ ] 原典标准引文字母、编号、短横、残损、问号和省略符按实际刊本保持。

## 五、原文和中文

- [ ] 所选完整范围逐字核到，包括声音词、无意义音节、七元音、回文、边注及图中文字。
- [ ] 原文图案就是该仪式原本图案，能合法显示则嵌入，否则准确原图查看链接；未借相邻配方图。
- [ ] 版面、分行、分栏、递减、方向、相对位置、边框和空白保留。
- [ ] 中文完整覆盖同一范围，代词、对象、神名、数量、重复与顺序正确。
- [ ] 古代第一人称、强迫、威胁、性命令、否定和敌对请求没有伦理软化。
- [ ] 残字、缺行、译者补语与刊者校订分开；没有将尚未取得材料说成古文破损。
- [ ] 比较表省排呼号或以短横代表动词的情况已识别，完整诵词不遗漏这些词。
- [ ] 古代用的载体、笔墨及器物准确；现代编号未混进图案、原文或实际要抄的纸张。

## 六、现代仪式独立可用

- [ ] 只看现代部分就能从准备做到收礼，没有“读完上文”“按某页神名”等回找指令。
- [ ] 时间、地点、执行人数、分工、朝向、服装、沐浴、净手和空间清洁写全。
- [ ] 供台、书写板、笔墨、莎草纸或羊皮纸、神像、卷与器物实际摆放明确。
- [ ] 每行动作紧接实际诵词，所有神名、秘名、唱名、声音串、姓名位置和重复次数在操作处给全。
- [ ] 全部存文和请求保留，补缺只补缺口，没有用一个短仪式取代原文。
- [ ] 现代接续有对应古文或平行材料，内部逐处记源与位置，不冒称原卷失字复原。
- [ ] 日常祷词也从现存祷词提取，不堆无出处泛愿或管理话。
- [ ] 首次“原材料（可改为……）”后直接操作，不逐步解释边界、安全口号或未添加器物。
- [ ] 替代物在相同位置承担实际作用，准备、动作和收尾前后一致。
- [ ] 未要求违法、墓葬侵扰、伤害人或动物、毒物摄入或高危险动作，古文译文仍忠实。
- [ ] 长礼分连续阶段，不像几个独立仪式；新纸与重写有实际来源或必要作用，不凭空每段重来。
- [ ] 魔法圆、三脚架、坩埚、灯、火盆、神龛等有实际用途、位置、规格或图案和结束处理。
- [ ] 折叠、佩戴、封存、撤供、熄火、余烬、清洗、收具和保存写清；读者不需猜。

## 七、图片与许可

- [ ] 所用图的对象、馆藏号、年代、题记、神形、左右位置和文字说明对应。
- [ ] 现代摹本没有称考古照片，复合神没有称单独神，搜索缩略图或商品定名不作身份依据。
- [ ] 原件、照片和刊本的许可分别核；网络可读不自动算可重用或可商用。
- [ ] 公共领域或允许当前用途的图下载后实际嵌入，并按许可署名。
- [ ] 权限未明确或受限图只给精确可查看链接，不公开复制、不画AI替代。
- [ ] 查看链接定位到正确对象或原页图版，不是主页、错误框号或相邻文字。
- [ ] 缺合法图且无合适查看入口的文物未标完成，缺项在内部记，不出现公开“待补图”横幅。
- [ ] 商品魔法圆、淘宝定制图的出处、设计与授权状态内部清楚，未推定销售权，未冒充古图。
- [ ] 相对路径、文件扩展名和Unicode文件名实际解析，图不变形，未暴露临时令牌或私人下载地址。

## 八、节历与关联页面

- [ ] 古代月日或周期与现代纪念日期并列；依已确认表给公历日期，不让读者自行换算。
- [ ] 古代历法、现代固定纪念与当年城市日出日落区分，日期没有无依据统一。
- [ ] 真实来源可追溯，不因隐藏外部商业标识而隐去日期出处。
- [ ] 文物页有名称、编号、年代、地区、材料、尺寸、使用者、具体使用、文字图像及同类差异。
- [ ] 手稿页讲正文实际内容、版本、原词、动作神名和后世使用，而非只讲重要性。
- [ ] 地点页按实际神庙、祭司、机构、故事、仪式、实物和时代变化展开。
- [ ] 主档所用原典、仪式、文物、地点及节庆页构成完整单元，任一关键配套未完未称母本。

## 九、文笔、公开语言与排版

- [ ] 现代作者无我／我们及隐性自述，古代说话者不被删。
- [ ] 段落连续自然，没有连续一句一段、AI排比、模板句、机械纠错或强行升华。
- [ ] 每段新增具体信息，解释为什么重要，但不以抽象关系、能量或漂亮话代替事实。
- [ ] 读者能据正文说明对象身份、年代与出处、实际用途和操作、原文内容、判断依据及尚未确定的具体问题。
- [ ] 公开页没有制作说明、母本主档话、证据范围或边界栏目、TODO、完成标签、任务卡和属性。
- [ ] 文件名自动标题与正文同名标题不重复；不同分篇的原文和中文子标题没有被误删。
- [ ] 公开正文无星号强调或列表，原典实际星号必要时准确保存在源文展示，不删原字符。
- [ ] 长表管道正确转义，字段换行、字体、图片比例与引文清楚。
- [ ] 神明逐章或二级首见补链，紧邻复现不反复加；完整人名、地名、神物和复合名不被拆链。
- [ ] 文件、标题、块定位及双向链接检查通过；零失链不冒称内容合格。

## 十、交付与远端同步

- [ ] 资料结构检查与文风仪式检查均通过，实际阅读软件另验；没有以本地路径存在或自制预览替代。
- [ ] 状态、缺项及范围内部记录准确，局部修改、C0、单元母本和全库完成分开。
- [ ] 交付主档、原典、完整仪式、文物、地点、节历的直接检查案例，各不同样式有入口。
- [ ] 未故意分段交半成品让Suen反复说继续；有相关安全步骤时继续执行。
- [ ] 后续长期要求、已确认执行方法、顺序或验收条件有变动时，按Suen既有授权在当前执行轮直接同步GitHub相应章节，清除旧冲突并同步README及清单，不重复请示、不积累待传、不只在末尾堆补丁；局部读法和未确认猜测未擅自升级为全库规则。
- [ ] GitHub更新限数据库规则区相关文件，核当前main并保留其他任务变更，不强推、不夹带商业文件；提交后读回远端完整正文逐文件确认，登记提交、Blob SHA及适用范围，再更新本地接续记录；失败或未执行照实记未同步。
- [ ] 规则已上传与数据库已做完明确分开，未把上传成功称内容母本完成。

## 硬性退回条件

任一项出现，先返工，不能以其余检查通过抵销：错神首图；原文或译文删句；原图案缺失或被AI重绘替代；称号多截或原字错配；现代仪式需回原文找词；有毒或伤害性现实操作；办公纸便宜化；现代替代不承担原作用；日期虚构；许可不明公开复制；古话被伦理软化；公开属性或施工语言；实际软件字图不可读；关键配套未完却称母本或全库完成。

版权查看例外、古代真实残损、古文重复或第一人称，以及有出处的短分场不是自动退回理由，须按具体材料和已获用户确认的规则判断。
