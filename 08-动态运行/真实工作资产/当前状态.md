本文件只记录**真实工作现在进行到哪一步，以及是否已经具备可公开复用的现实素材**。

它不是选题池，不保存 P0 / 平台优先级 / 冷却，也不要求为了内容推进项目。

## 状态定义

统一使用：
- **研究 / 方案评估**：查资料、比较方案、询价、判断可行性；尚未采购 / 制作 / 执行；
- **已采购 / 已收到**：真实购买或材料到手；
- **制作 / 执行中**：已经发生真实制作、仪式、交付或项目执行；
- **已完成**：真实项目 / 产品已经完成，但不代表已有结果；
- **结果跟踪中**：已完成执行，正在等待 / 记录真实后续；
- **案例可用**：存在足够具体、允许公开、已去身份化的真实结果材料；
- **暂停 / 取消**：当前不继续。

任何状态升级必须有真实事实支持。研究不能自动升级为制作；完成不能自动升级为有效案例。
