【活跃候选｜5个】

1.《这个17世纪瓶子里，为什么装着人尿和12根铁钉？》
【栏目：文物】
状态：高优先候选
观看体验：奇怪的东西 → 奇怪的问题
现实依据：当前抖音大号前段留存仍是明显短板，需要无需背景就能立即理解的强实物入口；同时避开近期古埃及 / 所罗门密度。
对标参考：穹印之源｜中文低门槛对象入口；ESOTERICA｜真实器物→历史研究；中文女巫观察层只借“瓶子+内容物”的视觉熟悉度。
风险：不能把所有 witch bottle 功能统一解释。
资产复用：公众号 / Patreon。

2.《一双手套被偷了，罗马人为什么会把诅咒写给墨丘利？》
【栏目：文物】
状态：高优先候选
观看体验：现实冲突 → 古代魔法对象
现实依据：“手套被偷”比专业术语更适合当前陌生人入口；与巫瓶形成“强视觉 vs 强冲突”两种A型入口。
对标参考：Let’s Talk Religion｜熟悉问题→实际资料；ESOTERICA｜古代魔法对象+原始材料；穹印之源｜标题先冲突后术语。
风险：铅片本体视觉较弱；不能把“折五次”解释成未经证实的固定魔法机制。
资产复用：公众号 / 古代诅咒专题。

3.《两个魔法师记录“天使对话”，为什么最后出现了“交换妻子”的命令？》
【栏目：异录】
状态：高优先候选
观看体验：人物 → 事件 → 强转折
现实依据：当前资料 / 静态对象偏多，需要一个真正靠人物和时间线推动的故事型入口；可测试故事留存而不放弃史料品牌。
对标参考：Let’s Talk Religion｜具体人物/历史对象进入复杂历史；ESOTERICA｜人物+手稿+魔法史同链组织。
风险：必须区分史实、Dee/Kelley记录中的声称、后世传说；不能把“天使确实发令”写成客观事实。
资产复用：公众号 / Patreon。

4.《为什么护符经常要贴身佩戴，甚至要靠近身体出问题的位置？》
【栏目：隐理】
状态：高优先候选
观看体验：熟悉物件 → 魔法实践底层机制
现实依据：当前缺低门槛机制题；“为什么护符要戴在身上”无需先懂神秘学，且能展示Suen解释“接触 / 距离 / 身体位置为何成为作用条件”的能力。
对标参考：Angela’s Symposium｜普通问题→机制与史料；Let’s Talk Religion｜具体行为→历史材料；ESOTERICA｜跨传统时保留差异，不造万能通则。
机制证据：
• 古埃及资料直接把佩戴 / 放在身体上与向使用者传递护符力量联系；
• 罗马—晚期古代医学 / 魔法材料存在明确 proximity principle，治疗性护符常尽量靠近疼痛或失调部位。
风险：不能统一成“能量接触”；保护、治疗、死者语境要分开。
资产复用：公众号 / Patreon / 护符机制专题。
5.《判断题：塔罗牌一开始就是拿来占卜的吗？》
【栏目：辨伪】
状态：高优先候选
观看体验：熟悉神秘学对象 → 明确对错 → 历史翻转
现实依据：
• 塔罗本身对普通观众高度熟悉，进入门槛低于陌生手稿名 / 魔法书名；
• 9/11现有《牌记》样本说明塔罗对精准受众有较高互动，但当前需要测试更大众的“熟悉对象 + 历史误区”入口；
• 明天身份视频承担主页身份识别后，这题可以继续建立“既会实践，也会核查历史”的品牌认知；
• 与当前两个文物、异录、隐理的观看体验不同。
对标参考：
• Let’s Talk Religion 2026-09-08《House of Wisdom》：高度神话化对象 → 回原始 / 学术资料；
• Angela’s Symposium 2026-09-06：用普通人直接能进入的问题承载严肃研究；
• ESOTERICA长期：流行神秘学印象 → 历史证据重建。
判定：错。
证据起点：
• 15世纪北意大利早期塔罗首先属于纸牌游戏 / trick-taking game；
• 现今占卜与神秘学关联是后来发展，并非中世纪塔罗的原始用途。
风险：不要把“后来才出现”粗暴写成“直到某一年才第一次有人占卜”；正式稿需区分游戏起源、cartomancy发展与18—19世纪 occult tarot。
资产复用：公众号 / 小红书长卷 / Patreon可选。
