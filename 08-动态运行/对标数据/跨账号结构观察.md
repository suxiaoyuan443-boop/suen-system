# 对标数据｜跨账号结构观察

状态：初版｜随年度数据补齐持续更新  
更新时间：2026-09-24

本文件只写**当前数据已经支持的候选规律**。  
不是永久选题公式，也不能覆盖 Suen 自己的第一方数据。

## 1｜“普通人马上能懂的大问题”是目前最重复出现的强入口

当前不同账号都能看到相近现象：

### Let's Talk Religion
近一年51条当前样本中：
- What Is Alchemy?｜472,941｜约6.18×年度中位数；
- The Mysterious Sabians...｜243,275｜约3.18×；
- The Weirdest Part Of...｜198,392｜约2.59×；
- The Lost Suras Of The Qur...｜180,926｜约2.36×。

标题先给问题 / 奇怪点，再进入复杂宗教史。

### Angela Puca
已知近一年强outlier：
- Your Tradition is Fake. Now What?｜439.53K｜47.96× vidIQ outlier；
- Is Ancient Magic Really More Powerful?｜104.76K｜2.39×；
- This Changes Solomonic Magic Forever｜109.17K｜5.76×。

学术内容被翻译成实践者会真正争论的问题。

### 穹印之源
近一年仅约3条本人正式发布，当前最高：
- 《唐朝人居然也会魔法？一个视频看懂星体魔法世界史》约1.1万；
明显高于同期《星期的起源》2073。

当前只能记为低频单账号信号，但方向和前两者相容。

### 对 Suen 的含义
A｜流量题优先检查：
> **一个完全不懂这个学科的人，看到标题第一句能不能立刻知道“怪在哪里 / 为什么想知道答案”。**

专业术语放到第二层。

## 2｜“熟悉对象 + 意外的一面”比纯陌生术语更有迁移价值

已经出现：
- 唐朝 + 魔法；
- Ancient Magic + old/new；
- Solomonic Magic + “changes forever”；
- Alchemy + “What is”；
- 已知历史人物 / 神名 + 起源变化。

所以当前值得重点测试：
- 牛顿 + 炼金术；
- 医生 + 月亮 / 放血；
- 被偷手套 + 向 Mercury 申诉；
- 熟悉仪式动作 + 一个反直觉要求。

这只是结构迁移，不代表对标题照抄。

---

## 3｜“真假 / 真相”只有在有现实利害时才更强

Angela 的强样本不是纯粹：
> “历史上到底对不对”

而是：
> “如果你的传统历史被证明是假的，你现在怎么办？”

Suen 9/23塔罗起源辨伪在抖音表现偏弱，也说明：
**纯知识纠错不自动等于强冷流量。**

当前更高优先的是：
- 对现实实践有影响；
- 对人物形象有强反差；
- 对普通常识有冲突；
- 有具体对象 / 场景可以第一屏展示。

## 4｜不同 benchmark 承担不同功能，不能混成一个“爆款榜”

### Let's Talk Religion
最适合学：
- 大众问题入口；
- 陌生宗教史如何降低理解门槛。

### 穹印之源
最适合学：
- 中文神秘学标题翻译；
- 中文观众理解速度；
- “熟悉中国历史 / 日常概念 + 魔法反差”。

### ESOTERICA
最适合学：
- 具体文本 / 书 / 手稿如何成为标题主角；
- 高证据密度内容怎么保持大众入口。

### Angela Puca
最适合学：
- 学术争议 → 实践者现实问题；
- 辨伪 / 机制 / “古代 vs 现代”冲突。

### Foolish Fish
最适合学：
- 内容 → 产品 / 会员 / 咨询 / affiliate / sponsor；
- 稳定商业容器，而不是单纯追高播放。

## 5｜当前对今天 P0 的影响

今天 P0：
《一双手套被偷了，罗马人为什么会把诅咒写给墨丘利？》

在当前对标框架里，它不是因为“诅咒片很怪”被选中，而是同时满足：
- 普通人懂“东西被偷”；
- 有明确行动：“向神申诉 / 请求报复”；
- 有真实对象；
- 有原文可证明；
- 可以沿事件继续推进，不是一句话揭晓答案。

因此今天验证的核心仍然是：
**强现实冲突能否改善 Suen 抖音前2—5秒留存。**

对标只能提高立项依据，不能替代发布后的 Suen 第一方真实数据。

## 6｜现代女巫层提供的是“观看体验”，不是历史证据

### 子童-witch
2026年公开题目流非常清楚：
- 3月：新手教程 / 跟做仪式 / DIY；
- 5月以后：制作 / ASMR / 打包 / 盲盒；
- 7—8月：盲勺、黑盐、蜡烛、定制包裹继续系列化。

最值得 Suen 学：
**一个真实商品 / 器物可以连续产生制作、开箱、打包、订单、ASMR、隐藏款等不同观看体验。**

这更适合 Suen 小号和小红书实践层。

**愿望结果 → 简单材料 → 跟做步骤 → 商品自然露出。**

可以参考入口效率和产品出现方式，不能照搬其历史 / 有效性结论。

### 魔女小玉塔罗

> 先有一个真的值得判断的现实问题，再展示“为什么这样判”，而不是从牌义百科进入。

## 7｜同一个“流量”要拆成两种

当前对标越来越支持把高上限入口分成：

### 研究型流量
来自：
- Let's Talk Religion
- ESOTERICA
- Angela Puca
- 穹印之源

核心：
**问题 / 冲突 / 熟悉对象 → 证据解释。**

主要服务 Suen：
- 抖音大号；
- 小红书研究内容。

### 视觉 / 实践型流量
来自：
- 子童-witch
- witchstar星莱
- 水水解忧工作室
- 部分 Foolish Fish

核心：
**制作 / 器物 / 跟做 / 打包 / 参与 → 持续观看与商业兴趣。**

主要服务 Suen：
- 抖音小号；
- 小红书实践与实物层。

这两种不能混成“哪个账号播放高就学哪个”。

大号继续让证据当主体；小号与小红书可以明显吸收视觉满足感和真实工作过程。

## 8｜Let's Talk Religion：当前最完整的“标题入口 × 年度表现”样本

当前51条近一年样本与频道上传总量变化高度吻合，可认真做账号内部比较。

| 标题入口 | n | 中位播放 | 相对年度中位 |
|---|---:|---:|---:|
| 强框架 / 强悬念 | 11 | 146,877 | **1.92×** |
| 明确问题型 | 11 | 93,010 | 1.22× |
| 描述 / 专题型 | 29 | 61,989 | 0.81× |

可见互动中位：
- 强框架 / 强悬念：5.25%；
- 明确问题：4.29%；
- 描述型：5.08%。

因此目前不是“问句一定最好”，而是：

> **把谜团、误解、异常点或真相冲突放到前台，在这个账号的一年样本里同时更容易得到高播放，而且互动没有明显牺牲。**

强框架组有3条达到 ≥3× 年度中位的 high outlier；明确问题型更常落在1—2×的稳定偏强区。

## 9｜ESOTERICA：25条已核视频说明“研究对象可以直接做前台”

当前25条直接可量化主视频临时基线：
- 中位：125,806；
- P75：165,095；
- P90：约406,914。

Hook内部中位：

|---|---:|---:|---:|
| descriptive_topic | 3 | 506,200 | 4.02× |
| strong_mystery | 1 | 137,195 | 1.09× |
| explicit_question | 7 | 127,218 | 1.01× |
| specific_text | 5 | 127,100 | 1.01× |
| specific_object | 1 | 119,844 | 0.95× |
| familiar_unexpected | 2 | 105,907 | 0.84× |
| how_to | 2 | 90,149 | 0.72× |
| person_story | 4 | 63,125 | 0.50× |

这里**不能**因为 descriptive_topic 的3条很高就宣布“描述型最好”。那3条恰好包含《Evolution of Ghosts》《Philosophy of Witchcraft》这类高认知大主题，样本又极小。

更稳定的意义是：
- explicit_question 有7条，整体就在账号临时中位附近；
- specific_text 有5条，也在中位附近，而且 Steganographia 能冲到430K+；
- 高证据密度并不会天然把内容做窄；
- 具体文本 / 书 / 手稿完全可以直接成为大众前台对象。

所以 ESOTERICA 对 Suen 的核心价值仍然是：
**资料主体如何被做成前台，而不是给一个爆款标题词典。**

真正的超大 outlier 仍集中在：

- The Real History of the Green Man｜约10,000；

因此当前最稳的迁移仍然不是“做争议题”，而是：

> **争议是否会改变目标观众的身份、实际做法、有效性判断或下一步选择？**

同时新增数据进一步否定几个过度简化：
- “知名恶魔 / 熟悉对象 + 历史转型”不自动强：Paimon 8,912、Asmodeus 9,405、Necronomicon 14,460；
- “现实冲突”本身也不自动强：Magical Art of Peace 3,749；
- “知识清单”可以中等偏强：Six Models Every Magician Should Know 39,705；
- “实用方法 + 科学/神秘交叉”也可较强：Lucid Dream 48,892。

所以 Angela 对 Suen 的价值是**把学术问题翻译成有现实后果的判断问题**，不是提供一个万能标题词。

## 11｜Foolish Fish：27条直接YouTube样本继续支持“稳定容器 vs 参与容器”

当前27条直接 YouTube 同来源样本：

| 类型 | n | 中位播放 | 中位点赞率 | 播放CV |
|---|---:|---:|---:|---:|
| Esoteric News | 20 | **2,304.5** | **8.22%** | **0.099** |
| Pick a Symbol Tarot | 7 | **2,618** | **13.04%** | **0.316** |

Tarot中位播放约为 News 的 **1.14×**，绝对差距仍不大；更明显的是互动和波动：

- News范围：2,124—3,030；
- Tarot范围：1,902—4,529；
- Tarot播放CV约为News的3.2倍；
- Tarot中位点赞率也更高。

随着News从9条扩到20条，“低波动稳定底盘”仍然成立，因此这已经比早期印象更可靠。

当前功能判断：

> **Esoteric News = 稳定触达 + 商业承载；Pick a Symbol = 更高互动 + 更高波动的参与容器。**

这不是栏目价值排名，而是不同KPI：
- A｜流量可以接受波动、追上限；
- C / D｜商业容器更看重稳定、重复出现和承载能力；
- 商业容器没爆不等于失败；
- 参与型内容点赞高也不等于它适合塞全部商业信息。

## 13｜三类研究 benchmark 已经可以分工，而不是混成一个海外账号模板

### Let's Talk Religion
最有量化支持的是：
**把复杂宗教史翻译成普通人立即理解的谜团 / 问题 / 误解。**

### ESOTERICA
最有价值的是：
**让具体文本、书、手稿、历史魔法对象直接成为前台内容单位。**

### Angela Puca
最有量化支持的是：
**把学术争议变成实践者必须做现实判断的问题。**

这三种功能可以组合，但不能机械混成一种标题：

> **大众入口（LTR） + 资料主体（ESOTERICA） + 现实后果（Angela）**

这会比“找一个国外爆款标题照着改”更适合 Suen。

## 14｜当前对 Suen 爆款选题最有用的检查顺序

一个 A｜流量候选现在优先问：

1. **普通人一眼能懂吗？**
   - 不需要先懂术语。
2. **有具体冲突 / 异常 / 谜团吗？**
   - 不只是“知识点正确答案”。
3. **这个答案有后果吗？**
   - 会改变做法、理解、选择、人物形象，还是知道以后就结束？
4. **有没有真实对象 / 原文 / 手稿承担画面？**
   - 不是纯口述观点。
5. **能不能继续推进至少两三层？**
   - 不是第一句揭晓答案后就没有中段。
6. **和 Suen 最近7天的观看体验重复吗？**
7. **发布后用 Suen 第一方数据验收。**

当前最值得继续测试的短视频方向因此仍然包括：
- 失窃手套 → Mercury诅咒片；
- 1518放血图 → 医生为什么看月亮；
- 牛顿 → 炼金术与炉具手稿；
- 护符为什么贴身 / 靠近身体特定部位。

这些是**数据支持下值得测试的候选**，不是“对标账号证明它们一定爆”。
