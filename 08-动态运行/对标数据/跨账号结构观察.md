# 对标数据｜跨账号结构观察

状态：初版｜随年度数据补齐持续更新  
更新时间：2026-09-24

本文件只写**当前数据已经支持的候选规律**。  
不是永久选题公式，也不能覆盖 Suen 自己的第一方数据。

## 1｜“普通人马上能懂的大问题”是目前最重复出现的强入口

当前不同账号都能看到相近现象：

### Let's Talk Religion
近一年51条当前样本中：
- What Is Alchemy?｜472,941｜约6.18×年度中位数；
- The Mysterious Sabians...｜243,275｜约3.18×；
- The Weirdest Part Of...｜198,392｜约2.59×；
- The Lost Suras Of The Qur...｜180,926｜约2.36×。

标题先给问题 / 奇怪点，再进入复杂宗教史。

### Angela Puca
已知近一年强outlier：
- Your Tradition is Fake. Now What?｜439.53K｜47.96× vidIQ outlier；
- Is Ancient Magic Really More Powerful?｜104.76K｜2.39×；
- This Changes Solomonic Magic Forever｜109.17K｜5.76×。

学术内容被翻译成实践者会真正争论的问题。

### 穹印之源
近一年仅约3条本人正式发布，当前最高：
- 《唐朝人居然也会魔法？一个视频看懂星体魔法世界史》约1.1万；
明显高于同期《星期的起源》2073。

当前只能记为低频单账号信号，但方向和前两者相容。

### 对 Suen 的含义
A｜流量题优先检查：
> **一个完全不懂这个学科的人，看到标题第一句能不能立刻知道“怪在哪里 / 为什么想知道答案”。**

专业术语放到第二层。

## 2｜“熟悉对象 + 意外的一面”比纯陌生术语更有迁移价值

已经出现：
- 唐朝 + 魔法；
- Ancient Magic + old/new；
- Solomonic Magic + “changes forever”；
- Alchemy + “What is”；
- 已知历史人物 / 神名 + 起源变化。

所以当前值得重点测试：
- 牛顿 + 炼金术；
- 医生 + 月亮 / 放血；
- 被偷手套 + 向 Mercury 申诉；
- 熟悉仪式动作 + 一个反直觉要求。

这只是结构迁移，不代表对标题照抄。

---

## 3｜“真假 / 真相”只有在有现实利害时才更强

Angela 的强样本不是纯粹：
> “历史上到底对不对”

而是：
> “如果你的传统历史被证明是假的，你现在怎么办？”

Suen 9/23塔罗起源辨伪在抖音表现偏弱，也说明：
**纯知识纠错不自动等于强冷流量。**

当前更高优先的是：
- 对现实实践有影响；
- 对人物形象有强反差；
- 对普通常识有冲突；
- 有具体对象 / 场景可以第一屏展示。

---

## 4｜不同 benchmark 承担不同功能，不能混成一个“爆款榜”

### Let's Talk Religion
最适合学：
- 大众问题入口；
- 陌生宗教史如何降低理解门槛。

### 穹印之源
最适合学：
- 中文神秘学标题翻译；
- 中文观众理解速度；
- “熟悉中国历史 / 日常概念 + 魔法反差”。

### ESOTERICA
最适合学：
- 具体文本 / 书 / 手稿如何成为标题主角；
- 高证据密度内容怎么保持大众入口。

### Angela Puca
最适合学：
- 学术争议 → 实践者现实问题；
- 辨伪 / 机制 / “古代 vs 现代”冲突。

### Foolish Fish
最适合学：
- 内容 → 产品 / 会员 / 咨询 / affiliate / sponsor；
- 稳定商业容器，而不是单纯追高播放。

## 5｜当前对今天 P0 的影响

今天 P0：
《一双手套被偷了，罗马人为什么会把诅咒写给墨丘利？》

在当前对标框架里，它不是因为“诅咒片很怪”被选中，而是同时满足：
- 普通人懂“东西被偷”；
- 有明确行动：“向神申诉 / 请求报复”；
- 有真实对象；
- 有原文可证明；
- 可以沿事件继续推进，不是一句话揭晓答案。

因此今天验证的核心仍然是：
**强现实冲突能否改善 Suen 抖音前2—5秒留存。**

对标只能提高立项依据，不能替代发布后的 Suen 第一方真实数据。

## 6｜现代女巫层提供的是“观看体验”，不是历史证据

### 子童-witch
2026年公开题目流非常清楚：
- 3月：新手教程 / 跟做仪式 / DIY；
- 5月以后：制作 / ASMR / 打包 / 盲盒；
- 7—8月：盲勺、黑盐、蜡烛、定制包裹继续系列化。

最值得 Suen 学：
**一个真实商品 / 器物可以连续产生制作、开箱、打包、订单、ASMR、隐藏款等不同观看体验。**

这更适合 Suen 小号和小红书实践层。

### witchstar星莱
当前近一年题目同时存在：
- 固定知识系列；
- 节日 / devotional；
- 私定产品与发货。

最值得学：
**系列标签让知识、人格和产品在同一个账号里不显得割裂。**

### 水水解忧工作室
当前样本体现：
**愿望结果 → 简单材料 → 跟做步骤 → 商品自然露出。**

可以参考入口效率和产品出现方式，不能照搬其历史 / 有效性结论。

### 魔女小玉塔罗
当前样本更像：
**大众已经感兴趣的悬疑 / 网络故事 → 塔罗承担判断。**

对 Suen《牌记》的启发是：
> 先有一个真的值得判断的现实问题，再展示“为什么这样判”，而不是从牌义百科进入。

## 7｜同一个“流量”要拆成两种

当前对标越来越支持把高上限入口分成：

### 研究型流量
来自：
- Let's Talk Religion
- ESOTERICA
- Angela Puca
- 穹印之源

核心：
**问题 / 冲突 / 熟悉对象 → 证据解释。**

主要服务 Suen：
- 抖音大号；
- 小红书研究内容。

### 视觉 / 实践型流量
来自：
- 子童-witch
- witchstar星莱
- 水水解忧工作室
- 部分 Foolish Fish

核心：
**制作 / 器物 / 跟做 / 打包 / 参与 → 持续观看与商业兴趣。**

主要服务 Suen：
- 抖音小号；
- 小红书实践与实物层。

这两种不能混成“哪个账号播放高就学哪个”。

大号继续让证据当主体；小号与小红书可以明显吸收视觉满足感和真实工作过程。
