# 对标数据｜跨账号结构观察

状态：当前可用｜生产期封板  
更新时间：2026-09-25

本文件只保留当前数据已经支持、且仍会影响 Suen 选题与平台判断的跨账号观察。

使用顺序固定为：

**Suen 第一方数据 / 当前真实工作与商业状态 → 对标库防撞 → 对标结构参考 → Suen 自己的候选 → 发布后第一方后验。**

benchmark 不负责替 Suen 决定具体讲什么，也不能覆盖第一方真实数据。部分对标账号年度库仍不完整，因此这里只写当前证据能支持到的程度。

## 1｜研究型内容最稳定的共性：先把复杂对象翻译成普通人立即理解的问题

当前核心研究账号里，`explicit_question` 是重复性最好的入口之一：

- Angela：当前重复样本组中位约为同格式基线 1.91×；
- Let's Talk Religion：约 1.22×；
- ESOTERICA：约 1.01×。

这不等于“标题带问号就会更强”。

真正值得迁移的是：

**一个普通人马上能懂的问题 + 一个具体对象 / 动作 + 后面确实还有资料、机制或事件可继续展开。**

Suen 第一方也有对应支持：
- 小红书 9/18《为什么仪式开始之前要先画一个圆？》截至9/25作品列表 5464观看、716赞；此前已确认339藏；9/17—9/24粉丝贡献 +99；
- 这条同时形成了收藏、精准关注和持续放量，是目前最强的实践机制型第一方样本。

因此后续可以继续测试“具体问题 + 具体对象 / 动作”，但不能把候选池机械扩成一排“为什么”。

## 2｜强异常对象仍然适合承担陌生流量入口

Let's Talk Religion 当前 strong_mystery 组明显高于其年度中位，是外部较强信号，但跨账号复现还不够完整。

Suen 第一方已有两个不同平台样本：
- 小红书白色锥体：历史精确快照 55,398观看、CTR 22.8%，属于强陌生流量入口；
- 抖音 9/21 Witch bottle：最新1253播放、2秒跳出34.42%，此前阶段快照5秒完播43.3%、均看14秒，前段理解 / 留存明显优于近期多条内容。

当前可用结论只到：

**一眼能看出“怪在哪里”的真实对象，值得继续作为 A｜流量入口测试。**

它不自动带来最高涨粉。白色锥体本身已经说明，大盘流量与精准关注效率必须分开验收。

## 3｜人物 / 事件 + 强转折值得继续测试，但目前仍是单条第一方强样本

抖音 9/22 Dee / Kelley 截至9/25：
- 1928播放；
- 90赞；
- 23藏；
- +13粉；
- 完播6.18%；
- 2秒跳出36.62%。

它同时成为9/18—9/24七日新增播放贡献第一，是近期抖音最强综合单条样本。

外部 `familiar_unexpected` / person-story 结构并没有跨账号稳定高于各自基线，所以现在不能升级成“人物反差必爆”。

后续真正值得继续找的是：

**人物 / 事件本身有清楚时间线，而且确实存在一个会改变观众理解的强转折，同时有档案、手稿、原文或其它可见证据。**

具体人物仍需先做14账号现有库防撞。原“牛顿 + 炼金术”已经因为 Angela Puca 存在同人物同核心行为内容而淘汰，不再列为当前方向。

## 4｜纯历史辨伪不是当前抖音强冷流量结构

9/23塔罗历史辨伪截至9/25累计：
- 1031播放；
- 27赞；
- 6藏；
- +1粉；
- 2秒跳出41.6%；
- 完播3.07%。

它有讨论，但没有形成强流量、强收藏或强涨粉。

Angela 的 practice_dispute 组虽然存在高上限，内部跨度也很大。当前更值得迁移的是：

**这个问题会不会真的改变目标观众下一步怎么做、怎么判断、怎么选择。**

因此“纠正一个历史说法”不能因为有争议就自动当 A｜流量题。存在真实实践后果时，才值得进一步测试。

## 5｜原文 / 具体文本更适合精准关注与专业识别，不自动等于冷流量

外部现有样本里，specific_text 本身并没有稳定高于比较基线。

但 Suen 第一方《第二木星星符到底写了什么？》仍是很清楚的精准关注样本：
- 9/25作品列表1694观看、198赞；
- 此前已确认66藏；
- 近30日粉丝贡献 +48。

所以原文、手稿、星符、PGM 等内容继续值得做，但前台要把“这份资料为什么值得看”翻译出来。

当前用途更接近：
**B｜精准关注 / 收藏 / 研究品牌识别。**

## 6｜研究型 benchmark 与视觉 / 实践型 benchmark 必须分开用

### 研究 / 历史层
Let's Talk Religion、ESOTERICA、Angela Puca、穹印之源主要帮助判断：
- 普通人入口；
- 具体文本 / 文物 / 手稿怎么前台化；
- 研究争议如何转成有现实后果的问题；
- 高证据密度内容如何继续推进。

### 视觉 / 实践层
子童-witch、witchstar星莱、水水解忧工作室等主要帮助观察：
- 制作过程；
- 器物视觉；
- 打包 / ASMR / 跟做；
- 商品如何自然出现；
- 同一真实工作如何形成不同观看体验。

这两类不能混成一个“谁播放高就学谁”的榜单。

Suen 大号继续让资料与判断做主体；小号 / 小红书实践层可以明显吸收真实制作和器物过程。

## 7｜Foolish Fish 更适合参考“固定容器如何承担商业”，不是拿来找爆款题

当前资料更支持：
- Esoteric News 承担稳定更新与 sponsor / affiliate / membership / consultation 等商业连接；
- Pick-a-Symbol Tarot 更偏参与与互动；
- Book Review / roundup 自然承接书籍 / affiliate；
- Patreon 节点承接会员、课程、月度活动与咨询优惠。

对 Suen 的意义是：

**商业节点可以有自己的容器，不需要每条专业研究内容都硬接销售。**

这和当前“每天原则上只保留一个主要商业信号”“大号不为了高客单改成接单号”一致。

## 8｜成熟研究账号反复出现“主内容之外的二次入口”，但不能复制发布频率

当前供给结构可以确认：
- Angela：当前去重已知下限108个独立事件，其中50条主内容、58条独立附加上传；
- ESOTERICA：滚动365天当前上传下限至少80；2026 YTD 59条中已恢复56个身份（43 Long/live + 13 Shorts），剩余3个 Long-form unresolved；
- Foolish Fish：固定 News / Tarot / 书评 / Patreon 节点长期并行。

可迁移到 Suen 的不是“多发”，而是：

**一份已经做过的真实研究 / 工作，后续是否还有第二个观看体验真正不同的入口。**

例如星符制作可以分别留下原典问题、真实制作片段、材料判断、完成品，但每个平台仍要独立判断，不能把一份稿子机械复制过去。

## 9｜第一方数据已经把两个平台的任务拉开

### 抖音大号
9/18—9/24：
- 2秒跳出44.93%；
- 5秒完播37.41%；
- 均看12.41秒；
- 净增27。

与上一周期相比，前2—5秒更弱，但均看和净增改善。

因此当前最主要的问题仍是：
**前2—5秒让人更快理解为什么值得继续看。**

不能再笼统写成“中段也全面恶化”。

### 小红书
9/17—9/24：
- 新增关注188；
- 当前总粉丝468；
- 主页访客476；
- 主页转粉率12.8%；
- 新增关注74.5%来自视频推荐。

当前已经不是“先证明能不能精准涨粉”的阶段。

下一步更值得观察：
- 强内容能否继续复制高质量关注；
- 搜索与收藏能否逐步形成稳定入口；
- 新增长能不能进一步走到服务理解、询盘与首次付费。

## 10｜当前生成新候选时的检查顺序

候选题生成时依次检查：

1. Suen 最近真实在研究 / 制作 / 服务什么；
2. 最近7天各平台已经发了什么，避免观看体验连续重复；
3. 第一方强弱样本说明当前缺什么；
4. 当前商业阶段是否需要补服务认知、执行证据或结果证据；
5. 14个对标账号现有库是否撞到同一人物、事件、文物、文本、recipe 或核心争议；
6. benchmark 是否支持这个入口值得测试；
7. 正式定题再过证据、素材、栏目与硬门槛；
8. 必要时才做塔罗盲测，发布后以真实数据后验。
