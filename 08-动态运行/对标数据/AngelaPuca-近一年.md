### 对数据工程的意义

Angela 后续不再优先补“她这一年到底发了什么”，而是：
1. 给这50条逐条补 YouTube URL / video ID；
2. 补 views / likes / comments；
3. 标 `essay / interview / livestream / promo / shorts`；
4. 把当前24条数值样本嵌回50条全清单；
5. 最后才能比较同样标题结构在不同格式中的真实表现。

### 重复直播页处理规则

YouTube 公开检索中，Angela 部分直播会同时出现：
- 普通标题的完整直播页；
- 带 📱 标记的另一 watch ID / 竖屏或并行直播页。

本年度库按**一次内容事件只计一个主样本**处理：
- 优先计普通标题的主直播页；
- 📱 重复页保留在备注，不进入年度行级样本数；
- 不把两个 watch ID 的播放相加；
