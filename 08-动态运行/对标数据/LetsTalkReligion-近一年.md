## 当前可见结构信号｜只作候选，不升级为永久公式

从这一批数据能先看到几个值得继续编码的方向：

1. **普通人立刻能理解的大问题**可以跑得很高，例如“What Is Alchemy?”属于全年极强样本；
2. **神秘 / 争议对象 + 明确问题**比纯内部学术标题更容易出现高上限；
3. **被遗忘 / 被误解 / 真相 / 最奇怪部分**这类入口多次出现在高表现区，但要继续区分题材本身与标题结构；
4. 纯旅行 / 现场记录、频道里程碑、较窄人物专题在当前样本里更容易落到中位数以下，但不能只凭单条定性；
5. 后续需要为51条逐条补 `hook_type / topic / first_screen_type / story_structure`，再做真正的结构统计。

### 当前最值得注意的信号

> **同样是复杂宗教 / 历史内容，先把最值得普通人好奇的冲突、谜团、误解或问题写到标题前台，比纯描述型专题更值得优先测试。**

区别不在“标题党”，而在：
**标题先把普通人应该好奇的那一层说出来。**

当前解释：

- **明确问题型**比描述型有更高的播放中位数，但可见互动中位数没有同步提高；
- **强框架 / 强悬念型**同时拥有最高播放中位数和略高的可见互动中位；
- 描述型虽然播放中位较低，但留下来的观众并不一定低互动。

所以当前更精确的候选规律不是：
> “问句标题一定更好。”

而是：
> **问题句更像降低点击门槛；真正把播放和互动一起拉高的，当前更像“有明确谜团 / 误解 / 真相 / 异常点”的入口。**

仍然不能做因果结论，因为题材认知度、封面、时长没有控制。
