# 对标数据｜爆款结构证据表

状态：当前可用｜随年度数据补齐更新  
建立：2026-09-24

用途：只保留**当前已经有数据支持、可以直接辅助 Suen 选题**的结构，不把“账号风格印象”当证据。

这不是标题模板库，也不是保证爆款公式。

## 跨账号统一编码v1｜当前最稳的重复入口

基于 `核心5账号-统一编码v1.csv` 当前160条可比行：

### explicit_question｜当前跨账号一致性最好

- Angela's Symposium：n=5，组中位约 **1.91×同格式基线**；
- Let's Talk Religion：n=11，组中位约 **1.22×**；
- ESOTERICA：n=7，组中位约 **1.01×**。

这是当前唯一一个在3个核心账号都有重复样本，且三者组中位都没有低于各自比较基线的Hook。

但它不能被简化成“问句一定高播放”。结合 Suen 第一方数据，更合理的工作结构是：

> **普通人马上能懂的具体问题 + 明确对象 / 动作 / 后果 + 后面还有第二层机制或原始资料。**

第一方对应：
- 小红书《为什么仪式开始之前要先画一个圆？》：4718观看 / 643赞 / 339藏 / +78粉；
- 9/23塔罗历史辨伪则是反例：有纠错问题感，但缺强对象/强后果，抖音前段没有跑强。

因此后续优先测试“具体为什么问题”，而不是机械加问号。

### 其它Hook暂不升级
- familiar_unexpected：3账号有重复，但Angela低、ESOTERICA略高、穹印高，跨账号不稳定；
- descriptive_topic：4账号有重复，只有ESOTERICA两条大题异常高，明显受小样本影响；
- person_story：Angela偏上、ESOTERICA偏下；
- specific_text：Angela与ESOTERICA组中位都低于基线，说明“具体文本”本身不是自动流量入口。

## A｜当前证据最强：把“谜团 / 异常 / 误解”放到标题前台

### Let's Talk Religion｜51条年度行级样本

当前全样本：
- 播放中位数：**76,552**；
- 中位可见互动率（赞+评）：**4.90%**；
- 中位点赞率：**4.16%**。

以当前机器表 `hook_class_v1` 为唯一正式标题入口编码：

| Hook | n | 中位播放 | 相对年度中位 | 中位可见互动率 |
|---|---:|---:|---:|---:|
| strong_frame｜强框架 / 强悬念 | 11 | **146,877** | **1.92×** | 5.25% |
| explicit_question｜明确问题 | 11 | **93,010** | 1.22× | 4.29% |
| descriptive｜描述 / 专题 | 29 | **61,989** | 0.81× | 5.08% |

当前解释：
- 不是“问句一定最好”；
- 当前一年里，**把谜团、误解、极端点、真相冲突直接放在前台**的 strong_frame 中位播放最高；
- strong_frame 的中位互动率并没有明显牺牲，至少当前样本不支持“强入口必然低互动”；
- explicit_question 整体偏强，但远没有 strong_frame 稳定；
- descriptive 里仍然能出现巨大爆款，因此题材认知度和主题本身不能被标题编码替代。

### Angela 的格式分层

当前45条量化样本：
- long_form 32条，中位 **25,041.5**；
- interview/livestream 13条，中位 **2,876**。

所以外部“爆款结构”判断以后优先在同格式内比较。  
混合总中位9,405只描述账号一年里所有公开发布事件的整体分布，**不能拿它直接当研究长视频基线**。

当前解释因此收紧为：

> **不是“有争议 / 有现实冲突 / 有熟悉对象就强”，而是问题是否真正触及目标观众的身份、有效性、做法或下一步选择。**

这组数据反而让规则更稳：
- practice_dispute 可以产生极高上限，但不是低风险模板；
- familiar_unexpected 当前4条样本中位约12,497.5，约为临时全样本中位1.33×；
- real_world_conflict 当前只有1条，而且很低；
- 标题结构必须和受众利害、题材认知度、第一屏与内容推进一起判断。

对 Suen：
- 《隐理》《辨伪》《牌记》可以继续找“现实后果”；
- 但不能机械制造争议；
- “现实冲突”只作为候选入口条件，不再单独视为爆款证据。

## B｜精准关注 / 收藏：不能只靠强标题

Let's Talk Religion量化已经出现：
- 强问题 / 强好奇结构播放更高；
- 但点赞率、评论率没有同步更高。

所以 B｜精准涨粉至少还需要：
- 真实稀缺资料；
- 明确新知识；
- 可收藏的信息；
- Suen自己的判断能力；
- 看完后知道“关注这个账号以后还能得到什么”。

这与小红书《魔法圆》强收藏 / 强涨粉样本一致：
**入口负责进人，资料价值负责留下人。**

# 当前用于选题的优先检查

一个新的 A｜流量候选，优先问：

1. 普通人第一秒能理解问题吗？
2. 有没有现实冲突 / 熟悉对象 / 意外行为？
3. 标题是在讲“研究对象”，还是已经翻译成“为什么我要知道”？
4. 正文是否还有第二层、第三层推进，而不是答案一句就结束？
5. 第一屏有没有真实视觉对象？
6. 这个题只是会点，还是也有关注 / 收藏理由？

满足1—4更像流量候选；
5—6决定它有没有机会同时变成强样本。

# 当前不能做的事

- 不把以上结构排成永久“爆款排名”；
- 不说某个关键词本身导致播放；
- 不跨账号直接比绝对播放；
- 不因为 Angela 的大标题强，就把 Suen 写成争吵型账号；
- 不因为子童制作内容多，就让 Suen 大号变成商品号。

**所有外部证据最后都要回到 Suen 自己发布后的真实数据验收。**
