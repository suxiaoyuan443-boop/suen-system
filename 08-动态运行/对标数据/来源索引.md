# 对标数据｜来源索引

更新时间：2026-09-24

用途：记录年度对标库使用的公开来源、数据口径与限制。

## YouTube / 英文账号

### YouTube 原始视频页 / YouTube 搜索结果
用于：
- 单条视频准确标题；
- 发布日期；
- 当前累计播放；
- 点赞；
- 视频ID / URL；
- 时长（可取得时）。

优先级：
**单条 YouTube 原始视频页 / 搜索结果 > 第三方单条视频估算。**

如果第三方与 YouTube 当前累计值不同：
- 先检查抓取日期；
- 视为动态累计变化，不自动判某一方错误；
- 文件中保留较新的当前值，同时注明旧快照口径。

### Podcast / Apple Podcasts / Spotify / Podcast Republic
只在对应内容与 YouTube 主内容可确认是同一主题时，用于补：
- 日期；
- 时长；
- 题目。

不能：
- 用播客发布日期直接覆盖 YouTube 发布日期；
- 用播客分发量代替 YouTube views；
- 在不同平台日期冲突时自行挑一个。

### Social Blade
当前用于：
- ESOTERICA 当前频道总播放 / 视频数的交叉核验；
- 观察短期视频总数变化。

限制：
- 当前总量会随抓取时间变化；
- 不直接提供完整近一年行级视频表；
- 第三方当前值和vidIQ不同步时，保留两套时间戳，不强行选一个覆盖另一个。

限制：

- 不把无法确认时间标签的一组数据写成“近一年正式统计”。

## 使用优先级

同一个指标发生冲突时：

1. 平台官方后台 / 作者自己公布的后台截图；
2. 作者自建归档的精确记录；
3. 平台公开页；
4. 可追溯第三方统计；
5. 搜索结果摘要 / 转载页；
6. 仅用于题目结构的代理清单。

不同来源只要口径不同，就并列保存，不强行合并成一个“正确数字”。

最终目标：

**每一个对标结论都能回答：这个数字从哪来、抓取什么时候、是什么口径、能证明什么、不能证明什么。**

## 同一内容跨平台重新分发去重

年度库已经遇到真实案例：
ESOTERICA《What is Spiritual Alchemy?》的 YouTube 原视频为 2025-11-14，但播客聚合页在 2026 年重新出现。

统一规则：
- 同一内容如果有 YouTube 原视频，YouTube 首发日期作为视频年度归属；
- RSS / Podcast / Apple / Spotify 后续重新分发记为 syndication，不新增一条 YouTube 样本；
- 标题略改但描述 / 音轨明显相同，也先查是否为旧内容重发；
- Patreon“Early Access”只有在能与对应新视频匹配时才作为预发布时间辅助；
- 不允许同一内容因为跨平台日期不同被重复计入年度发布数。


## 同题不同平台版本

同一标题 / 同一研究主题可能在：
- YouTube；
- Podcast；
- Substack；
- Patreon；
- 直播回放

出现不同长度、不同剪辑或不同发布日期。

真实案例：
Angela Puca《Can AI Become a Magical Familiar?》
- Podcast：2026-07-19，50:58；
- Substack：2026-07-21；
- Substack内嵌YouTube ID：83KoQMVvnZA；
- YouTube章节可见时长明显短于播客版。

因此：
- 同主题可共享一个 `topic_id`；
- 每个平台版本分别保存 `platform_publish_date / platform_duration / platform_url`；
- 只有能确认是完全相同媒体文件时，才允许合并时长；
- 不用Podcast长度解释YouTube观看表现。


## 搜索索引数值冲突

已经出现真实案例：
穹印之源同一条《2026全球预测大赛》在不同 Bilibili 公开搜索快照中出现 **3,492 / 12,531 / 13,681** 三个互相冲突的数值。

统一处理：
- 搜索页优先用于确认发布顺序、标题、日期、时长；
- 关键播放值如果不同快照不满足累计播放的单调性，标记为 `conflict`；
- 原始冲突快照全部保留；
- 不自行挑最大、最小或“看起来最新”的一个当真值；
- 能取得原视频页 / BVID 后，以原视频页优先；
- 冲突未解决前，该条退出定量中位数 / P75 / P90计算，但仍保留题目结构样本。
