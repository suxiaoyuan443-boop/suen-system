## 三个账号放在一起后，真正重复出现的结构

不是“多发”本身，而是：

### 1. 主内容与二次入口分开
Angela最清楚；ESOTERICA近期切片也显示主研究只占部分上传。

### 2. 商业节点可以独立存在
Angela有课程 / 书 / 活动上传；ESOTERICA有古籍目录 / giveaway；Foolish Fish用News与书评承接affiliate / sponsor / membership。

### 3. 公开品牌允许多格式并行
研究型账号不必为了统一风格只保留一种视频：
- 长研究；
- seminar；
- live；
- 具体问题；
- 书评；
- 参与型；
- promo节点
可以共存，只要各自任务清楚。

### 4. 不能把所有内容用同一个KPI验收
- 主研究：流量 + 专业品牌；
- 卫星 / 问题入口：触达与入口翻译；
- seminar：课程式连续供给；
- News：稳定 / 商业容器；
- Tarot participation：互动；
- promo节点：商业 / 社区事件。

## 对 Suen 当前最可迁移的版本

不是增加大号日更次数，而是：

> **一份已经做过研究的资产，后续是否还有第二个“观看体验不同”的入口。**

可迁移方向：
- 《文物》主片 → 同一对象的一个异常细节；
- 《残页》完整拆解 → 其中一句“到底写了什么”；
- 《隐理》完整机制 → 一个最具体的“为什么要这样做”；
- 人物故事 → 一个档案 / 手稿 / 行为切口；
- 星符 / 护符真实制作 → 准备、材料、局部、完成品、打包等不同观看体验（更适合小号 / 小红书）。

硬限制：
- 大号仍执行六栏目路由，不为了复用强行重复同题；
- 同一题材必须改变观看体验，而不是只换标题；
- 每个二次入口仍需独立通过事实核查与平台任务判断；
- 商业节点单独承接，不让所有研究视频突然加硬CTA。
