# Suen｜爆款结构证据分层 v1

状态：2026-09-25 当前证据版  
用途：把核心5账号年度/准年度结构统计，与 Suen 自己的一方真实样本合并。  
这不是永久爆款公式，也不直接等于正式选题池。

## 0｜使用顺序：先 Suen，再 benchmark

从 2026-09-25 起，这份结构表只按下面顺序使用：

1. 先从 Suen 自己已有的研究资产、真实内容数据、课程 / 数据库边角材料、现实服务判断中找**具体对象**；
2. 用当前全部14个对标账号已取得的年度库 / 题目流做撞题检查；
3. 撞到同一人物 + 同一事件、同一文物、同一文本、同一 recipe 或同一具体争议，默认换对象，不靠改标题规避；
4. 只有通过防撞以后，再用下面的结构数据判断入口值得不值得测试；
5. benchmark 负责回答“这种入口结构是否值得测”，不负责回答“Suen 应该讲什么”。

部分对标账号年度库仍不完整，因此防撞结论只能写“现有库未发现同题”，不能写成绝对没有做过。

## 当前最值得保护的原则

外部统一编码和第一方数据合起来以后，最清楚的不是“某个题材最强”，而是：

**入口负责让人进来，原始资料 / 机制 / 判断负责让人留下来。**

因此后续高上限候选优先满足：
1. 第一秒就有普通人能懂的问题、异常对象或冲突；
2. 后面有真实第二层推进，不是一句话就能讲完；
3. 至少有一个可见的真实对象 / 原图 / 手稿 / 文物 / 行为；
4. 流量、收藏、涨粉、询盘分开验收。
