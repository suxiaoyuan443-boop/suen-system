# Suen｜爆款结构证据分层 v1

状态：2026-09-25 当前证据版  
用途：把核心5账号年度/准年度结构统计，与 Suen 自己的一方真实样本合并。  
这不是永久爆款公式，也不直接等于正式选题池。

## 0｜使用顺序：先 Suen，再 benchmark

从 2026-09-25 起，这份结构表只按下面顺序使用：

1. 先从 Suen 自己已有的研究资产、真实内容数据、课程 / 数据库边角材料、现实服务判断中找**具体对象**；
2. 用当前全部14个对标账号已取得的年度库 / 题目流做撞题检查；
3. 撞到同一人物 + 同一事件、同一文物、同一文本、同一 recipe 或同一具体争议，默认换对象，不靠改标题规避；
4. 只有通过防撞以后，再用下面的结构数据判断入口值得不值得测试；
5. benchmark 负责回答“这种入口结构是否值得测”，不负责回答“Suen 应该讲什么”。

部分对标账号年度库仍不完整，因此防撞结论只能写“现有库未发现同题”，不能写成绝对没有做过。


## A｜双重支持，可优先继续验证

### 1. 具体问题 + 具体对象 / 动作

外部：
- Angela `explicit_question`：5条，中位约 **1.91×同格式基线**；
- Let's Talk Religion：11条，约 **1.22×**；
- ESOTERICA：7条，约 **1.01×**。

这是当前唯一一个在3个核心账号都有重复样本、且三者组中位都没有低于各自比较基线的 Hook。

第一方：
- 小红书《为什么仪式开始之前要先画一个圆？》：9/25作品列表5464观看、716赞；此前已确认339藏；9/17—9/24粉丝贡献+99；
- 已经同时形成收藏、精准涨粉和持续放量，而且后续分发没有把关注转化冲掉。

当前真正可迁移的不是“标题带问号”，而是：
> **普通人马上听懂的问题 + 一个具体对象 / 动作 + 后面还有机制或原始资料可展开。**

当前活跃池已经出现4/5明确问句，因此后续不再把 `explicit_question` 机械扩写成更多“为什么……”候选；需要主动保留强异常对象、故事或其它非问句入口。

## B｜有价值，但用途必须分清

当前用途：

以后不再把“原文题”默认当A流量题；它要想冲冷流量，前台仍需做普通人入口翻译。

当前可继续验证：《古埃及魔法文本里，施术者为什么会直接说“我是荷鲁斯”？》；它用原文承担证据，但前台主问题是身份 / 权威机制，不把“具体文本”本身当流量保证。

### 4. 实践争议 / 现实选择后果

外部：

第一方反例：

因此当前结构必须收紧成：
> **真正影响“我该怎么做 / 这套东西还有效吗 / 下一步怎么办”的问题**，而不是“历史上这个说法错没错”。

当前用途：

当前可继续验证：《为什么有些行星星符不能想做就做，还要等到特定时辰？》；重点是“制作条件会改变下一步怎么做”，不复制 Angela 的任何具体争议题。

不能把“曾经锁定P0”当成已经完成实验。

## 当前最值得保护的原则

外部统一编码和第一方数据合起来以后，最清楚的不是“某个题材最强”，而是：

**入口负责让人进来，原始资料 / 机制 / 判断负责让人留下来。**

因此后续高上限候选优先满足：
1. 第一秒就有普通人能懂的问题、异常对象或冲突；
2. 后面有真实第二层推进，不是一句话就能讲完；
3. 至少有一个可见的真实对象 / 原图 / 手稿 / 文物 / 行为；
4. 流量、收藏、涨粉、询盘分开验收。
