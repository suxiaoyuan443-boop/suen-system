### 4. 实践争议 / 现实选择后果

外部：

> **真正影响“我该怎么做 / 这套东西还有效吗 / 下一步怎么办”的问题**，而不是“历史上这个说法错没错”。

当前用途：

## 当前最值得保护的原则

外部统一编码和第一方数据合起来以后，最清楚的不是“某个题材最强”，而是：

**入口负责让人进来，原始资料 / 机制 / 判断负责让人留下来。**

因此后续高上限候选优先满足：
1. 第一秒就有普通人能懂的问题、异常对象或冲突；
2. 后面有真实第二层推进，不是一句话就能讲完；
3. 至少有一个可见的真实对象 / 原图 / 手稿 / 文物 / 行为；
4. 流量、收藏、涨粉、询盘分开验收。
