## 原始迁移资料

Slack 原始迁移归档位于：

`../历史/2026-09/`

正常工作不要读取。

只有以下情况才回原始归档：
- 结构化基线缺字段；
- 两条记录冲突；
- 需要核对旧消息原话；
- 审计迁移是否遗漏。

## 比较规则

- 不同统计时点不能假装同一窗口；
- 视频与图文先分开比较；
- 单条爆款不直接固化成长期公式；
- 同一内容有多次快照时，保留阶段复盘与后续累计的区别；
- 询盘 / 成交只有可靠确认来源时才归到具体内容；
- 未知数据不估算。

## 新数据怎么写

事实写入触发统一执行 `00-系统总控/每日总结与更新工作流.md` 四-A：Suen在普通总控对话明确确认的发布、交付或质量反馈也要写回，不要求重复说“总结”。生产事实与发布样本分别记录。

真实内容事实发生后：

1. 首先写当月 `YYYY-MM.md`；
2. 如果改变当前判断，更新 `当前状态.md`；会影响接管的变化同步总览必要摘要，不复制完整过程；
3. 历史基线不要求每次发布都立即重写；
4. 当样本量足够、需要重新总结第一方规律时，再更新对应平台历史基线。
