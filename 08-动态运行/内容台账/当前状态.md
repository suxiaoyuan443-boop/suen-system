- 一句底层机制答案：**古埃及这类治愈实践并不把石碑上的神像与咒文当成被动的“说明图”和文字，而把它们放进与神庙 cult image 同类的有效图像 / 有效言语逻辑中：图像使神圣力量与胜利状态具象在物体上，咒文以 performative speech 重演并调用神话先例；水与这一被仪式化的图像—文字复合体接触，被认为承接其效力，再通过饮用或涂抹把这份效力作用到患者身上。**
- 底层机制链：
  1. **图像不是纯象征。** Ritner 将 Horus cippi 放在长期的 Egyptian “healing images” 连续谱系中，并明确说，这类治愈图像被认为有效的底层理由与神庙 cult image 并无不同；在古埃及观念中，图像可以作为神圣力量的有效中介，而不只是“画了一个神”。
  2. **文字也不是纯说明。** Ritner 把 Egyptian magic 明确拆成 speech / property / rite；Liverpool 也直接强调 spoken word 的 effectiveness / performativity。咒文在仪式里是行动的一部分，不只是解释发生了什么。
  3. **图像与咒文共同重建一个已经成功解决过的神话事件。** Horus 被毒物 / 危险攻击又被治愈，是 cippi 反复调用的 mythic precedent；患者的当下危机被嵌入这个已有成功结局的神话结构。
  4. **接触是效力进入物质媒介的节点。** ISAC 明确说，患者饮用流过石碑表面的水，因为水经与刻出的 images and spells 接触而被“charged”；Met 也说这类水会被“transformed into a curative remedy”。
  5. **饮用 / 涂抹让仪式效力进入患者身体。** 因而“喝水”不是第二个独立迷信动作，而是把前面已经在图像—咒文—神话先例中建立的治愈效力，通过物质媒介落实到患者身上的最后一步。
- 关键底线：
  - 不写成“石碑释放能量，水吸收能量”；
  - 不把 ḥkꜢ / heka 简化成现代“能量”；
  - 不把“我是荷鲁斯”硬写成水变有效的直接原因；ritual identity 可作为相关底层机制旁证，但除非具体 cippus 文本建立直接链条，否则不并入主因果链；
  - 不说所有古埃及魔法都按这一套运作，只限定 Horus cippi / healing images 及有对应证据的治疗实践。
- 证据层：

#### 02｜1590 Edmonton conjurers｜《异录》｜符合，但有“档案清单化”风险
- 《异录》要求“这个真实故事值得从头听到尾”，人物、行动、时间线、转折与结果必须是推进骨架。
- 本题具备：被撞见正在 conjuring → 一人逃跑 → 追踪 / ratsbane → 一人被抓 → 搜出物品 → 讯问 → 保释等待后续 sessions。
- 死红公鸡、Satan水晶、王冠、权杖等应作为故事中的现场发现，不得把正文写成“1590年的魔法用品清单”。
- 成稿红线：如果超过主要篇幅都在逐项介绍物件用途，人物行动与搜捕线变成包装，则不再像《异录》；专用对话必须重写为事件推进，而不是硬保栏目。
- 结论：**栏目正确，调性成立，但依赖成稿保持说书式事件推进。**

#### 03｜Uley失窃手套｜《残页》｜高度符合
- 《残页》的核心是“这一句 / 这一段原文到底写了什么”，原页与具体词句必须不可替代。
- 本题真正有价值的就是八行文字本身：“交给 Mercury”“失窃手套”“blood and health”“尽快实现”等具体表达。
- 五次折叠、Uley出土环境与同地点近百张铅片只做上下文，不抢原文主角。
- 成稿必须实际给出定位、原文 / 转写、工作译文、中文译义和关键词说明；不能只把原文当一张背景图，再讲罗马诅咒文化。
- 结论：**非常符合《残页》调性。**

#### 04｜Horus cippi 治愈水｜《隐理》｜符合，但必须防止“文物化”
- 《隐理》主角必须是“大家已经默认会做的一步为什么存在、起什么作用”，不是某一件 cippus。
- 本题前台动作成立：水先接触刻有图像 / 咒文的治疗石碑，再被饮用或涂抹。
- 当前机制链可以在拿掉任意单一馆藏以后继续成立：effective image / ritual speech → mythic precedent → material contact → ingestion / application。
- 成稿红线：不能围绕某一件 Met / BM cippus 的年代、尺寸、图像细节讲太久；这些只是机制证据。如果观众最后记住的是“某块石碑很特别”，就漂成《文物》。
- 结论：**符合《隐理》调性；必须让“为什么这一步会被认为有效”始终是正文主轴。**

#### 05｜Maqlû VII 183–203｜《残页》｜条件符合，必须缩到具体段落
- 如果题目是“Maqlû整套反巫术仪式如何烧人偶、为什么这样做、后半夜如何净化”，价值中心会变成整套仪式 / 机制，已经不再像《残页》。
- 要保留《残页》，主角必须明确缩到 **Maqlû VII 183–192、200–203** 这一组具体咒文：黏土 / 油脂人偶在火中的动作、对 Fire-god 的呼唤、原文使用的毁灭 / 熔化 / 裁决表达，以及可靠译文怎样处理。
- ritual tablet、整夜仪式、后半夜净化只作为必要上下文，不能成为主体。
- 成稿红线：如果不逐行 / 逐词解释这组具体文本，而主要讲“巴比伦人怎样做反巫术”，应退件重路由，不能继续标《残页》。
- 结论：**当前选题可以属于《残页》，但必须把题目收窄为具体行段；这是5支中栏目漂移风险最高的一支。**

### 本轮栏目结论
当前无需为了凑齐六栏目再补《辨伪》或《牌记》；GitHub规则明确不机械轮播。

栏目匹配排序：
