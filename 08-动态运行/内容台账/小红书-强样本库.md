# 小红书｜强样本库

更新时间：2026-09-25
用途：记录已经跑出明显强信号的小红书内容，用于拆入口、视觉、观看、收藏、涨粉和商业潜力。
这不是“爆款排行榜”，不同样本可以分别在不同指标上成立。

## 使用原则

- 第一方真实数据优先；
- 单条高播放 ≠ 一定是高价值样本；
- 播放、收藏、涨粉、主页承接、询盘分别判断；
- 强样本只提炼结构，不机械复制题目；
- 新样本进入后，优先在未来 1—2 周测试 2—3 个“结构相邻、题材不同”的候选；
- 如果后续有真实询盘 / 成交能可靠归因，再补充商业价值，不倒推归因。

## 强样本进入标准

新内容满足以下任一情况，可候选进入本库：

- 明显高于近期账号播放 / 曝光基线；
- 收藏或涨粉效率明显高于近期其它内容；
- 在继续放量后仍保持较高收藏 / 关注；
- 带来可确认的主页访问、有效询盘或成交；
- 一个新内容结构在多条样本里开始重复成立。

进入后必须记录：
- 原始数据；
- 信号类型；
- 当前判断；
- 不能证明什么；
- 下一步该测试什么。
