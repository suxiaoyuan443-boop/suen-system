### 1. 《为什么护符经常要贴身佩戴，甚至要靠近身体出问题的位置？》
【栏目：隐理】  
状态：高优先候选

观看体验：熟悉物件 → 实践机制

现实依据：
当前缺一个真正低门槛的机制题；“为什么护符要贴身”无需神秘学背景，也可延续《魔法圆》验证过的“反直觉实践动作 + 为什么”结构。

对标参考：
- 核心5账号统一编码v1：`explicit_question` 当前在 Angela / Let’s Talk Religion / ESOTERICA 三个账号的重复样本组中位均未低于各自比较基线；
- Suen 第一方强样本《为什么仪式开始之前要先画一个圆？》已经验证“普通人能懂的问题 + 反直觉实践动作 + 原始资料”可带来高收藏与精准涨粉；
- ESOTERICA 继续作为证据组织参考：跨传统保留差异，不造万能通则。

结构证据v1：
**A｜外部跨账号 + 第一方双重支持。**
本题真正测试的不是“问句”，而是“为什么要贴身”这个具体动作能否像魔法圆一样形成低门槛机制入口。

机制证据起点：
- The Met 的 Ancient Egyptian Amulets 说明，古埃及护符通常被佩戴或放置在身体上，并明确把这种贴身使用解释为让护符所被赋予的作用直接施加于主人；
- Christopher A. Faraone 关于古典—晚期古代身体护符位置的研究摘要进一步指出，罗马与晚期古代医疗 / 魔法手册中的治疗性护符常尽量靠近疼痛或失调部位，例如痛风护符系在脚踝、肾脏护符靠近髋部；
- 因而本题已有“贴身”与“靠近问题部位”两层机制证据，不需要用现代泛能量说补解释。

风险：
不能统一解释成现代“能量接触”；保护、治疗、死者语境必须分开。

资产复用：公众号 / 护符机制专题。

入口主要会吸引谁：已经接触过护符、正在考虑购买 / 使用护符、或对实际制作与佩戴方式有明确兴趣的人；比纯历史猎奇更接近“已有消费经验 / 明确实践需求”的人群，但不把它直接等同于购买意愿。

对标撞题检查：核心5统一编码库当前未见以“护符为什么贴身 / 为什么靠近患处”为同一核心问题的内容；允许迁移明确问题结构，不迁移任何 benchmark 的具体对象。

### 2. 《牛顿为什么会认真研究炼金术，甚至自己画炼金炉？》
【栏目：异录】  
状态：高优先候选

观看体验：熟悉人物 → 意外身份 / 行为 → 手稿证据

- “牛顿”本身降低陌生人理解成本；
- “科学史熟人 + 炼金术实验 / 炉具草图”形成强反差，不需要先懂神秘学；
- Cambridge University Library 的 Newton Exhibition 明确记载：Newton 1660年代末开始阅读炼金术书，并在 King’s College, Cambridge, Keynes MS 62, f.4r 中抄录炼金文本、画出蒸馏水银所需的器皿与炉子；
- Cambridge Repository 保存 Newton 的 chemistry / alchemy experiment notes，可作为后续研究入口。

栏目路由：
人物与事件 / 研究活动是主角；拿掉 Newton 本人后题目价值大幅下降，因此归《异录》。

对标基线：
- 统一编码v1显示 `familiar_unexpected` 当前跨账号并不稳定：ESOTERICA 4条组中位约1.09×，Angela 4条约0.50×，穹印之源2条约1.87×；

- 因此本题不能再以“名人 + 神秘学反差”本身作为强流量证据，真正的加分项是 **牛顿这一高认知人物 + 炼金炉草图 / 实验笔记等真实档案视觉 + 可推进的故事线**。

结构证据v1：
**B｜混合证据，高上限候选。**

风险：

- 不写 Newton 因炼金术“发现万有引力”等无证据因果；
- Cambridge 数字手稿多为 All Rights Reserved，正式制作前必须单独解决图片授权 / 可用素材问题。

资产复用：公众号长文 / 科学史与炼金术专题。

入口主要会吸引谁：以科学史、名人反差、炼金术历史兴趣人群为主；更偏广泛兴趣与精准关注，不作为高商业接近度候选。

对标撞题检查：核心5库存在“炼金术”大类内容，但当前未见 Newton / 牛顿炼金实验 / 炼金炉草图这一同一人物与事件对象；因此大类相邻但不构成撞内容。

### 3. 《这张1518年的放血图，为什么医生还要看月亮？》
【栏目：文物】  
状态：高优先候选

观看体验：熟悉医学场景 → 月亮 / 黄道反差 → 真实历史图像

- `explicit_question` 是当前统一编码里跨账号一致性最好的重复Hook；
- 本题同时具备具体历史图像、普通人熟悉的“医生 / 放血”、以及“为什么还要看月亮”的明确反常动作；
- `familiar_unexpected` 单独看并不稳定，因此本题的核心不应写成“原来医生也信占星”，而应让 **1518年具体图像 + 为什么这样择时** 成为入口和中段推进。

结构证据v1：
**A/B｜问题结构强 + 熟悉对象反差辅助。**

主要验证价值：
测试“熟悉现实制度 / 医学 + 神秘学反差”能否成为除异常器物以外的新高上限入口。

风险：
- 不写成“中世纪医生全都靠占星治病”；
- 不拿现代医学有效性取代历史解释；

资产复用：医学史 / 占星史专题。

入口主要会吸引谁：医学史、占星史、历史反常识兴趣人群为主；商业接近度不是主价值，主要承担陌生人理解速度与收藏 / 关注测试。

对标撞题检查：核心5库当前未见 Stöffler 1518《Calendarium Romanum Magnum》、放血图或“放血为什么看月亮”的同一对象 / 问题；与 benchmark 的占星大类相邻，但具体内容独立。

### 5. 《古埃及魔法文本里，施术者为什么会直接说“我是荷鲁斯”？》
【栏目：隐理】  
状态：高优先候选

主要入口：
正常祈求应该是在“向神说话”，但一些古埃及与希腊—埃及魔法文本里，施术者会突然改成“我是荷鲁斯”“我是阿努比斯”这一类第一人称神名公式。普通观众能立刻理解这个反常点。

观看体验：原文怪句 → 实践机制 → 古埃及魔法中的身份 / 权威

现实依据：
- 最近7天大号没有古埃及机制题，能补当前主页的传统与视觉变化；
- 这个题属于 Suen 自己长期古埃及 / PGM-PDM 研究资产，不是从 benchmark 的炼金术、Solomonic magic、witchcraft 等题材反推出来；
- 小红书《魔法圆》已经验证“一个反直觉实践动作 + 为什么”可带来高收藏和精准涨粉；本题延续的是结构，不复制题材；
- 公开只讲清一个机制和少量文本例子，不交付完整仪式复原，符合《内容与课程区隔》。

对标参考：
- 核心5统一编码中，`explicit_question` 仍是当前跨 Angela / Let’s Talk Religion / ESOTERICA 一致性最好的重复入口；
- Angela 可迁移的是“问题会不会改变实践者理解和下一步判断”，不是她的具体争议题；
- ESOTERICA 可迁移的是“原始文本 / 手稿可以直接成为前台证据”，不是复制其具体书目或研究对象。

基础证据起点：
- 古埃及魔法文本中确有第一人称神祇认同公式。Borghouts《Ancient Egyptian Magical Texts》收录如“我是荷鲁斯”等例子；
- PDM xiv.239–95 中，施术者宣称“我是荷鲁斯，伊西斯之子”，并以此推进占卜 / 召请动作；
- PGM IV 的双语占卜材料中也出现“荷鲁斯公牛是我的名字 / 真名”这一类自我认同公式；
- 相关研究将这种第一人称 `ink` / “I am”陈述视为具有转换性功能：施术者在仪式话语中取得神祇身份 / 权威位置，以更好地执行文本要求。正式生产时需要区分古埃及文本、Demotic / Greek magical papyri 与后世解释，不能写成所有传统共享的一条万能理论。

结构证据v1：
**B/C｜原典怪句 + 机制解释 + 专业识别。**
它不是纯猎奇的“古人为什么自称神”，而是能让观众看到 Suen 如何从一句奇怪原文判断它在仪式里承担什么作用。

入口主要会吸引谁：
古埃及、PGM/PDM、仪式魔法、原典实践兴趣人群，以及已经接触过仪式但会追问“为什么要说这句话 / 这一步到底在干什么”的人。更偏精准关注和专业信任，不把它直接当高商业意向题。

对标撞题检查：
核心5统一编码库当前对 Horus / Isis / Anubis / PGM / Demotic / self-identification 的标题级检索均为0；没有发现同一人物公式、同一文本问题或同一机制题。该题只迁移 benchmark 的明确问题 / 原始资料前台化结构，具体内容对象来自 Suen 自己的研究资产。

风险：
- 不能简单解释成现代“附体”；
- 不能把所有“I am X”公式统一成同一种神学机制；
- 不能把希腊—埃及魔法纸草直接等同于更早期古埃及实践；
