### 1. 《这个17世纪瓶子里，为什么装着人尿和12根铁钉？》
【栏目：文物】
状态：已转定题｜2026-09-21
主任务：A｜流量
主要验证：真实强异常对象 + 一眼能懂的内容物问题，是否能改善抖音大号前2秒留存并获得更好的陌生流量观看。

观看体验：奇怪的东西 → 奇怪的问题

现实依据：
当前抖音大号需要前2秒无需背景即可理解的强实物入口；同时避开近期古埃及 / 所罗门高密度。

对标参考：
- 穹印之源：中文低门槛对象入口；
- ESOTERICA：真实器物 → 历史研究；
- 中文现代女巫观察层只借“瓶子 + 内容物”的视觉熟悉度，不作为历史证据。

证据核查：
- 已确认对象为 Greenwich 发现的晚17世纪 Bellarmine / Bartmann 类 witch bottle；
- 2004 年发现，保持密封并接受 X-ray / CT 与化学分析；
- 内容物可可靠支持：人尿、12根铁钉、8枚黄铜针、头发、指甲屑、被钉穿的皮革片，并有硫存在的化学证据；
- Historic England / Old Royal Naval College 与考古研究资料可提供真实对象与 X-ray 素材。

证据风险：
不能把所有 witch bottle 功能统一解释；具体“如何起效”的历史解释需要区分文本记录、考古证据与后世学术解释。

对标：
当天 2—3 个近期 benchmark 样本未可靠取得，按规则降级使用长期方法，不编造近期趋势。

资产复用：公众号 / Patreon。

### 2. 《一双手套被偷了，罗马人为什么会把诅咒写给墨丘利？》
【栏目：文物】
状态：高优先候选

观看体验：现实冲突 → 古代魔法对象

现实依据：
“手套被偷”比专业术语更适合当前陌生人入口；与巫瓶形成“强视觉 vs 强冲突”两类 A 型入口。

对标参考：
- Let’s Talk Religion：熟悉问题 → 实际资料；
- ESOTERICA：古代魔法对象 + 原始材料；
- 穹印之源：标题先冲突后术语。

证据风险：
铅片本体视觉较弱；不能把“折五次”解释成未经证实的固定魔法机制。

资产复用：公众号 / 古代诅咒专题。

### 4. 《为什么护符经常要贴身佩戴，甚至要靠近身体出问题的位置？》
【栏目：隐理】
状态：高优先候选

观看体验：熟悉物件 → 魔法实践底层机制

现实依据：
当前缺低门槛机制题；“为什么护符要戴在身上”无需神秘学背景，也能体现 Suen 对接触 / 距离 / 身体位置在实践中功能的解释能力。

对标参考：
- Angela’s Symposium：普通问题 → 机制与史料；
- Let’s Talk Religion：具体行为 → 历史材料；
- ESOTERICA：跨传统保留差异，不造万能通则。

机制证据起点：
- 古埃及材料把佩戴 / 放在身体上与向使用者传递护符力量联系；
- 罗马—晚期古代医学 / 魔法材料存在 proximity principle，治疗性护符常尽量靠近疼痛或失调部位。

风险：
不能统一成“能量接触”；保护、治疗、死者语境要分开。

资产复用：公众号 / Patreon / 护符机制专题。

### 5. 《判断题：塔罗牌一开始就是拿来占卜的吗？》
【栏目：辨伪】
状态：高优先候选

观看体验：熟悉神秘学对象 → 明确对错 → 历史翻转

判定：错。

现实依据：
塔罗是普通观众高度熟悉的神秘学对象；可测试“熟悉对象 + 历史误区”这一低门槛结构，同时强化“会实践，也会核查历史”的品牌识别。

对标参考：
- Let’s Talk Religion：神话化对象 → 实际资料；
- Angela’s Symposium：普通问题承载严肃研究；
- ESOTERICA：流行神秘学印象 → 历史证据重建。

证据起点：
15世纪北意大利早期塔罗首先属于纸牌游戏语境；今天熟悉的占卜 / occult 关联属于后来的发展。

风险：
不要把“后来发展”粗暴写成某一年首次占卜；正式稿要区分游戏起源、cartomancy 发展与18—19世纪 occult tarot。

资产复用：公众号 / 小红书长卷 / Patreon可选。
