对标参考：
- Let’s Talk Religion：普通问题先行，再进入复杂历史；

- 置信度：Medium；

### 2. 《为什么护符经常要贴身佩戴，甚至要靠近身体出问题的位置？》
【栏目：隐理】  
状态：高优先候选

观看体验：熟悉物件 → 实践机制

现实依据：
当前缺一个真正低门槛的机制题；“护符为什么贴身”无需神秘学背景，也可延续《魔法圆》验证过的“反直觉实践动作 + 为什么”结构。

对标参考：
- Angela Puca：普通问题 → 机制与史料；
- Let’s Talk Religion：具体行为 → 历史材料；
- ESOTERICA：跨传统保留差异，不造万能通则。

机制证据起点：
- 古埃及材料可见佩戴 / 放在身体上的使用方式；
- 罗马—晚期古代医学 / 魔法材料存在治疗性护符靠近疼痛或失调部位的例子。

风险：
不能统一解释成现代“能量接触”；保护、治疗、死者语境必须分开。

资产复用：公众号 / Patreon / 护符机制专题。
