## 当前平台目标

优先观察：
- 搜索；
- 收藏；
- 精准关注；
- 服务理解；
- 高意向人群；
- 图文 / 视频 / 《长卷》哪个形式最适合当前问题。

抖音大号当天发什么，不自动决定小红书当天发什么。  
如果同一题同时适合两个平台，只做“生产复用”，各自标题 / 封面 / 配文仍重新判断。

## 视频 / 实践候选

### 高客单服务认知

本区不计入抖音大号“2—5个高优先候选”上限。  
用途：服务当前高客单验证，优先投放抖音小号 / 小红书 / 朋友圈；只有存在大号要求的证据主角时才回大号路由。

### A. 内部命题｜感情仪式咨询第一步不是选项目
建议平台：抖音小号主发；小红书可做独立实践 / 经验内容。  
状态：高价值商业候选

当前题眼：**想复合时，先看两个人现在还有没有联系。**

候选阶段不锁最终标题。  
自然标题方向可参考：**《想复合，先看你们现在还联不联系》**

正式标题 / 封面 / 开头在成稿后按 Suen 历史标题基线重写，不在候选阶段硬造“强钩子”。

主要入口：
观众以为咨询感情仪式以后第一步就是“选一个项目”，实际第一步是先把关系现在到底处在什么状态说清楚。

现实依据：
- 9/23、9/25 已连续出现真实感情 / 仪式询盘，服务理解已经是现实成交问题，不是凭空制造的商业题；
- 当前高客单目标客户假设就是“有明确现实问题、愿意进入具体判断的人”；
- 这条内容能提前训练潜在客户：来找 Suen 时要先讲情况，而不是只问一个统一商品价格。

目标客户看完更理解的购买价值：
**定制差异 + 判断过程。**

benchmark 参考：
- `explicit_question` 的跨账号数据支持“一个普通人马上听懂的具体问题”；
- Angela 的 `practice_dispute` 只迁移“问题会改变下一步怎么做”，不迁移其任何具体争议；
- 中文现代女巫对标当前更多是跟做、制作、爱情愿望与客订展示，本题不复制其具体内容。

对标撞题检查：
当前14个对标账号现有年度 / 题目流未发现“咨询感情仪式第一步不是选仪式、而是先判断关系状态”的同一具体内容。数据不完整账号只记“现有库未发现”。

风险：
- 不虚构某个具体客户故事；
- 可以说“有人来问 / 平时有人问”，因为已有真实仪式询盘；
- 不把所有感情问题总结成一个固定判断流程；
- 不在正文里硬接价格或预约。

一句话保留理由：
**它直接服务我们正在验证的高客单客户，而且内容来自真实询盘，不来自对标题目。**

### B. 内部命题｜为什么不直接承诺固定见效天数
建议平台：抖音小号；小红书可做搜索 / 服务理解版。  
状态：高价值商业候选

当前题眼：**感情仪式到底多久会有变化。**

候选阶段不锁最终标题。  
自然标题方向可参考：**《感情仪式到底多久会有变化？》**

正式标题 / 封面 / 开头在成稿后再写；不把“我不保证 / 我不会报7天”本身当钩子。

主要入口：
不是从“免责声明”进入，而是从一个客户真的会问的问题进入：为什么明明是在做一个有目标的仪式，却不能直接告诉他第几天一定发生变化。

现实依据：
- 9/25 转介绍客户真实连续询问效果、起效时间、保证和反馈；
- 这是当前成交链里已经发生的结果可信度 / 时间风险问题；
- 如果内容提前把这件事说成人话，以后私聊不需要第一次才解释完整逻辑。

目标客户看完更理解的购买价值：
**真实预期 + 风险透明 + 服务可信度。**

benchmark 参考：
- `explicit_question` 支持把复杂解释压成一个具体问题；
- Angela 的高现实后果题支持“会影响下一步决策”的入口；
- 不迁移任何 benchmark 的仪式效果内容，也不使用中文对标常见的“太灵了 / 显化效果”结果宣称。

对标撞题检查：
当前14个对标账号现有年度 / 题目流未发现“服务者为什么不直接报固定见效天数”的同一具体主题。

内容中心：
先讲这个项目本来是往什么现实变化去做；再讲真正观察的是联系、互动、机会、订单等项目对应现实变化；最后自然说明时间没有一个可以负责任报死的统一数字。  
不能做成整条“不保证 / 因人而异”的防御视频。

风险：
- 不编“通常7天 / 21天”等没有自己数据支持的区间；
- 不把没有结果写成“能量还在运行”这类不可验证解释；
- 不把无法保证结果讲成仪式本身没有目标。

一句话保留理由：
**这是今天真实客户直接暴露出来的高客单成交问题，优先级高于再找一个泛神秘学知识题。**

### C. 内部命题｜同样想复合，现实状态不同就不能直接套同一方案
建议平台：小红书优先；小号可做第一人称短视频。  
状态：高价值商业候选

当前题眼：**还在联系和已经断联，复合时不能直接当成同一种情况。**

候选阶段不锁最终标题。  
自然标题方向可参考：**《还在联系和已经断联，复合的时候会一样吗？》**

正式标题 / 封面 / 开头在成稿后再写，不使用“一个A一个B / 真的能吗 / 怎么可能”这类模板式冲突。

主要入口：
两个客户表面上都说“想复合”，但一个仍有稳定联系，一个已经长期断联，现实状态不同，不能只因为目标名字一样就自动当成同一种情况。

现实依据：
- 当前目标客户要逐渐从“买一个商品”转向“把自己的具体情况交给 Suen 判断”；
- 这条比抽象说“我们是定制服务”更容易让人理解定制到底差在哪里；
- 同时可以筛出愿意说明现实背景、而不是只找最低价统一套餐的人。

目标客户看完更理解的购买价值：
**适配度 + 定制差异 + 为什么专业判断会影响执行。**

benchmark 参考：
- `explicit_question` 和 `practice_dispute` 的有效部分都指向“问题会改变下一步选择”；
- 对标只提供入口结构，不提供复合题材；
- 中文现代女巫当前已有爱情愿望 / 爱情磁场内容，因此本题刻意不做“爱情效果 / 仪式展示”，而做“现实状态为什么影响判断”。

对标撞题检查：
当前14个对标账号现有年度 / 题目流未发现“同样想复合但因现实关系状态不同而不直接给同一建议”的同一具体服务判断题。

风险：
- 在没有完整真实案例授权时，用两个**抽象情境**说明差异，不伪装成两个真实客户案例；
- 不在公开内容里替观众远程判断“你一定适合 / 不适合某仪式”；
- 不把定制复杂度本身当效果保证。

一句话保留理由：
**它直接解释高客单为什么不是“同一件东西卖贵一点”。**

### 当前使用顺序

这3条不是要求连续发布，也不要求立刻全部生产。

当前优先验证逻辑：
- A 看能否把询盘语言从“多少钱 / 做什么”推进到“我的情况是……”；
- B 看能否提前处理效果 / 时间风险，而不降低服务吸引力；
- C 看目标客户能否理解“定制”为什么真的会改变建议与执行。

发布后不只看播放，还要看：
**主页访问、私信 / 加好友、询盘是否主动说明具体情况、是否进入方案 / 报价。**

## 《长卷》候选

当前不为了“有长卷栏目”强行补题。  
只有某个问题确实需要长上下文、原始资料或完整研究链，且价值高于做成短视频时，才进入这里。

## 当前使用原则

- 小红书候选不占抖音大号2—5个高优先候选上限；
- 同一内部命题必须单独生成小红书标题 / 封面；
- 小红书标题可以更具体、更带搜索词、更完整解释利益点；
- 服务认知题发布后重点看：收藏、主页访问、私信 / 加好友、询盘是否主动说明具体情况；
- 不用抖音播放逻辑替代小红书判断。
