## 当前平台目标

9/25最新第一方状态：
- 内容 / 账号窗口9/18—9/24：5.3万曝光、1.5万观看、1057赞、500藏；
- 粉丝窗口9/17—9/24：新增关注188，当前总粉丝468；
- 同一粉丝窗口主页访客476，主页转粉率12.8%；
- 新增关注74.5%来自视频推荐；
- 魔法圆7日粉丝贡献+99，仍是当前最强增长样本。

因此当前已经不是“先证明小红书能不能精准涨粉”的阶段。接下来优先观察：
- 强内容能否继续带精准关注与收藏；
- 新增长能否进一步形成服务理解和高意向询盘；
- 实践 / 原典 / 材料类内容是否能复制高质量关注，而不是只追更大曝光；
- 搜索是否逐步形成稳定入口；
- 图文 / 视频 / 《长卷》哪个形式最适合当前问题。

主页当前没有证据显示是主要增长瓶颈，不因为单条内容表现波动反复重做主页。

抖音大号当天发什么，不自动决定小红书当天发什么。  
如果同一题同时适合两个平台，只做“生产复用”，各自标题 / 封面 / 配文仍重新判断。

## 视频 / 实践候选

### 高客单相关内容｜内容先成立

本区不计入抖音大号“2—5个高优先候选”上限。  
用途：服务当前高客单验证，但所有公开候选先满足“去掉销售目的以后仍然值得看”。小红书优先选择真实实践、材料、判断、案例过程；纯成交异议优先留在私聊。

### A. 内部命题｜感情仪式咨询第一步不是选项目
建议平台：抖音小号主发；小红书可做独立实践 / 经验内容。  
状态：高价值商业候选

当前题眼：**想复合时，先看两个人现在还有没有联系。**

候选阶段不锁最终标题。  
自然标题方向可参考：**《想复合，先看你们现在还联不联系》**

正式标题 / 封面 / 开头在成稿后按 Suen 历史标题基线重写，不在候选阶段硬造“强钩子”。

主要入口：
观众以为咨询感情仪式以后第一步就是“选一个项目”，实际第一步是先把关系现在到底处在什么状态说清楚。

现实依据：
- 9/23、9/25 已连续出现真实感情 / 仪式询盘，服务理解已经是现实成交问题，不是凭空制造的商业题；
- 当前高客单目标客户假设就是“有明确现实问题、愿意进入具体判断的人”；
- 这条内容能提前训练潜在客户：来找 Suen 时要先讲情况，而不是只问一个统一商品价格。

目标客户看完更理解的购买价值：
**定制差异 + 判断过程。**

benchmark 参考：
- `explicit_question` 的跨账号数据支持“一个普通人马上听懂的具体问题”；
- Angela 的 `practice_dispute` 只迁移“问题会改变下一步怎么做”，不迁移其任何具体争议；
- 中文现代女巫对标当前更多是跟做、制作、爱情愿望与客订展示，本题不复制其具体内容。

对标撞题检查：
当前14个对标账号现有年度 / 题目流未发现“咨询感情仪式第一步不是选仪式、而是先判断关系状态”的同一具体内容。数据不完整账号只记“现有库未发现”。

风险：
- 不虚构某个具体客户故事；
- 可以说“有人来问 / 平时有人问”，因为已有真实仪式询盘；
- 不把所有感情问题总结成一个固定判断流程；
- 不在正文里硬接价格或预约。

一句话保留理由：
**它直接服务我们正在验证的高客单客户，而且内容来自真实询盘，不来自对标题目。**

### B. 内部命题｜为什么不直接承诺固定见效天数
建议平台：**暂不作为公开主视频；优先私聊，或未来朋友圈个人感想。**  
状态：暂缓公开

当前题眼：**感情仪式到底多久会有变化。**

候选阶段不锁最终标题。  
自然标题方向可参考：**《感情仪式到底多久会有变化？》**

正式标题 / 封面 / 开头在成稿后再写；不把“我不保证 / 我不会报7天”本身当钩子。

主要入口：
不是从“免责声明”进入，而是从一个客户真的会问的问题进入：为什么明明是在做一个有目标的仪式，却不能直接告诉他第几天一定发生变化。

现实依据：
- 9/25 转介绍客户真实连续询问效果、起效时间、保证和反馈；
- 这是当前成交链里已经发生的结果可信度 / 时间风险问题；
- 如果内容提前把这件事说成人话，以后私聊不需要第一次才解释完整逻辑。

目标客户看完更理解的购买价值：
**真实预期 + 风险透明 + 服务可信度。**

benchmark 参考：
- `explicit_question` 支持把复杂解释压成一个具体问题；
- Angela 的高现实后果题支持“会影响下一步决策”的入口；
- 不迁移任何 benchmark 的仪式效果内容，也不使用中文对标常见的“太灵了 / 显化效果”结果宣称。

对标撞题检查：
当前14个对标账号现有年度 / 题目流未发现“服务者为什么不直接报固定见效天数”的同一具体主题。

内容中心：
先讲这个项目本来是往什么现实变化去做；再讲真正观察的是联系、互动、机会、订单等项目对应现实变化；最后自然说明时间没有一个可以负责任报死的统一数字。  
不能做成整条“不保证 / 因人而异”的防御视频。

风险：
- 不编“通常7天 / 21天”等没有自己数据支持的区间；
- 不把没有结果写成“能量还在运行”这类不可验证解释；
- 不把无法保证结果讲成仪式本身没有目标。

一句话保留理由：
**这是重要的真实成交问题，但当前更适合私聊处理；等有更多真实案例数据以后，再判断是否值得公开做内容。**

### C. 内部命题｜同样想复合，现实状态不同就不能直接套同一方案
建议平台：小红书优先；小号可做第一人称短视频。  
状态：高价值商业候选

当前题眼：**还在联系和已经断联，复合时不能直接当成同一种情况。**

候选阶段不锁最终标题。  
自然标题方向可参考：**《还在联系和已经断联，复合的时候会一样吗？》**

正式标题 / 封面 / 开头在成稿后再写，不使用“一个A一个B / 真的能吗 / 怎么可能”这类模板式冲突。

主要入口：
两个客户表面上都说“想复合”，但一个仍有稳定联系，一个已经长期断联，现实状态不同，不能只因为目标名字一样就自动当成同一种情况。

现实依据：
- 当前目标客户要逐渐从“买一个商品”转向“把自己的具体情况交给 Suen 判断”；
- 这条比抽象说“我们是定制服务”更容易让人理解定制到底差在哪里；
- 同时可以筛出愿意说明现实背景、而不是只找最低价统一套餐的人。

目标客户看完更理解的购买价值：
**适配度 + 定制差异 + 为什么专业判断会影响执行。**

benchmark 参考：
- `explicit_question` 和 `practice_dispute` 的有效部分都指向“问题会改变下一步选择”；
- 对标只提供入口结构，不提供复合题材；
- 中文现代女巫当前已有爱情愿望 / 爱情磁场内容，因此本题刻意不做“爱情效果 / 仪式展示”，而做“现实状态为什么影响判断”。

对标撞题检查：
当前14个对标账号现有年度 / 题目流未发现“同样想复合但因现实关系状态不同而不直接给同一建议”的同一具体服务判断题。

风险：
- 在没有完整真实案例授权时，用两个**抽象情境**说明差异，不伪装成两个真实客户案例；
- 不在公开内容里替观众远程判断“你一定适合 / 不适合某仪式”；
- 不把定制复杂度本身当效果保证。

一句话保留理由：
**它直接解释高客单为什么不是“同一件东西卖贵一点”。**

### D. 内部命题｜星符最简单的其实是把图刻上去
建议平台：小红书图文优先；有真实制作素材时可复用到抖音小号。  
状态：高价值实践候选

当前题眼：
**图案刻对只是开始，真正会改变制作的是材料、尺寸、时间和具体用途。**

来源：
来自 Suen 最近真实寻找银片、比较尺寸、复原行星材料与择时的工作，不从销售话术反推。

为什么比直接讲“定制服务”更值得公开：
- 本身就是一个真实实践问题；
- 有物件、有过程、有判断，内容先成立；
- 看完以后自然理解“同样一张图，不是照着刻就完全一样”；
- 能吸引更重视材料、原典和执行条件的人，但不用主动筛客户。

建议形式：
**图文优先。** 可用银片 / 草图 / 原典页 / 实际研究截图，不新增第二支视频剪辑。

商业价值：
专业执行 + 定制差异，但不主动卖。

风险：
不写成“条件越复杂效果越强”；不把尚未核完的制作条件提前写死。

### E. 内部命题｜有些材料能换，有些不能为了方便硬换
建议平台：小红书图文；朋友圈可从个人感想角度使用同一真实经历，但不建议同日重复。  
状态：高价值实践候选

当前题眼：
**复原里真正难的是判断：换到哪一步以后，已经不是原来的做法。**

来源：
来自当前七行星墨水、植物材料、保存期、金属星符等现实复原问题。

为什么值得公开：
- 是 Suen 自己真实一直在碰的问题；
- 既有原典，也有现代实践限制；
- 对认真买材料 / 做实践的人有收藏价值；
- 专业感来自具体选择，不需要讲“我很专业”。

建议形式：
图文 / 工作记录，不优先做新视频。

风险：
每次只能讲已经核过的具体例子，不能先造一个跨传统通用替代规则。

### 当前使用顺序

这5条不是要求连续发布，也不要求立刻全部生产。

当前优先验证逻辑：
- D / E 优先：先用真实实践内容建立“材料 / 时间 / 原典 / 执行真的会改变做法”的认知，销售感最低；
- A / C 低频穿插：只有近期确实需要服务认知时再发，观察询盘是否更愿意说明具体情况；
- B 暂不作为公开主内容：当前优先在私聊真实回答，未来有更多结果数据后再决定是否公开。

发布后不只看播放，还要看：
**主页访问、私信 / 加好友、询盘是否主动说明具体情况、是否进入方案 / 报价。**

## 《长卷》候选

### 《阿格里帕第二卷里，行星图像到底要在什么时间制作？》
状态：**高价值长卷候选｜来自9/25已完成研究资产，不要求今天发布**

来源：
9/25 原定《隐理》的“行星星符为什么要等时辰”在成片阶段发生栏目漂移。问题不适合继续用宽机制题包装，但现有 Agrippa 研究、章节定位、行星图像要求和版本核查本身具有长文价值。

为什么更适合《长卷》：
- 可以把范围老实收窄到 Agrippa，而不是泛化成“所有行星星符”；
- 允许完整比较 Book II ch.34—35 与 ch.38—44 的具体要求；
- 可以把行星日、行星时、行星位置、不同 planetary images 的要求分别讲清；
- 可以放原页、版本、章节、具体例子和现代常见混淆；
- 这类内容的价值来自完整研究链，压成短视频反而容易被单一原文牵着走。

硬边界：
- 不把 Agrippa 直接代表成所有行星魔法传统；
- 不把“星符 / seal / image”在不同文本中的术语差异抹平；
- 不把现代择时体系反写成 Agrippa 原文；
- 不是把今天的视频口播直接扩写，必须按《长卷》规则独立重写。

当前不为了“有长卷栏目”强行补题。  
只有某个问题确实需要长上下文、原始资料或完整研究链，且价值高于做成短视频时，才进入这里。

## 当前使用原则

- 小红书候选不占抖音大号2—5个高优先候选上限；
- 同一内部命题必须单独生成小红书标题 / 封面；
- 小红书标题可以更具体、更带搜索词、更完整解释利益点；
- 服务认知题发布后重点看：收藏、主页访问、私信 / 加好友、询盘是否主动说明具体情况；
- 不用抖音播放逻辑替代小红书判断。
