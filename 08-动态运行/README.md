# Suen｜动态运行区

状态：当前正式动态真源
建立：2026-09-20
时区：Asia/Shanghai

## 作用

本目录保存“现在实际是什么状态”和可追溯的运行历史。

与规则目录分工：

- GitHub 规则文件：规定应该怎么做；
- `08-动态运行/`：记录现在正在发生什么；
- `历史/`：保存已经发生过的事实与旧状态，不反向覆盖当前文件；
- Git commit：保存每一次修改版本。

Slack 自 2026-09-20 起不再作为正式真源。旧 Slack 内容已迁入历史归档，仅保留作核查来源。

## 日常读取原则

普通任务优先只读：

1. `00-当前总览.md`
2. 当前任务对应的短状态文件
3. 对应 GitHub 正式规则

只有需要跨月复盘、核对旧决定或历史数据时，才读取 `历史/`。

## 核心原则

**当前文件回答“现在是什么”，历史文件回答“以前发生过什么”。不要把历史记录重新当成当前状态。**


## 防膨胀规则

- “当前状态”文件只保存**现在仍影响判断**的信息，不长期堆每一笔历史事件；
- 已经发生且不需要持续显示的事实，写入对应 `YYYY-MM.md`；
- 当一个状态被新状态替代时，旧状态进入月度记录或由 Git commit 保留；
- 普通接管不读取 `历史/`，也不为了恢复上下文读取全部月度文件；
- 只有跨月复盘、历史核账、争议追溯时才加载对应月份。

目标：系统运行越久，日常读取量仍保持稳定。


## 月度滚动

进入新的上海自然月后：

1. 新的已发布内容写入 `内容台账/YYYY-MM.md`；
2. 新的询盘 / 成交 / 商业事实写入 `商业/YYYY-MM.md`；
3. 新的天象经营历史写入 `天象/YYYY-MM.md`；
4. “当前状态”文件继续保留跨月仍有效的状态，不因为换月清空；
5. 上月文件停止追加，除非是在补录明确属于上月的事实；
6. 补录旧月份时必须写真实发生日期，不按补录当天日期归档。

换月不复制一整份旧当前状态到新月文件，只记录真实发生的月度事实。


## 当前总览同步规则

`00-当前总览.md` 是导航摘要，不是第二套独立真源。

当以下任一项发生实质变化时，更新对应当前文件后必须同步检查总览：

- 当前主要经营瓶颈改变；
- 轻量灵感库存的定位或结构发生实质改变；
- 身份识别 / 主页承接状态改变；
- 经营周期、成交累计、主要商业信号改变；
- 当前开放 / 关闭的天象窗口改变。

如果总览与细分当前文件冲突：

**以细分当前文件的最新可靠事实为准，并立即修正总览。**

普通细节变化不要求同步进总览，避免总览膨胀。
