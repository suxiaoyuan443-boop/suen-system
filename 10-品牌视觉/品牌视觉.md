# Suen Akhet｜品牌视觉系统

状态：当前正式规则
最后核对：2026-09-17
依据：Suen Akhet Visual System · refined v2

## 核心气质

博物馆图录感 + 古籍研究感 + 当代编辑设计感。

整体应克制、清楚、有证据感。目的不是把页面装饰得“神秘”，而是让人第一眼感觉内容经过认真编辑：图片有来源、文字有层级、版面愿意给知识留出呼吸。

## 视觉关键词

Museum catalogue / Archive / Bronze / Papyrus / Editorial silence

## 配色

长期基础色：

- 骨白纸色 `#F7F0E4`
- 炭黑墨色 `#1D1916`
- 暗酒红 `#5A1D1A`
- 古铜金 `#B48650`
- 石灰褐 `#8B8375`

配色原则：背景先安静，重点色后出现。金色只做标尺、页码、细线、徽章等小面积元素，不做大片填充。深色页用于封面和章节转场，不作为全文底色。

## 字体与正文

- 标题/章节/引文/封面：思源宋体 / Noto Serif CJK SC 类
- 正文说明：思源黑体 / Noto Sans CJK SC 类
- 不用花体，不做“水晶店感”
- 正文保持完整自然段，行距略松，不做短视频式一句一行
- Egyptological transliteration / Greek / Latin 是证据行，不是装饰图案

## PDF

封面像出版物，不像宣传单。

内页：

- 主标题一次只讲一个重点
- 正文通常以 2—3 个自然段承载一个信息单元
- 图注与正文分开
- 图注写清文物名称 / 编号 / 年代 / 馆藏或来源
- 页眉页码低调，内容区稳定
- 章节转场页少字，不堆信息

## PPT

每页只让一个信息成为主角。

常用结构：

- 文物讲读：一图 + 一段讲读
- 文本对照：原文 / transliteration / working translation / 中文译文 + 讲读
- 流程页：动作 / 文本 / 解释逐步展开

不要满页堆字。

## 图片

真实资料做主体，AI 只做气氛。

真实文物图、馆藏图、纸草图版、手稿图承担证据功能，图注必须写清名称、编号、年代、馆藏或来源。

AI 可用于：

- 封面
- 章节页
- 背景纹理
- 明确的气氛视觉

AI 不得假装历史现场或真实文物证据。

## 海报

主视觉要强，字要少，气质不能便宜。

## 避雷

不要：

- 满屏星星月亮
- 假古埃及符号乱贴
- 紫黑渐变 + 金字堆叠的廉价神秘学模板
- 字压在复杂背景上
- 图片与正文无关

要：

- 主图承担证据
- 标题少而准确
- 用细线、编号建立秩序
- 用留白保护质感
- 每个素材都能解释为什么放在这里

## 交付检查

1. 标题是否一眼可读
2. 正文是否少而完整
3. 图片是否与内容真实对应
4. 图注是否写清来源
5. 颜色是否控制在稳定的小范围
6. 是否出现廉价神秘学模板味
7. PDF / PPT / 海报是否像同一个品牌

目标：页面安静但不空，有历史感但不旧，有神秘感但不廉价。
