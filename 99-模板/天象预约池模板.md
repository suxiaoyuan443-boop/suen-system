# Slack｜天象检索与预约简版模板

状态：当前正式模板
最后核对：2026-09-17

用于把完整技术择时分析压缩为 Slack `#天象检索与预约` 的经营记录。完整技术推导保留在专用择时系统，不复制到 Slack。

```text
【天象窗口】
项目：
目的：
地点：
日期：
时间窗口：
评级：B / A / S / SS
状态：候选 / 待复核 / 已确认 / 开放预约 / 准备中 / 执行中 / 已完成 / 已淘汰 / 已取消
适合用途：
核心优点：
1.
2.
需要注意：
1.
2.
是否允许商业宣传：
当前预约数：
承载能力：
商业阶段：
```

原则：

- 正式记录尽量控制在约 20 行以内。
- Slack 简版只保留结论层和经营层信息。
- 行星、月亮、应用/分离、orb、VOC、接纳、Bonatti 检查、原典长文等完整推导留在专用择时系统。
- 未完成复核时不得把候选窗口写成“已确认”。
- 只有 Suen 明确确认后才能标记“已确认”。
- 如果精确执行时刻在不同记录之间存在冲突，`时间窗口` 不得自行挑一个填写成最终公开时刻；应写“待复核 / 以专用择时系统最新可靠复核为准”，或保留当前内部记录并明确冲突状态。
- 经营层可以先记录“开放预约 / 是否允许商业宣传”等状态，但对外公开具体时分前必须以专用择时系统最新可靠复核结果为准。
