# Slack｜天象预约池简版模板

状态：正式模板
最后更新：2026-09-17

用于把完整技术择时分析压缩为 Slack `#天象预约池` 可直接使用的短记录。完整技术推导保留在专用择时系统，不复制到 Slack。

```text
【天象窗口】
项目：
目的：
地点：
日期：
时间窗口：
评级：B / A / S / SS
状态：候选 / 待复核 / 已确认 / 开放预约 / 准备中 / 执行中 / 已完成 / 已淘汰 / 已取消
适合用途：
核心优点：
1.
2.
需要注意：
1.
2.
```

原则：
- Slack 简版只保留结论层信息。
- 行星、月亮、相位、应用/分离、orb、VOC、接纳、原典要求等完整推导留在专用择时文件/对话。
- 未完成复核时不得把候选窗口写成已确认。
