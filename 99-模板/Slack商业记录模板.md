# Slack｜客户商业记录模板

状态：当前正式模板
最后核对：2026-09-17

仅当 Suen 明确说“生成总结 / 总结”时使用。

目标：**短、能复盘、能直接贴 Slack。**

## 输出

```text
【本次沟通结果】
阶段：
意图：
结果：
下一步：

【可直接发 Slack】
【客户商业记录】
日期：
来源：
需求：
阶段：
报价/成交：
卡点：
下一步：
```

## 省略规则

- 没有实际意义的空字段直接省略，不为了模板完整保留一排“无 / 未知”。
- 尚未报价时可写“报价：未报价”，但不需要再单列“是否报价 + 报价金额”两个字段。
- 已成交时把成交金额并入“报价/成交”。
- 未成交且没有明确卡点时，“卡点”可以省略。
- 不复制客户完整原话。
- 不记录客户姓名、联系方式、付款资料等隐私到 GitHub。

## 示例逻辑

一条记录只保留商业复盘真正需要的信息：**从哪里来 → 想买什么 → 现在到哪一步 → 钱有没有谈清楚 → 下一步做什么。**
