# 内容复盘台账模板

状态：当前正式模板  
最后核对：2026-09-23

用于“总结”阶段。只输出已经发生的事实。

默认时区：**Asia/Shanghai**。

## 一、通用规则

每个平台独立短复制块。

第一行：

```text
【复盘日期｜约X小时早期数据 / 后续数据】
【平台】
发布时间：
```

如内容涉及仪式 / 星符，可另写：

`涉及项目执行日期：YYYY-MM-DD`

但不能把它当发布时间。

未知字段省略，不为了模板完整填空。

## 二、通用内容块

按平台真实数据删减：

```text
【YYYY-MM-DD｜约X小时早期数据】
【平台】
发布时间：
栏目 / 合集 / 内容类型：
题目：
制作耗时档位：（首次复盘且已知时）

播放 / 浏览 / 曝光：
点赞：
评论：
收藏：
分享：
新增粉丝 / 关注：
主页访问：

平台特有指标：

私信：（能确认由本条带来时）
有效询盘：（能确认由本条带来时）
成交：（能确认由本条带来时）

评论信号：
具体问题 / 服务兴趣信号：（真实出现时）
```

## 三、平台差异

### 抖音大号

填写正式前台栏目。

可记录：2秒跳出、5秒完播、平均播放时长、完播率、封面进入率等后台真实字段。

### 抖音小号

额外可写：

- 内容类型；
- 内容形式：视频 / 图文；
- 入口结构；
- 主题标签。

具体分类回 `01B-抖音小号/小号规则.md`。

视频与图文只保留各自真实指标，不混填。

### 小红书

额外可写：

- 前台合集；
- 内容形式；
- 后台内容角色；
- 入口结构；
- 主题标签。

具体分类回 `02-小红书/README.md`。

如果与抖音大号是同一支成片，不重复记录主制作耗时。

### 公众号｜贴图 / 长文

必须拆成两个独立块。

可记录：

- 当前阅读；
- 推荐来源；
- 搜一搜来源；
- 分享；
- 文章页自然关注；
- 是否受抽奖 / 活动干扰。

**未满约24小时不得写“24h阅读”。**

长文如有贴图导流，可单独记录。

### Patreon

只有有新帖、会员变化或阶段复盘时记录：

```text
【YYYY-MM-DD｜Patreon】
发布时间：
题目：
内容类型：公开帖 / Full Research Essay / Selected Practice Record / Source Pack
访问层级：公开 / 付费会员

浏览 / 阅读：
互动：
当前付费会员：
本期新增 / 取消：
由本帖直接带来的付费会员：（能确认时）
订阅收入 / 到账：（需要且能可靠取得时）
来源 / 评论信号：
```

不记录银行卡、地址、税务等支付隐私。

### 朋友圈

记录：

- 发布时间；
- 内容主题；
- 涉及项目执行日期（如有）；
- 点赞 / 评论；
- 能可靠归因的私聊、询盘、成交。

## 四、未发布 / 待确认

```text
【平台】
发布状态：未发布
```

或：

```text
【平台】
发布状态：待确认
计划发布时间：（如已知）
```

计划时间不得冒充实际发布时间。

## 五、写入前最后检查

只检查 9 件事：

1. 日期是否按上海时间；
2. 是否确认真实发布；
3. 复盘日期、发布时间、项目执行日期是否分开；
4. 大号 / 小号、公众号贴图 / 长文是否拆开；
5. 未满24小时是否误写24h；
6. 未知数据是否被估算；
7. 询盘 / 成交是否真的能归因；
8. 具体问题 / 服务兴趣是否被误算成有效询盘；
9. 同一支抖音 + 小红书成片是否避免重复计算制作耗时。
