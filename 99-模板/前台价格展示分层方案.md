# Suen｜前台价格展示分层方案

状态：内部正式展示规则  
建立：2026-09-27

用途：
整理现有公开价格表的展示结构，使客户更容易理解：
- 什么是标准服务；
- 什么是标准产品 / 仪式；
- 什么需要先判断再报价；
- 哪些专业项目不需要长期占据第一屏。

本文件不改变任何当前正式价格。

---

## 一、为什么不再用“一张总价目表承担全部功能”

当前现行价目表同时包含：
- ¥20 / 问；
- ¥88 / 次；
- ¥108—300 塔罗 / 运势；
- ¥300—500 星符；
- ¥528 专业召唤；
- ¥688 固定仪式；
- 实物与免费祈福。

未来还会加入：
- 四位数完整定制；
- 高成本银制手工星符。

如果全部长期并列在同一张图中，客户会把不同服务逻辑直接按价格横向比较。

因此前台展示改为三层：

1. 标准服务 / 产品价格；
2. 定制服务入口；
3. 专业项目按需询问 / 自然承接。

---

## 二、标准服务价目表

适合继续明码标价：

### 咨询 / 判断
- 塔罗基础项目；
- 感情 / 婚姻；
- 财运 / 事业；
- 学业 / 考试；
- 月运 / 季度运势；
- 查事 / 传讯等。

### 标准实物 / 护符
- 铜制星符；
- 羊皮纸星符；
- 蜂蜜罐；
- 护符；
- 道家符；
- 招财蛋等。

### 标准仪式
- 固定感情 / 复合仪式 ¥688；
- 其它已经存在、流程稳定且价格明确的固定项目。

原则：
客户已经知道自己想买什么时，价格清楚、下单路径简单。

---

## 三、定制服务入口

未来完整定制不直接和标准价格表并排成一个普通商品。

前台说明重点：

**适合：**
- 情况比较复杂；
- 现有固定项目不能直接对应；
- 需要重新判断、择时、材料 / 方案调整；
- 不确定自己该选什么。

**流程：**
说明现实问题
→ 补必要信息
→ Suen判断是否适合
→ 给出定制方案
→ 正式报价
→ 确认后准备 / 排期 / 执行

正式价格未由 Suen确认前：
**不写虚假“¥XXXX起”。**

未来价格确认并有真实成交验证后，可以再决定是否公开起价用于预算筛选。

---

## 四、专业项目展示

### Ars Paulina / 水晶召灵

当前都为¥528，但实际约2—3小时。

由于：
- 专业程度高；
- 工时较长；
- 当前经济效率偏紧；

前台不需要把它们长期放在最显眼的主价格入口。

处理建议：
- 保留可购买；
- 有明确需求时自然承接；
- 研究 / 实践内容中自然出现；
- 后续价格验证后再决定是否重新进入主推区。

这不是下架。

---

## 五、未来银制星符

暂不进入现行价格表。

上线前至少完成：
- 真实成品；
- 材料总成本；
- 制作 / 编绳 / 排版 / 刻制总工时；
- 损耗；
- 包装；
- 正式售价确认。

上线后应与铜制 / 羊皮纸明确分层，例如：

**标准星符**
- 羊皮纸
- 铜制

**手工高阶星符**
- 银制

具体名称与正式价格在产品真实完成后再定。

---

## 六、建议的前台结构

### 入口 1｜我已经知道自己想买什么

进入：
**标准服务 / 产品价目表**

### 入口 2｜我有一个具体问题，但不知道该选什么

进入：
**先描述情况 → Suen判断**

### 入口 3｜我就是来问某个古典魔法 / 召唤项目

进入：
**专业项目自然承接**

客户不需要先读完整技术目录。

---

## 七、当前价格表改版时的保留原则

保留：
- 当前已经确认的真实价格；
- 免费祈福；
- 产品有效期等真实说明；
- 客户已经习惯的项目名称（如无必要不同时大改名）。

减少：
- 同一张图中所有产品平铺；
- 低价与未来高客单完全同屏；
- 客户必须自己理解复杂体系后才能购买。

不做：
- 虚构高端套餐；
- 自动把标准项目升级成定制；
- 为了显得高级删除所有低价产品；
- 把隐藏价格当成高端感。

---

## 八、推荐的展示资产

未来前台最好分成：

### A｜标准价目表
解决：
**“这个现成项目多少钱？”**

### B｜定制服务说明
解决：
**“我的情况不知道该选什么。”**

### C｜案例 / 工作过程
解决：
**“为什么值得信任和付更高价格？”**

三种资产分别承担价格、入口和证据，不让一张海报同时做所有事。
