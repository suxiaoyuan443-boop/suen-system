# Suen｜专用对话执行提示词模板

状态：当前正式模板  
最后核对：2026-09-19

原则：**总控只传当天变量；专用对话自己读取当前规则并把任务做完。**

## 默认交接

```text
执行今天正式更新。

前台合集 / 内容产品：
题目：
主任务：A｜流量 / B｜精准涨粉 / C｜服务认知 / D｜商业承接
今日重点：
商业边界：纯内容 / 唯一允许的商业方向

按当前 GitHub 本栏目 / 平台规则完整执行。
没有真实阻塞时，自行完成研究、成稿、素材和 QA，一次性交付，不停下来等“继续”。
```

小红书同步追加：

`小红书同步同一成片，并补小红书标题 / 封面文字 / 发布配文，不重新制作第二支视频。`

## 专用对话最小读取

正式生成前实际读取：

1. 本平台 / 本栏目当前规则；
2. `00-系统总控/Suen统一文笔总则.md`；
3. 对应交付规则；
4. 视频再读 `99-模板/视频类统一交付格式.md`。

需要判断大号栏目边界时再读：

`01-抖音大号/栏目选题边界与路由.md`

正常不再额外加载旧的“文笔成稿验收协议 / 专用对话执行验收协议”全文；它们已经合并到统一文笔总则。

## 回执

稳定日不展示一串 SHA。

Suen 明确要求、仓库刚改、发生规则冲突或需要排错时，再按 `规则读取验收协议.md` 展示简短读取回执。

## 生产保护

题目已定后，文笔、素材、链接、排版、交付问题由专用对话自己修。

只有核心事实 / 证据不成立、题目无法回答、栏目路由错误、商业 / 天象 / 法律硬冲突或 Suen 改任务时，才退回总控。

## 视频

最终体验服从 `视频类统一交付格式.md`：

**完整口播 → 紧跟真正对应图片 → 下一段口播 → 对应图片**

主体结束后直接附最终标题和标签。

### Patreon

Patreon 正式成稿必须同时读取：

- `00-系统总控/Suen统一文笔总则.md`
- `06-Patreon/Patreon研究与实践规则.md`

不能只读 Patreon 文件后自行概括“自然、研究感”来代替 Suen 的统一文笔真源。

Patreon 多轮返工后如果出现明显旧稿惯性，可以新开专用对话；新对话只带可靠研究成果与当前任务，不复制整份失败稿。

Patreon 长链路任务（多手稿 + 找图 + 双语全文 + DOCX / HTML）默认在普通 Chat 中拆成 2—4 个阶段完成；Work 只在 Suen 明确选择时使用。普通 Chat 连续两次长时间执行中断后，不再第三次重复同一超长单轮任务，而是缩短每轮范围。

## 公众号 / 朋友圈

- 公众号：总控只传贴图 / 长文、题目、主任务、商业边界；专用对话读取公众号规则。
- 朋友圈：只有总控安排时生成；读取朋友圈规则。

目标：提示词越来越短，但成品越来越完整。
