# Suen｜视频类统一交付格式

状态：当前正式模板
最后核对：2026-09-17

本文件规定 `suen-system` 内所有正式视频成品的统一交付格式。

适用范围包括：

- 抖音大号 7 个前台合集：文物、异录、辨伪、残页、隐理、世问、牌记；
- 抖音小号；
- 当天小红书直接同步的抖音同一支视频；
- 以后纳入本仓库、且属于“需要口播/台词 + 画面/素材”的其它视频内容。

不适用于：

- 公众号；
- 小红书《长卷》；
- 朋友圈文字；
- 商业总控记录；
- 非视频型文章或数据库内容。

如果某个视频栏目有更具体的画面要求，栏目规则可以增加细节，但不得把本文件规定的“口播 ↔ 对应素材”关系重新拆散。

---

## 核心原则

正式成片稿必须让 Suen 从上往下直接完成：

**读左边完整口播 / 台词 → 打开右边对应素材 → 剪这一段 → 继续下一段。**

不得先给一整篇口播，再在后面单独堆一份素材清单，让 Suen 自己重新判断哪张图对应哪段。

也不得为了配图把自然口播强行拆成一句一句。

---

## 固定双栏格式

所有正式视频成品主体采用两列表格：

| 完整口播 / 台词 | 对应图片 / 素材链接 |
|---|---|
| 一整段可以连续录制的完整口播 | 这一段真正对应的图片直链 / 视频素材 / 来源页 + 具体画面说明 |
| 下一段完整口播 | 下一段对应素材链接 + 来源页 + 使用方式 |

### 左栏｜完整口播 / 台词

要求：

- 必须是自然、连续、可以直接照着录的一整段；
- 不为了素材匹配强行一句一句拆开；
- 一格里可以有连续数句话，只要它们自然属于同一个画面 / 素材组；
- 口播继续服从 `00-系统总控/Suen统一文笔总则.md` 与栏目专属文笔；
- 如果视频是现场对话 / 情景 / 无旁白动作，则左栏写完整现场台词、字幕或动作说明，不制造不存在的旁白。

### 右栏｜对应图片 / 素材链接

每一格必须直接对应左边这一整段。

涉及外部真实资料时，优先给：

1. **可打开的 HTTPS 图片直链 / 原始素材直链**；
2. **来源页**；
3. 图片 / 手稿 / 文物 / 页面是什么；
4. 这一段具体看哪里；
5. 需要时写明放大、圈选、滑动、局部裁切、前后切换；
6. 能取得时给馆藏号、页码、年代、机构等。

涉及 Suen 自己拍摄的真实动作 / 桌面 / 仪式准备时：

- 右栏直接写清拍什么、怎么拍、镜头动作；
- 标注 `本人实拍｜无外部链接`；
- 不为了“每格必须有URL”硬找一张无关网图替代本人实拍。

涉及已经上传 / 已有的本地真实素材时：

- 写清使用哪个素材和具体片段；
- 如果当前系统能提供可打开的文件引用 / 链接，则一并给；
- 如果不能提供外链，明确写 `已有本地素材｜无外部直链`。

---

## 图片与资料链接硬要求

如果右栏使用外部图片 / 手稿 / 文物 / 原书页：

- 优先给能直接打开图片的 HTTPS 直链；
- 同时给来源页；
- 不只写“这里放某某纸草 / 某某文物”；
- 不只给来源页却把它冒充成图片直链；
- 不用不相关对象补位；
- 不用 AI 图冒充真实文物、历史现场、手稿或原页。

如果当前未取得稳定图片直链：

**必须明确写：`当前未取得稳定图片直链`**

然后提供可靠来源页和人工获取提示。

如为局部裁切：

- 明确写“局部”；
- 如果原文阅读依赖上下文，优先先出现整页 / 整件，再放大局部。

---

## 原文 / 手稿 / 文物类视频

资料越硬，导航越简单。

右栏不能只给一整页原文让观众自己找。

需要明确写：

- 先出现哪张整页；
- 放大哪一行；
- 圈哪个词 / 哪个符号；
- 哪一句口播对应这个位置；
- 下一步切到什么图。

但左栏仍保持自然完整口播，不因为视觉导航变成一句一格。

---

## 同一素材可覆盖多句话

如果同一张图 / 同一页手稿 / 同一段实拍可以覆盖连续多句话：

- 这些话保留为一个完整口播块；
- 右栏只对应这一组素材；
- 在右栏写清内部镜头变化，如 `全图 2 秒 → 放大右上铭文 → 圈出第三行`。

不要为了形式机械“一句一图”。

---

## 栏目特殊要求仍然有效

统一双栏格式只统一“交付怎么排”。

它不取消各栏目原有的：

- 文物的真实馆藏带看；
- 残页的原文逐步放大与标注；
- 异录的故事时间线；
- 辨伪的固定判断题结构；
- 隐理的机制解释；
- 世问的现实判断；
- 牌记的真实翻牌 / 指牌 / 判断过程；
- 小号的真实桌面、动作、生活化现场感。

栏目逻辑继续由栏目文件决定。

---

## 小红书同步视频

如果小红书当天直接同步抖音同一成片：

- 视频主体只交这一份双栏稿；
- 不重新制作第二份逐镜头视频稿；
- 在同一成片稿之后追加小红书标题、封面文字、发布配文即可。

---

## 禁止的交付方式

禁止：

- 完整口播和素材表完全分离；
- 先给一篇口播，最后再给十几个链接让 Suen 自己配；
- 一句话拆成一格导致口播支离破碎；
- 只写素材名称不给来源 / 链接；
- 只有来源页，却声称已经给了图片直链；
- 为了填满右栏使用无关文物、AI假史料或相似但错误的对象；
- 小红书同步同一成片时再额外生成一份重复视频稿。

---

## 最终检查

正式交付前确认：

- 左栏从上到下连起来是一份自然完整的成片口播 / 台词；
- 每个左栏内容块都能立刻找到右栏对应素材；
- 外部资料有可靠来源；
- 本人实拍明确标明拍摄动作；
- 缺失直链明确说明，不伪装已经取得；
- 用户不需要二次做“口播 ↔ 图片”匹配工作。
