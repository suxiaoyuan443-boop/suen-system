# Suen｜常驻服务入口模板

状态：当前正式模板  
建立：2026-09-27

用途：用于主页置顶、微信服务说明、私域欢迎信息或其它长期存在的服务入口。

本模板负责“让客户知道怎么开始”，不替代现有价格表，也不要求所有平台同时公开。

高客单正式执行继续读取：
- `07-销售与运行/高客单机会漏斗.md`
- `07-销售与运行/高客单Offer与报价规则.md`
- `99-模板/高客单正式报价模板.md`

---

## 一、入口目标

陌生人进入后应快速明白：

1. 不需要先理解所有魔法体系；
2. 不确定选什么时，可以直接描述现实问题；
3. Suen 会先判断适配，再决定是咨询、现有标准项目还是定制执行；
4. 高客单定制在方案明确后报价；
5. 现有标准服务仍可按当前价目表直接查看。

入口不是完整商品目录。

---

## 二、客户前台第一步

建议核心表达：

> 如果你不确定该选哪个项目，直接把现在遇到的事情、目前发展到哪一步，以及你想解决什么告诉我就可以。我会先看具体情况，再判断更适合咨询、现有项目还是定制方案。

这是结构参考，不要求逐字复制。实际发布继续按 Suen 本人自然表达调整。

---

## 三、问题入口

不按复杂技术体系分组，优先按客户现实问题进入。

可覆盖：

- 感情 / 关系 / 复合 / 相处推进；
- 事业 / 财富 / 工作 / 机会；
- 学业 / 考试 / 沟通 / 写作；
- 人际 / 保护 / 阻碍 / 小人；
- 其它明确现实问题；
- 完全不知道选什么：直接说明情况。

不需要把所有技术项目列在第一屏。

---

## 四、三条服务路径

### A｜咨询 / 判断

适合：
- 还不确定问题怎么判断；
- 需要先看具体情况；
- 当前不一定需要进入复杂执行。

具体项目与价格读取现行价目表。

### B｜现有标准项目

适合：
- 客户已经明确知道自己要现有某个固定项目；
- 当前产品 / 服务有稳定规格和现行价格。

例如现行塔罗、部分护符、祈愿、标准实物、现有固定仪式 / 星符等。

是否继续公开全部项目由 Suen 决定，不在本模板自动删减。

### C｜定制项目

适合：
- 现实目标比较具体；
- 需要结合个人情况、时间、材料、执行条件或多个因素判断；
- 现有标准菜单不足以直接回答。

流程：

`说明现实问题 → 补必要信息 → Suen判断是否适配 → 定制方案 → 正式报价 → 确认后准备 / 排期 / 执行`

当前正式价格尚未统一确认，因此不提前写虚假“¥X起”。

---

## 五、定制项目对外不需要先展示的东西

第一入口不需要把以下内容全部列给客户：

- PGM / PDM；
- Ars Paulina；
- 不同 grimoire；
- 行星智慧体 / 精灵；
- 复杂材料对应；
- 全部择时技术；
- 每一种可调用仪式名称。

这些属于 Suen 的后台专业工具库。

客户购买的是：
**针对自己的具体问题，得到适配判断与相应执行方案。**

---

## 六、价格表与定制入口的关系

现行价格表继续承担：

**“我已经知道自己想买什么”**

定制入口承担：

**“我有一个问题，但不知道应该用什么解决”**

两者不放在完全相同的购买逻辑里。

如果以后定制仪式正式确认起价，可以在定制入口中增加真实起价，用于提前筛选预算；未确认前不虚构。

---

## 七、私聊接管

客户从常驻入口进入后：

1. 先回答他真正的问题；
2. 判断是否为有效询盘；
3. 达到高客单条件时进入机会漏斗；
4. 信息足够时不要无限聊天，进入方案；
5. 方案适配后再正式报价。

前台不出现“Qualified Opportunity / Pipeline / Revenue P0”等内部商业术语。

---

## 八、当前建议的前台资产分工

### 现有价格表
角色：标准服务 / 产品价目表。

### 常驻服务入口
角色：不知道买什么、存在现实问题的人怎么开始。

### 高客单案例 / 执行证据
角色：降低高价购买风险。

三者分开，不要求一张海报同时完成全部商业任务。
