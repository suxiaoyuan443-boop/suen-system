# 赫苏恩 Hesuen Sol｜抖音大号

状态：当前正式规则
最后核对：2026-09-18

## 当前前台合集

前台共 7 个合集：

1. `文物`｜原版资料讲解型
2. `异录`｜神秘学小故事
3. `辨伪`｜神秘学判断题
4. `残页`｜原文拆解
5. `隐理`｜神秘学里没人讲清楚的问题
6. `世问`｜神秘学里的现实问题
7. `牌记`｜塔罗牌

`口述` 不再作为前台合集名称，只保留为内部内容形式/母类。任何口述型选题正式发布前必须归入 `隐理` 或 `世问` 等具体前台合集。

## 栏目选择先看“价值中心”

正式选题边界统一读取：`栏目选题边界与路由.md`。

总控不得先决定今天想发哪个栏目，再把一个题硬改成该栏目的样子。

先问：

> **观众看完以后真正应该记住的是什么？**

快速路由：

- 具体真实对象本身是主角 → `文物`
- 人物、事件、时间线与转折是主角 → `异录`
- 能在明确范围内稳定判对 / 错 → `辨伪`
- 一段原文本身是主角 → `残页`
- 实践者默认接受、但长期没人解释清楚的底层机制是主角 → `隐理`
- 现实遇到以后怎么判断 / 处理是主角 → `世问`
- 一副具体牌在一个具体问题里为什么这样判 → `牌记`

栏目是**内容价值中心的分类**，不是素材标签。出现文物、原文、塔罗牌、历史事件或机制解释，都不能单独决定栏目。

## 对外只保留一条品牌主线

内部可以有 7 个合集、A/B/C/D、实验变量和后台标签，但这些不应该让普通观众感觉成 7 个互不相关的账号。

对外统一认知压缩为：

> **Suen 研究真的存在过、也仍在被实践的神秘学，并把资料、做法和判断讲清楚。**

所有大号内容最终只需落到三种观看体验之一：

1. **奇怪的东西**：文物、手稿、原文、器物、真实历史对象；
2. **奇怪的问题**：为什么这样做、真的假的、原文什么意思、某个做法从哪里来；
3. **现实里的神秘学**：现代女巫实践、塔罗判断、实际工作、今天的人怎么用这些东西。

这三类是品牌层的母方向，不是新的前台栏目，也不要求机械轮播。

现代女巫、古埃及、PGM、塔罗、星符、巫瓶等都只是主线下面的具体对象，不各自发展成独立品牌。

总控定题时额外检查：

- 新题是否仍能回到“资料 / 实践 / 判断”中的至少一项核心能力；
- 连续几条是否让主页看起来像多个无关账号拼在一起；
- 如果只是跟热点或女巫流量，却无法回到 Suen 的真实资料、真实实践或真实判断能力，则不占大号当天唯一发布位。

## 当前发布基线

抖音大号当前实际基线是：**每天 1 条。**

这里的“1条”指：

- 每天只发布 7 个前台合集中的 **1 个栏目 / 1 条内容**；
- 不是 7 个合集每天全部更新；
- 不为了“栏目平衡”一天堆多条。

如果商业总控基于真实数据、用户工作量、平台状态或当天明确指令决定某天停更，可以例外，但必须有实际理由；不能把“是否发布”默认理解成完全随意。

## 调度规则

- 由 `Suen｜内容商业总控` 根据当前瓶颈、近期内容频率、**账号当前已有内容结构**与商业任务决定当天栏目。
- 7 个合集不做机械等量轮播，可以连续发布当前最适合的栏目。
- 纯内容可以只承担流量、精准涨粉或专业信任，不强制销售 CTA。
- A / B / C / D 的完整定义统一读取 `00-系统总控/商业总控.md`。
- 正式定题同时执行 `00-系统总控/选题定稿硬门槛.md` 的账号主页结构检查。

### 账号早期尤其要看主页现在像什么

当大号实际发布样本还很少时，不能只看“最近 7 天有没有重复”，还要看**当前主页全部已发布内容共同形成了什么认知**。

例如：如果当前可见内容几乎全部来自同一个栏目，再继续选同栏目时，总控必须先比较：

- 继续这个栏目是否有明显更强的数据 / 时效 / 证据价值；
- 是否有质量接近、但能让主页出现第二种内容体验的候选；
- 新观众连看主页时，会不会误以为整个账号只讲这一类内容。

这不是要求七个栏目轮流发，也不为了“凑齐栏目”牺牲题目质量。

原则是：

> **强题优先，但账号早期的每一条都在定义“这是什么账号”，所以主页现有结构必须进入选题判断。**

如果两个候选题的质量、证据和流量潜力接近，优先补全账号前台认知，而不是继续堆已经占绝对多数的同一种内容。

## 不同合集主要承担什么

这不是固定 KPI 绑定，只是总控选栏目的优先参考。同一栏目可以根据具体题目承担不同任务，但当天应明确一个主任务。

### A｜流量入口优先

- `文物`
- `异录`
- `辨伪`
- 部分 `隐理`

共同特点：陌生人不需要大量预备知识，就能先被一个具体对象、事件、问题或反差带进去。

### B｜精准涨粉 / 专业信任优先

- `残页`
- `文物`
- `隐理`
- 部分 `辨伪`

共同特点：原典、文物、机制和证据密度更高，能强化“认真查资料、能解释清楚”的品牌识别。

这里的“专业信任”属于 B 类常见辅助目标，不另造第五种主任务。

### C｜服务认知优先

- `世问`
- `牌记`
- 真实实践 / 判断过程类内容

这些内容让观众自然看到 Suen 会怎样判断现实问题、占卜问题和实践边界，但**不等于每条都销售**。

### D｜商业承接

不固定绑定任何一个合集。

商业信号仍由当天商业总控统一决定。不能因为《世问》更接近现实需求，就自动在每条结尾增加咨询、预约或购买引导。

## 当前前台内容公式

优先寻找：

**具体真实对象 + 奇怪 / 神秘现象 + 普通人马上能理解的问题。**

中段再进入：

- 原典
- 馆藏
- 手稿
- 历史语境
- 仪式机制
- 判断过程

长期希望形成的观众认知是：

**“这个账号专门讲真正存在过的神秘事物，而且会把原始证据翻出来给你看。”**

神秘感必须建立在真实文物、真实手稿、真实文本、真实历史记录和真实仪式传统上，不为了流量虚构灵异故事或降低证据标准。

## 内容底线

所有栏目共同遵守：

- 真实性优先
- 原始资料优先
- 可追溯来源优先
- 具体信息优先于氛围
- 明确区分史实、古人观念、学者解释、当事人声称、民间传说与现代实践
- 不把现代拼合包装成未经改变的古代传统
- 不用明显 AI 式开头、空泛升华、营销号腔或连续反驳模板

全局文笔底线读取 `00-系统总控/Suen统一文笔总则.md`。

运营优化可以调整题目、时长、第一屏、信息顺序、案例数量和素材节奏，但不能因此把正式成品改成普通短视频营销文案。

具体成品交付统一读取 `统一交付规则.md`；与付费课程的内容边界读取 `内容与课程区隔.md`。
