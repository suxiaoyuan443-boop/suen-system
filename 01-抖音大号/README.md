# 赫苏恩 Hesuen Sol｜抖音大号

状态：当前正式规则
最后核对：2026-09-17

## 当前前台合集

前台共 7 个合集：

1. `文物`｜原版资料讲解型
2. `异录`｜神秘学小故事
3. `辨伪`｜神秘学判断题
4. `残页`｜原文拆解
5. `隐理`｜神秘学里没人讲清楚的问题
6. `世问`｜神秘学里的现实问题
7. `牌记`｜塔罗牌

`口述` 不再作为前台合集名称，只保留为内部内容形式/母类。任何口述型选题正式发布前必须归入 `隐理` 或 `世问` 等具体前台合集。

## 调度规则

- 大号每个发布日只发 1 条，不在同一天机械堆多个栏目。
- 由 `Suen｜内容商业总控` 根据当前瓶颈、近期内容频率与商业任务决定当天栏目。
- 7 个合集不做机械等量轮播，可以连续发布当前最适合的栏目。
- 纯内容可以只承担流量、精准涨粉或专业信任，不强制销售 CTA。

## 不同合集主要承担什么

这不是固定 KPI 绑定，只是总控选栏目的优先参考。

### 流量入口优先

- `文物`
- `异录`
- `辨伪`
- 部分 `隐理`

共同特点：陌生人不需要大量预备知识，就能先被一个具体对象、事件、问题或反差带进去。

### 精准涨粉 / 专业信任优先

- `残页`
- `文物`
- `隐理`
- 部分 `辨伪`

共同特点：原典、文物、机制和证据密度更高，能强化“认真查资料、能解释清楚”的品牌识别。

### 服务认知优先

- `世问`
- `牌记`
- 真实实践 / 判断过程类内容

这些内容让观众自然看到 Suen 会怎样判断现实问题、占卜问题和实践边界，但**不等于每条都销售**。

### 商业承接

不固定绑定任何一个合集。

商业信号仍由当天商业总控统一决定。不能因为《世问》更接近现实需求，就自动在每条结尾增加咨询、预约或购买引导。

## 当前前台内容公式

优先寻找：

**具体真实对象 + 奇怪 / 神秘现象 + 普通人马上能理解的问题。**

中段再进入：

- 原典
- 馆藏
- 手稿
- 历史语境
- 仪式机制
- 判断过程

长期希望形成的观众认知是：

**“这个账号专门讲真正存在过的神秘事物，而且会把原始证据翻出来给你看。”**

神秘感必须建立在真实文物、真实手稿、真实文本、真实历史记录和真实仪式传统上，不为了流量虚构灵异故事或降低证据标准。

## 内容底线

所有栏目共同遵守：

- 真实性优先
- 原始资料优先
- 可追溯来源优先
- 具体信息优先于氛围
- 明确区分史实、古人观念、学者解释、当事人声称、民间传说与现代实践
- 不把现代拼合包装成未经改变的古代传统
- 不用明显 AI 式开头、空泛升华、营销号腔或连续反驳模板

全局文笔底线读取 `00-系统总控/Suen统一文笔总则.md`。

运营优化可以调整题目、时长、第一屏、信息顺序、案例数量和素材节奏，但不能因此把正式成品改成普通短视频营销文案。

具体成品交付统一读取 `统一交付规则.md`；与付费课程的内容边界读取 `内容与课程区隔.md`。
