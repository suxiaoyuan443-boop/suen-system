## 二A、大号长期内容重心

大号以后以**解释 / 证据 / 原文 / 判断**为主：

- 资料讲解；
- 真实文物；
- 原文拆解；
- 稳定辨伪；
- 有可靠证据支持的实践机制；
- 有真实资料支撑的历史宗教与魔法做法（古术）；
- 具体塔罗牌局判断。

大号不承担仪式日常记录、纯工作现场或神明氛围剪辑的常规生产；这些优先进入抖音小号。

如果历史上某条完整机制讲解误发在小号，而它明显更符合大号定位，可以在总控确认后迁移到大号；迁移视为账号结构纠正，不因此恢复“小号也常规做完整机制讲解”。

## 二B、研究主号规则与实际账号

本目录中的“大号”指承担研究内容的主账号角色；实际账号、停更与试运行状态读取 `08-动态运行/内容台账/当前状态.md`，不从目录名推定发布落点。

经Suen明确决定由新账号接替研究主号时，新号继承本目录的七栏目定位、路由、共同文笔、选题硬门槛、素材和交付规则；不另建一套重复规则。原小号继续按 `01B-抖音小号/` 承担其既定任务，账号调整不自动改变小号定位。

规则继承不等于新号平台合集已经创建，也不自动迁移、删除或重发旧作品。试运行方法读取 `00-系统总控/内容实验与验证规则.md` 六-B；各平台标题、封面与配文按自己的规则调整。

## 视频口播可说性硬规则｜2026-09-26

本栏目所有视频口播同时执行 `00-系统总控/Suen统一文笔总则.md` 与 `99-模板/视频类统一交付格式.md` 的“视频口播可说性硬规则”。

额外确认：
- 口播按真实讲话写，不把馆藏说明、论文摘要直接搬进嘴里；
- 难读英文 / 外文优先换成自然中文解释，原词放字幕、图片或来源；
- 馆藏号、墓号、长串编号默认不念；
- 年代、尺寸只保留真正影响理解的数字，不在一句话里连续塞多组数字；
- 交付前按正常语速读一遍，凡是容易卡、需要提前练、像在念资料卡的句子都继续改。
