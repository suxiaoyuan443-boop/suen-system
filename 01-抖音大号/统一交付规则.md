# 抖音大号｜统一交付规则

状态：当前正式规则
最后核对：2026-09-17

本文件适用于文物、异录、辨伪、残页、隐理、世问、牌记。栏目专用文件可增加要求，但不得降低这里的真实性与来源标准。

共同文笔底线读取 `00-系统总控/Suen统一文笔总则.md`。栏目文件可以增加自己的语气与结构规则。

## 每条正式成品至少包含

1. 完整中文口播
2. 逐句或逐段对应的时间轴
3. 对应画面、镜头或动作
4. 每张资料图/页面的真实可追溯出处
5. 可打开的来源页或直接资料链接
6. 说明图片为什么与该句匹配
7. 封面标题
8. 发布文案

默认只生成当前实际运营需要的中文版本。除非 Suen 当次明确要求，不额外制造英文/TikTok等版本工作量。

## 素材优先级

优先使用：

- 博物馆公开馆藏
- 大学项目
- 数字手稿/纸草/原书扫描
- 原始文献
- 论文与学术出版物
- 历史地图、历史照片、档案页面

找不到准确对应的真实素材时，应明确说明，并改用原文页面、馆藏说明、历史地图或明确标注的复原/示意画面。

不得为了画面好看使用与口播对象无关的文物。

## AI 画面

默认不使用 AI 画面代替真实资料。确需使用复原或示意时必须明确标注，不得冒充真实文物、真实历史现场或原始手稿。

## 信息结构

- Hook 控制在开头约 3—5 秒以内。
- 正文承担至少约 80% 的实际信息量。
- 不允许“标题很猛，正文只有口水”。
- 优先选择圈内不容易一眼识别为常识的内容，或对常见说法做有出处的细化、纠偏和机制解释。

## 文风

- 正经但自然，信息密度高。
- 不使用“你有没有想过 / 很多人不知道 / 你绝对想不到 / 今天带大家看看”等流水线开头。
- 避免连续“不是 / 不能 / 并不 / 不等于 / 不是……而是……”的反驳段落。
- 不用一句一段的碎句堆节奏。
- 不靠“本质上 / 真正重要的是 / 说到底”等空泛总结制造深度。
- 术语出现时必须解释。
- 运营层可以调整题目、时长、信息顺序、案例数量和第一屏，但**不能因为追求流量把 Suen 的口播改成普通营销号文风**。

## 事实边界

需要主动区分：

- 史料直接记载
- 文物/文本能证明到什么程度
- 学术解释
- 当事人声称
- 民间传说
- 后世接受史
- 现代重构或现代实践

如果证据只支持局部结论，就只写局部结论。

## 口述类固定交付格式｜适用于《隐理》与《世问》

《隐理》与《世问》属于内部的“口述类内容”。这两类成品交付时，**不得把完整口播放一块、图片素材又单独放到另一块，让 Suen 自己重新匹配。**

固定使用两栏对应格式：

| 完整口播 | 对应图片/素材链接 |
|---|---|
| 一整段连续、可以直接照着录的完整口播 | 这一段实际对应的图片直链 + 来源页 + 简短画面说明 |
| 下一段完整口播 | 下一段对应图片直链 + 来源页 + 简短画面说明 |

### 左栏｜完整口播

- 放完整的连续口播段落，不拆成一句一句；
- 一段应当可以直接照着录，不需要 Suen 再自己拼句子；
- 同一张图片如果能覆盖连续几句，可以把这些句子合成一个完整口播块；
- 不为了配图把自然口播拆碎。

### 右栏｜对应图片/素材链接

每个口播块右边直接给这一段实际要用的素材，优先包括：

1. **图片直链**：可直接打开图片的 HTTPS URL；
2. **来源页**：博物馆、图书馆、原始文献、项目页或可靠资料页；
3. **画面说明**：这张图具体在这一段展示什么；
4. 必要时补：馆藏号、页码、行号、年代、机构；
5. 如果需要局部放大，明确写“放大哪里 / 圈哪里 / 看哪一行”。

如果当前只有来源页、没有稳定图片直链：

- 明确写“当前未取得稳定图片直链”；
- 仍给来源页；
- 不得只写图片名称而不给任何可打开链接；
- 不得拿不相关的氛围图补位。

### 禁止

口述类内容禁止以下交付方式：

- 先给完整口播，最后再单独列一堆图片；
- 让 Suen 自己判断哪张图对应哪一段；
- 只写“这里放纸草 / 这里放文物”，不给链接；
- 把一句自然口播拆成很多碎句，只为了做到“一句一图”；
- 有来源页却没有说明这一段到底该展示哪里。

### 最终目标

Suen 拿到稿件后，可以直接从上往下操作：

**看左边完整口播 → 录这一段 → 打开右边对应图片链接 → 插入这一段的画面 → 继续下一段。**
