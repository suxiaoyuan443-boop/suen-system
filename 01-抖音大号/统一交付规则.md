# 抖音大号｜统一交付规则

状态：当前正式规则
最后核对：2026-09-17

本文件适用于文物、异录、辨伪、残页、隐理、世问、牌记。栏目专用文件可增加要求，但不得降低这里的真实性与来源标准。

共同文笔底线读取 `00-系统总控/Suen统一文笔总则.md`。栏目文件可以增加自己的语气与结构规则。

**所有视频类正式成品统一继承：`99-模板/视频类统一交付格式.md`。**

即：视频主体默认采用“两栏对应稿”——**左边完整口播 / 台词，右边这一整段真正对应的图片 / 素材链接与画面说明。**

不得再把完整口播与素材清单拆成两个独立区块，也不得为了配图机械一句一图。

## 每条正式成品至少包含

1. 完整中文口播 / 台词
2. 按自然内容块对应的时间轴或时长建议
3. 与每个口播块直接对应的画面、镜头或动作
4. 每张外部资料图 / 页面真实可追溯出处
5. 可打开的来源页或直接资料链接
6. 必要时说明该素材具体看哪里、放大哪里、圈哪里
7. 封面标题
8. 发布文案

默认只生成当前实际运营需要的中文版本。除非 Suen 当次明确要求，不额外制造英文/TikTok等版本工作量。

## 固定视频交付形式

正式视频主体统一使用：

| 完整口播 / 台词 | 对应图片 / 素材链接 |
|---|---|
| 一整段连续、可以直接录制的完整口播 | 这一段真正对应的素材直链 / 来源页 + 具体画面说明 |
| 下一段完整口播 | 下一段对应素材链接 + 来源页 + 使用方式 |

详细规则见 `99-模板/视频类统一交付格式.md`。

栏目可以增加：时间码、馆藏号、页码、行号、镜头动作、实拍要求等，但不能把两栏重新拆散。

## 素材优先级

优先使用：

- 博物馆公开馆藏
- 大学项目
- 数字手稿/纸草/原书扫描
- 原始文献
- 论文与学术出版物
- 历史地图、历史照片、档案页面

找不到准确对应的真实素材时，应明确说明，并改用原文页面、馆藏说明、历史地图或明确标注的复原/示意画面。

不得为了画面好看使用与口播对象无关的文物。

## AI 画面

默认不使用 AI 画面代替真实资料。确需使用复原或示意时必须明确标注，不得冒充真实文物、真实历史现场或原始手稿。

## 信息结构

- Hook 控制在开头约 3—5 秒以内。
- 正文承担至少约 80% 的实际信息量。
- 不允许“标题很猛，正文只有口水”。
- 优先选择圈内不容易一眼识别为常识的内容，或对常见说法做有出处的细化、纠偏和机制解释。

## 文风

- 正经但自然，信息密度高。
- 不使用“你有没有想过 / 很多人不知道 / 你绝对想不到 / 今天带大家看看”等流水线开头。
- 避免连续“不是 / 不能 / 并不 / 不等于 / 不是……而是……”的反驳段落。
- 不用一句一段的碎句堆节奏。
- 不靠“本质上 / 真正重要的是 / 说到底”等空泛总结制造深度。
- 术语出现时必须解释。
- 运营层可以调整题目、时长、信息顺序、案例数量和第一屏，但**不能因为追求流量把 Suen 的口播改成普通营销号文风**。

## 事实边界

需要主动区分：

- 史料直接记载
- 文物/文本能证明到什么程度
- 学术解释
- 当事人声称
- 民间传说
- 后世接受史
- 现代重构或现代实践

如果证据只支持局部结论，就只写局部结论。

## 外部资料链接缺失时

如果某个口播块需要真实外部图片 / 手稿 / 文物，但当前只有来源页、没有稳定图片直链：

- 右栏明确写 `当前未取得稳定图片直链`；
- 仍给来源页；
- 不得只写图片名称却不给任何可打开入口；
- 不得拿不相关的氛围图补位。

如果该段本来就是 Suen 本人实拍：

- 右栏写清镜头、动作、构图；
- 标记 `本人实拍｜无外部链接`；
- 不为了凑链接寻找无关网图。

## 小红书同步

如果当天小红书直接同步同一支抖音成片：

- 视频主体只交一份两栏成片稿；
- 不重新制作第二份视频稿；
- 同一成片稿末尾追加小红书标题、封面文字、发布配文即可。
