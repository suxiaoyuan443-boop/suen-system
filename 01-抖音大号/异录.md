# 异录｜神秘学小故事

状态：当前正式规则
最后核对：2026-10-07

共同文笔、成稿 QA 与完整执行统一读取：`00-系统总控/Suen统一文笔总则.md`。

正式视频交付统一读取：`99-模板/视频类统一交付格式.md`。

本文件只补充本栏目的专属定位、结构、语气与证据要求，不覆盖共同文笔真源。

## 核心定位

《异录》是说书式神秘学故事栏目。

重点不是“把资料念出来”，而是从真实史料、档案、手稿、审判记录、报刊、人物传记或历史研究中，挑出**有人物、有事件、有转折、有奇怪细节**的故事，让观众愿意听完。

故事可以有神秘感、仪式感和画面感，但不能为了好听虚构人物、场景、对白、仪式或结局。

完整栏目路由统一读取：`栏目选题边界与路由.md`。如果一个题真正的价值中心不是人物与事件发展，就不要因为“能讲成故事”硬归《异录》。

## 适合的故事

优先：

- 魔法师、祭司、占星师、灵媒、术士等历史人物；
- 审判记录、控诉、调查、法院档案；
- 灵媒事件与争议案件；
- 手稿流转、遗失、发现、收藏史；
- 某个仪式真正发生过的历史记录；
- 与神秘学有关的历史怪案；
- 有清楚时间线和结局的事件；
- 同一个故事在史料和后世传说里差异很大的案例。

不优先：

- 只有一个概念，没有人物和事件；
- 只能靠都市传说、二手短视频或论坛转述；
- 学界只能确认一小段，却需要虚构大量情节才能讲完整；
- 与《文物》《残页》相比，真正有价值的部分其实是对象或原文而不是故事本身。

## 前台叙事与口播｜2026-10-07

《异录》的前台目标不是“把史料讲清楚”，而是：**把一件有史料底座的玄幻轶事讲得让人愿意一路听到结尾。**

严谨、版本、来源和证据边界必须在后台完成；前台只在真正影响理解的地方标一次来源属性，不把核查过程写进口播。

### 1. 开头允许先说“今天我们来讲什么”

“今天我们来讲……”本身不是禁句。

可以自然使用：

> 今天我们来讲一个发生在1666年伦敦大火之后的故事。那场火刚烧完，议会却把一个占星师叫去问话。

判断标准不是有没有“今天我们来讲”，而是后面有没有立刻进入**当天这个故事独有的人物、事件或怪点**。

避免空壳式开头：

- “今天我们来讲一个神秘学故事。”
- “今天带大家了解一个历史事件。”
- “很多人不知道……”
- “你绝对想不到……”

这类句子删掉题目以后仍然能套到任何视频，不属于 Suen 的自然开场。

### 2. 第一人称不是机械禁止

《异录》允许在开头、转场或带观众进入材料时自然使用少量“我们”，例如：

- “今天我们来讲……”
- “这里我们先回到1651年。”
- “再往后看，这件事又出现了一个版本。”

默认仍然减少作者自我表现，不用“我最近查到 / 我发现 / 我研究了一下”制造真人感。

栏目需要的是**讲故事的人在场**，不是作者反复发表自己。

### 3. 叙事结构只做后台检查，不准直接写成前台提纲

后台需要确认：

- 人物是谁；
- 事情从哪里开始；
- 时间怎么往前走；
- 哪个细节让事情发生变化；
- 转折在哪里；
- 最后怎么收；
- 哪一处需要补史实 / 自述 / 后世传说的边界。

这些只是成稿前检查项，**不是九段式写作模板**。

正式口播不写成：

> 背景 → 人物介绍 → 原因 → 事件 → 关键细节 → 转折 → 结局 → 总结。

故事要像正常说话一样自然推进，前面已经讲清的东西直接往下走，不每一段都重新起承转合一次。

### 4. 不把完整故事压成“事件梗概”

《异录》不设固定字数，也不因为是短视频就默认把人物和事件压成一千字左右的摘要。

资料足够时，应保留真正让故事成立的内容，例如：

- 人物为什么会卷进这件事；
- 前一件事怎样引出后一件事；
- 当事人做了什么；
- 哪个旧文本 / 记录后来重新出现；
- 调查、审判、召见或争议怎样继续推进；
- 事情最后停在哪里。

需要删的是重复、旁枝和解释性废话，不是故事本身。

如果成稿只剩“某年发生A → 某年发生B → 后来有人问C”，即使事实都对，也视为**事件摘要，不是《异录》成稿**。

### 5. 玄幻感由事件本身产生

优先使用史料里已经存在的：

- 怪事；
- 巧合；
- 象征；
- 预言感；
- 多年以后重新出现的旧书 / 手稿 / 记录；
- 调查、审判、传唤；
- 当事人的异常说法；
- 人物命运与后世传说之间的错位。

不要靠“阴森、神秘、诡异、危险、最关键、更离谱”这些形容词替故事制造气氛。

也不要虚构：

- 现场动作；
- 对白；
- 心理活动；
- 没有来源的因果；
- 为了画面感补出的天气、表情、房间气氛或人物反应。

原始记录里有戏剧性强的原话时可以使用，但必须保留“谁说的 / 谁记录的”这一层来源属性。

### 6. 禁止 AI 说书节奏

正式口播重点检查以下问题：

- 不一句一段，不连续用短句人为制造紧张感；
- 不连续三次以上使用同一类句式；
- 不连续抛多个设问替代事件推进；
- 不反复使用“事情还没有结束 / 接下来更离谱 / 奇怪的地方就在这里 / 真正关键的是 / 性质就完全不一样了”等转折提示词；
- 不在每段末尾替观众总结“所以这件事为什么有意思”；
- 不把年份写成机械节拍，如“1665年。瘟疫来了。1666年。大火来了。”；
- 不为了显示严谨反复说“真的 / 确实 / 实际上 / 可确认的是”。

如果删除这些提示词以后故事就不成立，说明正文还没有真正写成故事。

### 7. 严谨藏在后台，但不能消失

史实、当事人自述、证词、后世传说和无法确认的部分仍必须严格分层。

前台处理原则：

- 第一次出现某个关键说法时标明属性；
- 后面继续沿用时不重复免责声明；
- 不把后世解释回写成当时事实；
- 不因为追求玄幻感扩大预言、异象、仪式或人物能力。

可信度主要由原书、档案、传票、报刊、手稿和来源页承担，不靠口播反复强调“这是真的”。

### 8. 结尾停在故事里

结尾优先停在：

- 最后一个有画面的动作；
- 人物最后的处境；
- 一份旧材料后来留下的余波；
- 史实与传说之间仍然存在的缝隙。

不强行写“这告诉我们……”“所以真正重要的是……”，也不把最后一段改成历史课总结。

### 9. 整稿退回标准

出现以下任一情况，视为《异录》文风不合格，整稿重写：

- 像纪录片旁白；
- 像历史冷知识；
- 像学术核查视频；
- 像 AI 把资料“故事化”以后生成的脚本；
- 只有事件顺序，没有人在事件里行动；
- 靠短句、设问和转折提示词制造戏剧性；
- 为了严谨把前台写成不断自证来源的说明文。

一句话验收：

> **去掉来源卡以后，前台像 Suen 在给人讲一件越听越怪、但顺着人物和时间线自然发生下去的事；把来源卡放回去以后，每个怪点又都能追到材料。**

## 真实性分层

故事中的信息必须主动分层：

### 可以确认的史实

来自档案、手稿、人物记录、报刊、学术研究等。

### 当事人或证人的声称

可以讲，但必须用“他声称 / 证人记录称 / 报道写道”等方式保留来源属性。

### 后世传说

可以作为故事接受史的一部分，但要明确它是后世版本，不回写成当时事实。

### 无法确认的部分

如果核心细节无法确认，就不能用确定口吻补齐。

## 画面

优先真实材料：

- 人物肖像；
- 审判记录；
- 手稿；
- 报纸扫描；
- 档案页；
- 历史地点照片；
- 地图；
- 书页；
- 与事件直接相关的文物。

如果没有事件实景，不用 AI 画面假装“当时现场”。

需要建立氛围时，可以使用真实地点、历史地图、原始档案局部、文字排版和环境空镜，不制造伪纪录片感。

## 与其他栏目的区别

- 主要价值在“人物与事件发展” → 《异录》
- 主要价值在“一件文物怎么用” → 《文物》
- 主要价值在“一段原文到底说什么” → 《残页》
- 主要价值在“为什么一个机制会这样运作” → 《隐理》
- 主要价值在“现实遇到这种情况怎么判断” → 先按价值中心重新路由：具体牌局进《牌记》，可证实实践机制进《隐理》；如果只是个人判断 / 服务原则，没有适合大号的证据主角，优先放小号、朋友圈或适合的小红书内容

## 证据要求

正式成品必须至少有一条可靠的一手或高质量二手证据链。

如果是著名传说，必须追到最早可确认版本，而不是直接引用现代网文。

关键人物、日期、地点、事件结果发布前实际核对。

## 栏目漂移红旗｜专用对话必须退件

出现以下任一情况时，不继续按《异录》写：

- 人物和时间线只是开头包装，正文主要在解释一个知识点 / 机制；
- 事件没有真正推进、转折或结果，只是围绕一个文物 / 原文反复说明；
- 去掉人物姓名、年份和事件顺序后，内容几乎原样成立；
- 为了“讲成故事”需要补大量无法核实的场景、心理、对白或因果；
- 观众看完最可能记住的是某件东西怎么用、某段原文怎么翻、某机制为什么存在，而不是“这件事后来怎么发展”。

处理：
- 对象主导 → 《文物》；
- 原文主导 → 《残页》；
- 机制主导 → 《隐理》；
- 无法形成真实故事推进 → 淘汰或换题。

《异录》不能只靠叙事语气冒充故事，必须真的有人物 + 事件 + 时间线。


## 标题定稿｜本栏目专属校准

最终标题必须在故事时间线、转折和结局已经核清以后再定，并先执行 `00-系统总控/内容商业对标系统.md` 的 benchmark title pass。

《异录》的标题优先抓**这件事到底发生了什么**，而不是先介绍人物是谁：
- 陌生历史人物没有天然认知度时，不默认把姓名放在标题最前；
- 优先事件、转折、后果、异常命令、调查、审判、骗局、失踪、公开翻车等能让人自然追问“然后呢”的部分；
- 标题不把整条时间线压缩成一句完整摘要；
- 不使用“一个X为什么…… / 某某背后的故事 / 你绝对想不到……”一类通用故事模板；
- 如果标题删掉人物名以后仍然更好懂、更想点，优先保留事件，不强塞姓名。

本栏目标题优先参考 Let's Talk Religion 的人物 / 历史事件前台化、ESOTERICA 的 familiar_unexpected，以及 Suen 自己的人物事件强样本。只迁移转折和事件入口，不复制具体人物与题目。

## 商业边界

《异录》主要承担流量、停留和品牌氛围，不强制商业连接。

除非总控当天明确指定，否则不在故事结尾突然加入“需要仪式可以私信”等服务导向。

## 正式交付

除 `统一交付规则.md` 外，还需给：

- 人物与事件时间线；
- 哪些是史实、哪些是声称、哪些是后世传说；
- 每个关键画面的来源；
- 若存在多个版本，说明采用哪个版本及原因；
- 故事结局的可靠出处。

## 视频口播可说性硬规则｜2026-09-26

本栏目所有视频口播同时执行 `00-系统总控/Suen统一文笔总则.md` 与 `99-模板/视频类统一交付格式.md` 的“视频口播可说性硬规则”。

额外确认：
- 口播按真实讲话写，不把馆藏说明、论文摘要直接搬进嘴里；
- 难读英文 / 外文优先换成自然中文解释，原词放字幕、图片或来源；
- 馆藏号、墓号、长串编号默认不念；
- 年代、尺寸只保留真正影响理解的数字，不在一句话里连续塞多组数字；
- 交付前按正常语速读一遍，凡是容易卡、需要提前练、像在念资料卡的句子都继续改。
