# 抖音大号｜栏目选题边界与路由

状态：当前正式规则
最后核对：2026-09-17

本文件负责解决一个问题：**一个选题到底应该进入哪个前台合集。**

总控不得先想到一个题，再为了当天想发某个栏目而硬塞进去。必须先判断这个题真正的“价值中心”是什么，再决定栏目。

---

## 总原则｜先看谁是主角

判断栏目时，先问：

> **观众看完这条以后，真正应该记住的是什么？**

是一个具体对象、一个故事、一个对错结论、一段原文、一个底层机制、一个现实判断，还是一副具体牌为什么这样判？

栏目由这个“价值中心”决定，不由素材形式决定。

同一条内容里可以同时出现文物、原文、历史背景和机制解释，但只有一个东西应该是主角。

---

# 1. 文物｜具体真实对象是主角

核心：**这件东西本身值得看。**

适合：

- 某件文物为什么长这样；
- 为什么有这个结构 / 图像 / 铭文；
- 怎么使用；
- 为什么会放在这个位置；
- 某个具体细节说明了什么；
- 一件具体对象的奇怪用途、异常位置、特殊结构与历史做法。

硬判断：

> **把这件具体对象拿掉以后，原来的问题基本就不成立了。**

例如：

- “为什么新亚述人把这些守护小像埋在门下面？” → 《文物》
- “为什么这个护符上有两个孔？” → 《文物》
- “为什么这尊像底部刻了这句话？”如果重点仍是对象结构和用途 → 《文物》

即使内容里解释了某种机制，只要观众的入口、画面主体和核心记忆仍是一件具体对象，就优先归《文物》。

---

# 2. 异录｜人物与事件发展是主角

核心：**这个真实故事值得从头听到尾。**

适合：

- 有人物；
- 有事件；
- 有明确时间线；
- 有奇怪细节；
- 有推进、转折或结果；
- 史料与后世传说之间有值得讲的变化。

硬判断：

> **如果把人物和事件时间线拿掉，内容就失去主要价值。**

只有一个奇怪知识点、一个文物或一段原文，不因为“讲得像故事”就自动成为《异录》。

---

# 3. 辨伪｜能够稳定判对 / 错是主角

核心：**大家容易搞错，但现有证据足够支持明确判断。**

适合：

- 现代常见说法与原始材料不一致；
- 文物用途被长期说错；
- 神明功能被过度简化；
- 两个传统常被混为一谈；
- 某个术语在现代传播中被改了意思。

硬判断：

> **题目必须能够在明确范围内稳定判“对 / 错”。**

如果答案真正是“看时期”“看传统”“证据不足”“学界仍有明显争议”，不要为了栏目形式硬判，改进《残页》《隐理》或长内容。

---

# 4. 残页｜原文本身是主角

核心：**这一句 / 这一段原文到底写了什么。**

适合：

- 纸草具体行；
- 手稿页；
- 咒文具体段落；
- 魔法书具体句子；
- 星符文本；
- 仪式 recipe；
- 经常被误译、截断或二手转述错误的具体文字。

硬判断：

> **观众看完以后，最重要的收获应该是“这一句终于看懂了”。**

如果原文只是拿来证明一个更大的“为什么”，而观众最后应该记住的是机制，就不归《残页》，优先归《隐理》。

---

# 5. 隐理｜默认实践背后的底层机制是主角

前台全名：**神秘学里那些没人讲清楚的问题。**

核心：

> **实践里大家已经默认会做、会要求、会接受，但很少有人真正解释清楚“为什么要有这一步，它到底在系统里承担什么功能”。**

这是底层机制栏目，不是“奇怪历史行为解释栏目”。

优先问题：

- 为什么名字在仪式里重要；
- 为什么要建立边界 / 门槛 / 圆；
- 为什么某些材料通过接触、书写、佩戴等方式可以代表目标；
- 为什么神像 / 护符制作完成以后，还会有启用、临在、奉献等步骤；
- 为什么供品在不同传统里会经历不同的献纳与处理逻辑；
- 为什么仪式会强调特定时间；
- 为什么某些处理方式是埋、烧、沉水，而不是简单丢掉；
- 为什么重复、书写、触碰、涂抹会成为独立仪式动作。

### 两个硬筛选

**A. 去掉具体案例以后，问题仍然成立。**

例如：

- 去掉埃及、PGM、中世纪具体案例，“为什么名字在仪式里重要？”仍然成立 → 《隐理》
- 去掉某批亚述小像以后，“为什么这些小像埋在门下？”这个具体问题就不存在 → 《文物》

**B. 标题里的“为什么”必须真能回答。**

资料必须能够支持一个机制答案：

> X 会这样，是因为 Y。

文物、原文、手稿和案例是用来证明 Y 的，不得拿“例子很多”代替机制答案。

如果只能证明现象存在，或者最关键原因只能说“不知道 / 可能是”，就改题或淘汰。

---

# 6. 世问｜现实中的判断与处理是主角

核心：**现实遇到这种情况，到底怎么看、怎么判断、要不要处理。**

适合：

- 最近一直不顺，要不要净化；
- 什么情况其实不应该做仪式；
- 一件事先占卜、先观察还是先处理现实条件；
- 同一个问题连续占很多次怎么办；
- 什么情况下需要介入，什么情况下先等；
- 委托仪式以前应该先确认什么。

硬判断：

> **答案必须帮助观众处理一个现实情境。**

如果问题是“历史 / 仪式体系为什么会形成这种机制”，归《隐理》；如果是“一副具体牌为什么这么判”，归《牌记》。

---

# 7. 牌记｜一副具体牌为什么这样判是主角

核心：**具体问题 + 具体牌阵 + 具体牌面条件共同产生判断。**

适合：

- 恋人牌在某个复合问题里为什么不能直接判复合；
- 同一张牌在“他怎么想”和“关系怎么发展”里为什么不同；
- 正位看起来很好，为什么周围牌会改变结论；
- 宫廷牌在这个具体牌阵里为什么判人物 / 状态。

硬判断：

> **如果拿掉这副具体牌和问题背景，内容就失去主要判断价值。**

“某张牌是什么意思”不是《牌记》；“为什么占卜不建议反复问同一问题”更适合《世问》或在确有底层机制可讲时进入《隐理》。

---

# 总控快速路由顺序

筛选一个候选题时，按价值中心依次问：

1. **具体对象本身是主角？** → 《文物》
2. **人物 + 事件 + 时间线是主角？** → 《异录》
3. **能够明确判对 / 错？** → 《辨伪》
4. **原文本身是主角？** → 《残页》
5. **是实践者默认接受、但长期没人解释清楚的底层机制？** → 《隐理》
6. **是现实中怎么判断 / 处理？** → 《世问》
7. **是一副具体牌为什么这样判？** → 《牌记》

这个顺序不是机械优先级，而是为了逼迫总控先判断“题的真正价值中心”。

如果一个题同时能放两个栏目，继续问：

> **删掉哪一部分以后，这条内容就最不像原来那条了？**

那一部分通常就是它真正的主角。

---

# 禁止的选题方式

禁止：

- 先决定“今天必须发《隐理》”，再把一个文物题改写成“为什么”；
- 因为题目里有原文，就自动归《残页》；
- 因为有机制解释，就把任何具体文物都归《隐理》；
- 因为有真实历史事件，就把任何内容包装成《异录》；
- 因为一句话看起来有争议，就硬做《辨伪》；
- 因为涉及现实神秘学，就全部塞给《世问》；
- 因为出现塔罗牌，就自动归《牌记》。

栏目是内容价值中心的分类，不是素材标签。
