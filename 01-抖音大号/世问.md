# 世问｜历史栏目说明

状态：**已撤出当前前台生产结构**  
生效：2026-09-19

《世问》不再作为抖音大号 / 小红书独立前台合集，也不再安排机械轮播或独立生产任务。

撤出原因不是“现实判断 / 服务认知”没有价值，而是这类功能单独成栏后需要额外建立一套真人口播、拍摄与剪辑语言，生产成本高，并且与现有栏目、小号、朋友圈和小红书实践内容存在较强重叠。

原《世问》的功能现在这样分配：

- **具体牌局产生的现实判断** → `牌记.md`
- **有可靠资料支持的实践机制 / 为什么这样处理** → `隐理.md`
- **具体文物 / 原文 / 真伪 / 人物事件** → 回各自 `文物 / 残页 / 辨伪 / 异录`
- **纯个人判断、服务原则、是否接某类需求、现实建议** → 优先抖音小号、朋友圈或适合的小红书内容

`C｜服务认知` 继续保留为商业总控的任务标签，可以附着在任何真正适合的栏目 / 平台上，但不再对应一个独立前台合集。

正式路由以：

- `01-抖音大号/栏目选题边界与路由.md`
- `00-系统总控/内容地图.md`

当前最新版为准。

历史已经发布或曾计划的《世问》题目可以保留在台账 / 历史记录中，不需要删除；未发布候选题重新按当前六栏目与平台规则路由。
