## 核心定位

《世问》回答的是：

**“遇到这种情况，到底应该怎么看？”**

它处理现实判断、实践边界和是否需要介入的问题，不负责解释纯机制；纯“为什么”优先归《隐理》。

完整栏目路由统一读取：`栏目选题边界与路由.md`。只有当答案真正帮助观众处理一个现实情境时，才优先进入《世问》。历史 / 仪式体系为什么形成某种机制，不因为“实践里会遇到”就自动归《世问》。

## 主要承担

- 服务认知
- 评论互动
- 现实需求识别
- 潜在询盘前置教育
- 判断过程与边界意识

它不是直接销售栏目，也不以结尾硬性咨询引导作为固定动作。

## 适合选题

优先来自普通人真实会遇到的判断问题，例如：

- 最近一直不顺，到底需不需要做净化？
- 什么情况下其实不该做仪式？
- 一件事应该先占卜、先观察，还是直接处理？
- 仪式做完以后为什么不建议一直盯结果？
- 所谓“能量异常”到底怎么判断，哪些只是情绪或巧合？
- 什么时候需要介入，什么时候应该先等一等？
- 占卜能回答到哪里，什么问题本身就问错了？
- 同一个问题连续占很多次，判断会出现什么问题？
- 现实冲突出现后，什么时候适合用仪式，什么时候应该先处理现实条件？
- 委托一个仪式以前，真正需要先确认哪些条件？

## 内容重点

每条尽量讲清：

1. 现实情境是什么；
2. 先看哪些具体条件；
3. 哪些信号有判断价值；
4. 哪些情况暂时不需要介入；
5. 如果需要处理，应先做什么；
6. 判断边界在哪里。

重点展示“怎么判断”，而不是给一个万能答案。

## 证据与实践

现实问题可以使用：

- 历史资料
- 原典中的边界或做法
- 实际占卜 / 仪式判断逻辑
- 经验性实践条件
- 对现实因素的观察

但要说明依据来自哪一层，不把个人经验伪装成所有传统都适用的历史规则。

涉及具体传统时，必须说明体系；不同文化的规则不能揉成统一“神秘学法则”。

## 文风

《世问》的口播优先级是：**先像一个真人正在回答问题，再保证逻辑完整。**

目标不是“更口语的知识稿”，而是让观众感觉：**刚刚有人真的问了 Suen 这个问题，Suen 现在直接在回答。**

具体执行：

- 可以自然使用“我一般会先问”“你比如说”“那这个时候”“诶，这里就有点不对”“先停一下”“这个其实不用占”等真实说话时会出现的连接和反应；
- 允许少量插话、自我补充、反问和自然停顿，不要求每句话都完整、工整、像书面成稿；
- 可以直接模拟一个现实情境往下讲，例如“你说你想复合，那我肯定先问，你们为什么分？现在还联不联系？”；
- 专业感来自 Suen **实际会问什么、先看什么、什么时候停、什么时候继续**，不要靠“现实条件 / 判断价值 / 介入 / 目标明确 / 前置步骤 / 信息不足”等术语化表达；
- 能说“材料还没交，截止日期就在眼前，那先把材料处理掉”，就不要改写成“先处理现实条件”；
- 能说“聊到这里我还是觉得有地方没搞明白，那我才会占”，就不要写成“当信息不足时，占卜具有进一步判断价值”；
- 不为了显得专业，把一句普通人能直接说清楚的话整理成三项并列、四层框架或定义句；
- 结构可以清楚，但不能让观众明显听出“第一点、第二点、第三点”的稿件骨架；
- 允许保留一点真实说话时的重复和口头连接，只要不拖沓，不需要把每句话都修得过分漂亮；
- 像认真回答一个真实问题，不像课程录音、咨询说明书或 AI 问答稿；
- 不使用 AI 式开头，不堆术语，不连续使用“不是 / 不能 / 并不 / 不等于”等反驳模板；
- 不一句一段制造虚假节奏，不强行升华，不在结尾重新总结一遍已经讲过的全部内容；
- 答案尽早出现，但可以顺着真实案例边讲边把判断说出来，不要求先给一句“标准答案”。


### 文笔活度基准｜2026-09-19确认

Suen 已确认：正式口播需要比“自然、口语”再活一层。以后《世问》不要只做到“没有 AI 味”，而要做到**真的像有人刚在 Suen 面前问了一句，Suen 当场顺着这个人的情况往下问、往下判断。**

执行时优先保留真实说话反应，例如：

- “不一定啊。”
- “等一下，你想干嘛？”
- “那怎么不顺？”
- “你材料交了吗？”
- “什么时候截止？”
- “那你先去交材料啊！”
- “因为我连你发生什么都还不知道呢，我占什么？”
- “诶，等一下，这里好像还有个东西没搞明白。”

这些例句只用于校准**说话的活度、即时反应和现场感**，不是固定句式，不得每条机械复用。

进一步要求：

- 可以直接把对方可能说的话带进口播，再由 Suen 接着追问；
- 问句可以连续出现，只要符合真实聊天过程，不必改写成说明句；
- 允许一句很短的即时判断插进长段落，例如“这个其实不用占”“那你先去做这个”“好，这个时候我才会占”；
- 允许出现轻微情绪和反应，如惊讶、觉得莫名其妙、发现问题、临时停住，但不表演化、不故意夸张；
- 不要把这些真实反应在润色阶段全部磨平，也不要为了语法完整把它们改回书面语；
- 不要把“问清楚 → 发现问题 → 再追问 → 改变判断”提前整理成一套前台框架。观众应该听见判断是怎么一步步发生的；
- 服务认知类内容尤其如此：重点不是告诉观众“服务流程有哪些步骤”，而是让观众直接看见 Suen 面对一个具体问题时会问什么、为什么突然停、什么时候才会继续；
- 成稿如果读起来像“已经整理得很自然的一篇知识稿”，仍然不够活，需要再往真实对话现场推进一层。

最终听感基准：**不像在给观众讲课，而像观众刚好坐在 Suen 对面，问了一句以后，Suen 真的开始回答他。**

### 口播自检

正式交付前把稿子按正常语速读一遍，再问：

1. 这句话像 Suen 嘴里会直接说出来的吗？
2. 有没有为了“专业”把简单话写复杂？
3. 有没有连续出现整理过的并列句、框架词或抽象名词？
4. 如果删掉字幕，只听声音，还像一个人在回答另一个人吗？
5. 有没有一句虽然“完全正确”，但现实里几乎没人会这么说？

如果有，优先改成更直接、更生活化的说法。

## 低成本拍摄与剪辑｜默认模式

《世问》默认优先使用**真人口播极简模式**，因为本栏目核心价值是“一个真实的人在回答现实问题”，不是靠复杂资料蒙太奇建立专业感。

默认拍法：

- 手机竖屏固定机位；
- Suen 本人半身 / 胸口以上出镜；
- 先把整条口播按 3—5 个自然段完整录完；
- 不要求一句口播配一个新镜头；
- 不要求为了每段内容额外拍大量 B-roll；
- 没有证据必要时，可以整段一直保留真人口播；
- 外部图片只在“这张图本身能证明一句关键事实”时插入。

默认剪辑只做：

1. 删口误和过长停顿；
2. 自动字幕 / 手动修正重点词；
3. 关键句可做轻微推近或裁切变化；
4. 必要时插入 1—3 张真实资料图 / 实物图；
5. 不做复杂转场、镜头调度、连续景别变化或大量补拍。

### 世问交付给 Suen 的拍摄说明

正式成稿如果使用真人口播极简模式，交付时默认直接写：

- 主镜头：本人固定机位连续口播
- 这里不用换镜头
- 这里插 1 张图
- 这里轻微推近
- 这里剪掉停顿即可

不要把拍摄说明写成影视分镜教材，也不要给大量可选镜头让 Suen 自己做二次导演判断。

如果一条《世问》在没有硬性证据需求的情况下，需要 Suen 为 60—90 秒口播额外拍很多镜头、准备很多道具或学习复杂剪辑，默认视为制作方案过重，应先降级为真人口播极简模式。

目标：**先让 Suen 能稳定、低成本地把《世问》做出来，再逐步增加拍摄复杂度。**

## 与《隐理》《牌记》的边界

### 隐理

问：**为什么这个底层机制会存在？**

例如：为什么名字在仪式里重要、为什么要建立边界、为什么供品会有特定处理逻辑。

### 世问

问：**现实遇到这种情况怎么看 / 怎么判断 / 要不要处理？**

例如：要不要净化、要不要介入、应该先占卜还是先处理、什么时候不该做仪式。

### 牌记

问：**这一副具体牌为什么这样判？**

如果拿掉具体牌阵以后问题依然是现实判断问题，通常更适合《世问》。

## 商业边界

《世问》可以自然建立服务认知和筛选真实需求，但：

- 不把每个问题都导向付费服务；
- 不把“你需要找我”当固定结尾；
- 不用恐吓制造需求；
- 只有商业总控当天明确指定商业任务时，才加入一个高度相关的商业信号。

## 评论信号

如果评论区持续出现现实判断类问题，可进入《世问》候选池，并在商业总控中记录为“评论信号”。

评论中的明确问价、能否处理、服务内容等，属于服务认知 / 潜在询盘信号，但仍需单独判断，不自动等于有效询盘。

## 交付

正式成品至少包含：

- 标题 / 问题；
- 开头尽早给出答案或判断方向；
- 完整口播；
- 判断条件与边界；
- 需要时给真实案例或资料依据；
- 与每个自然口播块直接对应的图片、画面或动作；
- 涉及历史资料时保留可靠来源；
- 事实与边界核查。

同时遵守本目录 `统一交付规则.md` 与 `99-模板/视频类统一交付格式.md`。

### 最终交付样式

凡是需要“口播 + 对应图片 / 画面”：

- 当前界面支持时：左边完整口播，右边直接显示对应图片；
- 当前界面不支持稳定双栏嵌图时：一段完整口播 → 紧跟对应图片 / 画面 → 下一段完整口播 → 紧跟下一组；
- 不默认增加时间列或预计时间码；
- 不用素材编号 / 文件名代替图片本身；
- 不把图片统一堆到末尾；
- 不要求 Suen 打开 ZIP / TXT 才知道哪段配哪张图。

如果某段主要是现实演示 / 本人动作，就让对应动作说明紧跟该段口播；如果涉及历史资料，则优先直接展示真实资料图片。

最终标准：Suen 看到这段口播时，立刻就知道这一段具体用什么图或什么画面，不需要二次匹配。
