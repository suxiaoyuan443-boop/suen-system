# 辨伪｜神秘学判断题

状态：当前正式规则
最后核对：2026-09-17

共同文笔、成稿 QA 与完整执行统一读取：`00-系统总控/Suen统一文笔总则.md`。

正式视频交付统一读取：`99-模板/视频类统一交付格式.md`。

本文件只补充本栏目的专属定位、结构、语气与证据要求，不覆盖共同文笔真源。

## 核心定位

《辨伪》是一道**证据足够明确、普通人又容易搞错**的神秘学判断题。

核心结构：

**一个明确问题 → 对 / 错判定 → 最关键证据 → 把正确内容讲清楚。**

它不是“打假情绪栏目”，也不是靠嘲讽别人制造优越感。

完整栏目路由统一读取：`栏目选题边界与路由.md`。只有真正能在明确范围内稳定判“对 / 错”的题才进入《辨伪》；如果答案核心是时期差异、传统差异、争议或机制解释，不硬做判断题。

## 固定开头

固定使用：

**“判断题：……对还是错？”**

开头后尽快给判定，不再额外加一层 AI 式钩子。

## 适合选题

必须同时满足：

- 大众确实容易混淆；
- 证据相对明确；
- 能做二元判断；
- 有真实原始资料或可靠研究可支持；
- 判完以后还能讲出一个有价值的正确知识点。

适合：

- 现代常见说法和原始文本不一致；
- 某件文物用途被长期说错；
- 某个神明功能被现代内容过度简化；
- 某个传统经常被和另一个传统混在一起；
- 某个术语在现代传播里被改了意思。

## 不适合选题

不要把下列问题硬做成“对/错”：

- 学界争议很大；
- 不同地区/时期本来就存在多个版本；
- 证据只支持“可能”；
- 需要十分钟背景才能理解题目；
- 问题本身包含错误前提，无法简单判定；
- 只是个人流派偏好，而不是事实判断。

这些更适合《隐理》《残页》或长文。

## 判定方式

开头给出“对 / 错”以后，重点不是连续说“错在哪”，而是马上解释正确内容。

推荐顺序：

1. 判断题；
2. 对 / 错；
3. 最关键的一条证据；
4. 正确情况是什么；
5. 为什么现代容易传错；
6. 必要时补一个例外或时期差异。

## 文风

- 明确、轻松、像朋友认真聊天。
- 不写成审判式“打脸”。
- 不整条连续出现“错 / 不是 / 不能 / 并不 / 不等于”。
- 不堆术语。
- 不一句一段。
- 不强行总结或升华。
- 可以极少量使用栏目人格，例如“这题我会判错 / 判对”，但不要反复出现“我觉得 / 我认为 / 在我看来”。

## 证据

判定必须能落到具体材料：

- 原始文本；
- 文物；
- 手稿；
- 博物馆馆藏说明；
- 学术出版；
- 同行评议研究。

不能只因为“某博主说过”就下结论。

如果同一问题在不同时期/地区答案不同，应在题目里把范围说清楚，例如：

- “在新王国时期……”
- “在 PGM 语境下……”
- “在现存法老时期材料中……”

## 画面

优先让证据直接出现在画面里：

- 判断题文字；
- 原文或馆藏页；
- 关键句高亮；
- 文物细节；
- 必要的时期/地区对照。

不是“人对着镜头说答案 + 背景随便放古埃及图”。

## 与其他栏目的区别

- 能清楚判对/错 → 《辨伪》
- 需要解释“为什么会这样” → 《隐理》
- 需要逐句翻原文 → 《残页》
- 需要讲现实遇到后怎么处理 → 先按价值中心重新路由：具体牌局进《牌记》，可证实实践机制进《隐理》；如果只是个人判断 / 服务原则，没有适合大号的证据主角，优先放小号、朋友圈或适合的小红书内容

## 栏目漂移红旗｜专用对话必须退件

出现以下任一情况时，不继续按《辨伪》交付：

- 开头能说“对 / 错”，但正文最后其实只能落到“看时期 / 看地区 / 看传统 / 证据不足”；
- 为了维持二元判定，必须忽略重要例外或争议；
- 真正有价值的是解释一个机制，而不是纠正真假；
- 真正有价值的是拆一段原文 / 一个术语，而“判断题”只是包装；
- 判完“对 / 错”以后，核心内容仍可以完全脱离这个判定成立。

处理：
1. 能缩小范围后稳定二分 → 缩题继续《辨伪》；
2. 机制更重要 → 《隐理》；
3. 原文 / 术语更重要 → 《残页》；
4. 仍然只能回答“复杂 / 有争议” → 不做《辨伪》。

不允许为了保栏目制造假确定性。


## 标题定稿｜本栏目专属校准

最终标题必须在“对 / 错”确实能够稳定成立以后再定，并先执行 `00-系统总控/内容商业对标系统.md` 的 benchmark title pass。

《辨伪》的标题不等于机械写“X是真的吗？”：
- 优先把**观众原本相信的判断**放到前台，再看是否存在足够大的认知落差或现实后果；
- “真假 / 真相 / 误解”只有在对象本身值得在意时才有用，不能拿这些词替代题眼；
- 题目如果只能回答“看时期 / 看地区 / 看传统”，不得靠标题强行二元化；
- 可以是陈述句，也可以是判断问句；形式服从当前题目最自然的说法；
- 固定“判断题：……对还是错？”属于视频开头格式，不自动等于最终发布标题。

本栏目标题优先参考 Angela Puca 的 practice_dispute、Let's Talk Religion 的 misunderstood / truth / dispute 类入口，以及 Suen 自己的辨伪后验。迁移的是“为什么值得重新判”，不是把所有题都写成“真相”。

## 商业边界

《辨伪》主要承担精准涨粉与专业可信度。除非商业总控明确指定，否则不自行加入服务 CTA。

## 正式交付

除 `统一交付规则.md` 外，还需给：

- 完整判断题句子；
- 明确判定；
- 最关键证据；
- 适用时期/地区/传统范围；
- 如果存在例外，明确例外；
- 证据画面具体高亮位置；
- 资料来源。

## 视频口播可说性硬规则｜2026-09-26

本栏目所有视频口播同时执行 `00-系统总控/Suen统一文笔总则.md` 与 `99-模板/视频类统一交付格式.md` 的“视频口播可说性硬规则”。

额外确认：
- 口播按真实讲话写，不把馆藏说明、论文摘要直接搬进嘴里；
- 难读英文 / 外文优先换成自然中文解释，原词放字幕、图片或来源；
- 馆藏号、墓号、长串编号默认不念；
- 年代、尺寸只保留真正影响理解的数字，不在一句话里连续塞多组数字；
- 交付前按正常语速读一遍，凡是容易卡、需要提前练、像在念资料卡的句子都继续改。
