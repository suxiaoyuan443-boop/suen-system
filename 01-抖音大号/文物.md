# 文物｜原版资料讲解型

状态：正式迁移版
最后更新：2026-09-17

## 定位

资料主体型栏目。核心是带观众一起看真实文物、博物馆页面、原始书页、手稿、纸草与历史图像。

## 核心规则

- 资料始终是主体，人物绿幕只作为辅助。
- 用户本人可使用左下角小绿幕头像，头像尺寸偏小，不抢资料主体。
- 正式口播不使用作者第一人称。
- 禁止“我最近看到 / 我查到 / 我觉得 / 今天我来讲”等作者式引入。
- 允许“先看这里 / 这一行写的是 / 再看这件东西胸口的位置 / 最关键的是这一处”等带看式表达。
- 不使用 AI 式开头，例如“你有没有想过 / 很多人不知道 / 你绝对想不到”。
- 避免连续使用“不是 / 不能 / 并不 / 不等于”等反驳句式。
- 专业感来自真实资料与具体细节，而不是术语堆砌。

## 画面

优先：文物原图、博物馆页面、原始书页、纸草、历史图像、局部放大与标注。

## 交付

每条正式成品应包含：镜头/画面、动作、完整口播字稿、时长建议、配图直链或资料来源。
