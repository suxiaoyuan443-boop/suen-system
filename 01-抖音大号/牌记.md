# 牌记｜塔罗牌

状态：当前正式规则
最后核对：2026-09-17

## 核心定位

《牌记》不做词典式牌义教学。

核心问题始终是：

**“为什么在这个具体问题里，这张牌要这样判？”**

专业感来自判断过程，而不是背关键词。

## 固定判断逻辑

**牌义 → 问题 → 所在位置 → 正逆位 → 周围牌 → 现实背景 → 最终判断**

任何一张牌都不能脱离问题直接下结论。

## 核心规则

- 必须先明确提问是什么；
- 必须知道牌在牌阵中的位置或功能；
- 正逆位只作为判断条件之一，不替代整体牌阵；
- 必须看周围牌如何修改、强化或限制这张牌；
- 必须结合现实背景；
- 最终判断要能解释“为什么”，不能只给结论。

不做：

- “抽到恋人 = 一定复合”；
- “抽到死神 = 一定分手”；
- “圣杯二 = 他一定爱你”；
- “恶魔 = 一定有第三者”；
- 单张牌关键词套现实。

## 适合选题

优先选大众很容易套关键词、但实际需要重新判断的场景：

- 恋人牌出现在复合问题里为什么不一定是复合；
- 死神在关系问题里什么时候才真的指向结束；
- 圣杯二为什么不等于稳定关系；
- 星币十在感情问题里为什么可能更多指现实结构；
- 高塔出现在工作问题里到底看什么；
- 宫廷牌什么时候代表人物，什么时候更像状态；
- 同一张牌在“他怎么想”和“关系会怎么发展”里为什么会判得不一样；
- 正位看起来很好，但周围牌为什么会把结果拉下来；
- 逆位什么时候是阻滞、内部化、减弱或另一种表现，而不是简单“反义词”。

## 不适合做成《牌记》的内容

- 单纯“XX 牌是什么意思”；
- 一张牌十个关键词；
- 没有真实问题背景的牌义百科；
- 为了流量编造客户案例；
- 把一次私人客户占卜原封不动公开。

## 一条内容怎么讲

推荐顺序：

1. 先说具体问题；
2. 展示牌阵 / 当前牌位；
3. 说明普通人最容易怎么套关键词；
4. 回到这张牌在这个问题里的实际功能；
5. 看正逆位；
6. 看旁边的牌；
7. 加入现实背景；
8. 给最终判断；
9. 解释如果某个条件改变，结论为什么也可能变。

不需要每次显式念出 9 步，但判断不能跳步骤。

## 文风

- 可以少量使用第一人称经验，例如“这张我会先看……”；
- 不反复使用“我觉得 / 我认为 / 在我看来”；
- 不使用 AI 式开头；
- 不堆关键词；
- 不一句一段；
- 不连续反驳；
- 不强行升华；
- 不用玄而又玄的“能量告诉你……”代替判断逻辑。

如果判断确实存在不确定性，就明确说条件不足，不为了视频完整硬给确定答案。

## 真实案例与隐私

使用真实看牌经验时：

- 不泄露客户身份；
- 不公开能识别个人的信息；
- 必要时把具体背景抽象成不可识别的案例；
- 不为了内容效果编造客户反馈或最终结果。

## 拍摄规则

继续使用 Suen 本人的真实塔罗牌、真实桌面和真实手部操作。

重点增加“正在判断”的过程：

- 现场翻牌；
- 手部操作；
- 牌阵逐步展开；
- 指牌；
- 停顿；
- 移动或重新排列牌；
- 对比两张牌；
- 补牌（只有实际判断需要时）；
- 重新判断或补充结论。

减少：

- 全程固定俯拍；
- 牌早就摆得整整齐齐再照稿讲；
- 字幕像知识卡模板；
- 为了“高级感”加入与判断无关的 AI 画面。

## 画面和口播关系

口播说到哪张牌，镜头就让观众明确看到哪张牌。

涉及：

- 正逆位；
- 牌阵位置；
- 周围牌；
- 两张牌之间的关系

时，要用手势、局部放大或简单标注帮助观众跟上。

## 与其它栏目的边界

### 牌记

回答：**这副牌为什么这样判？**

### 世问

回答：**现实遇到这种神秘学问题应该怎么判断 / 处理？**

例如：

- “同一个问题连续占很多次会怎么样？” → 《世问》
- “为什么这组复合牌里恋人牌反而不能直接判复合？” → 《牌记》

## 商业边界

《牌记》可以自然建立塔罗服务认知，但不要求每条结尾都写：

- 可以找我占；
- 私信预约；
- 多少钱。

只有商业总控当天明确分配塔罗商业信号时，才加入一个高度相关的承接。

## 正式交付

生成正式《牌记》成品至少包含：

- 具体问题；
- 牌阵 / 牌位；
- 牌面；
- 正逆位；
- 周围牌；
- 现实背景；
- 完整判断过程；
- 最终结论；
- 对应的翻牌 / 指牌 / 停顿 / 调整动作；
- 完整口播；
- 时长；
- 标题与发布文案。

《牌记》以真实牌面和真实操作为主，不需要为每张牌寻找历史资料配图；通用文风与交付仍读取 `统一交付规则.md`。
