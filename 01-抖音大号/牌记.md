# 牌记｜塔罗牌

状态：当前正式规则
最后核对：2026-09-19

共同文笔、成稿 QA 与完整执行统一读取：`00-系统总控/Suen统一文笔总则.md`。

正式视频交付统一读取：`99-模板/视频类统一交付格式.md`。

本文件只补充本栏目的专属定位、结构、语气与证据要求，不覆盖共同文笔真源。

## 核心定位

《牌记》不做词典式牌义教学。

核心问题始终是：

**“为什么在这个具体问题里，这张牌要这样判？”**

专业感来自判断过程，而不是背关键词。

完整栏目路由统一读取：`栏目选题边界与路由.md`。只有当**具体问题 + 具体牌阵 + 具体牌面条件**本身是内容主角时，才优先进入《牌记》。如果拿掉这副具体牌以后，问题依然成立，就不要为了服务认知硬塞进《牌记》；有可证实机制时回《隐理》，纯现实判断 / 服务原则优先放小号、朋友圈或适合的小红书内容。

## 固定判断逻辑

**牌义 → 问题 → 所在位置 → 正逆位 → 周围牌 → 现实背景 → 最终判断**

任何一张牌都不能脱离问题直接下结论。

## 核心规则

- 必须先明确提问是什么；
- 必须知道牌在牌阵中的位置或功能；
- 正逆位只作为判断条件之一，不替代整体牌阵；
- 必须看周围牌如何修改、强化或限制这张牌；
- 必须结合现实背景；
- 最终判断要能解释“为什么”，不能只给结论。

不做：

- “抽到恋人 = 一定复合”；
- “抽到死神 = 一定分手”；
- “圣杯二 = 他一定爱你”；
- “恶魔 = 一定有第三者”；
- 单张牌关键词套现实。

## 适合选题

优先选大众很容易套关键词、但实际需要重新判断的场景：

- 恋人牌出现在复合问题里为什么不一定是复合；
- 死神在关系问题里什么时候才真的指向结束；
- 圣杯二为什么不等于稳定关系；
- 星币十在感情问题里为什么可能更多指现实结构；
- 高塔出现在工作问题里到底看什么；
- 宫廷牌什么时候代表人物，什么时候更像状态；
- 同一张牌在“他怎么想”和“关系会怎么发展”里为什么会判得不一样；
- 正位看起来很好，但周围牌为什么会把结果拉下来；
- 逆位什么时候是阻滞、内部化、减弱或另一种表现，而不是简单“反义词”。

## 不适合做成《牌记》的内容

- 单纯“XX 牌是什么意思”；
- 一张牌十个关键词；
- 没有真实问题背景的牌义百科；
- 为了流量编造客户案例；
- 把一次私人客户占卜原封不动公开；
- 拿掉具体牌阵以后依然只是“现实中该怎么办”的问题。

## 一条内容怎么讲

推荐顺序：

1. 先说具体问题；
2. 展示牌阵 / 当前牌位；
3. 说明普通人最容易怎么套关键词；
4. 回到这张牌在这个问题里的实际功能；
5. 看正逆位；
6. 看旁边的牌；
7. 加入现实背景；
8. 给最终判断；
9. 解释如果某个条件改变，结论为什么也可能变。

不需要每次显式念出 9 步，但判断不能跳步骤。

## 文风

《牌记》的口播必须先像真人正在看牌，再保证判断链完整。

它不是“牌义课口语版”，而应该像 Suen 正在桌前看这一副牌，边看边告诉观众自己为什么会这样判。

具体执行：

- 可以自然说“这张我第一眼不会先看感情”“你看它放在这个位置就不一样了”“等一下，旁边这张一出来，前面的意思就要改”“这组我不会直接判复合”等真实看牌时会说的话；
- 允许“诶、你看、等一下、这里就有意思了、我会先看……”这类自然口头连接，但不要为了口语感故意堆语气词；
- 可以边指牌边讲，不必先把牌义完整定义，再套进问题；
- 专业感来自**现场怎么取舍、哪张牌改变了判断、为什么这一张在这个位置不能照关键词读**，而不是术语、关键词和完整定义；
- 能说“旁边这张一出来，我就不会把恋人直接当复合”，就不要写成“周围牌对核心牌义形成限制与修正”；
- 能说“如果问的是他怎么想，我会这么看；但问关系会不会继续，我就不会这么判”，就不要整理成抽象的“问题维度改变牌义功能”；
- 判断逻辑“牌义 → 问题 → 牌位 → 正逆位 → 周围牌 → 现实背景 → 结论”是**后台检查顺序**，不是前台口播模板；
- 不要求每条视频把所有步骤逐项念出来，只要实际判断没有漏掉会改变结论的关键条件；
- 不为了完整，把一副牌讲成“三点原因”“四个层次”“五个判断依据”；
- 允许有现场改判：前面先说初步感觉，看到旁边牌后自然补一句“那这样我会改”，这比把最终答案一次性整理得过于完美更像真实看牌；
- 可以少量使用第一人称经验，但不反复使用“我觉得 / 我认为 / 在我看来”；
- 不使用 AI 式开头，不堆关键词，不一句一段，不连续反驳，不强行升华；
- 不用“能量告诉你”“宇宙在暗示”等抽象话代替具体牌面判断。

如果判断确实存在不确定性，就直接说“这几张还不够”“这里我不会现在就下结论”“还得看……”，不要为了视频完整硬给确定答案。


### 文笔活度基准｜2026-09-19确认

Suen 已确认：《牌记》不能只做到“像真人讲牌”，而要像**Suen 真的正在桌前看这一副牌，看到哪、想到哪、发现哪张牌改变了前面的判断，就当场说出来。**

执行时允许并鼓励真实看牌反应，例如：

- “等一下，这张一出来就不太一样了。”
- “你先别急着看恋人牌，我会先看它在哪个位置。”
- “诶，这里我刚才那个判断要改一下。”
- “如果只看到前两张，我可能会这么判，但旁边这张出来以后就不行了。”
- “这个我现在不会直接下结论，还得往后看。”
- “你看，这就是为什么我不会看到这张牌就直接说复合。”

这些例句只用于校准**即时反应、现场感和说话活度**，不是固定模板，不得机械复用。

进一步要求：

- 可以让观众听见判断形成的过程，而不是只听整理好的最终解释；
- 允许前一句给出初步感觉，下一张牌出现以后马上改口、补充或收回；
- 允许短反问、插话、停顿和“等一下 / 诶 / 你看”一类自然连接，只要确实跟当前牌面变化有关；
- 不要在润色时把现场改判全部消灭，真实判断本来就可能有“先这么看 → 看到另一张 → 改”的过程；
- 后台仍然完整检查问题、牌位、正逆位、周围牌、现实背景等条件，但前台不要把它们整理成教学步骤；
- 不要为了专业感把“这张一出来我就不会这么判了”改成“周围牌对核心牌义形成限制”；
- 成稿如果听起来像一个老师把一次占卜复盘得非常完整，仍然太整齐；目标是让人感觉这一副牌正在眼前被判断。

最终听感基准：**不像塔罗教学视频，也不像整理后的案例复盘，而像观众正坐在桌子另一边，看 Suen 一边看牌一边把脑子里的判断说出来。**

### 口播自检

正式交付前按正常语速读一遍，再问：

1. 这像 Suen 正在桌前看牌，还是像老师在讲牌义？
2. 有没有一句话本来能指着牌直接说，却被写成了术语？
3. 判断步骤是不是偷偷变成了“第一、第二、第三”的课程结构？
4. 有没有把现场本来会有的停顿、改判、补充全部修得过分整齐？
5. 如果观众闭上眼睛只听声音，会不会觉得这就是一个人在真实看牌？

不符合时，优先改成更直接、更像现场判断的说法。

## 真实案例与隐私

使用真实看牌经验时：

- 不泄露客户身份；
- 不公开能识别个人的信息；
- 必要时把具体背景抽象成不可识别的案例；
- 不为了内容效果编造客户反馈或最终结果。

## 拍摄规则

继续使用 Suen 本人的真实塔罗牌、真实桌面和真实手部操作。

重点增加“正在判断”的过程：

- 现场翻牌；
- 手部操作；
- 牌阵逐步展开；
- 指牌；
- 停顿；
- 移动或重新排列牌；
- 对比两张牌；
- 补牌（只有实际判断需要时）；
- 重新判断或补充结论。

减少：

- 全程固定俯拍；
- 牌早就摆得整整齐齐再照稿讲；
- 字幕像知识卡模板；
- 为了“高级感”加入与判断无关的 AI 画面。

## 画面和口播关系

口播说到哪张牌，镜头就让观众明确看到哪张牌。

涉及：

- 正逆位；
- 牌阵位置；
- 周围牌；
- 两张牌之间的关系

时，要用手势、局部放大或简单标注帮助观众跟上。

## 与其它内容的边界

《牌记》只在**具体问题 + 具体牌阵 + 具体牌面条件**共同产生判断时成立。

如果没有具体牌局：

- 可证实的占卜 / 仪式实践机制 → 优先《隐理》；
- 个人服务原则、现实建议、是否接某类需求 → 优先小号、朋友圈或适合的小红书内容；
- 不为了“服务认知”虚构牌阵或补一副无必要的牌。

C｜服务认知可以成为《牌记》的当天任务，但服务认知必须从真实看牌过程自然产生，不能覆盖栏目本身。

## 商业边界

《牌记》可以自然建立塔罗服务认知，但不要求每条结尾都写：

- 可以找我占；
- 私信预约；
- 多少钱。

只有商业总控当天明确分配塔罗商业信号时，才加入一个高度相关的承接。

## 正式交付

生成正式《牌记》成品至少包含：

- 具体问题；
- 牌阵 / 牌位；
- 牌面；
- 正逆位；
- 周围牌；
- 现实背景；
- 完整判断过程；
- 最终结论；
- 完整口播；
- 每个自然口播块直接对应的真实牌面、实拍画面或动作；
- 标题与发布文案。

《牌记》以真实牌面和真实操作为主，不需要为每张牌寻找历史资料配图；通用文风与交付读取 `统一交付规则.md` 与 `99-模板/视频类统一交付格式.md`。

### 最终交付样式

如果已经有牌面照片、已上传素材或可直接显示的真实牌面：

- 当前界面支持时：左边完整口播，右边直接显示对应牌面 / 局部图；
- 当前界面不支持稳定双栏时：一段完整口播 → 紧跟对应牌面图片 → 下一段完整口播 → 紧跟下一组。

如果这一段主要依赖现场翻牌 / 指牌 / 移动牌面：

- 该段完整口播后立刻紧跟具体动作说明；
- 例如 `本人实拍｜翻开第三张后停 2 秒，手指点恋人牌，再把镜头推近周围两张牌`；
- 如果已有对应实拍素材，优先直接显示 / 引用，而不是只写文件名。

默认不增加时间列或预计时间码，不用素材编号 / 文件名代替真实牌面或动作，不要求 Suen 打开 ZIP / TXT 才完成口播与画面的匹配。

最终标准：**口播说到哪张牌，Suen 在同一位置就能立刻看到 / 知道这一段要展示哪张牌和怎么拍。**
