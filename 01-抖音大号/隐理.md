# 隐理｜神秘学里没人讲清楚的问题

状态：当前正式规则  
最后核对：2026-09-19

共同文笔、成稿 QA 与完整执行统一读取：`00-系统总控/Suen统一文笔总则.md`。

本文件只补充本栏目的专属定位、结构、语气与证据要求，不覆盖共同文笔真源。

## 一、核心定位

《隐理》解释：

> **神秘学实践里大家已经默认会做的一步，为什么存在？它实际起什么作用？**

主角是**机制**，不是某件文物、某一段原文、某个人物或某个现实咨询问题。

栏目路由读取：

`栏目选题边界与路由.md`

## 二、两个入选条件

### 1. 去掉具体案例，问题仍然成立

例如：

- 为什么名字在仪式里重要 → 可以成立；
- 为什么很多仪式要先画圈 / 规定位置 → 可以成立；
- 为什么某批具体守护像被埋在某扇门下 → 更像《文物》。

### 2. “为什么”真的有证据答案

标题问“为什么 X”，最终必须能回答：

`因为 Y`

而且 Y 有可靠材料支持。

如果只能证明“这个现象存在”，却解释不了原因，就改题或换栏目。

尤其不要为了回答：

- 偏偏为什么是某个数字；
- 某个材料为什么一定如此；
- 某一步为什么具有某个万能象征

而用现代猜测、泛能量理论或无证据联想补洞。

## 三、优先题型

适合：

- 名字；
- 重复；
- 圆 / 门槛 / 方向；
- 时间；
- 材料；
- 接触、书写、佩戴；
- 供品；
- 临在 / 启用 / 奉献；
- 埋、烧、沉水等处理动作。

不适合：

- 纯现实咨询 / 个人服务原则，没有可证实机制主角 → 不强塞大号，优先小号、朋友圈或适合的小红书内容；
- 稳定对 / 错 → 辨伪；
- 主角是一段原文 → 残页；
- 主角是一件具体对象 → 文物；
- 主角是人物 / 事件时间线 → 异录。

## 四、内容结构

答案尽早出现。

优先顺序：

1. 先给一句核心答案；
2. 说清实际发生了什么；
3. 当时文本 / 实践者怎样理解；
4. 这个动作在该系统里起什么作用；
5. 如果跨时期 / 传统，分别讲清差异；
6. 后世解释有没有变化；
7. 最后只补现代常见混淆，不重新总结整条视频。

每个案例都必须增加新信息。没有新增功能、时期差异、动作或证据的案例删除。

## 五、跨文化

跨文化比较不等于寻找一个“所有魔法都这样”的共同原理。

古埃及、希腊—埃及、犹太、中世纪、近代仪式魔法、民间实践、现代重构需要按真实材料分别处理。

只有存在传播、翻译、文本借用、人员交流或接受史证据时，才讨论直接影响。

## 六、证据

优先：

- 原始文本；
- 神庙日课；
- 手稿；
- 文物；
- 仪式 recipe；
- 学术研究；
- 有上下文的历史案例。

只有现代 occult 作者解释时，明确写现代解释，不反写成古代通则。

## 七、时长

《隐理》**没有几十秒硬上限**。

已存在 4分44秒成片先例。

常见可落在约 **3—5分钟**，但不是硬卡秒：

- 2分钟讲清就结束；
- 4—5分钟才讲清就保留；
- 优先删重复、背景铺垫和不推进答案的案例，不删核心机制。

前 5—10 秒尽快进入问题和答案方向。

## 十、商业边界

《隐理》主要承担精准涨粉和专业信任。

当题目本身确实有可证实的实践机制时，《隐理》可以承担 C｜服务认知，让观众在理解机制的同时知道 Suen 实际会怎么判断 / 处理。但 C 是任务标签，不改变《隐理》“机制为主角”的栏目标准。

除非商业总控当天明确指定，不自行加入接单、价格、预约或购买 CTA。
