# Suen｜Patreon

状态：当前正式平台规则  
最后核对：2026-09-24

Patreon 是 Suen 商业系统里的**海外付费研究档案 + 订阅会员层**。

它不是新的日更公域账号，不承担抖音 / 小红书那种高频流量任务，也不要求把中文内容机械翻译后重复发布。

## 当前定位

> **Suen 的西方神秘学研究与实践付费档案。**

主要承接：

- 完整研究文章；
- 原始资料 / 手稿 / 纸草 / 文物专题；
- 某个具体魔法传统、仪式或做法的来源研究；
- 阅读笔记与资料整理；
- 历史魔法与现代实践之间的关系；
- Suen 愿意公开的真实实践记录；
- 后续可下载资料包（真正准备好文件以后再启用）。

## 当前商业结构

当前唯一付费档位：

**Research & Practice｜US$5 / month**

当前核心权益：

1. **Full Research Essays**
2. **Selected Practice Records**

暂时不为了“看起来福利多”硬拆重复权益。

只有真正持续提供下载文件后，才新增：

**Downloadable Source Packs**

当前不默认包含：

- 一对一咨询；
- 定制仪式；
- 塔罗；
- Discord / 社群；
- 实物邮寄；
- 对外固定周更 / 月更数量承诺。

这些如果以后要增加，必须回到 Suen｜内容商业总控 重新决定。

## 平台角色

Patreon 当前主要解决：

- 把 Suen 已经投入的大量研究变成可重复售卖的数字资产；
- 让公开短内容背后的完整研究有明确付费去处；
- 建立英文 / 海外受众的长期付费档案；
- 测试订阅型收入，而不是靠一次性定制服务承接全部现金流。

当前经营状态统一读取 `08-动态运行/商业/当前商业状态.md`。截至 2026-09-24，Patreon **暂停主动生产与运营推进**：不进入日更 / 周更任务，也不设内部篇数目标；只有 Suen 明确恢复后再重新决定频率。

恢复后优先验证：

- 是否有人愿意订阅；
- 哪类研究文章最容易带来付费；
- 订阅后是否愿意继续留存；
- 实践记录与研究文章各自的阅读 / 留存表现。

## 内容与公开层

Patreon 可以同时有公开帖和付费帖。

公开内容主要承担：

- Start Here / 页面说明；
- 研究预览；
- 阅读材料 / 更新说明；
- 部分公开研究笔记。

付费内容主要承担：

- 完整研究文章；
- 完整资料链；
- 版本比较；
- 具体文本 / 手稿 / 文物分析；
- Selected Practice Records。

公开内容不是广告垃圾桶，付费内容也不能只是抖音口播加长版。

## 语言

正式发布默认：

1. **英文正式版**
2. **中文完整核对版**

英文必须自然，不做中文直译腔。

## 与其它平台的关系

Patreon 是**深度付费层**，不是第 6 个需要机械日更的平台。

典型链路可以是：

公开平台的具体问题  
→ Patreon 公开预览 / Start Here  
→ Patreon 完整付费研究文章  
→ 长期付费档案

可以复用同一研究主题，但不能把抖音 / 小红书原稿原样搬过去收费。

## 商业边界

Patreon 专用内容对话不自行决定：

- 是否涨价；
- 是否新增档位；
- 是否开放咨询 / 仪式 / 星符；
- 是否增加一次性数字产品；
- 是否在抖音 / 小红书 / 公众号主动引流；
- 当天是否把 Patreon 设为主要商业信号。

这些都回到 Suen｜内容商业总控。

## 收款与隐私

Patreon 已完成收款方式配置。

仓库**不保存**：

- 银行卡号；
- 身份证件号；
- 住址；
- 税务表单具体个人信息；
- Payoneer / PayPal 账号；
- 其它付款隐私。

只记录“收款基础设施已配置”这一经营状态。

## 内容生产规则

Patreon 正式成稿固定读取：

1. `00-系统总控/Suen统一文笔总则.md`
2. `06-Patreon/Patreon研究与实践规则.md`

前者负责 Suen 的共同文风底线，后者负责 Patreon 英文长文与研究专属要求。两者缺一不可。

## 新对话接管

Patreon 长研究如果已经多轮返工、旧稿明显干扰执行，可以直接新开专用对话。

新对话固定先读：

- `00-系统总控/Suen统一文笔总则.md`
- `06-Patreon/Patreon研究与实践规则.md`

只迁移可靠研究成果与当前任务，不迁移失败稿的写作惯性。


## 长研究任务执行方式

同时涉及多手稿研究、找图、双语全文和 DOCX / HTML 的任务，默认在普通 Chat 中分阶段完成。Work 仅作为 Suen 主动选择的可选加速方式，不作为 Patreon 默认消耗。

内部仍按“来源核查 → Figure Manifest → 文本复原 → 英文成稿 → 中文核对 → 文件验收”推进；普通 Chat 可拆成 2—4 个独立轮次，每轮输出可复用的阶段成果。

普通 Chat 如果已经连续两次长时间执行后中断，不再重复同一超长单轮请求。
