# 塔罗判断训练系统｜架构

状态：当前正式规则
建立：2026-09-23

## 四层结构

### A｜原始资产层
百度网盘等 Suen 私有资料源。保存课程视频、音频、PDF、课件、原始字幕。默认只读，不为了训练重排母库。

### B｜索引 / 转录层
保存轻量派生信息：路径、fsid、文件名、类型、大小、是否已有 content / abstract、字幕状态、来源时间戳。

优先使用百度网盘已生产的视频字幕 / 音频文稿 / 摘要；只有缺失且确实需要的文件才下载并转录。

### C｜案例与规则层
案例按 `01-案例数据规范.md` 结构化；多案例归纳按 `02-规则提取与证据等级.md`。

### D｜Suen 采用与运行层
候选规律必须经过 adopted / modified / observe / rejected，再进入运行时。

## 数据流

```text
百度网盘原始母库
→ 只读索引
→ content / abstract 检查
→ 高信息案例初筛
→ 已有字幕优先
→ 案例结构化
→ 规则候选 + 反例
→ Suen 采用层
→ 运行时解牌 / 《牌记》
```

缺字幕时才走：

```text
目标视频 → 定向下载 → FFmpeg抽音频 → 语音转录 → 时间戳文本 → 案例结构化
```

## 当前工具层参考

- 官方 `baidu-netdisk/mcp`：目录 / 文件 / 视频 / 语义搜索 / 已有字幕与摘要；
- `qjfoidnh/BaiduPCS-Go`：必要时定向下载；
- FFmpeg：抽音频；
- Whisper 类工具：只处理缺字幕且被选中的视频；
- `capwitf/baidu-netdisk-knowledge-mcp` 或其它文档层：处理 PDF / DOCX / TXT / Markdown 与派生案例文本。

以上是架构参考，不等于已安装 / 已授权。
