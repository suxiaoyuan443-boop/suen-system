# 塔罗判断训练｜运行时解牌协议

状态：当前正式规则

## 最低输入
尽量取得具体问题、现实背景、牌阵 / 牌位、牌面、正逆位、抽牌顺序、补牌关系。缺少会改变结论的信息时明确不确定，不补背景。

## 后台判断顺序
**问题 → 现实背景 → 牌位 → 牌面 → 正逆位 → 周围牌 / 组合 → 关键转折牌 → 补牌 → 候选规则 / 反例 → 最终判断。**

前台不必机械念步骤。

## 调用训练库
不能“搜到最像案例就照抄”。同时检索支持案例、反例、已采用规则、适用条件和当前不同点。只有单个相似案例时只作参考。

当问题属于**复合 / 会不会联系 / 会不会录取 / 会不会通过考试 / 明确时间结果**等结果型问题，或当前判断高度依赖恋人、圣杯二、圣杯六、塔、死神、倒吊人等容易被固定词义带偏的牌时，额外检查 `08-外部反馈验证层.md` 的反例。

具体解牌先按 `11-牌组与牌型方法路由.md` 选择第二层方法。

当牌局属于以下情况之一，可再读 `09-古典与公开老师方法参考层.md` 做**第二视角交叉检查**：
- 无固定牌位的三张 / 线性牌；
- 元素强弱、缺失、互相支持 / 削弱特别明显；
- 使用 Tarot de Marseille 或画面方向关系很强的牌；
- 用户明确要求“古塔罗 / 传统体系 / Golden Dawn / 马赛”；
- 当前 T/I 规则与牌面产生明显冲突。

M 层只能做交叉检查，不能反过来覆盖 Suen 已采用规则，也不能把 Golden Dawn 的元素尊贵度与鬼鬼散人自己的四元素发展模型当成同一套规则。

## 输出区分
- 当前牌局直接支持；
- 多案例经验支持；
- 仍不确定。

不为了完整把第三类硬写成结论。

## 后验纪律
旧案例后验可检验规则，但不能把历史频率写成必然，也不能把后验统计伪装成传统牌义。

以下为当前后验硬规则：

1. **先锁定原判断，再看反馈。** 有结果后不能把原本明确的“会 / 不会”无限改写成另一层含义来把失误救回来。
2. **主观过程反馈 ≠ 客观结果反馈。** “考试感觉很好”“聊天很开心”不能替代“实际通过 / 实际复合 / 实际录取”。
3. **问题层级必须一致。** 问“他的感觉”抽到互相吸引，不等于自动回答“最后会复合”。
4. **正面功能 ≠ 客观完成。** 希望、机会、好感、面试表现好、潜力存在，都不能自动写成“事情会成”。
5. **后验分四轴。** Result / Process / Mechanism / Timing 分开验收；最终结果判错时，不因过程描述命中而把整次判断记成正确。
6. **竞争问题显式加入第三方。** 求职、考试名额、竞标、选拔等不能只看求问者状态，还要考虑竞争者、决策人和资源约束。
7. **时间窗口不能事后延长。** 问“一周内 / 本月 / 某日前”就只按原窗口验收。
8. **情绪与阈值分离。** 失望不自动等于失败，满足 / 希望也不自动等于成功；考试分数、是否录取、是否到账等客观阈值单独判断。
9. **重复问不叠加置信。** 同一问题多次抽牌或多人都给出同一答案，不自动算多份独立证据。
10. **跨体系信号不重复计票。** 如果“元素受压”同时被老师体系和 Golden Dawn ED 描述到，只算一个结构信号，不因为两个体系说法相似就人为提高置信。
11. **先整组、后单牌。** 至少先形成一句能覆盖整组牌的主判断，再检查每张牌是否支持或反驳；不能靠逐张关键词拼接出结论。
12. **明确找一张反证牌。** 在下最终判断前，主动问“哪张牌最不支持我的结论？”如果无法解释，降低置信或修改结论。
13. **古典方法也要接受后验。** Elemental Dignities、OOTK、Marseille visual reading 等只能增加结构信息，不能获得“传统所以免检”的特权。
14. **感情分四层验收。** contact / reunion / commitment / durability 分别判断。
15. **时间是独立任务。** 日期 / 星期 / 几天后的判断单独给置信度，失败就记 Timing miss，不由事件后来发生来补救。
16. **外部门槛单独建模。** 求职 / 留学 / 迁移 / 住房等结果题，显式检查签证、资格、名额、预算、背景调查、决策人等 gatekeeper。
17. **本次失败不能推给未来别的事件。** 原问题 A 未发生，后来 B 发生，不能把本次正面牌自动解释成“其实说的是 B”。
18. **重复抽牌保留第一版。** 后抽的牌即使更贴近现实，也不能删除第一组 miss；多组冲突时降低置信。
19. **结果题允许第三种结果：事件被取消 / 条件改变。** 求职、考试名额、交易、预约等不只存在 yes/no；组织撤岗、规则改变、对方退出、资源取消都要作为独立可能性检查。
20. **核心 testimony 缺席时允许不判。** 如果问题问钱但关键牌组几乎不提供现实 / 财务证据，或问行动但牌组只描述情绪，明确降低置信，必要时回答“当前牌组不足以支持客观 yes/no”。
21. **按结构权重，不做吉凶牌计票。** 需要时调用 `09-古典与公开老师方法参考层.md` 的 W-01—W-09；问题 / 牌位相关性、整组支持、现实 testimony 和强反证，高于“这张通常很吉 / 很凶”。
22. **单牌按任务分流。** 单牌做 daily tone / 当前主题可以正常解释；单牌做录取、复合、到账等客观 yes/no 默认 Low confidence。


## 最终判断必须能回答的五件事

正式实践时，后台至少完成以下五项；前台表达可以自然，不必机械列字段：

1. **答案**：对原问题的直接判断是什么；
2. **依据**：哪几张牌 / 哪个牌位 / 哪个组合是主要依据；
3. **现实落点**：这些牌具体对应行动、关系状态、资源、决定、时间还是人物；
4. **反证与置信度**：哪张牌最不支持当前结论，是否足以改变判断；
5. **验收条件**：未来什么现实事实出现时算 hit、partial、miss 或仍 unknown。

如果不能说清第 5 项，说明问题定义仍然太模糊，不能把后续任何相似事件都算作命中。

## 实践准确度的验收维度

根据问题类型按需记录：

- **R｜Result**：最终事件；
- **P｜Process**：过程；
- **M｜Mechanism**：原因 / 阻碍 / 决策机制；
- **T｜Timing**：时间；
- **A｜Amount / Terms**：金额 / 条件 / 程度；
- **C｜Commitment / Durability**：关系承诺 / 持续性；
- **ID｜Target identity**：事件到底发生在谁身上。

一次解牌可以某几轴命中、某几轴失败。  
禁止用 P / M 命中掩盖 R 失败，也禁止用“事件后来发生”掩盖 T 失败。

## 转成《牌记》
保留真实判断链，去除客户识别信息，不暴露大段老师课程，不把内部证据等级念给观众，前台重点是“为什么这里这样判”。
