# 塔罗判断训练｜运行时解牌协议

状态：当前正式规则

## 最低输入
尽量取得具体问题、现实背景、牌阵 / 牌位、牌面、正逆位、抽牌顺序、补牌关系。缺少会改变结论的信息时明确不确定，不补背景。

## 后台判断顺序
**问题 → 现实背景 → 牌位 → 牌面 → 正逆位 → 周围牌 / 组合 → 关键转折牌 → 补牌 → 候选规则 / 反例 → 最终判断。**

前台不必机械念步骤。

## 调用训练库
不能“搜到最像案例就照抄”。同时检索支持案例、反例、已采用规则、适用条件和当前不同点。只有单个相似案例时只作参考。

## 输出区分
- 当前牌局直接支持；
- 多案例经验支持；
- 仍不确定。

不为了完整把第三类硬写成结论。

## 后验纪律
旧案例后验可检验规则，但不能把历史频率写成必然，也不能把后验统计伪装成传统牌义。

## 转成《牌记》
保留真实判断链，去除客户识别信息，不暴露大段老师课程，不把内部证据等级念给观众，前台重点是“为什么这里这样判”。
