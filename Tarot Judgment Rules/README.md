# Tarot Judgment Rules｜塔罗判断训练 Rule Vault

状态：当前正式 Rule Vault
建立：2026-09-23

## 作用

这个 Vault 只负责一件事：

**把 Suen 私有持有 / 可访问的塔罗课程、案例、老师判断与 Suen 自己的实占经验，整理成可追溯、可复核、可选择采用的判断规则。**

服务于 Suen 自己解牌、《牌记》具体案例判断、老师案例训练、反例与后验积累、规则长期校准。

不负责商业总控、普通选题、塔罗历史 / 辨伪研究，也不保存原始课程资产。


## 最高目标｜实践中可解释、可验证、可校准的精准判断

这个 Vault 的最终目标不是积累最多牌义，也不是让每次解牌听起来都合理。

目标是让 Suen 在真实实践中做到：

1. **判得准**：尽量准确回答现实问题本身，而不是只描述情绪或抽象主题；
2. **落到现实**：明确事件是否发生、谁行动、关系处于哪一层、钱是否到账、申请是否通过、时间窗是否命中；
3. **知道为什么这样判**：能指出问题层级、牌位、牌序、正逆、组合、人物身份、现实背景与关键反证分别起了什么作用；
4. **能被后验检验**：事情发生后，可以按原问题和原判断复核，而不是事后改题、改目标人物或重写牌义；
5. **能持续校准**：命中保留有效条件，失误记录原因与反例，逐步提高下一次同类问题的判断质量；
6. **知道什么时候不该强判**：证据不足、牌只描述过程而没有结果 testimony 时，宁可降低置信，也不为了“给答案”硬判 yes / no。

这里所说的“精准”不等于宣称塔罗具有科学上已证明的预测确定性，而是要求**在既定实践体系内，判断过程更一致、现实指向更清楚、后验验收更严格**。

## 读取入口

### 具体解牌 / 《牌记》案例判断

触发词不要求固定格式。用户明确表达“解牌 / 帮我看牌 / 看这副牌 / 解读这组牌 / 这个牌阵怎么判”等具体牌局意图时，即进入本路由。
1. 本文件
2. `04-Suen采用层.md`
3. `05-运行时解牌协议.md`
4. 需要调用首批老师案例训练结果时，再读 `06-首批归纳规则.md`
5. 遇到复合、联系、求职、考试等容易被固定牌义误导的结果型问题，或内部规则冲突时，再读 `08-外部反馈验证层.md`
6. 用户明确要求古塔罗 / 传统体系 / 马赛 / Golden Dawn，或牌局属于无牌位三张、元素关系特别关键、视觉方向特别关键时，再读 `09-古典与公开老师方法参考层.md`；需要看古典方法的具体操作案例时，再读 `13-古典案例与历史实战样本.md`
7. 如需追溯证据等级，再读 `02-规则提取与证据等级.md`

## 真源优先级

**Suen 当前明确说明 / 当前真实牌局事实 > Suen 已采用规则 > 有充分案例支持但尚未采用的候选规律 > 通用塔罗体系 > 泛化模型知识。**

老师的单个案例永远不能覆盖 Suen 当前明确判断。

## GitHub 数据边界

允许保存：方法规则、字段结构、案例 / 规则 ID 规范、概括性规律、Suen 采用状态、工作流与 Skill。

不保存：328GB 原始视频、完整课程音频、大段 / 全量课程转录、可替代原课程的逐字讲义、客户身份信息、百度网盘 Access Token / Cookie / BDUSS / STOKEN。

## 核心原则

1. 案例和规则分开。
2. 老师明确说过与从案例归纳必须分开标记。
3. 单例不升级成固定规则。
4. 必须保留反例。
5. 缺背景、牌位、正逆位时写 unknown，不补猜。
6. 后验有就记，没有就未知。
7. Suen 最终决定采用 / 修改 / 观察 / 拒绝。
8. 训练目的是提高判断质量，不模仿老师文风。

- `09-古典与公开老师方法参考层.md`：Golden Dawn / Opening of the Key、Papus、Tarot de Marseille 开放式 / 视觉读法等公开方法参考，保留流派来源，不自动并入老师 T 层；
- `10-外部来源索引.md`：公开方法和外部后验案例的可追溯来源入口；
- `11-牌组与牌型方法路由.md`：按 RWS / Marseille / Thoth-GD、固定牌位 / 无牌位三张 / 大型 tableau 选择第二层方法；
- `12-训练覆盖与缺口.md`：控制后续扩充方向，优先补薄区，不为凑总数重复收求职 / 复合案例；

`06-第一批案例校准结果.md` 与 `rules/` 下较早版本继续作为历史校准记录，不作为新的运行时优先真源。

当前所有派生规则仍为 `observe`；没有 Suen 明确确认，不得自动升级为 adopted / O4。具体解牌时，优先读取已采用层；只有需要案例经验校准时再读候选规则与外部验证层。
