# Tarot Judgment Rules｜塔罗判断训练 Rule Vault

状态：当前正式 Rule Vault
建立：2026-09-23

## 作用

这个 Vault 只负责一件事：

**把 Suen 私有持有 / 可访问的塔罗课程、案例、老师判断与 Suen 自己的实占经验，整理成可追溯、可复核、可选择采用的判断规则。**

服务于 Suen 自己解牌、《牌记》具体案例判断、老师案例训练、反例与后验积累、规则长期校准。

不负责商业总控、普通选题、塔罗历史 / 辨伪研究，也不保存原始课程资产。

## 真源优先级

**Suen 当前明确说明 / 当前真实牌局事实 > Suen 已采用规则 > 有充分案例支持但尚未采用的候选规律 > 通用塔罗体系 > 泛化模型知识。**

老师的单个案例永远不能覆盖 Suen 当前明确判断。

## GitHub 数据边界

允许保存：方法规则、字段结构、案例 / 规则 ID 规范、概括性规律、Suen 采用状态、工作流与 Skill。

不保存：328GB 原始视频、完整课程音频、大段 / 全量课程转录、可替代原课程的逐字讲义、客户身份信息、百度网盘 Access Token / Cookie / BDUSS / STOKEN。

## 核心原则

1. 案例和规则分开。
2. 老师明确说过与从案例归纳必须分开标记。
3. 单例不升级成固定规则。
4. 必须保留反例。
5. 缺背景、牌位、正逆位时写 unknown，不补猜。
6. 后验有就记，没有就未知。
7. Suen 最终决定采用 / 修改 / 观察 / 拒绝。
8. 训练目的是提高判断质量，不模仿老师文风。
