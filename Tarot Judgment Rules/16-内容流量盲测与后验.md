# 内容流量盲测与后验

状态：当前正式专项协议  
建立：2026-09-24

用途：在**选题已经通过数据、对标、证据和栏目硬门槛之后**，用塔罗做独立的发布前流量判断，并在发布后用真实平台数据验收。

这不是用塔罗替代内容策略，也不是把牌面当成平台算法证明。它的价值是：建立一套**事前锁定 → 事后验收**的长期样本，检验塔罗在 Suen 自己账号的流量判断中是否真的有稳定可重复性。

---

## 一、固定顺序

必须按以下顺序：

1. **先用内容系统定题**
   - 第一方账号数据；
   - 最近7天重复；
   - 对标结构；
   - 栏目路由；
   - 证据与素材；
   - 制作成本；
   - A / B / C / D 主任务。
2. 题目先达到“值得发 / 值得比较”的资格。
3. **再单独抽牌测试流量。**
4. 在看到发布结果以前锁定：
   - 问题；
   - 平台 / 账号；
   - 统计窗口；
   - 对照基线；
   - 牌位；
   - 牌面；
   - 直接判断；
   - 最强反证；
   - 置信度；
   - Hit / Partial / Miss 条件。
5. 发布后只用真实平台数据验收，禁止事后改题、改统计窗口或改“爆”的定义。

### 禁止倒置

不得：
- 先抽牌，再为了配合牌面硬找一个题；
- 用牌面救一个没有通过证据 / 栏目 / 素材硬门槛的弱题；
- 因为牌面吉就虚构“必爆”；
- 因为牌面弱就把本来有明确运营价值的题直接判为不能发；
- 看完真实数据以后重解释原牌，假装一开始就说中了。

---

## 二、发布前必须锁定的对象

每次至少明确：

- **平台 / 账号**：例如抖音大号；
- **唯一正式题目**；
- **主任务**：通常为 A｜流量；
- **正常制作前提**：按当前账号正常制作水平，不临时假设超常剪辑 / 投流 / 外部大V转发；
- **对照基线**：读取当前内容台账里的最近可比样本；
- **统计窗口**：发布前确定，例如“发布后约24小时”或“与最近可比样本同窗口”；
- **什么叫明显突破**：必须相对于当时账号真实基线定义，不能永久固定一个播放数。

如果账号阶段已经改变，过去“1000播放算基线”的定义自动失效，必须重新读取当前台账。

---

## 三、默认三张牌位

如果 Suen 没有另指定，内容爆款测试默认使用三张：

1. **首轮入口**
   - 标题 / 第一屏 / 首轮分发是否能让陌生人停下来；
2. **留存与互动**
   - 点进来后是否愿意继续看，并产生足够互动支撑后续分发；
3. **最终流量结果**
   - 是否明显突破当前近期基线，进入更高分发档，成为强样本 / 爆款候选。

### 解牌纪律

- 牌位优先；
- 不能因为第一张很吉就越权宣布最终爆；
- “互动好”与“最终大分发”分开；
- 必须指出最反对结论的牌；
- 必须给 High / Medium / Low 置信度；
- 不把吉牌机械等于爆款，不把逆位机械等于扑街。

---

## 四、发布前验收条件模板

每次必须在发布前写清：

**Hit**
- 实际表现与直接判断的主要方向一致，并达到事前定义的核心阈值。

**Partial**
- 过程层命中，但最终流量档位偏差；
- 或最终方向正确，但留存 / 互动机制与事前判断明显不同。

**Miss**
- 最终流量方向与事前锁定判断相反；
- 例如事前判“明显突破”，现实仍停在近期普通 / 弱样本；或事前判弱，现实成为明显强样本。

**Unknown / Invalid**
- 内容没有实际发布；
- 发布后被删除 / 违规 / 上传故障；
- 发生重大外部流量注入；
- 统计窗口没有取得；
- 发布版本与抽牌时锁定题目发生实质变化。

---

## 五、后验记录

发布后至少记录：

### R｜Result
最终播放 / 曝光是否达到事前定义的流量档位。

### E｜Entry
2秒跳出、前几秒留存、CTR或同平台入口指标。

### W｜Watch
平均观看、5秒完播、完播率或其它持续观看指标。

### I｜Interaction
点赞、评论、收藏、分享。

### F｜Follow
涨粉 / 精准关注。

### D｜Distribution
是否出现第二轮或更高一轮明显分发；能取得时记录来源结构。

不是所有平台都有全部指标；看不到就 N/A，不估算。

---

## 六、什么时候可以学牌

单个案例只能保存为案例，不能得到：
- “圣杯六 = 流量好”；
- “太阳 = 必爆”；
- “某张逆位 = 限流”。

只有在**多个独立、事前锁定、发布后有完整数据的样本**中重复出现同一模式，才允许写成“观察中的账号内候选规律”。

即使形成账号内规律，也只能作为 Suen 自己内容流量盲测的校准，不宣称为普遍塔罗定律。
