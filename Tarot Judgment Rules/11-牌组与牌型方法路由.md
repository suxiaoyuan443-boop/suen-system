# 塔罗判断训练｜牌组与牌型方法路由

状态：当前运行时路由  
建立：2026-09-24

## 一、总原则

**主体系不会因为换牌组而全部换掉，但第二层检查方法必须匹配牌组与牌型。**

固定主干：
1. 具体问题与现实背景；
2. Suen adopted / modified；
3. 鬼鬼散人 T/I 主读；
4. X 后验反例压力测试。

然后才选择一个最合适的 M 模块。

不同时开启所有传统方法投票。

## 二、RWS / 场景图像型牌组

默认：
- T/I 主读；
- 牌位；
- 场景中的人物动作 / 关系；
- X 层反例。

可选：
- 元素占比；
- Court 人物 / 阶段；
- 无牌位三张时轻量使用 GD triad weighting。

不默认：
- Marseille 纯视觉线条法；
- OOTK card counting；
- tableau 行列规则。

## 三、Tarot de Marseille / 古典 pip deck

优先第二层：
1. 整幅 picture；
2. 人物方向 / gaze / gesture；
3. 数字与花色状态；
4. 相邻牌之间“发生了什么动作”；
5. 必要时使用 Ben-Dov / Camelia / Enrique 的视觉检查。

T 层元素仍可作为交叉检查，但不要强行把 RWS 场景关键词塞给 Marseille 小牌。

## 四、Thoth / Golden Dawn 对应体系

优先第二层：
1. T/I 主读；
2. Elemental Dignities；
3. 占星 / 元素对应（只有任务确实需要时）；
4. 线性多牌可用 card counting / pairing；
5. 完整 OOTK 只有明确使用该法时才启动。

Golden Dawn ED 只做权重，不一票否决。

## 五、无固定牌位三张

默认按：
- 左 / 中 / 右先作为**关系结构**而非自动过去 / 现在 / 未来；
- 中间牌先作为 principal 候选；
- 左右修饰 / 支持 / 反证；
- 看元素关系；
- 看图像朝向；
- 形成一句 master sentence；
- 主动找一张最反对主句的牌。

如果用户明确指定过去 / 现在 / 未来，则服从指定牌位，不再使用“中心 principal”覆盖牌位。

## 六、固定牌位牌阵

固定牌位优先。

方法层只能回答：
- 这张牌在这个位置强不强；
- 周围牌如何修饰；
- 有无跨位重复主题；
- 有没有明显反证。

禁止因为视觉故事很好讲，就把“感受位”改造成“结果位”。

## 七、大型 tableau / 10+ 张牌

先做结构筛选，不逐张平铺：

1. significator / 主题核心；
2. 牌位或空间区域；
3. clumps / 重复主题；
4. 元素占比；
5. 关键 triads；
6. 若体系允许，再用 counting / pairing；
7. 最后才解释次要牌。

目标是找到**主叙事**，不是把每一张都讲满。

## 八、用户未说明牌组时

如果牌面图片能识别牌组，就按实际牌组路由。

识别不了时：
- 不为了方法细节猜 deck；
- 使用 T/I + 牌位 + X 的通用主干；
- 只有真正会改变判断时才说明“牌组版本可能影响视觉 / 元素层解释”。

## 九、最终输出

不向用户堆流派名字。

前台最终仍应是：
- 这副牌主要在说什么；
- 哪张 / 哪个结构最关键；
- 哪个地方限制这个结论；
- 结果倾向与置信度；
- 如果有，哪一部分仍不能确定。

流派与方法来源主要保留在后台推理与需要解释“为什么这样判”时使用。
