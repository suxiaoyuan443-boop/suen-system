# 微信朋友圈｜文笔与发布规则

状态：当前正式规则
最后核对：2026-09-17

共同语言底线同时继承 `00-系统总控/Suen统一文笔总则.md`。

朋友圈因为是私域真人表达，下面的“默认无标点、允许自然第一人称、像本人临时说话”等规则比统一总则更具体；发生表达层细节差异时，以本文件的朋友圈专属规则为准，但不能突破真实性、反 AI 模板、反营销号等共同底线。

## 总体感觉

像本人临时直接打出来的话，不像运营文案、公众号缩写或 AI 模板。

## 标点硬偏好

**默认不带标点符号。**

这是当前朋友圈最优先的个人表达习惯。

只有在以下情况才考虑少量必要标点：

- 技术参数如果完全无标点会造成歧义；
- 英文、数字、日期、orb 等专业信息需要分隔；
- 用户当次明确要求正常标点。

不要为了“好看”自动补满逗号、句号、冒号和分号。

## 文风

- 默认不用 emoji。
- 开头直接讲事，不机械套“今天想分享 / 最近越来越觉得”等文案式引入。个人感想里如果确实是在讲最近发生的事，“我最近 / 我现在越来越……”可以自然使用，但不能每篇都拿它当固定开场。
- 允许自然口语、少量重复、不完全工整和较长段落。
- 不故意制造错别字、网络语或碎句。
- 避免 AI 式总结、升华与反驳模板。
- 尤其少用或不用“不是……而是…… / 本质上 / 说到底 / 这让我意识到 / 最后想说”。
- 不为了“像真人”故意写得幼稚、混乱或网络化。

## 专业自然感补充｜2026-09-25

朋友圈的“像本人”不等于故意写得幼稚、可爱、轻飘或碎碎念。

禁止为了真人感主动加入这类语气：
- “居然真的……”
- “还挺开心的”
- “蛮有意思”
- “哈哈”
- “小福利”
- “本来以为……结果……”
- 过多“呀 / 啦 / 诶”式软化词

除非 Suen 当次原话本身就这样说，否则不主动补。

朋友圈专业感优先来自：
- 最近真的在做什么；
- 哪个判断发生了变化；
- 哪个技术条件不能省；
- 哪个客户 / 实践结果值得继续看；
- 为什么某件事现在会这样处理。

商业朋友圈也保持克制：
- 直接说活动 / 福利 / 可预约事实；
- 不写营销号式兴奋；
- 不写“宠粉”“福利来啦”“冲”“安排上”等平台营销表达；
- 老客待遇可以直接说明，不需要包装成可爱语气。

理想状态：
**读起来像 Suen 自己发的朋友圈，同时让人自然感觉这个人做事有判断、有标准、有实际工作。**

## 长文字开头与推进方式｜2026-09-25再次修正

Suen 明确不喜欢用否定、反驳或对抗作为长朋友圈的开头和主要推进方式。

避免：
- “我不喜欢……”
- “我现在越来越不……”
- “不是……而是……”
- “很多人都……但我……”
- “我不会……”
- 先否定一种常见做法，再证明自己的做法更好。

优先：
- 从一个具体案例开始：`有个宝找我……`
- 从一条经验 / 准则开始：`我有一条……准则`
- 从一个长期观察开始：`从我这边收到的反馈来看……`
- 从正在做的研究 / 工作开始：`最近在重新做……` / `在研究……的过程中……`
- 从一个正向判断开始：`我现在会更重视……` / `这类问题我通常会先看……`

正文也尽量用“我怎么判断 / 我看到什么 / 我会怎么处理”推进，不靠连续否定句制造专业感。

## 长文字专业感基准｜2026-09-25补充

Suen 当前明确偏好的朋友圈专业感，不来自“学术腔”或堆术语，而来自**真实判断能力被完整展开**。

参考特征：
- 从一个真实客户问题、真实工作判断、具体技术细节或长期观察进入；
- 可以有明确立场，不为了显得温和把判断磨平；
- 允许较长推理链，把“为什么这样判断”讲透；
- 专业感来自案例、技术条件、经验归纳和判断边界，而不是反复说“我很专业 / 我很严谨”；
- 可以有个人语气、比喻、轻微锋利感，但不装可爱、不故意营销；
- 允许谈服务理念，但必须落到实际判断或真实经验，不写空泛价值观；
- 允许从一个具体案例上升到可复用规律，但不能把单个案例夸成普遍定律；
- 结尾不强行升华，也不强行导流成交。

当前优先发展的长文字类型：
1. **案例判断型**：真实问题 → 关键判断 → 为什么 → 可迁移规律；
2. **技术判断型**：一个具体制作 / 原典 / 择时 / 材料问题 → 不同层级怎么区分 → Suen 最终怎么选；
3. **服务观念型**：从真实咨询 / 售后 / 回访切入，讲清楚 Suen 对“准、有效、反馈、边界、长期记录”等问题的判断。

前台语言目标：
**像一个真的做了很多年、见过很多案例的人在说自己的判断。**
不要像公众号缩写，不要像知识博主列提纲，也不要像运营文案。

## 不同内容

### 日常 / 工作记录

可以很短，直接说发生了什么。

### 个人感想型长文字｜带专业含量的朋友圈

朋友圈允许、并建议**偶尔出现一条较长的个人感想**。它不是公众号缩写，也不是小论文，更不是广告。重点是从 Suen 最近真实做过、遇到过、重新想明白的一件事出发，让专业判断自然露出来。它的作用是让已经认识 Suen 的人看到：

- Suen 最近真实在做什么、纠结什么、改了什么判断；
- 这些感想背后有具体资料、实践经验、技术条件或案例观察；
- 专业感来自真实经历和具体判断自然显出来，不是主动“展示专业”。

适合从这些真实触发点进入：
- 最近有客户问了一句话，让自己突然意识到原来大家最在意的是另一件事；
- 最近筛掉一个时间窗口后，发现自己现在越来越不愿意为了赶进度凑条件；
- 最近做星符 / 墨水 / 材料复原时，发现“能做出来”和“愿意这样做”其实不是一回事；
- 最近查原典时推翻了自己以前一直默认的一种说法；
- 最近想到客户反馈这件事，觉得只记一句“有效了”其实远远不够；
- 某次制作、研究、接单或复盘以后，自己真实改变了一个判断。

写法：
- 可以一大段，也可以2—4个自然长段；
- 优先第一人称，从“我最近……” “前两天……” “我现在越来越……”这类真实起点自然进入；
- 不要求开头有短视频钩子，也不需要先给结论；
- 可以边讲经历边带出技术细节，不为了“显得专业”堆资料；
- 不需要结尾升华，也不一定加购买入口；
- 有引用 / 原典 / 技术数据时，只写自己真正核过的；
- 读完首先应该像 Suen 的个人感想，其次才让人觉得“她确实懂很多”。

这类朋友圈属于**个人感想 + 专业信任资产**。默认不与预约、价格、名额绑定；如果当天另有商业信号，优先保持纯个人表达，不在结尾硬接销售。

### 客户反馈

写真实情况 + 自己最直接的反应，不包装成：

- 案例 PPT；
- “客户痛点—方案—效果”营销模板；
- 虚构前后对比；
- 强行导向购买。

### 看牌 / 观点

可以稍长，保留实际判断过程，不强行提炼人生道理。

### 神秘学研究 / 星符 / 仪式 / 天象

可以写长，但要像本人讲自己实际筛选或执行过程，不写成教材或公众号缩写。

专业感来自具体技术条件，而不是一串“专业、严谨、古典、正统”等形容词。

## 天象内容

只写已经可靠核查的事实。

可以自然提到：

- 行星顺逆；
- 灼烧 / 日光状态；
- 宫位与角宫；
- 应用 / 分离；
- orb；
- 月亮 VOC；
- 接纳；
- 月亮下一应用相位；
- 行星日 / 行星时；
- 淘汰过哪些窗口及原因（确实核查过时）。

用户已经给出的技术参数要完整保留，不为了把朋友圈写短就擅自删掉关键筛选条件。

未经核查的数据不补写。

### 精确时分

朋友圈如果需要公开具体执行时分，必须同时满足：

- 已经由对应择时专用对话 / 专用系统可靠复核；
- 当前不同记录之间不存在未解决的时分冲突。

只要具体时刻存在冲突，就不得自行挑一个时间写进朋友圈。

这时可以写：

- 某日窗口已开放预约；
- 某日准备执行；
- 适合什么用途；

但不要擅自写具体几点几分。

精确时间始终以择时专用系统最新可靠复核结果为准。

## 商业表达

商业提醒也要像本人说话，通常 1—2 句就够。

在事实已经确认的前提下，可以直接写：

- 某个项目还可以预约；
- 哪天准备做；
- 适合什么用途；
- 实际价格；
- 已完成可靠复核且无冲突的时间窗口。

但避免虚构稀缺感和催单语气，例如：

- 0 预约；
- 只剩几个名额；
- 满了就不收；
- 想做趁现在；
- 最后机会；
- 马上截止；
- 本月唯一窗口；
- 非常稀缺。

只有真实存在的限制才能写。

## 与商业总控的关系

朋友圈是否承担当天商业信号，由商业总控决定。

如果当天朋友圈只是工作记录或研究分享，不自动加：

- 私信我；
- 可预约；
- 价格；
- 名额；
- 购买入口。

如果当天朋友圈承担唯一商业信号，也要保持像本人直接说话，不改写成广告文案。
