# 微信朋友圈｜文笔与发布规则

状态：当前正式规则
最后核对：2026-09-17

## 总体感觉

像本人临时直接打出来的话，不像运营文案、公众号缩写或 AI 模板。

## 标点硬偏好

**默认不带标点符号。**

这是当前朋友圈最优先的个人表达习惯。

只有在以下情况才考虑少量必要标点：

- 技术参数如果完全无标点会造成歧义；
- 英文、数字、日期、orb 等专业信息需要分隔；
- 用户当次明确要求正常标点。

不要为了“好看”自动补满逗号、句号、冒号和分号。

## 文风

- 默认不用 emoji。
- 开头直接讲事，不用“今天想分享 / 最近越来越觉得”等文案式引入。
- 允许自然口语、少量重复、不完全工整和较长段落。
- 不故意制造错别字、网络语或碎句。
- 避免 AI 式总结、升华与反驳模板。
- 尤其少用或不用“不是……而是…… / 本质上 / 说到底 / 这让我意识到 / 最后想说”。
- 不为了“像真人”故意写得幼稚、混乱或网络化。

## 不同内容

### 日常 / 工作记录

可以很短，直接说发生了什么。

### 客户反馈

写真实情况 + 自己最直接的反应，不包装成：

- 案例 PPT；
- “客户痛点—方案—效果”营销模板；
- 虚构前后对比；
- 强行导向购买。

### 看牌 / 观点

可以稍长，保留实际判断过程，不强行提炼人生道理。

### 神秘学研究 / 星符 / 仪式 / 天象

可以写长，但要像本人讲自己实际筛选或执行过程，不写成教材或公众号缩写。

专业感来自具体技术条件，而不是一串“专业、严谨、古典、正统”等形容词。

## 天象内容

只写已经可靠核查的事实。

可以自然提到：

- 行星顺逆；
- 灼烧 / 日光状态；
- 宫位与角宫；
- 应用 / 分离；
- orb；
- 月亮 VOC；
- 接纳；
- 月亮下一应用相位；
- 行星日 / 行星时；
- 淘汰过哪些窗口及原因（确实核查过时）。

用户已经给出的技术参数要完整保留，不为了把朋友圈写短就擅自删掉关键筛选条件。

未经核查的数据不补写。

## 商业表达

商业提醒也要像本人说话，通常 1—2 句就够。

可以直接写：

- 某个项目还可以预约；
- 哪天准备做；
- 适合什么用途；
- 实际价格；
- 已经确认的时间窗口。

但避免虚构稀缺感和催单语气，例如：

- 0 预约；
- 只剩几个名额；
- 满了就不收；
- 想做趁现在；
- 最后机会；
- 马上截止；
- 本月唯一窗口；
- 非常稀缺。

只有真实存在的限制才能写。

## 与商业总控的关系

朋友圈是否承担当天商业信号，由商业总控决定。

如果当天朋友圈只是工作记录或研究分享，不自动加：

- 私信我；
- 可预约；
- 价格；
- 名额；
- 购买入口。

如果当天朋友圈承担唯一商业信号，也要保持像本人直接说话，不改写成广告文案。
