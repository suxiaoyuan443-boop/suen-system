# Suen｜统一文笔与成稿执行总则

状态：当前正式跨平台规则  
最后核对：2026-09-19

本文件同时负责：**共同文笔底线 + 成稿 QA + 专用对话完整执行要求**。

平台 / 栏目规则更具体时，以更具体规则补充执行。

## 一、成品应该是什么感觉

像一个真的看过资料、知道对象怎么使用的人，把事情自然讲清楚。

专业感来自：

- 具体对象、动作、材料、位置；
- 原始资料、文物、手稿、文本；
- 明确用途、判断条件、版本差异；
- 能追到来源的证据。

不靠术语密度、营销口吻、故作神秘或空泛总结制造专业感。

## 二、文笔硬规则

避免：

- 换任何题都能套的 AI 开头；
- 连续“不是 / 并不 / 不能 / 不等于”；
- “本质上 / 说到底 / 真正重要的是 / 这告诉我们”等空泛总结；
- 一句话一段的故意碎句；
- 强行升华；
- 同一个结论换几种说法重复；
- 用“空间结构 / 建立边界 / 底层逻辑”等抽象词替代本来能直接说清的动作；
- 用现代常识补历史文本没有说明的原因。

具体能写成“谁站哪里、什么写在哪里、先做什么、后做什么”，就优先写具体版本。

“你有没有发现”不是机械禁词；只有后面立刻接真实、具体、与当天主题直接相关的场景时才成立。

## 二点五｜标题反 AI 硬规则

标题是成稿的一部分，同样执行“像真人会说的话”。

### 优先
- 直接说这条最有意思的事实 / 问题；
- 像 Suen 自己真的会问、会说的一句话；
- 能短就短，不为了“钩子感”补第二层反转；
- 普通词优先，不用运营词替代正常中文；
- 问句只有真的自然时才用，不把所有题都改成“为什么 / 真的能吗 / 到底怎么回事”。

### 强吸引仍然是硬要求

“反 AI”**不等于标题变平、变弱、变成资料目录。**

标题和开头仍然要尽可能强地抓住人，但吸引力优先来自内容本身：

- 一个真的奇怪的东西；
- 一个普通人马上能懂的冲突；
- 一个反常动作；
- 一个具体数字 / 时间 / 物件；
- 一句原文本身就很怪的话；
- 一个“为什么会这样”的真实问题。

优先做法：
1. 先找到这条内容里**最值得点开的那个事实**；
2. 把它放到标题或开头最前面；
3. 用普通中文直接说；
4. 删掉第二层运营话术和人为反转；
5. 如果事实本身不够强，不靠模板补成“强钩子”，回头换题或换入口。

例如 Suen 已经验证过的自然强标题：
- 《这个17世纪瓶子里为什么装着人尿和铁钉？》
- 《死后你的心脏会告发你？》
- 《你的名字也会被杀死？》
- 《古埃及墓里这扇门到底给谁走？》

它们强，不是因为套了营销句式，而是因为**对象和问题本身就足够怪，而且一句话马上听懂。**

### 开头同样执行

开头前2—5秒仍需强吸引，但不要写成广告脚本。

优先：
- 直接把最怪的对象 / 动作 / 冲突说出来；
- 先给具体事实，再解释背景；
- 尽量让观众在第一句话就知道“这条到底怪在哪里”。

避免：
- “你绝对想不到……”
- “很多人都不知道……”
- “今天带你了解……”
- “接下来这个可能颠覆你的认知……”
- 为了留人故意藏答案很久。

### 禁止高频 AI 标题模板
默认避免：
- “先别急着……”
- “一个A，一个B，真的能……吗？”
- “这个数字 / 这个答案我不会随口说”
- “你以为……其实……”
- “看似……其实……”
- “同样都是X，为什么……”
- “真正的问题不是……”
- “这件事比你想的更复杂”
- 为了制造冲突硬塞“真的 / 居然 / 竟然 / 怎么可能”

这些句式不是绝对永远不能出现；只有 Suen 当下自然会这样说、且内容确实需要时才可用。不能把它们当标题生成公式。

### Suen 当前标题基线

优先参考已经实际使用过、语气自然的标题，例如：
- 《第二木星星符到底写了什么？》
- 《古埃及墓里这扇门到底给谁走？》
- 《这个17世纪瓶子里为什么装着人尿和铁钉？》
- 《供品都给神了，为什么古希腊人最后还能把肉吃掉？》
- 《你的名字也会被杀死？》

共同点：
- 一条标题只放一个主要怪点 / 问题；
- 词很普通，像真人会问；
- 不叠两层“反差 + 反转 + 判断”；
- 不为了显得会做短视频而加多余态度词；
- 题目本身够怪时，标题就停在那里，不再二次加工。

候选阶段只需要把**题眼**说清楚，不要求提前产出最终发布标题。  
正式标题优先在口播 / 正文已经成型以后再写，并回看上述历史基线。

### 标题 QA
正式交付前单独问：
> **这句话如果不加书名号，像不像 Suen 会直接发给朋友 / 写在自己账号上的一句话？**

如果像“短视频运营课示例标题”，即使点击逻辑成立也要重写。

内部命题、运营目的、Hook 标签不得直接转换成发布标题。

## 三、研究型内容

文物、残页、辨伪、异录、隐理、长卷、公众号研究内容默认减少作者第一人称。

区分：

- 原始材料实际写了什么；
- 学者如何解释；
- 后世如何发展；
- 现代实践如何选择。

推测不能写成事实。

资料越硬，导航越简单：出现原页、希腊文、拉丁文、埃及语、魔法字符时，必须告诉观众具体看哪里、什么意思、为什么重要。

中文平台观众端默认中文表达；原始语言作为证据时保留原文，并同步给中文定位 / 解释。

## 四、完整执行

任务已经明确且没有真实阻塞时，专用对话默认自己完成：

1. 读取当前规则；
2. 确认核心答案有证据；
3. 完成必要研究；
4. 成稿；
5. 找素材 / 核查链接；
6. 文笔与交付 QA；
7. 自己修正明显问题；
8. 一次性交付完整成品。

不要做到一半停下来等 Suen 说“继续”。

不要把本可自行完成的搜图、原文定位、素材匹配、裁切建议、重复删除、排版修复转回给 Suen。

只有核心事实无法成立、缺少只有 Suen 才能提供的必要信息、或需要 Suen 做真实取舍时才提问。

## 五、长稿前内部门槛

长文、隐理、原典研究等，在完整写稿前先内部确认：

- 核心答案一句话能否说清；
- 主要证据分别支持什么；
- 哪些只是推测；
- 标题有没有承诺超过证据；
- 栏目路由是否正确。

证据不足时收窄题目或换题，不先写完整长稿再整篇返工。

## 六、交付前 QA

必须自己检查：

- 每段是否增加新信息；
- 是否存在同义复述；
- 是否有无证据拔高；
- 是否连续否定；
- 是否把具体动作写成抽象概念；
- 是否自然可说 / 可读；
- 是否符合栏目自己的语气；
- 是否把运营优化写成营销号文风；
- 素材是否真实、正确、可用；
- 交付格式是否完整；
- 是否无故留下半成品。

视频口播在脑内按正常语速完整读一遍；说不顺就改。

## 七、真实性

不得为了流量、神秘感、商业或补素材：

- 虚构历史、文物用途、原始文本；
- 把学者推测写成事实；
- 把现代重构反写成古代传统；
- 用 AI 图冒充真实历史资料；
- 虚构体验、客户反馈或功效。

## 八、用户指出“不对”时

先检查：规则有没有读对、执行有没有漏、证据是否支撑、文笔 QA 是否失败、交付格式是否漏。

不要先重新发明栏目理论、时长限制、多日准备期或更多临时提示词。

## 九、正式成稿最小读取

正式内容任务至少读取：

1. 对应平台 / 栏目当前规则；
2. 本文件；
3. 对应交付规则；
4. 视频再读 `99-模板/视频类统一交付格式.md`。

正常情况下不再额外加载旧的两个验收协议全文。


## 十、统一文笔不等于统一栏目口吻

统一总则只负责共同底线，**不能把不同栏目写成同一种声音**。

正式成稿必须同时执行：

1. 统一文笔底线；
2. 当前栏目自己的文风 / 叙事 / 开头 / 结构规则；
3. 当天总控变量。

当“统一总则”和“栏目具体表达方式”同时适用时：

- **栏目更具体的语气、叙事和结构要求优先**；
- 统一总则继续约束真实性、AI腔、重复、抽象空话、证据边界和完整执行；
- 不能为了统一文笔，把《异录》写成《残页》，把《辨伪》写成《隐理》，或把《牌记》写成研究论文。

六个大号栏目必须保留各自明显差异：

- **文物**：带着观众看真实对象，指哪里就讲哪里；
- **异录**：说书式真实故事，人物、事件、转折和画面感优先；
- **辨伪**：判断题，明确、轻松、朋友聊天感；
- **残页**：最高严谨度，从原页、具体行、词义和版本进入；
- **隐理**：解释实践机制，答案早出现，具体动作优先；
- **牌记**：像真实看牌过程，允许少量经验型第一人称，重点是为什么这样判。

“服务认知”是当天任务标签，不是独立文风或独立栏目。需要展示现实判断时，先服从实际承载它的栏目 / 平台：具体牌局回《牌记》，可证实的实践机制回《隐理》，纯个人判断 / 服务原则优先放小号、朋友圈或适合的小红书内容。

验收时如果一篇稿子只满足“没有 AI 味”，但失去了当前栏目的声音，仍然视为不合格。


## 十一、真人口语参照

从 2026-09-20 起，视频口播、朋友圈、抖音小号及其它需要“像 Suen 本人说话”的内容，优先参考 Suen 当天自我介绍视频中的自然表达方式。

核心特征：

- 像人顺着想法直接说，不像提前写好的说明书；
- 允许自然停顿、转折、稍微绕一下再说清楚；
- 不为了“信息完整”把每一句都写成标准答案；
- 少用“第一、第二、第三”“我主要分成两部分”“所以这个账号会……”这类提纲式表达；
- 不强行把每段都收束成一句结论；
- 可以保留“其实、反正、我平时、我会、对我来说”这类真实口语，只要不过度重复；
- 专业感继续来自真实资料、具体经历、明确判断，不靠正式腔；
- 如果成稿读起来像品牌介绍、课程简介、AI整理稿，即使信息都对，也要继续改到像真人会说的话。

正式研究型长文仍按对应栏目规则执行，不机械套用口语化。
