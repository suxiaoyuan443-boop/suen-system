# Suen｜认可文笔样本库

状态：当前正式正向语感真源
建立日期：2026-10-07

本文件只保存 **Suen 已明确认可完整文笔 / 口播语感** 的成稿样本。

用途：
- 给正式内容生产提供正向语感锚点；
- 防止“反AI”只停留在禁词与禁句；
- 让专用对话真正知道什么叫“像 Suen 会说的话”。

## 一、当前状态

**当前暂无可验证的完整认可样稿。**

说明：
- 已发布 ≠ 明确认可文笔；
- 某个标题被认可 ≠ 整篇口播被认可；
- 助手自己判断“这版不错” ≠ Suen 认可；
- 有HTML / 已完成 / 已做QA ≠ 文笔认可。

因此在第一份认可样稿进入本库前，任何专用对话都不得声称：
- “已按 Suen 历史认可稿对齐”；
- “已复刻 Suen 语感”；
- “已参考认可样稿”。

## 二、入库条件

只有满足以下任一明确反馈，完整成稿才可入库：
- Suen 明确说“这版文笔可以”；
- Suen 明确说“这版对”；
- Suen 明确说“可以发”，且上下文没有保留文笔异议；
- Suen 明确指定“以后按这个文笔 / 这个语感来”。

如果只是：
- 没有继续修改；
- 已生成HTML；
- 已发布但没有专门评价文笔；
- 只认可某一句 / 某个标题；
都不自动进入本库。

## 三、样本保存方式

每个样本必须保存：
- 栏目；
- 题目；
- 完整最终口播；
- Suen 的明确认可语句或认可状态；
- 该样本最值得迁移的语感特征；
- 不可机械复制的题材专属部分。

## 四、没有样本时怎么写

在本库为空时，正式口播统一使用 **低修辞具体口语模式**：
- 先说当前对象 / 动作 / 原句 / 人物行为；
- 顺着事情自然往前；
- 少解释路标；
- 少总结；
- 少抽象名词；
- 不按研究提纲直接写；
- 不用口头禅、碎句、故意停顿伪造“真人感”；
- 不把HTML口播块当作文段生成模板。

最终判断：
> 去掉标题、图片和来源以后，正文应该像一个真正知道这件事的人在自然讲，而不是在替资料做整理。

## 五、维护原则

- 本库只做正向语感真源，不存失败稿；
- 失败经验继续写入文笔总则 / 栏目规则；
- 不为了让样本库“看起来完整”强行塞入未确认稿；
- 一旦 Suen 明确认可新的完整成稿，应优先补入本库，供后续专用对话读取。
