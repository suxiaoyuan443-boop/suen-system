# Suen｜商业总控启动索引

状态：当前正式运行入口
最后核对：2026-09-27

本文件负责让新商业总控对话用最少读取恢复系统。

## 1. 最小接管顺序

固定先读取：

1. 本文件；
2. `商业目标与产品优先级.md`；
3. `08-动态运行/00-当前总览.md`。

然后只按当前任务读取需要的规则和动态文件，不默认全仓库加载。

## 2. 真源分工

### 正式规则
栏目定义、路由、工作流、指标口径、硬门槛、交付要求，以 GitHub 对应正式规则文件为准。

### 当前动态事实
统一读取：

- 内容：`08-动态运行/内容台账/当前状态.md`
- 灵感（可选辅助，不是定题真源）：`08-动态运行/灵感库存/当前灵感.md`
- 商业：`08-动态运行/商业/当前商业状态.md`
- 天象：`08-动态运行/天象/当前预约池.md`

### 历史
月度文件、Git commit 和 `08-动态运行/历史/` 只用于复盘 / 核查，不反向覆盖当前文件。

优先级：

**Suen 当前明确指令 > GitHub 当前正式规则 + GitHub 当前动态文件 > 月度历史 / Git commit / 旧聊天 / 记忆。**

## 3. “总结”

读取：

- `内容历史台账规则.md`
- `99-模板/内容复盘台账模板.md`
- `08-动态运行/内容台账/当前状态.md`
- 当前月份 `08-动态运行/内容台账/YYYY-MM.md`（存在时）

只补已经发生的事实，不重新定新题。

## 4. “更新”

读取：

1. `08-动态运行/内容台账/当前状态.md`
2. `08-动态运行/商业/当前商业状态.md`
3. `08-动态运行/天象/当前预约池.md`
4. `商业总控.md`
5. `每日总结与更新工作流.md`

每天重新根据第一方数据、最近 7 天发布、当天制作条件与商业状态现场定题，不从预设候选池继承优先级。

`08-动态运行/灵感库存/当前灵感.md` 只在需要补充研究线索时按需读取；其中任何条目都必须按当天状态重新判断，不能自动续成正式题。

## 6. 选题任务额外保险

当天需要生成 / 判断新题时，必须先读：

1. `01-抖音大号/栏目选题边界与路由.md`（涉及六栏目时）
2. `内容商业对标系统.md`
3. 本轮对应栏目 / 平台规则
4. `08-动态运行/内容台账/当前状态.md`
5. `08-动态运行/商业/当前商业状态.md`

先根据当天状态提出少量候选，再做必要的栏目、证据、重复与素材检查；不提前维护高优先级候选池，也不因为旧题已投入研究成本而优先救题。

- 已读本文件与商业目标；
- 已读 `08-动态运行/00-当前总览.md`；
- 已按任务读取所需当前动态文件；

正常工作不读旧 Slack 归档；规则变更历史直接看 Git commit / CHANGELOG。只有排错或历史核查时才回看归档。
