# Suen｜内容商业对标系统

状态：当前正式规则  
最后核对：2026-09-19

本文件只负责：**第一方内容信号怎么理解 + 外部 benchmark 怎么采样。**

不负责栏目路由、最终定题、商业状态或平台成稿。

## 一、品牌入口

长期前台公式：

**具体真实对象 / 行为 / 冲突 + 普通人马上能理解的问题 → 原典、馆藏、手稿、历史语境、仪式机制或现实判断。**

神秘感必须来自真实材料，不靠伪史、夸张或 AI 假资料。

## 二、第一方数据优先

在看外部账号前，先看 Suen 自己已经发生的真实结果。

信号分三档：

- **单样本信号**：一次表现明显，只说明值得继续验证。
- **重复信号**：多个相对可比样本在同一目标指标上重复出现。
- **稳定结构**：多个时期 / 样本持续有效，或跨平台后在相同目标指标上重复有效。

播放、点赞、收藏、涨粉、主页访问、询盘 / 成交分别判断，不互相替代。

跨账号迁移只迁移**题目结构 / 入口假设**，不能把小号跑通直接写成大号已验证。

## 三、当前值得继续验证的第一方结构

这些是候选结构，不是永久公式：

1. 熟悉视觉 + 奇怪对象
2. 反直觉仪式行为
3. 熟悉神秘学对象 + “原文到底写什么”
4. 死亡 / 身体 + 一个具体怪问题
5. 大众默认判断 + 实际需要重新判

是否升级为重复信号 / 稳定结构，以最新 Slack 复盘为准。

## 五、近期创作采样

每个 Asia/Shanghai 运营日第一次进行“新增 / 优化选题池”或“正式定新的前台题”时：

- 先读取 Suen 当前第一方真实状态，再实际查看最相关 **2—3 个**账号近期内容；
- 默认优先最近约 **7—30 天**；
- 同日已刷新且任务没有变化时可复用；
- 不机械刷五个账号；
- 不直接复制对标题目；
- 每一个候选必须在选题池中写明“对标参考”，指出借鉴的是入口 / 第一屏 / 问题结构 / 证据组织 / 系列化 / 商业连接中的哪一项；
- 每一个候选同时写“现实依据”，说明为什么适合 Suen 当前账号数据、商业瓶颈、主页结构或近期内容节奏。

重点看：

- 题目入口；
- 第一屏 / 开头；
- 内容结构；
- 原始资料 / 案例怎么组织；
- 新形式 / 系列；
- 商业信息位置和密度。

无法可靠取得近期样本时写：

`近期样本未可靠取得`

然后降级使用长期方法，不编造“最近他们都在做什么”。

## 七、重复与主页结构

默认重点检查最近 **7 天**的观看体验重复，不只看标题。

例如连续都是：

- 原页 / 古书 / 资料页；
- 相近死亡题材；
- “资料 + 翻译 + 解释”；
- 同一种视觉和问题结构。

账号样本很少时，还要看**当前全部已发布内容**形成的主页第一印象。

这不是机械轮播；强题仍可连续同栏目，但必须知道自己在重复什么体验。

## 八、对标的边界

- 第一方真实数据 > 外部经验；
- 长期方法 ≠ 刚看过近期内容；
- 单样本 ≠ 稳定公式；
- 流量账号 ≠ 历史证据源；
- 对标只帮助找到更好的入口和组织方式，不能降低 Suen 的真实性与原始资料标准。


## 九、小红书增长上行策略

生效：2026-09-20

小红书 600 / 800 / 1000 等月度数字只作为最低检查线，不作为增长上限。阶段目标是持续争取更高分发与更多精准涨粉。

### 每周内容组合

在正常更新中，至少保留 1 个“高上限候选位”。它不是保证爆款，也不是为爆款牺牲真实性，而是在立项时优先满足：

- 陌生人无需背景即可理解；
- 第一屏 / 封面有明确真实对象或异常细节；
- 标题提出一个马上能听懂的具体问题；
- 原始资料、馆藏、手稿或可靠历史材料足够支撑；
- 看完后有明确可带走的信息，具备收藏 / 关注理由；
- 题材与最近 7 天主页观看体验不过度重复。

达到月度粉丝检查线以后，不主动降频、不保守选题、不停止高潜力题测试。出现高表现样本时，优先继续拆其有效结构，而不是复制题目本身。

### 当前优先验证的高上限结构

1. 强实物异常：熟悉物件 + 非常规内容物 / 用途；
2. 强现实冲突：偷窃、诅咒、关系、身体问题等普通人立刻理解的冲突；
3. 反直觉实践动作：为什么要画圆、贴身佩戴、写某些名字等；
4. 熟悉神秘学对象 + 历史翻转：塔罗、护符、星符等大众对象的真实起源 / 原文；
5. 人物故事 + 强转折：真实人物、时间线、记录中的异常命令或事件。

高上限候选仍需通过证据和栏目规则；不能用伪史、夸张、AI假图或现代流行说法换取点击。
