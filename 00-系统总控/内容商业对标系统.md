# Suen｜内容商业对标系统

状态：当前正式规则  
最后核对：2026-10-12

本文件负责：**第一方内容信号、外部 benchmark 采样，以及用全账号强样本与对标高表现题材共同生成新候选。**

不负责栏目路由、最终定题、商业状态或平台成稿。

## 一、品牌入口

长期前台公式：

**具体真实对象 / 行为 / 冲突 + 普通人马上能理解的问题 → 原典、馆藏、手稿、历史语境、仪式机制或现实判断。**

神秘感必须来自真实材料，不靠伪史、夸张或 AI 假资料。

## 二、第一方数据优先

在看外部账号前，先看 Suen 自己已经发生的真实结果。

信号分三档：

- **单样本信号**：一次表现明显，只说明值得继续验证。
- **重复信号**：多个相对可比样本在同一目标指标上重复出现。
- **稳定结构**：多个时期 / 样本持续有效，或跨平台后在相同目标指标上重复有效。

播放、点赞、收藏、涨粉、主页访问、询盘 / 成交分别判断，不互相替代。

跨账号迁移只迁移**题目结构 / 入口假设**，不能把小号跑通直接写成大号已验证。

## 二-A、全账号强样本与对标高表现题材｜新候选生成前必检

Suen 已明确要求：**从自己所有账号数据中找表现最好的已发布作品，同时参考对标账号有数据支持的高表现视频题材，再生成接下来的选题。** 对标既参与“讲什么”，也参与“怎么讲”；不能只在已有题目后参考问句、标题或剪辑。

适用于新的 A｜流量、B｜精准关注及研究型前台选题。纯履约通知、已经确定的商业动作及基于真实客户的 C / D 内容按实际职责判断，不为套爆款强行改题。已经进入生产保护的题不每日重新找题；Suen要求重评或出现影响判断的新事实时再启动。

### 1. 自有强样本：覆盖全部账号历史，不限最新截图

先读 `08-动态运行/内容台账/当前状态.md`，再读取抖音大号、抖音小号、小红书、公众号历史基线及相关月度补录；朋友圈只有取得实际可比较数据时才列作品表现。最新截图补入历史比较，不能因为截图只显示第一页或最近30天，就遗漏较早的头部作品。

按平台和内容形式分别识别：
- 触达头部：观看 / 播放 / 阅读；
- 保存与传播头部：收藏 / 分享；
- 精准增长头部：新增关注；
- 有可靠归因时，另看有效询盘 / 成交，不由前述指标替代。

保留作品、平台、实际指标、采集日和发布后观察窗口。不同字段来自不同日期时分别标注；未显示的涨粉、收入和留存不补猜。公众号推荐阅读人数、总阅读及搜索阅读分开，视频与图文先分开；不把跨平台绝对值相加做总榜。

取与当次任务相关的头部和较弱对照，说明哪个对象、题材、问题或内容承诺值得迁移。历史高表现是候选依据，不自动证明今天稳定有效；单样本、重复信号与稳定结构仍按第二节判断。

### 2. 对标高表现题材：读具体作品，不只读账号印象

先读 `08-动态运行/对标数据/当前覆盖总览.md`、`爆款结构证据表.md`，再用当前相关1—3个账号已取得的年度行级数据 / 题目流找到具体高表现作品。14账号仍用于后续原创性检查，不要求每次重新全量采集。

每个采用样本记录：
- 账号、平台、具体视频 / 文章标题和原始来源链接或行级样本定位；
- 发布日期、采集日期、真实可见指标及内容形式；
- 高表现判断依据：同账号 / 同格式相对表现、已确认头部或明确outlier；
- 样本覆盖和证据类型：原页、后台、第三方或检索线索。

完整度足够时使用年度中位数、Top10% / Top25%等已有比较；不足时只能称“当前已取得样本中的高表现”，不冒充完整年度爆款榜。只有点赞时只判断点赞高，不反推播放、关注或成交；没有指标的热门印象不算高表现证据。新作与成熟作品按发布年龄分层，不由短视频 / 直播低基线抬高研究长视频排名。

必须具体拆出**题材、对象 / 人物 / 文本 / 事件、核心问题、受众兴趣和内容推进**，再看标题与第一屏。不能仅写“参考ESOTERICA”“用为什么句式”，也不能只用泛“炼金术 / 古埃及 / 宗教”标签代替具体题材判断。

年度库已经足够时立即进入选题，不广泛补采。缺口真的影响当前判断时定向核查；历史高表现与当下公共热点分层，不把旧爆款称为今天正在热。

### 3. 两类证据共同生成少量候选

优先比较：
- 自有强样本已经获得响应的问题 / 内容承诺，与对标高表现题材能否形成新的具体研究问题；
- 自有强样本的相邻题材，能否由对标的对象、故事或原文提供有依据的新方向；
- 对标高表现题材在Suen尚无相应样本时，是否值得作为明确标注的新测试。

不要求每条都与某个旧题或外部视频同题，也不把交集机械变成固定配额。可以探索独立原典与真实实践；自有或对标证据不足时标明“新探索 / 外部证据缺失”，按实际缺口和硬门槛判断，不能包装成双重数据已经验证。

对标讲过同一公共对象、文本或事件，可以作为独立选题起点；必须独立取得可靠来源，并提出可说明的新增问题、证据、比较或解释。不能直接搬标题、句子、论证顺序或独特选材组合。外部视频是选题信号，历史事实仍回原典、馆藏与可靠研究核实。

### 4. 候选保留最小来源依据

每个候选在后台写清：
- **自有参照**：已发布作品＋账号＋哪项数据好＋采集日；没有可比样本就明说；
- **对标参照**：具体作品＋链接 / 行级定位＋实际指标 / 相对表现＋采集日 / 覆盖边界；
- **借鉴题材与核心问题**：本条准备研究什么，借用的是哪一层；
- **Suen新增价值**：独立资料、不同问题、新比较或新的具体解释；
- **本轮主任务与待核事项**：为什么适合当前平台，哪些证据或素材仍需取得。

Suen默认只需看到一句简短的选题依据；要求比较时再展开。完整字段不进入口播、文章正文或发布配文。没有实际核读两个来源层、只有泛账号名或只有“资料有趣”时，不声称已经按本流程选题。

### 5. 之后再过正式门槛

生成候选后执行最近7天全平台重复、七栏目价值中心与出镜形式、14账号原创性、证据范围、实际视觉供给、文笔及当日产能。播放高、旧稿现成、已经投入研究都不替代这些门槛；关注与高客单购买仍分别验证。未完成者保留“候选题｜待筛选”，不自动写入跨日P0池。

## 三、当前值得继续验证的第一方结构

这些是候选结构，不是永久公式：

1. 熟悉视觉 + 奇怪对象
2. 反直觉仪式行为
3. 熟悉神秘学对象 + “原文到底写什么”
4. 死亡 / 身体 + 一个具体怪问题
5. 大众默认判断 + 实际需要重新判

是否升级为重复信号 / 稳定结构，以最新 GitHub 内容台账与商业运行复盘为准。

## 三-A、高上限内容与爆款验证｜先看传播势能，再看制作兑现

“好内容 / 专业内容”和“高上限内容”分开判断。A｜流量内容如果目标是突破当前分发池，除资料正确和栏目成立外，还要判断事实本身是否有足够大的陌生人传播势能。

### 高上限候选的陌生人压力测试

不新增机械评分；正式投入重制作前快速检查：
1. 完全不懂神秘学的人，前 2 秒能否知道哪里奇怪 / 有冲突 / 值得继续看；
2. 去掉“魔法、神秘学、塔罗、PGM、阿格里帕”等专业标签以后，这件事本身是否仍值得知道；
3. 看完后是否存在低解释成本的分享理由，即用户转给朋友时无需额外解释“为什么有意思”；
4. 是否有真实对象、原页、馆藏、记录或其它可靠证据可以兑现，而不是只靠口播形容。

四项都强时优先视为高上限候选；只有证据强但陌生人入口窄时，更可能是专业资产题，不要求它承担爆款任务。

### 当前优先继续验证的三类入口

结合当前第一方信号，优先继续验证而非固化为公式：
- **人物 / 事件 + 明确强转折**；
- **普通人马上懂的问题 + 反直觉实践动作 + 原始资料支撑**；
- **一眼异常的真实对象 + 一个具体问题**。

不同题材复测同一入口结构，避免把一次强样本误判为永久题材公式。

### 前 2—5 秒的制作原则

当前大号第一瓶颈若仍是前 2—5 秒，则 A 类内容优先：
- 0—2 秒先让异常事实、动作、对象或冲突发生；
- 2—5 秒留下一个具体未解决问题；
- 5 秒以后再补必要背景和解释。

前 5 秒不承担完整历史背景、术语定义或“今天要讲什么”的说明任务。

### 中段与结尾

中段持续检查是否真的在推进新信息。优先出现：
`新事实 / 新图像 / 新证据 / 新转折 / 更具体的异常细节`

避免：
`观点 → 重复解释观点 → 换句话重复 → 证据 → 再总结同一观点`

不要求机械按秒卡点，但如果较长一段没有新增信息，只是在重复解释，应删减或重构。

答案已经兑现时可以直接结束；不为了“完整”强加总结、升华或重复结论。

### 证据揭晓感

Suen 的差异化悬念优先来自真实证据，而不是夸张话术：

`异常事实 → 观众自然怀疑 → 原件 / 原页出现 → 指明关键位置 → 继续推进`

事实足够强时减少情绪形容词。不得为了降低跳出使用超出证据的“最恐怖 / 最变态 / 彻底失控 / 震碎三观”等评价性夸张。

原典在不同栏目承担不同作用：在《残页》中可以是主角；在故事型内容里可以只负责证明，不必每次打断叙事完整讲考据过程。

### 第一画面

第一画面优先让观众看到一个能快速辨认的主体或异常：
- 人物 + 具体异常事实；
- 奇怪器物 / 护符 / 文物；
- 原页上肉眼可定位的异常位置；
- 明确实践动作或视觉冲突。

“相关历史图片”不等于强第一画面。画面与口播应共同回答“这里到底哪里奇怪”。

### 观看体验垂直，而不是题材锁死

不把账号强行收缩为只讲古埃及、塔罗、PGM 或某一传统。更重要的是稳定前台观看承诺：

**Suen 拿出一个真实、具体、异常的对象 / 事件 / 问题，再用真实资料把它讲清楚。**

题材可以宽，但陌生人的消费理由应逐渐稳定。

### 5 个高上限 A 类样本｜突破实验

未来出现 **5 个真正通过硬门槛的高上限 A 类候选** 时，将其视为同一轮突破实验观察；不要求连续五天，也不为了凑实验样本降低选题门槛。

优先覆盖：
- 人物 / 事件强转折 × 约 2；
- 普通问题 + 反直觉实践 × 约 2；
- 异常真实对象 + 具体问题 × 约 1。

“约”表示结构覆盖目标，不是硬配额；当天更强真实候选可以覆盖。

主要观察顺序：
`2 秒跳出 → 5 秒留存 → 是否突破近期常见播放池 → 平均观看 / 完播 → 分享 → 精准涨粉 → 点赞`

单条强结果仍只是单样本；重复出现后再升级信号等级。

### 爆款后的第二条

若某条内容明显突破近期账号基线，下一条不机械复制同一人物 / 对象 / 题材。优先用另一个题材兑现相同账号承诺，让新观众确认“这种内容不是偶然”。

爆款复盘除播放 / 点赞外，还看精准涨粉、主页访问、后续内容承接和能可靠归因的询盘。高播放但带来不相关人群，不自动视为最优账号增长样本。

## 三-B、实时公共热点层｜2026-10-08

长期 benchmark 负责告诉我们“什么结构长期有效”；实时公共热点层负责回答另一件事：

> **今天 / 这几天，普通用户正在主动讨论什么。**

两者不能混在一起。

### 扫描范围
只有当天需要生成新前台题时才做，不机械日更：
- 抖音近期公开结果；
- 小红书近期公开结果；
- 微博 / 新闻 / 搜索层；
- 与 Suen 主题直接相关的公共讨论。

默认 freshness：
- 强热点：24—72 小时；
- 持续热点：7 天；
- 周期性慢热议题：最多看近 30 天。

### 记录什么
只需要轻量记录：
- 热点词 / 事件；
- 核对日期；
- 具体来源链接与平台；
- 原帖 / 文章发布日期（缺失就注明，不用抓取日替代）；
- 采集日、实际能确认的互动或评论问题，以及直读 / 检索摘要 / 用户观察的证据类型；
- 下次复核触发条件；
- 当前大众最常问的具体问题；
- 是否与七栏目存在自然路由；
- Suen 能提供的新增价值；
- 是否值得进入当天候选池。

只保存足以支持当前判断的少量样本。检索摘要与直接页面不一致时标待复核，不补推播放 / 点赞或“高互动”。区分天象 / 事件事实、公众实际讨论和Suen的解释；少量发帖只能证明存在话题，不证明全网集中升温。

当已有批次或当天P0可继续执行时不重新扫描。需要新候选才查，足够支持取舍就停止，不建立每日完整热点仓库或额外生产配额。

### 热点判断纪律
- 一个账号刚发过，不等于热点；
- 多个平台 / 多个近期发布重复出现同一话题，可信度更高；
- 单一平台若出现明显集中讨论、评论问题持续重复，也可进入候选层；
- 看不到真实近期信号时，不写“全网爆火”；
- 热点强度只影响候选优先级，不覆盖 Suen 第一方数据。

### 转化原则

热点只帮助辨认当前问题，正文仍按实际资料生成。可以从具体对象、动作、原文、人物 / 事件、现实判断条件进入；只有存在真实误解且证据能明确判定时才用辨伪。

可比角度包括：原文具体写了什么、传统怎样理解某个动作、某个真实事件如何发生、哪些条件改变判断。题目与句式由本次材料决定，不把所有热点套成“X不等于Y / 真相 / 原典有没有”。

泛运势流水账、热词搬运或缺证据的确定判断不作为正式生产。原典解释不等于现实预测已获验证；标题范围不得大于证据。

## 五、近一年全量基线 + 近期趋势层

动态年度数据统一读取：
- `08-动态运行/对标数据/当前覆盖总览.md`
- `08-动态运行/对标数据/采集状态.md`
- 与当天候选最相关的账号年度文件
- 需要跨账号结构判断时再读 `跨账号结构观察.md` / `公众号-跨账号结构观察.md`



对标账号不再以“近 7—30 天抽 2—3 条”为主样本。Suen 明确要求：**以滚动近 365 天为主观察窗，能取得的公开内容数据尽量全量纳入。**

原因：
- 部分核心对标更新频率低，7—30 天可能根本没有足够新内容；
- 只看最近几条容易被单次爆款 / 低谷误导；
- 一年窗口更适合看某个账号真正反复有效的题型、入口、形式和商业连接。

### A｜年度全量基线（主层）

对每个核心对标账号，原则上收集最近 365 天内**全部可取得的公开发布记录**，而不是只挑表现好的内容。

至少保存：
- 平台 / 账号；
- 发布日期；
- 标题；
- 当前可见播放 / 浏览；
- 点赞；
- 评论；
- 收藏 / 分享（平台公开时）；
- 视频时长 / 图文形式；
- 内容主题；
- 入口结构；
- 第一屏 / 开头类型；
- 是否强现实冲突 / 强异常对象 / 熟悉人物 / 反直觉动作 / 原文核查 / 其它；
- 是否带产品 / Patreon / 商业桥；
- 数据抓取日期；
- 原始来源页。

某项平台不公开就记 N/A，不估算。

### B｜近期趋势层（辅助）

年度全量基线之上，再看近期有没有结构变化：
- 默认看最近 90 天；
- 如果最近 90 天少于 5 条，就看“最近 3—5 条实际发布”，即使跨得更久；
- 7—30 天只作为更短的 freshness 补充，不再是必须满足的采样窗；
- 更新很勤的账号可额外看最近 30 天；更新很慢的账号不因没有 30 天新内容而降级。

### C｜怎么比较

不同账号体量不能直接拿绝对播放横比。优先使用账号内部相对表现：
- 近一年中位播放；
- Top 25% / Top 10%；
- 单条播放 ÷ 该账号近一年中位数；
- 同账号、相近内容形式之间比较；
- 能取得时再看互动率 / 收藏率 / 评论率。

发布时间不同造成累计时长差异时：
- 同时保存“发布至今的天数”；
- 30 天以内的新内容不要直接用累计播放和已经发布半年的内容硬比；
- 必要时按 0—30 / 31—90 / 91—180 / 181—365 天分层比较；
- `views/day` 只作辅助，不作为唯一质量指标，因为内容播放通常并非线性增长。

### D｜实际定题时怎么用

每个 Asia/Shanghai 运营日第一次进行“正式定新的前台题”时：

1. 先按二-A读取Suen各账号历史头部与最新第一方状态，不能只看最近7天或当前截图；
2. 再读取已经建立的**近一年对标基线**，实际采用相关高表现作品的题材与核心问题；
3. 根据当天候选，只深入查看最相关 1—3 个账号 / 题型的具体样本；
4. 只有年度库缺数据或对标账号出现新发布时，才补抓，不需要每天从零重扫全部账号；**当现有样本已经足够支持候选生成与结构判断时，停止为了“更完整”继续采集，直接进入选题反推；只有某个候选或供给结构判断真的被缺口阻塞时再定向补数据。**
5. 每个候选按二-A保留自有参照、具体对标作品与数据、借鉴题材 / 核心问题及Suen新增价值；入口 / 第一屏 / 证据组织等表达方法另作说明，不能替代题材参照；
6. 商业相关候选额外只做一个轻量判断：**“这个入口主要会吸引谁？”** 可区分纯猎奇、专业兴趣、已有消费经验、明确现实需求、正在比较下一次购买等实际接近购买的状态；不新增数值评分，也不用年龄、城市、职业替代真实购买行为；
7. 对标题材可以进入候选生成；同一公共对象按E节核独立问题、来源与新增知识，不直接复制标题、文案、人格或论证。

**年度全量数据用于找重复结构，近期趋势用于判断现在有没有变化。两层都不能覆盖 Suen 自己的第一方真实数据。**

### E｜原创性与同题比较

新候选使用当前全部 14 个对标账号已取得的年度库 / 题目流检查同一人物、器物、文本、事件、仪式和问题。检查目的在于识别重复表达与研究价值，不能把公共研究对象变成对标账号的排他题库。

同一对象被讲过时，核对：

- 是否直接沿用对方的选材组合、核心论证、叙事顺序、句子或独特包装；
- Suen 是否独立取得原始来源；
- 本次是否提出新的具体问题、证据、比较或解释；
- 观众能否获得可说明的新增知识。

只改标题 / Hook、同义改写或复制论证，换题或重新独立研究。共享公共对象、同一原典并有独立问题与证据时，可以继续，不需要额外申请同题例外。引用他人的独特判断应明确出处。

优先用已有年度库；只有当前原创性判断被缺口阻塞时定向补查。数据不全只能写“现有库未发现同题”，不声称完整排除，不编造公开指标或趋势。

## 八点五｜高客单目标下的内容分层

当当前商业目标涉及定制仪式、星符等高价值服务时，内容不只判断“会不会点开”，还要区分它在购买链路中的作用。

当前至少保留四种作用：
- **流量入口**：让陌生人先进入；强对象、强冲突、反直觉动作、真实故事；
- **专业识别**：原典、文物、历史语境、材料、择时，让观众知道 Suen 的研究能力；
- **判断能力 / 服务理解**：让有现实需求的人理解“不同情况为什么不能自动套同一方案”；
- **案例 / 结果认知**：只在存在真实案例与允许公开信息时，讲实际客户目标、判断、执行与客户后来报告的现实变化。

不设永久死比例。当前如果高客单是阶段重点，应主动补足第三层；第一、二层仍然承担流量和品牌，不能全部改成销售内容。

对商业相关候选，除“这个入口主要会吸引谁？”以外，再轻量回答：
**“看完以后，目标客户会更理解 Suen 的哪一种购买价值？”**
可回答：专业资料、判断能力、定制差异、执行质量、真实案例、服务范围等。不要为了填字段硬造商业价值。

### benchmark 在高客单目标中的角色

外部 benchmark 按二-A同时提供**高表现题材来源与表达方法**：
- 哪些具体对象、人物、文本、事件和实践问题有真实高表现证据；
- 什么入口更容易被点开；
- 什么第一屏更容易理解；
- 什么问题结构更容易把复杂专业内容翻译成大众入口；
- 什么证据组织有利于继续观看。

benchmark 不负责定义高客单客户，也不能证明哪种内容一定带来高客单成交。

高客单客户与产品方向优先由 Suen 自己的：
**真实询盘 → 报价 → 成交 → 项目结果记录 → 复购 / 转介绍**
来验证。

因此顺序固定为：
**Suen当前状态与全账号强样本 → 对标高表现题材 / 问题 → 独立研究生成少量候选 → 核内容与当前任务的适配 → 14账号原创性及正式硬门槛 → benchmark标题与表达校准。**

公开内容本身成立以后，再判断是否自然服务当前目标客户 / 商业问题；外部题材的高播放不能证明购买意愿。

商业目标可以提高某类真实内容的优先级，但不能反过来制造一条“没有销售目的就不值得看”的公开内容。

## 八点六｜内部命题 ≠ 前台标题

候选池里的研究命题、商业命题和正式发布标题必须分开。

内部命题负责准确回答“这条内容到底要讲什么”；前台标题 / 第一屏负责让目标观众愿意点开和继续看。

正式进入生产以前，必须重新生成平台前台包装：
- 抖音：标题 / 第一屏 / 开头优先一个具体、马上能懂的题眼，语言服从 Suen 自己的历史标题基线；有真实冲突就直接说，没有就不硬造；
- 小红书：标题 / 封面可以更完整，兼顾搜索词、收藏价值和明确利益点，但同样保持真人说话感；
- 朋友圈：不使用短视频标题腔，从真实经历或个人感想自然进入；
- 同一内部命题跨平台时，默认重新写前台包装，不直接复制。

前台包装的目标仍然是**强吸引**。  
但“强”优先来自具体对象 / 冲突 / 反常动作 / 原文怪句，而不是来自模板化语气。

判断标准：
- 如果把“你绝对想不到 / 先别急着 / 真的能吗 / 其实”这些运营词全部删掉，题目依然有吸引力，说明入口本身成立；
- 如果删掉这些词以后题目立刻变平，优先重新找题眼，而不是再套一个更强模板；
- 标题强度和自然度必须同时成立，不能二选一。

禁止：
- 把“服务认知”“高客单筛选”“为什么不能保证效果”这种后台命题原样当发布标题；
- 只因为标题事实准确就认为入口足够强；
- 为了强钩子制造不存在的客户结果、冲突或保证。



## 八点七｜七栏目最终标题必须走 benchmark title pass

这一条解决的是：**候选和正文已经成立以后，最终发布标题不能再由模型凭默认“短视频标题感”现编。**

七个抖音大号栏目（文物 / 异录 / 辨伪 / 残页 / 隐理 / 牌记 / 古术）在生成最终标题前，必须实际使用当前 benchmark 系统做一次标题校准。

### 固定顺序

1. 先完成题目、栏目、证据和正文，不用标题反推内容；
2. 读取本文件当前规则；
3. 读取当前已经建立的相关 benchmark 年度库 / 题目流；
4. 当现有库足以支持标题结构判断时直接使用，不为了形式广泛补采；
5. 如果现有库缺少当前栏目 / 当前题型可用样本，再定向公开搜索 2—5 个真实标题样本；
6. 只迁移“标题怎么把内容前台化”的方法，不复制对标账号具体题目、句子、人格或结论；
7. 最终标题必须再与 Suen 自己已经使用过的自然标题基线比较；
8. 标题定稿后再做事实范围检查，不能让标题比正文证据更强。

### 七栏目 benchmark 侧重点

#### 文物
优先参考：
- Let's Talk Religion：强异常 / strong_mystery 如何把复杂对象前台化；
- ESOTERICA：specific_object / 熟悉对象 + 意外功能；
- Suen 第一方强实物异常样本。

迁移重点：
**具体对象本身 + 一个肉眼或一句话就能明白的异常点。**

不要默认写成：
- “古代人为什么……”
- “这个文物背后到底……”
- “一件来自X时期的神秘……”

对象本身已经够怪时，标题可以只是短名词句 / 陈述句，不强制问句。

#### 异录
优先参考：
- Let's Talk Religion：人物 / 历史事件如何用冲突、转折、结果前台化；
- ESOTERICA：熟悉人物 / 对象 + 意外关系；
- Suen 自己已经跑出的 Dee / Kelley 等人物事件样本。

迁移重点：
**事件先于履历；转折先于人物介绍。**

陌生人物名字如果本身没有认知度，不要默认把名字放在标题最前。
优先让标题先回答：
“这个人到底发生了什么值得听的事？”

#### 辨伪
优先参考：
- Angela Puca：practice_dispute、真假 / 误解 / 实践后果；
- Let's Talk Religion：truth / misunderstood / lost / disputed 等前台结构；
- Suen 第一方历史辨伪后验。

迁移重点：
**观众原本相信什么 + 这个判断为什么值得重新判。**

不要为了栏目存在而机械写：
- “X是真的吗？”
- “X到底是不是……？”
- “关于X的真相”

如果“真假”对观众没有现实后果、认知落差或强兴趣，标题本身就不够强。

#### 残页
优先参考：
- ESOTERICA：working title → final title 的改写差异，尤其 specific_text 如何被翻译成普通人问题；
- Let's Talk Religion：失落文本、怪句、具体文本中的冲突；
- Suen 第一方《第二木星星符到底写了什么？》等精准涨粉 / 收藏样本。

迁移重点：
**先把原文里最怪、最有后果、最值得看的那句话 / 动作拿出来。**

不要默认把：
- 手稿名；
- 纸草编号；
- 作者名；
- 章节名

放在标题前台。它们是证据，不自动是点击理由。

#### 隐理
优先参考：
- Angela Puca：practice_dispute / explicit_question；
- 穹印之源：复杂机制如何翻译成普通人会问的问题；
- Suen 第一方“画圆”等反直觉实践样本。

迁移重点：
**一个真实实践动作 + 为什么这一步值得问。**

不要把所有《隐理》都机械写成：
“为什么X？”
问句可以用，但必须像真人真的会问，而不是标题生成器句法。
如果一句短陈述更自然，就用陈述句。

#### 古术
优先参考：Suen历史做法类作品的具体收藏/关注与观看反馈，以及已取得的研究型宗教/魔法实践高表现样本；主任务与数据口径分开。

迁移重点：具体做法或器物怎样用于一个历史问题，原始资料逐步兑现。历史治疗/求问题材与现代功效分层；不用抽象机制标题替代操作证据，不复制对标的资料组合或叙述。

#### 牌记

优先参考：
- Suen 自己真实案例 / 已采用判断规则；
- 魔女小玉塔罗等中文塔罗账号的“现实问题直接前台”能力；
- 其它真实案例型塔罗内容只观察问题如何被说出来，不迁移“宇宙能量”等表达。

迁移重点：
**现实问题 + 这副牌里真正让直觉判断失效的地方。**

不要写成：
- “XX牌是什么意思”
- “XX牌正位 / 逆位解析”
- “塔罗告诉你……”
- 抽象的“关系能量 / 宇宙指引”

优先像一个真实客户问题或真实看牌瞬间。

### 标题风格的硬禁区

以下不是绝对禁词，而是默认高风险 AI / 运营模板；出现时必须证明它真的是当前题最自然的说法：
- “一个……为什么……”
- “古代人为什么……”
- “这件……背后到底……”
- “真的……吗？”
- “你绝对想不到”
- “很多人不知道”
- “居然 / 竟然”用于替代事实本身的强度
- 一句话同时塞背景 + 对象 + 怪点 + 问题 + 结论

### 标题验收

最终标题必须同时满足：

1. **像人写的**：单独拿出来像 Suen 会真的发，而不是模型总结题意；
2. **不是摘要**：不把整条视频的背景和答案都塞进标题；
3. **有题眼**：只留下最值得点开的一个东西；
4. **标题强度来自事实**：删掉“真相 / 居然 / 竟然 / 你不知道”等运营词以后仍成立；
5. **与 benchmark 有可说明的结构参照**：内部必须能回答“这次借鉴了哪个账号 / 哪类标题结构”，但不默认展示给 Suen；
6. **原创性**：仍检查14账号现有库；同一公共对象按独立问题、来源、论证与新增知识判断，不自动淘汰；
7. **不超证据**：标题承诺 ≤ 正文实际证明。

如果最终标题只是“信息完整、语法正确”，但读起来明显像 AI 概括句，视为未通过。


## 九、小红书增长上行策略

生效：2026-09-20

小红书 600 / 800 / 1000 等月度数字只作为最低检查线，不作为增长上限。阶段目标是持续争取更高分发与更多精准涨粉。

### 每周内容组合

在正常更新中，至少保留 1 个“高上限候选位”。它不是保证爆款，也不是为爆款牺牲真实性，而是在立项时优先满足：

- 陌生人无需背景即可理解；
- 第一屏 / 封面有明确真实对象或异常细节；
- 标题提出一个马上能听懂的具体问题；
- 原始资料、馆藏、手稿或可靠历史材料足够支撑；
- 看完后有明确可带走的信息，具备收藏 / 关注理由；
- 题材与最近 7 天主页观看体验不过度重复。

达到月度粉丝检查线以后，不主动降频、不保守选题、不停止高潜力题测试。出现高表现样本时，优先继续拆其有效结构，而不是复制题目本身。

### 当前优先验证的高上限结构

结合 2026-09-21—09-23 第一方样本，当前 A｜流量优先顺序不把所有结构等权处理：

1. **强实物异常**：熟悉物件 + 非常规内容物 / 用途；
2. **强现实冲突**：偷窃、诅咒、关系、身体问题等普通人立刻理解的冲突；
3. **反直觉实践动作**：为什么要画圆、贴身佩戴、写某些名字等；
4. **人物故事 + 强转折**：真实人物、时间线、记录中的异常命令或事件；
5. **熟悉神秘学对象 + 历史翻转**：保留为可测试结构，但**不再作为抖音大号 A｜流量的默认首选**。9/23《塔罗牌一开始就是拿来占卜的吗？》在抖音前段留存、播放、互动与涨粉均未形成强信号，说明“知识纠错本身”不足以保证冷流量入口；以后若再用，必须同时具备更强现实冲突、视觉对象或故事推进。

这里的顺序仍是当前证据下的工作优先级，不是永久排名。高上限候选仍需通过证据和栏目规则；不能用伪史、夸张、AI假图或现代流行说法换取点击。


### 强样本后的放大方式

当某条内容明显高于账号近期基线，不能只记录“爆了 / 数据好”，也不能立刻机械复制同题。

先拆四件事：

1. **入口为什么成立**：标题里的对象、冲突、问题是否无需背景即可理解；
2. **视觉为什么成立**：第一屏 / 封面是否有强对象、异常细节或真实原始资料；
3. **观看为什么成立**：是故事转折、机制解释、历史翻转还是原文证据在留人；
4. **转化为什么成立**：主要带来的是观看、收藏、关注、主页访问还是询盘。

然后在未来 1—2 周内优先测试 2—3 个“结构相邻、题材不同”的候选，验证真正有效的是结构还是单一题材。

例如《为什么仪式开始之前要先画一个圆？》跑强以后，可以继续测试：
- 另一个普通人能立刻理解的反直觉实践动作；
- 另一个有原始材料支撑、看完有收藏价值的“为什么”问题；
- 但不要求连续做“为什么仪式要……”的同句式复制。

爆款只提供新的证据，不变成永久模板。
