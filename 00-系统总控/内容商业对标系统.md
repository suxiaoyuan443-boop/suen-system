# Suen｜内容商业对标系统

状态：当前正式规则  
最后核对：2026-09-19

本文件只负责：**第一方内容信号怎么理解 + 外部 benchmark 怎么采样。**

不负责栏目路由、最终定题、商业状态或平台成稿。

## 一、品牌入口

长期前台公式：

**具体真实对象 / 行为 / 冲突 + 普通人马上能理解的问题 → 原典、馆藏、手稿、历史语境、仪式机制或现实判断。**

神秘感必须来自真实材料，不靠伪史、夸张或 AI 假资料。

## 二、第一方数据优先

在看外部账号前，先看 Suen 自己已经发生的真实结果。

信号分三档：

- **单样本信号**：一次表现明显，只说明值得继续验证。
- **重复信号**：多个相对可比样本在同一目标指标上重复出现。
- **稳定结构**：多个时期 / 样本持续有效，或跨平台后在相同目标指标上重复有效。

播放、点赞、收藏、涨粉、主页访问、询盘 / 成交分别判断，不互相替代。

跨账号迁移只迁移**题目结构 / 入口假设**，不能把小号跑通直接写成大号已验证。

## 三、当前值得继续验证的第一方结构

这些是候选结构，不是永久公式：

1. 熟悉视觉 + 奇怪对象
2. 反直觉仪式行为
3. 熟悉神秘学对象 + “原文到底写什么”
4. 死亡 / 身体 + 一个具体怪问题
5. 大众默认判断 + 实际需要重新判

是否升级为重复信号 / 稳定结构，以最新 Slack 复盘为准。

## 五、近期创作采样

每个 Asia/Shanghai 运营日第一次需要定新的前台题时：

- 实际查看最相关 **2—3 个**账号近期内容；
- 默认优先最近约 **7—30 天**；
- 同日已刷新且任务没有变化时可复用；
- 不机械刷五个账号；
- 不直接复制对标题目。

重点看：

- 题目入口；
- 第一屏 / 开头；
- 内容结构；
- 原始资料 / 案例怎么组织；
- 新形式 / 系列；
- 商业信息位置和密度。

无法可靠取得近期样本时写：

`近期样本未可靠取得`

然后降级使用长期方法，不编造“最近他们都在做什么”。

- 什么问题更容易收藏 / 跟做 / 评论；
- 制作过程、女巫生活方式、器物、愿望 / 蜡烛等怎样形成连续观看与商业兴趣。

可观察：

- 子童-witch

- 魔女小玉塔罗

这些账号**不能承担历史事实、原典解释、仪式有效性或宗教史证明**。

现代女巫只是大众入口层，不新增第 7 个大号栏目。进入大号时必须重新路由到现有 6 个合集。

## 七、重复与主页结构

默认重点检查最近 **7 天**的观看体验重复，不只看标题。

例如连续都是：

- 原页 / 古书 / 资料页；
- 相近死亡题材；
- “资料 + 翻译 + 解释”；
- 同一种视觉和问题结构。

账号样本很少时，还要看**当前全部已发布内容**形成的主页第一印象。

这不是机械轮播；强题仍可连续同栏目，但必须知道自己在重复什么体验。

## 八、对标的边界

- 第一方真实数据 > 外部经验；
- 长期方法 ≠ 刚看过近期内容；
- 单样本 ≠ 稳定公式；
- 流量账号 ≠ 历史证据源；
- 对标只帮助找到更好的入口和组织方式，不能降低 Suen 的真实性与原始资料标准。
