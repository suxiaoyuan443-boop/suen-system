状态：正式系统规则

## 版本优先级

发生冲突时按以下顺序判断：

1. Suen 最新明确指令
2. 最新 Slack 正式记录 / 频道结构
3. 最新专用对话长期规则
4. 当前正式母稿、规范文件
5. 旧 PDF、旧 GitHub 文件与历史对话

高优先级明确覆盖低优先级时，不把两个版本拼接成折中版。
