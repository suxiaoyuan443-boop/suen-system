# 迁移与冲突记录

状态：正式系统规则
最后核对：2026-09-17

## 版本优先级

发生冲突时按以下顺序判断：

1. Suen 最新明确指令
2. 最新 Slack 正式记录 / 频道结构
3. 最新专用对话长期规则
4. 当前正式母稿、规范文件
5. 旧 PDF、旧 GitHub 文件与历史对话

高优先级明确覆盖低优先级时，不把两个版本拼接成折中版。

旧规则“收到更新固定生成 1 篇 7000+ 长文 + 1 篇贴图”已经被后续规则覆盖。

当前为：贴图与长文独立判断、独立记录和独立 KPI。没有强题时可以只发贴图；长文保持深度资产定位，不机械日更。

贴图的标题 + 正文 + 图注 + 必要来源总量控制在 800 字以内，优先约 650—750 字。
