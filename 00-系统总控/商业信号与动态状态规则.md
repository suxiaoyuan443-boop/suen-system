# Suen｜商业信号与动态状态规则

状态：当前正式规则
最后核对：2026-10-08

本文件补齐商业总控中最容易遗漏的两类问题：

1. **什么算商业信号、同一天跨平台重复销售怎么算；**
2. **价格、预约、天象、当日总控等动态状态什么时候会失效。**

它不替代 `商业总控.md`、`商业目标与产品优先级.md`、销售规则或天象规则，只统一这些文件之间的商业密度与动态状态口径。

---

## 一、什么算“主要商业信号”

出现以下任一情况，默认视为明显商业信号 / 商业触点：

- 公开价格；
- 明确写“可预约 / 可购买 / 可下单 / 可报名”；
- 明确引导私信、咨询、加微信、进店、购买；
- 宣传某个当前可售服务 / 产品并承担成交承接；
- 用客户反馈、成品展示、名额 / 排期信息直接推动购买；
- 单条内容主任务被商业总控指定为 `D｜商业承接`。

以下情况**不自动等于主要商业信号**：

- `C｜服务认知` 中只展示判断过程、工作方式和服务边界，没有购买 CTA；
- 正常工作记录中自然出现正在做的产品 / 仪式，但没有价格、预约或购买引导；
- 纯知识内容里提到某项服务存在，但没有承担当日承接任务。

是否属于主要商业信号，最终看这条内容是否在**主动推动购买 / 预约 / 询盘**，不只看有没有出现产品名字。

---

## 二、按真实动作判断商业触点
不再执行固定80/20、连续条数或天数的推销调节。真实服务说明、购买入口、价格与预约按实际需要和平台许可判断；相同内容跨平台仍分别核许可，不机械重复CTA。未授权收费动作不借学术答疑导流。

## 三、抖音与小红书同步视频的商业信号规则

抖音大号和小红书可以使用同一支完整成片，但商业信号必须单独判断。

如果视频正文已经包含：

- 价格；
- 预约；
- 购买 / 私信 CTA；

那么同步到小红书时，这个商业信号也会被一并带过去。

商业总控必须提前决定：

- 是否允许两个平台都承载这次商业触点；
- 小红书配文是否继续重复 CTA；
- 是否更适合把视频保持纯内容，只让朋友圈或其它一个入口承担商业承接。

默认不要出现“视频里卖一次，配文再卖一次”的重复强化。

---

## 四、“今日总控”只对当天有效

所有带有“今日 / 今天”的经营决定，默认以 **Asia/Shanghai（UTC+8）** 的当天为有效期，例如：

- 今日纯内容；
- 今日主推某产品；
- 今日明确不推；
- 今日唯一商业信号；
- 今天朋友圈承担承接；
- 今天某平台停更。

上海日历日结束后，**不得自动把昨天的当日决定续到今天。**

只有以下情况可以跨日继续：

- Suen 明确说继续执行；
- 最新 GitHub 当前动态文件明确写成跨日 / 持续状态；
- 该信息本身属于长期规则，而不是某一天的调度。

因此专用对话不能拿“昨天总控说可以卖”作为今天继续加 CTA 的依据。

---

## 五、动态产品状态必须重新确认

“这个产品长期存在”不等于“今天可以按旧条件销售”。

以下信息属于动态商业状态：

- 当前是否可售 / 可预约；
- 当前价格；
- 当前排期；
- 当前承载能力 / 容量；
- 当前交付方式；
- 是否允许公开宣传；
- 是否有真实折扣 / 套餐；
- 是否接受定金、分期或其它付款方式；
- 当前退款 / 取消条件。

这些信息只能以：

1. Suen 最新明确指令；
2. `08-动态运行/商业/当前商业状态.md` 当前仍有效记录；
3. 对应专用真源最新明确状态；

为准。

**旧朋友圈、旧视频、旧报价、旧聊天中的价格和条件不能自动当成今天仍有效。**

如果没有确认：

- 不自创折扣；
- 不自创套餐；
- 不自创赠品；
- 不自创分期 / 定金方案；
- 不自创退款政策；
- 不自创容量 / 名额。

## 六、天象窗口过期后的状态处理

涉及星符和依赖择时的仪式时，除继续执行 `05-天象经营/天象预约池规则.md` 外，还增加时间有效性检查。

如果一个窗口的日期 / 时间已经过去：

- 不能继续把旧的“开放预约”当成当前可宣传状态；
- 不能因为日期过去就自动写“已完成”；
- 不能自动推断“已取消 / 已执行 / 已满”；
- 必须读取对应择时专用系统或 Suen 最新确认的实际状态。

在状态没有更新以前：

- 对未来公开宣传视为**不可用的旧窗口**；
- 内部记录可以保留历史状态，但必须标明日期已过 / 状态待更新；
- 如需判断是否已执行、是否完成，回到技术 / 实际执行真源确认。

### 过期窗口与下一预约窗口的滚动

`旧窗口停止预约` 与 `旧窗口是否已完成执行` 是两件事。

只要窗口日期 / 时间已经过去：

- 该窗口就不能再接受新的预约，也不能继续承担当前商业宣传；
- 不需要等待“已完成”状态确认以后才关闭预约；
- 如果下一条未来窗口已经 `已确认`，且 Suen 最新明确授权开放，可以立即把下一窗口切换为 `开放预约`。

同时必须区分：

- **开放预约**：可以承接自然询盘、预约、付款排期；
- **主动商业推广**：公开价格、明确 CTA、主动推预约等，仍按当天商业密度控制。

Suen 允许“临近窗口后开始商业动作”时，总控根据距离窗口、当前预约量、承载能力、最近商业密度和当天内容任务判断启动时机；除非 Suen 明确指定，不自行发明固定提前天数。

## 七、成本与供应链信息保护

公开内容默认不披露 Suen 的内部采购与利润信息。

包括但不限于：
- 采购成本 / 进货价 / 原料成本；
- 供应商报价与采购渠道；
- 具体规格对应具体成本价的组合；
- 毛利、加价倍率、内部利润结构；
- 尚未公开的打样方案、供应链选择与采购计划。

尤其注意：即使单独一个“尺寸”或“材质”本身不是秘密，只要与某个采购价格、店铺截图、供应商方案绑定后能够帮助观众反推出成本，就按内部信息处理。

公开售价与采购成本是两套信息。需要公开售价时，只读当前商业状态；不得顺带解释内部成本构成，除非 Suen 明确要求。

## 八、客户反馈与社会证明

客户反馈、成品展示和案例可以承担信任或商业承接，但必须满足：

- 真实发生；
- 不虚构结果；
- 不把个别结果写成普遍保证；
- 不把客户未确认的隐私信息公开；
- 必要时做不可识别化处理；
- 不通过夸大“前后对比”制造功效承诺。

如果客户反馈只是工作记录，可以是普通内容；如果明确用于推动购买，则按商业触点计入当天商业密度。

---

## 八-A、案例证据资产｜成交以后继续记录真实结果

真实成交不只是一笔收入，也是后续判断产品适配、客户质量和商业信任的重要证据。对适合跟踪的服务 / 仪式项目，在客户自愿正常沟通的前提下，尽量形成去身份化的结果记录：

`开始前现实状态 → 客户目标 → 实际采用的方案 / 执行 → 后续客户主动或回访报告的具体变化 → 最终状态 → 是否复购 / 转介绍`

要求：
- 没变化、部分变化、达到目标都记录，不只保留成功案例；
- 客户没有反馈时写“暂无反馈”，不能补推结果；
- 客户报告的变化只能表述为“客户反馈 / 客户报告”，不能自动写成仪式已被证明造成该结果；
- 不编成功率、固定见效时间或百分百保证；
- 公开前必须去除可识别客户的信息，并遵守客户隐私与授权边界；
- 不为了制造案例而给没有真实需求的人推销服务，也不为了成功率只选择容易展示的结果。

### 案例的商业用途

案例可用于：
- 判断哪些需求 / 方案值得继续提供；
- 识别成交后的真实满意度、复购与转介绍；
- 在证据足够且适合公开时，作为低频社会证明或服务认知素材。

案例不足时，正确处理是继续积累真实订单与跟踪，不用更强话术、其它项目反馈或虚构结果填补证据缺口。

## 九、商业承接不得改变事实结论

为了成交不得：

- 把不确定的历史 / 原典写成确定事实；
- 把个人仪式、塔罗或咨询结果写成保证；
- 把尚未确认的产品状态写成现货 / 开放；
- 把普通预约制包装成稀缺抢购；
- 为了卖服务放大恐惧、风险或后果；
- 因商业需要降低 Suen 原有事实核查或择时标准。

内容结论先成立，商业连接只能建立在真实内容与真实产品状态之上。

## 十、每周复盘要检查商业密度是否失控

周复盘除看询盘和成交外，还要回看最近 7 天：

- 哪些平台出现过明显商业触点；
- 是否连续多天都在卖；
- 是否同一天多个平台重复同一销售信息；
- 哪些商业触点产生真实询盘 / 报价 / 成交；
- 哪些只是增加销售感但没有商业结果；
- 是否应该下一周降低或提高商业承接密度。

不按比例或条数凑销售内容，只比较真实回应与商业效果。

## 十一、执行优先级

遇到商业状态冲突时：

**Suen 最新明确指令 > GitHub 当前正式规则 + `08-动态运行/` 当前动态状态 > 历史内容 / 旧报价 / 旧对话。**

动态状态过期或不确定时，宁可写“待确认 / 当前不主动宣传”，也不从历史记录猜一个对成交更有利的答案。

## 十二、平台规则与交易入口

Suen 授权某日推广，只代表内部允许该商业信号；发布、商业合作 / 广告、店铺类目和具体交易渠道分别核查平台许可。仓库有价格、历史店铺咨询或私域成交，不代表平台已允许当前服务。

发布前先判断内容性质和动作：历史 / 宗教研究、现代传统介绍、服务说明、商业合作、广告投放、店铺商品与站外交易分别处理。历史研究不能笼统按付费占卜广告处理，研究栏目也不能夹带被禁止的功效承诺或交易。

截至 2026-10-08 核查，小红书聚光广告审核规则列明占卜、算命、改运、驱邪等迷信服务与改变命运 / 健康 / 情感 / 财富的超自然功效限制，并限制规避监管的站外引流。此证据直接适用于广告审核；自然内容、蒲公英合作、店铺及交易动作还要查各自规则，缺核查时商业动作保留待确认。参考：[聚光审核规则](https://ad.xiaohongshu.com/next_help/docs/8dc5bd9c45c9a90cb9912f3400d43f92)、[蒲公英审核说明](https://pgy.xiaohongshu.com/help/detail?id=6495c527d1eedeeb48fb18b1f875650e&userType=4)。

不使用谐音、隐蔽导流、虚假类目或“咨询 / 文化研究”改名来规避实际服务限制。不能完成当前渠道核查时，先保留有独立知识价值的研究内容，另行确认真实允许的承接方式；不把平台限制变成自动转私域的许可。

客户反馈只证明其报告了变化，匿名化 / 获授权也不能把它升级为功效因果证明。公开内容的资料结论、销售说明与付款前约定均须对应实际可履行范围。
