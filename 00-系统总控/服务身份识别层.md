# Suen｜服务身份识别层

状态：当前正式规则  
生效：2026-09-19
最后核对：2026-10-12

这层只解决一个问题：

**陌生人进入主页以后，能不能很快看懂 Suen 不只是做神秘学资料研究，也实际做判断、实践和服务。**

它不是新的前台栏目，不新增机械更新频率，也不要求为了服务认知建立一套新的高成本拍摄方式。

## 一、为什么需要单独一层

抖音大号的强项仍然是：

- 真实文物；
- 原始手稿 / 原页；
- 历史事件；
- 实践机制；
- 具体牌局判断。

这些内容很容易建立“资料很强 / 研究很深”的认知，但如果主页没有稳定的身份说明，陌生人未必自然知道：

- Suen 也做实际判断；
- Suen 也有仪式 / 星符等实践工作；
- Suen 可以做原典核查 / 专题研究；
- 有些需求会被拒绝、延期或要求先判断，不是任何问题都直接导向付费项目。

因此，服务认知由主页结构 + 现有栏目 + 其它平台共同完成，不依赖单一前台栏目。

## 二、主页识别结构

主页优先让陌生人看到三件事：

1. **Suen 研究什么**  
   文物、手稿、原典、历史神秘学。

2. **Suen 实际做什么**  
   塔罗判断、仪式 / 星符实践、原典核查 / 专题研究，以及真实工作过程。

3. **Suen 怎么判断是否要做**  
   不把每个问题都直接变成仪式或付费项目；根据真实情况、资料、牌局或择时条件决定。

这三件事由主页简介、置顶内容和日常内容共同完成，不要求每条视频都重复介绍。

## 三、置顶内容建议

长期至少保留一个“身份识别资产”。

它不是广告，也不是新的前台合集。

推荐主题：

**“这里平时到底在研究和做什么？”**

内容可以同时出现：

- 真实手稿 / 原页；
- 文物或资料工作；
- 实际塔罗桌面；
- 已经允许公开的仪式 / 星符准备画面；
- 原典核查或专题研究工作画面。

重点只讲清：

- 平时研究什么；
- 实际做什么；
- 哪些事情需要先判断 / 等择时；
- 当前开放项目以真实状态为准。

不在固定置顶视频里写容易过期的：

- 具体价格；
- 临时名额；
- 未确认天象日期；
- “最后机会”；
- 当前短期折扣。

动态预约状态继续由朋友圈、私聊和商业总控管理。

## 四、7 个大号栏目怎么承担服务认知

C｜服务认知是后台任务，可以附着在现有栏目，但不能覆盖栏目价值中心。

- **牌记**：让观众看到 Suen 真实怎么判断牌，不只会讲牌义。
- **隐理**：题目有可靠机制证据时，让观众同时理解实际实践为什么这样处理。
- **古术**：用有史料依据的历史做法体现研究与解释能力；历史治疗/保护记载不直接转为现代服务功效或购买承诺。
- **残页**：自然展示原典核查 / 专题研究能力。
- **辨伪**：自然展示来源核查和判断能力。
- **文物 / 异录**：主要继续承担对象、故事和专业识别，不为了服务认知硬插销售。

不要求每个栏目都承担服务认知，也不设置机械轮播比例。

## 五、纯服务原则放哪里

如果一个内容没有大号需要的视觉 / 证据主角，只是在讲：

- 什么需求会接 / 不接；
- 什么情况先不做仪式；
- 实际工作习惯；
- 当前在准备什么；
- 为什么某个项目要等日期；
- 个人经验和服务判断；

优先路由到：

- 抖音小号；
- 朋友圈；
- 适合的小红书实践 / 经验内容。

这样既保留真人与服务认知，又不改变大号原有的视觉和研究型人设。

## 六、大号和小号在身份识别中的分工

- **大号**负责证明“为什么值得相信 Suen”：资料、文物、原文、机制、判断。
- **小号**负责证明“这些不是纸上谈兵”：真实仪式、供奉、制作、工作现场、神明相关内容。
- **主页身份视频 / 简介**负责把两边明确连起来，让陌生人知道它们属于同一个 Suen，而不是两个完全无关的账号。

因此，不要求大号靠大量工作现场证明实践，也不要求小号继续承担完整资料讲解。

## 六点五｜高客单服务认知

当阶段目标是逐步提高定制仪式 / 星符等高价值服务的客单与客户质量时，服务身份识别不只让人知道“有这个服务”，还要让潜在客户提前理解：

1. **Suen 会先看具体情况，不是所有需求都直接套同一个项目；**
2. **客户购买目标仍然是希望推动现实变化，不把服务讲成只卖分析；**
3. **材料、原典、择时、执行方式为什么会改变具体方案；**
4. **效果、时间、反馈可以真实说明，但不靠百分百保证成交；**
5. **真实案例出现以后，重点展示客户原来的状态、实际执行与后来报告的具体变化，不只发一句“有效了”。**

这类内容优先放：
- 抖音小号：第一人称经验、真实工作流程、实际准备 / 判断；
- 小红书：现实问题 + 可收藏的判断 / 服务理解；
- 朋友圈：真实工作状态、客订、完成记录、真实反馈；
- 抖音大号：只有当题目本身有可证实的机制 / 原典 / 对象价值中心时才附着，不为了高客单硬改大号定位。

前台不使用“高客单客户”“转化率”“风险异议”“社会证明”等后台商业语言。

## 六点六｜高客单内容的公开门槛

高客单相关内容正式公开前，先做一个最简单的判断：

> **把“想让客户更容易购买”这个目的拿掉，这条内容本身还值得看吗？**

如果答案是“值得”，可以公开，例如：
- 真实材料选择；
- 星符制作条件；
- 择时为什么会改变执行；
- 一个具体关系状态为什么会改变判断；
- 已经发生并允许公开的真实案例过程。

如果答案是“不值得，只是为了回答成交异议”，优先留在私聊，例如：
- 为什么不能保证百分百；
- 为什么不能承诺固定天数；
- 为什么价格不是只看材料成本；
- 针对某一个客户的具体风险解释。

例外：
以后某个销售问题本身已经积累出足够真实数据、案例或普遍认知价值，可以重新升级为公开内容。

目的：
**公开内容先有内容价值，再附带服务认知；私聊负责完成真正的销售解释。**

## 六点七｜商业信任四类证据

高客单服务长期需要四种不同证据，不能只靠其中一种：

1. **知识 / 判断证据**
   - 原典、文物、资料、牌局、机制；
   - 证明 Suen 知道自己在做什么。

2. **执行证据**
   - 材料、制作、择时、准备、完成过程；
   - 证明不是只会讲理论。

3. **结果证据**
   - 客户允许公开的具体后续变化、复购、转介绍；
   - 当前定制仪式结果资产弱，就明确弱，不用其它项目冒充。

4. **人格 / 工作方式证据**
   - 什么时候会拒绝、延期、换方案；
   - 真实工作感想、研究习惯、判断变化；
   - 证明这是一个稳定、可信的人，不是一条广告。

总控看最近内容时，不机械规定比例，但如果连续一段时间明显只剩一种证据，应优先在下一次真实工作出现时补缺失层。

例如：
- 连续全是研究科普 → 下一次真实执行优先留下过程素材；
- 连续全是工作现场 → 需要补解释“为什么这样做”的专业层；
- 连续在讲服务逻辑但没有案例 → 停止继续解释，先积累真实案例；
- 有真实结果但一直没有公开 → 在客户允许的情况下整理成去身份化案例资产。

## 七、商业边界

“让人知道 Suen 是做什么的”不等于每天卖东西。

身份识别层可以长期存在，但明显商业 CTA 继续服从当天商业总控：

- 价格；
- 预约；
- 购买；
- 名额；
- 具体天象窗口；
- 私信引导。

没有当天商业授权时，服务身份只做到“看得懂你会做什么”，不继续推进成交。

## 八、总控检查

总控做周复盘时额外检查：

**一个第一次进入主页的人，能不能在不翻很多条内容的情况下看懂：Suen 研究什么、实际做什么、怎么判断。**

如果答案是否定的，优先修：

- 主页简介；
- 置顶内容；
- 代表性内容排序；
- 一个已有栏目的 C｜服务认知任务；

不要第一反应新增栏目。
