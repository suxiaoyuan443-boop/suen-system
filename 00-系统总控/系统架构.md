# Suen System｜系统架构

状态：正式结构文件
最后更新：2026-09-17

## 1. GitHub

负责长期稳定规则、模板、自动化配置与版本历史。

原则：
- 一个主题只维护一个当前正式文件。
- 规则发生重要变化时更新文件，并在根目录 `CHANGELOG.md` 留记录。
- 不保存客户隐私、密码、Token、API Key 等敏感信息。

## 2. Slack

负责正在发生的运营与执行数据，例如：
- 商业总控
- 客户商业记录
- 天象预约池
- 内容数据与复盘
- 当日状态与下一步

Slack 中的日常流水不必全部复制进 GitHub；只有形成长期制度后才迁移。

## 3. Drive / Library

负责大体积文件与成品：
- PDF
- DOCX
- 图片
- 视频
- HTML
- 课程母本
- 研究资料

GitHub 仅保存这些文件的规则、索引或必要说明，不作为大文件主仓库。

## 4. ChatGPT

负责读取规则、执行分析、整理版本、跨系统调用与更新。

执行长期任务前，应优先读取对应 GitHub 正式规则；涉及当日经营状态时，再读取 Slack 最新数据。

## 5. 迁移规则

旧对话、Slack 消息、记忆摘要里的内容都可能存在历史版本。迁移到 GitHub 前必须：
1. 确认当前仍有效。
2. 去除互相冲突或重复的旧规则。
3. 写入唯一正式文件。
4. 标注最后更新时间。

完成迁移后，该 GitHub 文件成为该主题的长期规则真源。
