# Suen｜系统架构

状态：当前正式架构
最后核对：2026-09-20

## 一、时间基准

内容运营、动态台账、“今天 / 昨天 / 明天”默认使用 Asia/Shanghai（UTC+8）。

## 二、GitHub 双层结构

### 规则层
保存长期规则：商业总控、栏目、平台、指标、实验、对标、销售、模板。

### 动态层
`08-动态运行/` 保存当前经营状态与月度事实：

- `00-当前总览.md`
- `内容台账/当前状态.md`
- `选题池/当前选题池.md`
- `商业/当前商业状态.md`
- `天象/当前预约池.md`

## 三、历史层

- 月度文件保存已经发生的事实；
- Git commit 保存每次修改；
- `08-动态运行/历史/` 保存迁移来源与旧系统归档；
- 历史不能覆盖当前状态。

## 四、真源优先级

**Suen 当前明确指令 > GitHub 当前正式规则 + GitHub 当前动态文件 > 月度历史 / Git commit / 旧对话 / 记忆。**

规则负责“应该怎么做”，当前动态负责“现在是什么”。

## 五、正常读取原则

普通任务先读：
1. 启动索引；
2. 商业目标；
3. 当前总览；
4. 当前任务需要的动态文件；
5. 当前任务需要的正式规则。

不默认加载迁移档案或全部历史。

## 六、动态事实路由

- 已发布 / 数据 → 内容台账
- 候选题 / 冷却 → 选题池
- 询盘 / 报价 / 成交 / 当前瓶颈 → 商业
- 已筛选天象经营状态 → 天象预约池

## 七、Slack

Slack 自 2026-09-20 起退出正式真源。
旧 Slack 四频道内容已迁入 `08-动态运行/历史/2026-09/`。

正常工作不要求读取 Slack；只有核查迁移遗漏时才回看。
