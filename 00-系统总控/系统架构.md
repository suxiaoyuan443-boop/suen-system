# Suen System｜系统架构

状态：当前正式结构  
最后核对：2026-09-19

## 1. 运营时区

内容运营、Slack 台账、“今天 / 昨天 / 明天”默认使用 **Asia/Shanghai（UTC+8）**。

天象技术地点和时区仍由专用择时系统负责。

## 2. 四层结构

### GitHub 运营区

保存长期运营规则：商业总控、平台、指标、实验、对标、销售、Slack、模板。

### Slack

保存动态经营状态：

- `#内容历史台账`：实际发布与复盘事实；
- `#商业决策总控`：当前瓶颈、任务、询盘、成交、产品推进、经营决定；
- `#天象检索与预约`：已经筛选过的天象经营状态。

### Rule Vault / 外部知识资产

- `Suenakhet Database Rules/`：数据库长期写作 / 验收规则。
- Obsidian：数据库内容本体。
- Library / Drive：研究资料、课程母本、大文件。
- 专用择时系统：完整技术推导。

### ChatGPT / Work

负责读取对应真源、执行任务、产出成品；不靠旧记忆冒充当前规则。

## 3. 商业总控启动

新商业总控对话只固定读取：

- `00-系统总控/总控启动索引.md`
- `00-系统总控/商业目标与产品优先级.md`
- Slack 三个动态频道

随后按索引路由按需读取。

不默认加载全部平台、文笔、实验、对标、数据库规则。

## 4. 任务路由

- 今日调度 / 瓶颈 → 商业总控 + 每日工作流
- 新前台选题 → 内容地图 + 对标 + 选题硬门槛
- 价格 / 预约 / 商业 CTA → 商业信号规则 + Slack
- 询盘 / 成交 / 利润 → 商业指标口径 + Slack
- 制作成本 → 生产投入产出规则
- 低流量 / 重发 / 实验 → 内容实验规则
- 发布时间 → 发布时间实验规则
- 正式成稿 → 平台 / 栏目规则 + `Suen统一文笔总则.md` + 对应交付规则
- Patreon → `06-Patreon/`
- 数据库写作 → Database Rule Vault + Obsidian 当前页面
- 完整择时 → 专用择时系统

完整路由以 `总控启动索引.md` 为入口。

## 5. 动态状态

以下不能从旧 GitHub 文本或历史聊天自动沿用：

- 今日主推 / 今日纯内容 / 今日明确不推；
- 价格、折扣、排期、容量；
- 预约状态；
- 天象窗口当前是否允许宣传；
- 询盘、报价、成交；
- 内容是否真的已经发布。

跨日重新读取 Slack。

## 6. 冲突顺序

**Suen 最新明确指令 > 当前仍有效的 Slack 状态 / 当日决定 > GitHub 当前正式规则 > 历史记录。**

## 7. 独立项目

上海省钱情报局等独立项目不进入本神秘学商业总控的数据、产品和商业信号。

## 8. 核心原则

**静态规则按需读，动态状态每次核实；独立系统互相隔离。**
