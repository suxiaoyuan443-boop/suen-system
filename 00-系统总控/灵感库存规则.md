# Suen｜轻量灵感库存规则

状态：当前正式规则  
生效：2026-09-25

## 一、定位

轻量灵感库存只解决一件事：**避免值得以后研究的对象、问题或来源线索被忘掉。**

它不是选题池，不是动态真源，不参与每日优先级排序。

## 二、允许保存什么

每条最多保留：
- 对象 / 问题；
- 1—3条来源线索；
- 为什么当时觉得值得以后查。

不要求提前完成研究。

## 三、禁止保存什么

灵感库存不保存：
- P0 / P1 / P2；
- 高优先 / 冷却 / 已转定题；
- 固定平台归属；
- 固定栏目归属；
- benchmark完整验收；
- 14账号撞题结论；
- “已通过硬门槛”；
- 生产排期；
- 因为已经投入研究而形成的优先权。

## 四、每日定题关系

Suen 说“更新 / 今天发什么 / 定题”时，不要求先读灵感库存。

每天重新根据：
**第一方数据 + 最近7天真实发布 + 当前商业状态 + 当天制作条件 + 当前真实研究 / 工作素材**
现场生成少量候选，再做当天必要的栏目、证据、重复、素材和平台适配检查。

如果某条灵感被拿出来使用，它只是一条原始线索，必须按当天状态重新判断。

## 五、停止救题

某题连续出现栏目、范围、证据或成片形态问题时，允许直接取消。

已经研究过、写过一半、找过图或投入过时间，都不能成为继续做它的理由。
不得为了回收投入成本，默认把失败短视频改成其它栏目、长卷、公众号或其它平台内容。

## 六、历史

旧“选题池”文件删除后仍由 Git commit 和历史归档保留，需要复盘时再查。
不把旧候选自动迁入当前灵感库存。
