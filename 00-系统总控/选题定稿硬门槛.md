# Suen｜选题定稿硬门槛

状态：当前正式规则  
最后核对：2026-10-12

本文件只解决一件事：**一个候选题什么时候可以升级为正式题。**

适用于抖音大号，以及其它平台承担A/B/C/D任务的新前台选题；纯履约通知与已确定的客户动作按实际职责验收，不强套A类流量评分。视频素材与成片门按视频交付规则执行，文字/照片内容按对应平台交付规则执行。

未通过只能写：

`候选题｜待筛选`

## 一、定题顺序

### 0. 先明确任务，再判断入口

A 流量使用下方陌生人入口、无聊风险与 100 分比较。B 精准、C 服务认知、D 商业动作共用真实性、证据、素材、原创性、实际可售和平台门槛，但按各自职责验收：

- B：具体目标受众能否识别自己的问题，内容是否提供有依据的判断；
- C：是否讲清适用对象、判断依据、服务过程或可检查交付，减少一个真实购买疑问；
- D：价格 / 排期 / 范围 / 付款前事项与平台权限是否明确，下一步动作是否实际可用。

B / C / D 不要求奇异器物、答案反差或 A 类 80 分，也不据此降低资料与文笔标准。

以获客或服务理解为主要任务时，按《内容商业对标系统》二-B核目标对象、具体购买疑问、可展示信任依据和当前业务关系。C至少能用具体资料/判断/工作细节减少一个真实或明确待验证的服务理解问题；只展示研究水平、气氛或成品好看，不能自动通过C职责。D另核当前范围、价格/排期与实际可用的下一步。

选题通过只表示具备生产依据，不表示已获客。有没有实际有效询盘、合格机会或付款，回实验规则四-A与机会漏斗认定。A/B内容也可以有可靠归因的商业结果，保留原主任务，不事后改写实验目的。

任何平台都可承担相应任务，仍服从自身定位。七栏目测试只适用于进入七栏目的内容，纯工作记录/服务表达按内容地图及对应平台规则判断，不新开“获客”栏目、不为销售强改栏目。

### 0-A. A 类候选生成先过“陌生人入口”

先按 `内容商业对标系统.md` 二-A完成全账号强样本与对标高表现题材检视，再从真实对象、问题、材料或现实工作中寻找**普通陌生人愿意停下来理解的入口**；入口筛选在重型原典研究、成片制作与100分比较前完成，不能把“入口先行”理解为跳过数据来源。

候选至少先回答三个问题：

1. **我完全不知道 Suen 是谁，只看到第一屏，能不能马上知道在讲什么？**
2. **看到以后，会不会自然产生一个具体问题、反常感、纠偏欲望或结果好奇？**
3. **答案出来以后，是否存在明显的认知落差：原来如此，但直觉不会直接想到？**

候选入口可来自四类：
- **认知缺口**：见过但不知道是什么；
- **反常机制**：知道是什么，却不知道为什么这样做；
- **认知纠偏**：以为自己知道，实际判断与证据有差异；
- **具体后果**：一个动作、判断或结果会带来明确的现实 / 历史后果。

这四类只是**候选生成层**，不是新栏目，也不新增 KPI。

如果三个问题中无法形成清楚答案，不急着靠专业资料、栏目、benchmark或标题技巧把它救活；先与其它候选比较。

**这里判断的是“值不值得让陌生人停下来”，不是“专业价值够不够”。**


### 0-B. 实时热点候选层｜2026-10-08

当某个话题正在抖音 / 小红书 / 微博 / 新闻与搜索层明显升温时，可以把它作为**候选生成加速器**，但热点本身不等于正式选题。

热点候选必须先回答：

1. **这个热点和 Suen 的内容能力是否真的有关？**
   - 能否落到七栏目之一；
   - Suen 是否能拿出原典、手稿、文物、历史资料、占星文本、牌面判断或可靠研究，而不是只重复大众说法。

2. **Suen 能新增什么？**
   合格新增价值包括：
   - 辨伪：当前流行说法到底对不对；
   - 原文：传统文本真正怎么写；
   - 机制：为什么传统会这样判断；
   - 历史：这个说法从哪里来的；
   - 实务判断：什么条件下才成立，而不是一句泛运势。

3. **热点去掉以后，内容本身还成立吗？**
   - 热点只负责提高入口熟悉度；
   - 正文仍必须有独立知识价值；
   - 不能靠“大家都在聊”代替证据、故事或机制。

4. **时间价值还剩多少？**
   - 强时效热点优先在 24—72 小时内判断；
   - 已进入一周以上的持续热点仍可做，但必须确认不是热度已经明显退潮；
   - 如果研究 / 找图成本导致发布时热点大概率已过去，降低优先级。

5. **不因热点降低任何原有硬门槛。**
   仍必须通过：
   - 无聊风险；
   - 七栏目路由；
   - 证据范围；
   - 自有内容重复；
   - 素材覆盖；
   - 平台适配；
   - 文笔 / 成片 QA。

热点可以给候选增加当前大众入口优势；正式使用前核对来源、时点与适用范围。话题存在、热度强弱、传统解释和现实结果分别判断，不由其中一层代替其余。

原始图数量、有效焦点与实际呈现按 `99-模板/视频类统一交付格式.md` 分开验收，不因素材清单满数就判成片通过。

### 0.5 无聊淘汰门｜A类候选必须先过

“有意思”不等于“值得占当天唯一主发布位”。

A｜流量候选在进入栏目、benchmark和100分模型以前，先判断一次**无聊风险**。这一步不看资料价值，只看普通人是否真的会继续看。

固定检查：

1. **一句话讲完以后，陌生人会不会自然追问下一句？**
   - 合格反应更接近：“然后呢？”“为什么会这样？”“真的假的，后面发生什么了？”
   - 仅仅是“哦，挺有意思”“原来还有这个”不够。

2. **题眼是不是一层就消费完？**
   - 如果最怪、最冲突、最反常的事实在前3—5秒已经全部说完，后面只能补背景、年代、定义或资料说明，默认高无聊风险；
   - A类候选最好至少还能继续出现2—3次新的事实、转折、对象变化、证据升级或判断变化。

3. **有没有人类利害 / 欲望 / 冲突 / 后果？**
   可来自：
   - 钱、爱情、身体、死亡、骗局、惩罚、名誉、权力、犯罪、失败、欺骗、争夺、危险；
   - 或者对象本身强到一眼就值得看。
   单纯“冷知识”“历史上有过”“这个术语原来这样”默认不够。

4. **把专业标签拿掉以后还想不想看？**
   暂时删掉“魔法、神秘学、塔罗、PGM、古埃及、阿格里帕”等标签。
   如果剩下的事情本身就不值得知道，不能靠专业身份把它救成A类。

5. **标题不救题。**
   如果一个候选必须依赖“真相 / 居然 / 竟然 / 你不知道 / 背后”等运营词才显得有劲，默认换题，而不是继续包装。

### 无聊风险判定

- **低风险**：题眼本身强，而且正文天然还有连续推进；
- **中风险**：第一眼成立，但后面容易变成说明书 / 背景课；需要先验证中段还能不能持续给新信息；
- **高风险**：主要价值只有“资料正确 / 对象少见 / 学术上有趣 / 有一条原文”，普通人没有持续追问动力。

A｜流量P0原则上只从**低风险**候选中选。

中风险候选只有在当天没有更强低风险候选，且能够明确写出后续至少2—3个新的推进点时，才允许继续进入后续硬门槛。

高风险候选不靠标题、剪辑或benchmark救活；可改做B｜精准、公众号、长文、课程边角或直接淘汰。


### 1. 先读动态状态

读取 GitHub 当前动态真源（内容台账 / 商业状态 / 天象预约池），确认：

- 当前主要瓶颈；
- 最近实际发布内容；
- 当前商业 / 天象状态。

### 2. 先看与主任务相应的第一方依据

A/B/研究题读取 `内容商业对标系统.md` 二-A；C/D读取二-B及对应真实询盘、交付、服务约定和现有反馈，不以传播头部替代购买问题证据。新的流量、精准关注或研究前台题，必须实际检查各账号历史强样本与最新数据，并把具体对标高表现题材作为候选输入；不能只检查近期重复或已有草稿。按同一真源保留候选来源依据，缺数据时明确降级。

确认：

- 相关第一方结构现在是单样本 / 重复信号 / 稳定结构中的哪一档；
- 当前主页已经被什么内容体验占据；
- 最近 7 天有没有明显重复。

这里的“最近 7 天重复”必须按**整个 Suen 内容系统**检查，不只看准备发布的那个账号。至少同时扫：

- 抖音大号；
- 抖音小号；
- 小红书；
- 最近实际发布的公众号 / 朋友圈（如果主题高度相关）。

重复不只看标题，还要看：

- 同一个核心问题词；
- 同一个现实判断场景；
- 同一个 Hook；
- 同一个答案中心；
- 只是换账号 / 换栏目后继续讲同一件事。

例如：小号刚发过“我对不顺的看法”，大号短期内再用“最近一直不顺，要不要净化？”作为主入口，默认按相邻体验重复处理，除非这次明确是有价值的后续、商业承接或新证据补充。

**同一支成片按计划同步到小红书，不算重复选题。** 这是一个生产单元的跨平台分发，不是两个独立新题。

如果确实要重复同一主题，必须能说清新价值：新对象、新证据、新判断任务或明确商业承接，而不是只换措辞。

低样本账号如果某一栏目 / 体验已经占多数，至少筛出 **1 个其它内容体验的合格候选**进行比较；最终仍选主导类型可以，但要有真实理由。

### 2.5 成片形态预演｜先看“做出来会像什么”

以下针对视频及需要进入七栏目的内容；独立工作图文按平台规则检验实际表达与具体价值。在正式栏目路由和评分前，必须先做一次极短的**成片形态预演**，不能只看标题像不像某个栏目。

至少写清：
- 前5秒观众看到 / 听到什么；
- 中段主要靠什么推进；
- 证据是主角还是只是支撑；
- 观众看完最应该记住什么。

然后做七栏目反向删除测试：

- 删掉具体对象，内容基本不成立，且对象的结构 / 用法 / 细节是核心 → 《文物》；
- 删掉人物、事件推进、时间线，故事失去主要价值 → 《异录》；
- 拿掉明确“对 / 错”判定，内容核心就不存在，而且证据足以稳定二分 → 《辨伪》；
- 删掉当前具体原文 / 行号 / 词句 / 版本问题，整条基本塌掉 → 《残页》；
- 删掉任何单一案例后问题仍成立，多个材料只是共同证明机制答案 → 《隐理》；
- 删掉这副具体牌、牌位、正逆位、周围牌以后判断就不成立 → 《牌记》。
- 删掉具体目的、参与者、操作与实践环境后，核心做法解释失去主要价值 → 《古术》；不能只有一个怪点或步骤目录。

七个栏目一律按**成片实际推进方式**判断，不按题目字面、素材类型或总控预设标签判断。

**标题里写“为什么”不等于《隐理》。**
**证据里用了原文也不等于《残页》。**
最终看成片实际由什么推进。

如果预演结果显示成片会被另一个栏目的主角牵着走——例如文物变成机制课、异录变成知识讲解、辨伪只能回答“看情况”、残页变成泛机制、隐理被单一原典牵走、牌记变成通用牌义课——必须在P0前改题、改栏目或换候选，不能等成片做完才发现路由错。

### 3. 栏目路由

读取：

`01-抖音大号/栏目选题边界与路由.md`

按题目的**价值中心**路由，不先定栏目再硬改题。

### 4. 外部对标

A/B/研究题使用二-A的对标高表现题材路径；C/D按二-B使用相关对标表达参照，不要求外部播放证明获客，原创性仍须核对。长期 benchmark 方法参与判断；优先读取已有年度库与近期层，只有当前决策被缺口或明确新发布变化阻塞时定向补样本，不强制每天刷新 2—3 条。

**A/B/研究任务的benchmark在候选生成前提供有数据支持的题材、对象和核心问题，在定稿阶段再校准标题与表达。** 执行 `内容商业对标系统.md` 二-A；候选的自有 / 对标参照与Suen新增价值必须可核，不能只填一个账号名。外部高播放不替代栏目、原典与素材门槛。

无法可靠取得就明确降级，不编造。

### 5. A 类 100 分比较模型

100 分模型只比较 A 类已通过入口初筛的候选，是流量取舍的启发工具。它不预测付款概率，不替代实际数据；B / C / D 按任务入口的职责验收。

其中“陌生人理解速度、视觉奇异度、答案反差”继续承担前台比较；证据强度、Suen差异化、精准受众价值、商业桥接与制作效率用于决定多个合格候选之间的实际取舍。

正向评分：

- 陌生人理解速度：20
- 视觉奇异度：15
- 答案反差：15
- 证据强度：15
- Suen 差异化：10
- 精准受众价值：10
- 商业桥接：5
- 制作效率：10

制作效率看：

- 历史耗时；
- 素材是否现成；
- 是否能抖音 + 小红书复用；
- 返工风险；
- 是否能沉淀长期资产。

扣分 / 淘汰：

- 最近相邻题材 / 观看体验明显重复：-20（按整个内容系统检查；换账号 / 换栏目不自动消除重复）
- 需要大量背景解释：-10
- 标题专业但普通人不知道在讲什么：-20
- Hook 很猛但正文答案空：-20
- 与付费课程核心教学链高度重合：谨慎，必要时换角度或淘汰
- AI 伪史、AI 假文物、AI 假实景、核心事实无法核实：直接淘汰

分数使用：

- 80+：强前台 / 流量候选
- 70—79：结合当天瓶颈判断
- 60—69：更适合精准 / 窄题材
- <60：通常不占大号当天唯一主发布位

分数不能覆盖栏目资格、证据可答性、主页结构和当天真实瓶颈。



### 视觉异常后验门｜2026-09-27新增

当候选把“具体异常对象 / 一眼奇怪的东西”作为冷流量入口时，评分前额外做一次**裸图1秒测试**：

> 暂时遮掉标题、字幕、口播解释和知识背景，只看计划用于第一屏的真实对象约1秒。普通陌生人能否直接看出对象本身或对象关系存在异常？

执行：
- 若必须先解释“它代表什么 / 这是什么形状 / 为什么这在历史上特殊”，才能感到奇怪，则**不能按高视觉奇异度评分**；
- “学术上罕见 / 象征意义特殊 / 历史上重要”不能替代第一眼视觉异常；
- 若第一屏异常主要来自文字问题而非对象本身，应明确按“问题入口”评估，不能同时把对象视觉奇异度打高；
- 该测试只修正候选评分与前台入口判断，不要求所有好内容都必须视觉异常，也不自动淘汰资料价值高但视觉入口弱的题；这类题可根据平台职责转向精准内容、公众号或其它合适产品。

来源后验：2026-09-26《这个古埃及护符为什么做成一个结？》。该条抖音2秒跳出33.17%但5秒完播31.64%、平均观看7秒、完播1.65%；说明具体问题获得第一停留并不等于对象本身具备足够强的一眼视觉异常。当前为**单样本规则修正**，不升级为稳定内容公式。

### 5.5 题目范围匹配

在证据检查前确认：

- 标题范围不能大于证据范围；
- “有些 / 通常 / 这类 / 为什么会”这类泛化表述必须有对应范围的材料支撑；
- 当前只有单一作者 / 单一文本时，优先缩到该作者 / 体系 / recipe，不允许为了入口更宽而扩大结论；
- 《隐理》若主要依赖一个具体文本，必须再次做栏目复核。

### 6. 证据与素材

下列完整成片视觉路径要求用于视频；文字/照片工作内容检查其具体事实、实际图片与平台交付，不机械要求六个视频视觉单元。正式定题前必须确认：

- 核心答案能被可靠资料正面支持；
- 标题没有承诺超过证据；
- 真实图片 / 原页 / 文物 / 历史画面可取得；
- **不只确认“至少有一张图”，还要确认存在足以扩展成完整成片的视觉供给路径**：主对象之外至少能继续取得局部、同组物、不同角度、原页具体位置、版本、档案、历史图版或其它真实视觉中的若干项；
- 如果当前只能确认 1—2 张可用图，且没有合理的视觉扩展路径，素材门不得标“通过”，最多记为“素材待补”；
- 不依赖 AI 假史料；
- 制作复杂度与当天 P0 工作量匹配。

**正式口播完成以后还必须再过一次成片级素材覆盖 QA。** 定题阶段的素材门只证明“有可完成的视觉路径”，不能提前替代口播后的配图验收。具体读取 `99-模板/视频类统一交付格式.md` 的“画面脚本与素材覆盖硬门”。

### 7. 商业边界

如果题目涉及产品 / 服务，读取当前商业信号规则和 `08-动态运行/商业/当前商业状态.md`。

内容先成立，再决定今天是否需要商业桥。

### 8. 发布前验证

新的正式前台内容原则上只写 **1 个主要验证假设**。

读取：

`内容实验与验证规则.md`

至少写：

```text
主要验证：
主任务：A / B / C / D
主要观察指标：
对照基线：最近最可比样本 / 无可靠可比样本
```

时效通知、已确认商业动作或稳定结构复用可以写：

`无新增实验｜执行稳定结构`

### 9. 可选｜定题后的塔罗流量盲测

只有题目已经通过前面 1—8 的数据、对标、栏目、证据、素材与商业硬门槛以后，才可以进入塔罗测试。

固定顺序：

**理性定题 → 锁定题目 / 平台 / 基线 → 抽牌 → 发布前锁定判断 → 发布 → 真实数据后验。**

完整协议读取：

`Tarot Judgment Rules/16-内容流量盲测与后验.md`

硬边界：
- 塔罗不参与前面的候选生成和证据筛选；
- 牌面不能把未通过硬门槛的题“救活”；
- 牌面不能覆盖事实、平台合规、版权、栏目资格或真实商业状态；
- 如有多个同样通过硬门槛的高质量候选，可把塔罗作为附加比较 / 盲测层，但必须保留原始内容数据判断；
- 发布以后必须按事前定义的统计窗口验收，不允许看结果再改“什么叫爆”。

## 一-A、候选停止机制｜防止沉没成本继续吞生产时间

候选题进入研究后，总控不仅判断“能不能继续”，也必须判断“现在是否应该停止”。

### 立即停止 / 换题

出现以下任一情况，不因为已经投入研究时间而继续救题：
- 核心事实或原典证据无法支撑标题；
- 必须扩大证据范围、改变事实状态或虚构实践才能成立；
- 栏目价值中心持续漂移，换栏目也只是为了消化旧研究；
- 真实图片 / 原页等核心素材无法取得，且素材是题目成立条件；
- 涉及未发生的采购 / 制作 / 执行，只有包装成“已经在做”才有内容张力；
- 公开后会泄露采购成本、供应链、内部利润或其它默认保密信息；
- 与最近内容高度重复且没有新价值；
- 继续研究的预期价值已经明显低于当天其它合格候选或课程 / Database 等更高价值任务。

### 研究时间检查点

对于普通短视频 / 图文候选，连续研究约 30—45 分钟后仍无法形成以下四项，应主动停一次并重新比较候选，而不是默认继续深挖：
1. 普通人能理解的明确问题；
2. 足以支持答案的可靠证据；
3. 正确的平台 / 栏目价值中心；
4. 当天可完成的素材与生产路径。

30—45 分钟是**检查点，不是机械淘汰时限**。如果题目已经明确通过关键门槛，只是资料本身需要更长读取，可以继续；如果仍在反复寻找“怎么把它变成内容”，默认换题。

### 已投入研究不形成优先权

旧题、旧草稿、已经查过的资料、已经做过的截图或脚本，都不因沉没成本自动获得次日优先级，也不自动转移到小红书、《长卷》、公众号或其它栏目。未来只有在新的当天判断中独立通过，才可重新启用。
