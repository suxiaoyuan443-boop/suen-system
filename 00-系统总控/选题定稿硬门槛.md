# Suen｜选题定稿硬门槛

状态：当前正式规则  
最后核对：2026-09-19

本文件只解决一件事：**一个候选题什么时候可以升级为正式题。**

适用于抖音大号，以及当天承担主要流量 / 精准涨粉任务的小红书、公众号前台题。

未通过只能写：

`候选题｜待筛选`

## 一、定题顺序

### 1. 先读动态状态

读取 Slack 三个核心频道，确认：

- 当前主要瓶颈；
- 最近实际发布内容；
- 当前商业 / 天象状态。

### 2. 先看自己的数据

读取 `内容商业对标系统.md`。

确认：

- 相关第一方结构现在是单样本 / 重复信号 / 稳定结构中的哪一档；
- 当前主页已经被什么内容体验占据；
- 最近 7 天有没有明显重复。

低样本账号如果某一栏目 / 体验已经占多数，至少筛出 **1 个其它内容体验的合格候选**进行比较；最终仍选主导类型可以，但要有真实理由。

### 3. 栏目路由

读取：

`01-抖音大号/栏目选题边界与路由.md`

按题目的**价值中心**路由，不先定栏目再硬改题。

### 4. 外部对标

长期 benchmark 方法参与判断；当天第一次定新前台题时实际刷新最相关 2—3 个近期样本。

无法可靠取得就明确降级，不编造。

### 5. 100 分模型

正向评分：

- 陌生人理解速度：20
- 视觉奇异度：15
- 答案反差：15
- 证据强度：15
- Suen 差异化：10
- 精准受众价值：10
- 商业桥接：5
- 制作效率：10

制作效率看：

- 历史耗时；
- 素材是否现成；
- 是否能抖音 + 小红书复用；
- 返工风险；
- 是否能沉淀长期资产。

扣分 / 淘汰：

- 最近相邻题材 / 观看体验明显重复：-20
- 需要大量背景解释：-10
- 标题专业但普通人不知道在讲什么：-20
- Hook 很猛但正文答案空：-20
- 与付费课程核心教学链高度重合：谨慎，必要时换角度或淘汰
- AI 伪史、AI 假文物、AI 假实景、核心事实无法核实：直接淘汰

分数使用：

- 80+：强前台 / 流量候选
- 70—79：结合当天瓶颈判断
- 60—69：更适合精准 / 窄题材
- <60：通常不占大号当天唯一主发布位

分数不能覆盖栏目资格、证据可答性、主页结构和当天真实瓶颈。

### 6. 证据与素材

正式定题前必须确认：

- 核心答案能被可靠资料正面支持；
- 标题没有承诺超过证据；
- 真实图片 / 原页 / 文物 / 历史画面可取得；
- 不依赖 AI 假史料；
- 制作复杂度与当天 P0 工作量匹配。

### 7. 商业边界

如果题目涉及产品 / 服务，读取当前商业信号规则和 Slack。

内容先成立，再决定今天是否需要商业桥。

### 8. 发布前验证

新的正式前台内容原则上只写 **1 个主要验证假设**。

读取：

`内容实验与验证规则.md`

至少写：

```text
主要验证：
主任务：A / B / C / D
主要观察指标：
对照基线：最近最可比样本 / 无可靠可比样本
```

时效通知、已确认商业动作或稳定结构复用可以写：

`无新增实验｜执行稳定结构`

## 二、最终通过条件

以下全部成立才进入正式生产：

- [ ] Slack 最新动态已读取
- [ ] 当前瓶颈已判断
- [ ] 第一方历史信号已检查
- [ ] 当前主页 / 近 7 天重复已检查
- [ ] 低样本账号需要时做过跨体验候选比较
- [ ] 栏目路由正确
- [ ] 长期 benchmark + 当日近期样本已完成或明确降级
- [ ] 100 分模型已检查
- [ ] 核心答案证据成立
- [ ] 真实素材可取得
- [ ] 商业边界真实
- [ ] P0 工作量可完成
- [ ] 主要验证假设已写或明确无新增实验

通过后只需对 Suen 显示：

`选题状态：已通过硬门槛`

不默认展示完整评分表。

## 三、通过后进入生产保护

确定：

- 栏目 / 内容产品
- 题目
- 核心问题
- A / B / C / D
- 商业边界
- 主要验证

以后进入生产保护。

只有核心事实 / 证据、栏目路由、商业 / 天象 / 法律硬边界、Suen 新补充的真实账号结构或 Suen 最新指令发生变化时，才退回重新定题。

普通文笔、图片、链接、排版、素材匹配由专用对话自行修。
