# Suen｜选题定稿硬门槛

状态：当前正式规则
最后核对：2026-09-17

本文件解决一个执行问题：**总控不得因为“已经想到一个看起来不错的题”就直接把它写成最终选题。**

从现在开始，所有抖音大号正式选题，以及承担当天主要流量/精准涨粉任务的小红书、公众号前台题，在被写成“最终选题 / 今日正式题目”以前，必须完成下面的硬门槛。

如果任何必检项没有完成，这个题只能写成：

> 候选题｜待筛选

不得：

- 写成“最终题目”；
- 生成正式专用对话执行提示词；
- 写入 Slack 当日执行表作为已定题目；
- 因为当天赶时间就跳过检查。

---

## 一、先确认栏目路由

先读取：

`01-抖音大号/栏目选题边界与路由.md`

确认题目的价值中心确实属于当天栏目。

禁止先决定栏目，再把题目硬改成该栏目形式。

例如《隐理》必须额外通过：

1. 去掉具体文物 / 人物 / 单条 recipe 后，问题仍然成立；
2. 标题里的“为什么”能够被现有证据真正回答成“因为 Y”；
3. 文物、原文和案例只负责证明答案，不代替答案。

---

## 二、对标账号检查｜五项必须逐一过

读取：

`00-系统总控/内容商业对标系统.md`

每个候选题必须逐项经过以下五个已确认对标方法。

### 1. 穹印之源｜中文入口

检查：

- 中文普通观众第一眼能不能懂题目；
- 标题是不是具体问题，而不是论文式概念；
- 硬核资料有没有被包装成一个有吸引力、但不夸大的入口。

### 2. ESOTERICA / Justin Sledge｜证据与学术组织

检查：

- 有没有真正能支撑核心答案的原典、手稿、文物或可靠研究；
- 历史事实、文本内容、学者解释和争议有没有混在一起；
- 资料密度高时，能不能仍然让普通观众跟上。

### 3. Angela’s Symposium / Angela Puca｜source-based 品牌

检查：

- 这条是否强化 Suen 的“真实资料 + 研究解释”识别；
- 是否以来源为基础，而不是用现代 occult 常识代替历史证据；
- 是否有长期精准受众价值。

### 4. Foolish Fish｜商业连接

检查：

- 如果当天需要商业承接，连接是否自然；
- 如果当天是纯内容，是否明确保持纯内容，不为了“有商业价值”硬加 CTA；
- 题目本身是否仍然先成立为内容，而不是广告包装。

### 5. Let’s Talk Religion｜复杂问题的大众化解释

检查：

- 能不能从一个具体问题进入复杂历史 / 宗教 / 仪式背景；
- 是否需要大量前置知识才能听懂；
- 专业术语是否被解释，而不是拿术语密度代替解释能力。

### 对标检查的输出要求

总控内部至少要形成一句可复核判断：

- 穹印之源：通过 / 不通过 + 原因
- ESOTERICA：通过 / 不通过 + 原因
- Angela Puca：通过 / 不通过 + 原因
- Foolish Fish：通过 / 不通过 + 原因
- Let’s Talk Religion：通过 / 不通过 + 原因

**任何一个关键维度明显不通过时，先改题 / 改入口 / 改结构，再进入下一步。**

不要求模仿对标账号的人格、文风、结论或具体选题。

---

## 三、Suen 100 分模型

完成对标检查后，再按 `商业总控.md` 的 Suen 100 分模型评分。

必须检查：

- 陌生人理解速度；
- 视觉奇异度；
- 答案反差；
- 证据强度；
- Suen 差异化；
- 精准受众价值；
- 商业桥接；
- 制作效率；
- 最近 7 天相邻题材 / 观看体验重复扣分。

分数不能代替栏目资格和对标检查。

一个题即使 80+，如果栏目路由错误或核心“为什么”答不出来，也不能定稿。

---

## 四、近 7 天重复与当天瓶颈

必须回看 `#内容历史台账` 最近 3—7 天：

- 是否连续看同一类资料页 / 文物 / 原文；
- 是否连续出现相似死亡、古埃及、咒语等体验；
- 当前真正瓶颈是流量、精准涨粉、服务认知、询盘还是成交；
- 候选题是否解决当天瓶颈，而不是只因为“这个题有意思”。

---

## 五、最终定题门槛

只有下面全部为“是”，才允许写“最终选题”：

- [ ] 最新 Slack 三个核心频道已按工作流读取；
- [ ] 当前瓶颈已经判断；
- [ ] 栏目价值中心路由正确；
- [ ] 五个对标账号方法已逐项检查；
- [ ] 100 分模型已检查；
- [ ] 最近 7 天内容体验重复度已检查；
- [ ] 核心答案能够被可靠资料正面支持；
- [ ] 商业密度与当天任务一致；
- [ ] 制作素材可以真实取得，不依赖 AI 假文物 / 假历史实景。

只要有一项未完成：

> **候选题不得升级为最终题。**

---

## 六、Slack 与对话输出规则

当天写入 `#商业决策总控` 的正式总表中，抖音大号题目下方必须增加一行：

`选题硬门槛：已完成｜栏目路由 + 五对标 + 100分模型 + 近7天重复度 + 证据可答性`

如果没有完成，只能写：

`候选题：待完成选题硬门槛，不进入执行`

ChatGPT 对 Suen 说“最终确定 / 今天就做这个”以前，也必须先完成同一门槛。
