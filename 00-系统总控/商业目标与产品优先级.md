## 当前商业主线

下面的顺序与当前短期承接优先级一致；它描述“先承接什么”，不代表每天都要销售。

### 1. 塔罗 / 咨询

较轻的首次付费入口与日常现金流。

### 2. 定制仪式

核心高利润服务。依赖真实需求、执行能力与适合的时间窗口。

多数需要择时的仪式服从 `05-天象经营/天象预约池规则.md`；没有确认日期时，不为了成交虚构具体窗口或“最佳日期”。

### 3. 星符 / 特定古典魔法项目

预约型高价值项目，依赖经过确认的合适天象。

具体窗口、预约与宣传边界统一服从 `05-天象经营/天象预约池规则.md`，不能把星符当成 365 天随时执行的普通现货。

### 4. 蜂蜜罐 / 魔碗 / 护符等实物

承担视觉获客、内容素材与辅助收入。

### 5. 原典核查 / 专题研究

专业小众服务。材料成本低，以资料检索、原典定位、研究能力与可追溯结果作为价值。

### 6. 课程 + Suen Akhet 数据库

当前已经从“纯长期设想”进入**正式产品化阶段**：

- 《古埃及魔法实践》课程仍在继续完善；
- 数据库以 Obsidian 为内容载体；
- 对外方向为 Obsidian Publish；
- 需要正式数据库首页；
- **数据库必须作为可独立购买的正式产品存在，不作为课程附赠品降级处理；**
- 同时支持课程 + 数据库组合购买，但组合的作用是提高客单价与转化，不是替代数据库单卖；
- 数据库售卖模式仍需继续比较“一次性买断 / 订阅制 / 买断+更新期 / 其他组合方式”。

当前阶段优先完成：

1. 课程内容补全；
2. 数据库结构与首页；
3. 课程和数据库内容边界；
4. 数据库独立产品结构与售卖模式；
5. 课程 + 数据库组合购买机制；
6. 之后再定价格、访问周期、续费规则和正式发售节奏。

## 产品角色 ≠ 今日可售状态

上面的“商业角色”是长期产品定位，不代表今天自动可以公开销售。

如果当天要把某个产品 / 服务设成商业信号，商业总控还必须从 Suen 最新明确指令或 GitHub `08-动态运行/商业/当前商业状态.md` 确认至少这些动态事实：

- 当前是否真实可售 / 可预约；
- 实际价格是否已确认；
- 当前交付方式；
- 是否存在容量 / 排期限制；
- 是否依赖天象窗口；
- 是否允许当天公开宣传；
- 如果状态刚发生变化，是否已有最新记录覆盖旧状态。

不知道就标记“不确定 / 待确认”，不得从旧内容、旧报价或历史聊天自动推断今天仍然有效。

## 使用方式

商业总控不机械按上述顺序天天销售。

每天根据：

- 真实流量；
- 当前瓶颈；
- 咨询内容；
- 成交断点；
- 当天可售时间窗口；
- 产品是否已经准备好；
- 用户实际工作量

决定唯一主要商业信号。

一个产品“长期价值高”不等于“今天必须推”。


### 目标客户商业质量观察

当前不建立“年龄 / 城市 / 职业 / 刚毕业女生”等固定人口统计画像。商业判断优先观察真实购买行为：

- 可支配支付能力与实际成交金额；
- 现实需求强度；
- 对 Suen 的信任程度与购买方式；
- 是否重视专业判断、定制、原典依据、材料、择时和执行质量，而不只比较最低价格；
- 是否能够理解神秘学服务不做百分百现实结果保证；
- 是否存在复购或转介绍可能。

长期希望逐步吸引有稳定可支配收入、存在明确现实需求、愿意为专业服务支付数百元至千元以上的人。低价产品仍可承担首次成交、现金流和老客加购，但不把“只能几十元至一两百元消费、主要依赖最低价格决定”的人群设为品牌唯一核心商业人群。

这一层只作为目标客户的商业质量观察，不新增复杂评分，也不把当前少量样本写成已经验证完成的客户画像。

如果后续出现新的明确商业策略，Suen 最新明确指令覆盖本文件中的旧优先级。


### 高客单目标客户画像 v1｜2026-09-25

当前“高客单”不按年龄、城市、职业等人口标签定义，优先按**购买状态与行为**判断。

最希望逐步吸引的是：
- 有一个真实、明确、对本人重要的现实目标，而不是只对神秘学本身好奇；
- 已经有神秘学 / 咨询 / 护符 / 星符 / 仪式等消费经验，或至少能够理解专业服务为什么存在成本；
- 愿意把具体情况说明白，并根据适配度、方案、材料、原典、择时和执行质量做购买判断；
- 不只比较最低价格；
- 会认真问效果、时间、案例与风险，但在得到真实说明以后，能够理解现实结果不能百分百保证；
- 愿意为“针对自己的目标进行专业判断 + 定制执行”支付数百元至千元以上；
- 有复购、继续购买其它项目或转介绍的可能。

当前优先验证的一类客户：
**已经接触过神秘学消费 + 现在有明确现实问题 + 正在比较下一步解决方式的人。**

这一画像是当前验证假设，不写成已经跑通的稳定客群。后续只用真实询盘、报价、成交、复购与转介绍继续修正。

### 高客单价值主张

定制仪式的客户购买目标仍然是：**希望推动一个目前自己难以推进的现实结果。**

高客单不能只建立在“专业判断”本身，也不能建立在无法证明的“百分百有效 / 固定天数见效”上。

当前希望逐步形成的价值组合是：
**目标结果 + 专业判断 + 定制方案 + 原典 / 材料 / 择时 / 执行质量 + 真实案例证明。**

其中：
- “目标结果”解释客户为什么愿意买；
- “专业判断与定制执行”解释为什么值得找 Suen、为什么不是统一商品；
- “真实案例与复购 / 转介绍”逐步提供结果可信度；
- 不把客户反馈自动写成仪式与现实结果之间已经被证明的因果关系。

### 当前短期商业入口顺序（2026-09-20）

Suen 已确认当前短期商业承接不做“大而全服务菜单”，而是保持清晰入口：

- 第一入口：塔罗 / 判断类咨询；
- 核心高利润：定制仪式；
- 预约型高价值：星符与特定古典魔法项目；
- 辅助收入：蜂蜜罐、魔碗、护符等实物；
- 专业小众服务：原典核查 / 专题研究；
- 中期数字资产：课程 + Suen Akhet Database；
- 订阅资产：Patreon。

对外服务说明页的目标是让陌生人知道“现在可以找 Suen 做什么”，而不是陈列全部商品。课程、数据库在正式可售前不进入当前服务页主区；价格、天象窗口和预约状态仍以当下真实状态为准。
