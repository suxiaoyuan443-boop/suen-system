## 当前目标周期

2026-09-11 — 2026-10-10

核心目标：

- 有效询盘 ≥ 25
- 成交 ≥ 10
- 月净利润 ≥ ¥4000

**目前没有另行确认的“14 天有效询盘 5—8 个”正式目标。不要自行把 30 天目标换算成新的短周期 KPI。**

### 当前周期优先追踪什么

商业结果优先看：

1. **有效询盘数**；
2. **询盘来源**：平台 / 转介绍 / 老客户等；
3. **询盘对应内容**：能可靠确认时，记录具体哪条内容带来；
4. **报价**：是否报价、实际报价金额；
5. **成交率**：基于真实询盘 / 成交记录计算，不用点赞或私信数替代；
6. **成交金额**；
7. **预计毛利 / 净利润贡献**：成本足够明确时记录；
8. **复购**；
9. **转介绍**。

播放量、阅读、点赞、收藏、分享、涨粉属于重要的**内容诊断指标**，但不能代替真实商业结果。

同样，不能为了强调商业结果就忽略内容前端数据：总控需要用播放 / 阅读 / 留存 / 收藏 / 涨粉判断问题到底卡在流量、精准涨粉、服务认知、询盘还是成交。

### 利润口径提醒

当前目标使用的是“净利润”。

因此：

- `预计毛利` 不能直接当成 `净利润`；
- 成本覆盖不完整时，只报告已知成交额、预计毛利 / 已知利润贡献；
- 不为了显示目标进度估算未知平台费、退款、材料费或其它成本。

完整口径见 `商业指标口径.md`。

## 当前商业主线

### 1. 塔罗 / 咨询

较轻的首次付费入口与日常现金流。

### 2. 星符

高毛利、预约制、依赖经过确认的合适天象。

具体窗口、预约与宣传边界统一服从 `05-天象经营/天象预约池规则.md`，不能把星符当成 365 天随时执行的普通现货。

### 3. 定制仪式

高毛利、预约制，依赖真实需求、执行能力与适合的时间窗口。

多数需要择时的仪式同样服从 `05-天象经营/天象预约池规则.md`；没有确认日期时，不为了成交虚构具体窗口或“最佳日期”。

### 4. 原典核查 / 专题研究

高毛利、材料成本低，以资料检索、原典定位、研究能力与可追溯结果作为价值。

### 5. 蜂蜜罐 / 魔碗 / 护符等实物

承担视觉获客、内容素材与补充收入。

### 6. 课程 + Suen Akhet 数据库

当前已经从“纯长期设想”进入**正式产品化阶段**：

- 《古埃及魔法实践》课程仍在继续完善；
- 数据库以 Obsidian 为内容载体；
- 对外方向为 Obsidian Publish；
- 需要正式数据库首页；
- **数据库必须作为可独立购买的正式产品存在，不作为课程附赠品降级处理；**
- 同时支持课程 + 数据库组合购买，但组合的作用是提高客单价与转化，不是替代数据库单卖；
- 数据库售卖模式仍需继续比较“一次性买断 / 订阅制 / 买断+更新期 / 其他组合方式”。

当前阶段优先完成：

1. 课程内容补全；
2. 数据库结构与首页；
3. 课程和数据库内容边界；
4. 数据库独立产品结构与售卖模式；
5. 课程 + 数据库组合购买机制；
6. 之后再定价格、访问周期、续费规则和正式发售节奏。

Suen 当前判断：

### 数据库当前真实进度（2026-09-20）

Suen 当前判断：

- 数据库距离可正式作为 v1 售卖，预计还需要约 3 个月；
- 当前旧内容存在较明显的文笔与结构问题，正在大规模重写；
- 现阶段真正完成度较高、可作为正式样板的内容约 1—2 个；
- 因此数据库当前应视为“重构 / 产品化中”，不是“接近发售”；
- 在样板结构未稳定前，不用条目数量制造虚假的完成感；
- 先做少量高完成度样板，再统一模板、证据结构、导航和写法，之后再批量扩展。

**产品化优先级已经上升，但在数据库仍处于大规模重写阶段、课程尚未完成、售卖模式未定案前，不强行把课程/数据库设成当前周期主要现金收入来源。**

## 产品角色 ≠ 今日可售状态

上面的“商业角色”是长期产品定位，不代表今天自动可以公开销售。

如果当天要把某个产品 / 服务设成商业信号，商业总控还必须从 Suen 最新明确指令或 GitHub `08-动态运行/商业/当前商业状态.md` 确认至少这些动态事实：

- 当前是否真实可售 / 可预约；
- 实际价格是否已确认；
- 当前交付方式；
- 是否存在容量 / 排期限制；
- 是否依赖天象窗口；
- 是否允许当天公开宣传；
- 如果状态刚发生变化，是否已有最新记录覆盖旧状态。

不知道就标记“不确定 / 待确认”，不得从旧内容、旧报价或历史聊天自动推断今天仍然有效。

## 使用方式

商业总控不机械按上述顺序天天销售。

每天根据：

- 真实流量；
- 当前瓶颈；
- 咨询内容；
- 成交断点；
- 当天可售时间窗口；
- 产品是否已经准备好；
- 用户实际工作量

决定唯一主要商业信号。

一个产品“长期价值高”不等于“今天必须推”。

如果后续出现新的明确商业策略，Suen 最新明确指令覆盖本文件中的旧优先级。


### 当前短期商业入口顺序（2026-09-20）

Suen 已确认当前短期商业承接不做“大而全服务菜单”，而是保持清晰入口：

- 第一入口：塔罗 / 判断类咨询；
- 核心高利润：定制仪式；
- 预约型高价值：星符与特定古典魔法项目；
- 辅助收入：蜂蜜罐、魔碗、护符等实物；
- 专业小众服务：原典核查 / 专题研究；
- 中期数字资产：课程 + Suen Akhet Database；
- 订阅资产：Patreon。

对外服务说明页的目标是让陌生人知道“现在可以找 Suen 做什么”，而不是陈列全部商品。课程、数据库在正式可售前不进入当前服务页主区；价格、天象窗口和预约状态仍以当下真实状态为准。
