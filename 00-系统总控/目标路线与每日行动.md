# Suen｜目标路线与每日行动
状态：执行版｜2026-10-25落实收入优先、课程状态与条件排程
职责：阶段、当天动作及验收物；不自行改价格、KPI或交易条件。

## 一、方向
研究品牌、现有服务、一个有限课程单元与长期数据库共同推进。内容能否获客靠来源和付款记录，不预定某类视频必然能或不能获客。
知识产品能否重复售出依真实购买与支持负担验证；附件中的人数/年费算式、3—5人付款等不作为已批准价格或KPI。

## 二、阶段
单元主题已明确为古埃及生者护符。10/27核已有讲稿、完整范围和缺项；10/31检查一页范围、可试讲示范及资料/图片/交付缺项。不再重复选题，不把上传或样张当验收完成。
12/15复盘单元，12/25保留原阶段验收。2027的课程扩展、订阅及中英文市场仍待验证，不自动上线。

## 三、标准日
先保已付履约、约定客户动作及真实付费交付；近期把匹配的远程机会核实、岗位回复与对应材料排在内容制作前，课程日保留集中工作。
每周可投入保底约24小时是容量，不代表已有项目；未接项目时只做必要检索和材料调整，不强行刷满。求职、交付、内容、课程和沟通不重复计时。按每天约8小时、每周6天以内安排，周日休息；超出产能先减并行任务。

## 四、每周节奏
**工作尚未占用原排期：**每周4条原创视频、1篇独立公众号深文、2天集中课程、1天休息。先排必要求职动作，公众号与视频同天发布。

| 星期 | 主要安排 |
|---|---|
| 周一 | 先核付费机会、准备匹配材料，再做视频1 |
| 周二 | 课程；本周10/27核已有稿件、范围与缺项 |
| 周三 | 处理岗位回复/材料，再做视频2及公众号资料 |
| 周四 | 课程；本周10/29备齐试讲示范与配图 |
| 周五 | 先处理真实付费任务或匹配机会，再做视频3、公众号成稿 |
| 周六 | 视频4＋公众号；本周10/31核课程成果与真实业务进展 |
| 周日 | 休息，不排常规生产或补发 |

**已确认的付费工作接近24小时/周：**视频先按每周2条，现成合格成片且工时允许才加第3条；课程留1个集中日；公众号每两周1篇，与视频同天；周日休息。参考预算：付费工作24小时、视频8—10小时、课程4—6小时、公众号周均1—2小时、客户与机动4—6小时，合计不超过48小时。预算不当实测制作时长，超出就减并行量。
不足24小时但已发生交付冲突，也按真实工作当周重排；普通咨询、口头意向和求职准备不自动触发整周减量。
同一成片跨平台算1条；公众号独立原典问题，保留去重和课程区隔。候选3个、选1后写口播、采用后做素材，同题最多2轮。提前排核验、写稿与素材，不凑数、不累积补发债。
10/31节点保留；需补课过多先报告再调整日期。

## 六、保底工作现在做
容量约24小时/周，按真实项目安排，不默认随时在线。接受远程项目/兼职、按交付计费的内容运营、资料研究、文案、脚本及核查；不接受线下坐班或长期实时接待。
备选：事实核查、历史文化稿/脚本、作者/游戏/跑团资料包、已有素材整理。核原始需求、仍否招聘、工作形式、交付结算及试稿条件；排除纯分成、长期免费试工和无期限在线。
有匹配对象才改材料，暂停通用作品集美化。助手只查找和准备，投递/联系由Suen决定并操作。已有服务照常按适配承接；未知岗位、高客单或课程不预填收入。
