# Suen｜择时系统分流规则

状态：当前正式规则
建立：2026-09-20

## 核心原则

不同传统使用各自的择时体系，不再把一套标准强行套到所有仪式。

优先级：

**具体原典 recipe / 体系自己的明确时间要求 > 同一体系内部通用择时规则 > Suen 后期附加择时。**

除非 Suen 明确要求做“额外比较”，不得把另一套体系的规则反向覆盖原典。

## A｜PGM / PDM / 希腊—埃及语境 recipe

适用：
- PGM
- PDM
- 同一希腊—埃及语境的具体 recipe

### 固定流程

1. 先锁定具体编号与行号；
2. 先读该 recipe 自己的时间要求；
3. 提取：
   - 埃及历日期 / 禁日；
   - 月相；
   - 月亮黄道位置；
   - 白天 / 夜晚；
   - 第几时辰；
   - 日出 / 日落 / 月出；
   - 是否连续多日；
   - 其它文本明确要求；
4. recipe 有明确时间要求时，优先服从该 recipe；
5. recipe 没写时间时，才考虑 PGM / PDM 内部可合理适用的通用择时材料。

### 可作为 PGM 内部辅助的材料

例如：
- PGM VII.272–283：不宜魔法操作的埃及历日期；
- PGM VII.284–299：月亮运行十二宫时的操作适配；
- PGM III.275–281：相近的月亮黄道操作表；
- 某一 tractate 自己明确要求的 day/hour gods、lord of day/hour 等。

### 重要边界

PGM 是文集，不是假定存在一套覆盖所有 recipe 的统一择时法。

因此：
- PGM XIII《Key of Moses》内部要求 day/hour gods，不自动外推到 PGM XII；
- 某一 recipe 的月相、时辰要求，不自动推广到其它 recipe；
- 同一文集中出现的通用表，只能作为“PGM内部辅助”，不能压过具体 recipe 的明确要求。

### 默认不再套用

除非 Suen 明确要求做第二层比较，PGM / PDM 默认不使用：
- Bonatti 月亮17项；
- Suen Moon Hard Filter；
- “月亮天蝎 / 摩羯一律淘汰”；
- Via Combusta 一律淘汰；
- 默认行星日 + 行星时；
- 默认目标行星强弱；
- 现代古典占星的灼烧 / 接纳 / VOC 硬筛。

如果 PGM / PDM 原典自己出现相关天文要求，则按原典处理。

### 输出

默认输出：
- 原典编号 / 行号；
- 原典时间要求；
- PGM内部辅助择时；
- 可用日期 / 时间；
- PGM原典适配：D / B / A / S。

不默认再输出“Suen附加天象质量”。

只有 Suen 明确说“再叠加古典占星看看”时，才单独增加第二层比较，而且必须标明：
**这是附加比较，不是PGM原典要求。**

## B｜星符 / 古典魔法召唤

适用：
- 所罗门星符；
- 行星星符；
- Ars Paulina；
- 水晶显灵；
- 古典行星召唤；
- 其它明确依赖古典行星择时的 ceremonial / grimoire 操作。

### 默认择时体系

使用古典魔法 / 古典占星择时规则。

包括按对应体系核查：
- 行星日；
- 行星时；
- 目标行星是否逆行；
- 目标行星是否灼烧；
- 目标行星尊贵 / 失势与宫位状态；
- 月亮是否 VOC；
- 月亮是否灼烧；
- 月亮与火星 / 土星的凶相；
- 月亮与目标行星的关系；
- 应用 / 分离；
- 下一应用相位；
- 其它对应 grimoire / 星符文本的特殊要求。

具体项目仍以对应专用择时系统的正式技术规则为准。

## C｜发生冲突时

例如：

PGM VII：
月亮在摩羯可“say whatever you wish for best results”。

Suen 古典占星 Hard Filter：
月亮摩羯淘汰。

处理：

- 如果任务是 PGM recipe → 按 PGM 标准，不用 Hard Filter 淘汰；
- 如果任务是星符 / 古典魔法召唤 → 按古典魔法择时规则；
- 如果 Suen 明确要求两套都看 → 分成两层分别报告，不混成一个结论。

## D｜禁止

- 不得因为“招财”就自动改成木星日 / 木星时；
- 不得因为材料出现 Typhon / Set 就自动改成火星时；
- 不得把后世 planetary magic 对应关系伪装成 PGM 原典要求；
- 不得把 PGM XIII 的内部 day/hour 系统说成所有 PGM recipe 的统一规定；
- 不得为了得到“更漂亮的日期”降低对应传统自己的原典要求。

## 一句话执行

**PGM / PDM 用 PGM / PDM 自己的时间体系；星符和古典魔法召唤用古典魔法择时体系。**
